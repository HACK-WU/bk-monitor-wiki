## 容器运行时版本兼容（docker）

`ExtractDockerApiVersion` 处理 docker「客户端 API 版本过高被拒绝」的场景（见《06》`NewRuntime` 自动降级）：

- 常量 `DockerVersionApiError = "Maximum supported API version is"` 与正则 `DockerVersionErrorPattern = "Maximum supported API version is (\d+\.\d+)"`；
- 对 `error` 文本做正则捕获，命中返回 `(true, "x.y")` 最大支持版本，否则 `(false, "")`。

```go
func ExtractDockerApiVersion(errParam error) (bool, string) {
	re, _ := regexp.Compile(DockerVersionErrorPattern)
	result := re.FindAllStringSubmatch(errParam.Error(), -1)
	if len(result) > 0 && len(result[0]) > 1 {
		return true, result[0][1]
	}
	return false, ""
}
```

## vcluster 与 Pod 元数据解析（k8s）

多集群场景下 bk-log-sidecar 需识别由 vcluster 虚拟出的 Pod。`k8s.go` 提供两层能力：

**识别与字段回退**
- `IsNetworkPod(name)`：`name == "POD" || name == ""` 视为 pause/网络 Pod，跳过日志采集；
- `IsVclusterPod(pod)`：Pod labels 中存在 `config.VclusterLabelKey`（`vcluster.loft.sh/managed-by`）即判定为 vcluster Pod；
- `GetPodName/GetPodUid/GetPodNamespace`：vcluster Pod 优先从注解取（环境变量可覆盖的注解键），否则用原生字段；
- `GetPodWorkloadName/GetPodWorkloadType`：vcluster Pod 从注解取 owner 信息；原生 Pod 遍历 `OwnerReferences` 取 `Name`/`Kind`；
- `GetWorkloadName(name, kind)`：`kind` 为 `ReplicaSet`（大小写不敏感）时，按最后一个 `-` 截断得到 Deployment 名——与《04》`matchWorkloadType` 的 ReplicaSet→Deployment 特例呼应。

**标签/注解还原**
- `GetLabels`：vcluster Pod 的标签存储在注解 `vcluster.loft.sh/labels`（格式 `key="value"\nkey="value"`，value 为 JSON 字符串），逐行解析并 `json.Unmarshal` 还原；
- `GetAnnotations`：vcluster Pod 的注解键列在 `vcluster.loft.sh/managed-annotations`（`\n` 分隔），据此从全部注解中筛出。

```go
func IsVclusterPod(pod *corev1.Pod) bool {
	_, exists := pod.GetLabels()[config.VclusterLabelKey]
	return exists
}

func GetWorkloadName(name string, kind string) string {
	if ToLowerEq(kind, "ReplicaSet") {
		index := strings.LastIndex(name, "-")
		return name[:index]
	}
	return name
}
```

## 构建与镜像

**Makefile 关键目标**
- `build`：`go build -o bin/manager main.go`（生成 `bin/manager`）；
- `run`：`go run ./main.go`；
- `test`：`manifests generate fmt vet envtest` 后 `go test ./... -coverprofile cover.out`；
- `manifests`/`generate`：依赖 `controller-gen@v0.6.1` 生成 CRD 与 DeepCopy 代码；
- `docker-build`/`docker-push`：打镜像与推送；
- 工具链版本：`controller-gen v0.6.1`、`kustomize v3.8.7`、`envtest 1.21`。

**Dockerfile（多阶段）**
- builder：`golang:1.25`，`go mod download` 缓存依赖后 `COPY` 源码与 `api/controllers/define/utils/config`；
- 编译：`CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -a -o bk-log-sidecar main.go`；
- 运行镜像：`gcr.io/distroless/static:nonroot`，`USER 65532:65532`，`ENTRYPOINT ["/bk-log-sidecar"]`（静态二进制 + 非 root，最小攻击面）。

```dockerfile
FROM golang:1.25 as builder
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -a -o bk-log-sidecar main.go
FROM gcr.io/distroless/static:nonroot
COPY --from=builder /workspace/bk-log-sidecar .
USER 65532:65532
ENTRYPOINT ["/bk-log-sidecar"]
```
