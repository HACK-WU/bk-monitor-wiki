## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/proxy` |
| Handler | `proxy.HandleProxy` |
| 鉴权 | `MetaData` + `JwtAuth`（公共分组） |
| 用途 | 将请求透传到后端存储/网关，并统一封装为 `apiGwResponse`（含 `unify_response_process` 透传支持） |

代理接口路径由配置驱动（默认 `/proxy`）。当请求上下文携带 `unify_response_process` 标记时，响应数据经 `ContextKeyResponseData` 透传，由网关层统一包装；否则直接返回 `apiGwResponse`（`result`/`data`/`message`）。失败返回 `apiGwResponse` 错误体（HTTP 400）。

## 请求字段说明

请求为透传体，由代理层转发到目标后端。结构 `apiGwRequest`：`proxy/proxy.go#L26-L29`。

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| path | string | 是 | 目标后端地址 / 路径，代理据此转发 |
| data | json.RawMessage | 是 | 透传的原始负载，按目标后端协议构造 |

## 返回字段说明

成功响应为 `apiGwResponse`（`proxy/proxy.go#L39-L44`），HTTP 200。

| 字段 | 类型 | 说明 |
|------|------|------|
| result | bool | 是否成功，`true` 表示成功 |
| data | any | 后端原始响应，随目标而定 |
| message | string | 提示信息：成功时为 `success`；失败时为错误描述 |

成功响应示例：

```json
{
  "result": true,
  "data": { "...后端原始响应...": "" },
  "message": "success"
}
```

失败响应（HTTP 400）：`result` 为 `false`，`data` 为 `null`，`message` 为错误描述。

> 代理转发的是具体存储/网关能力，请求/响应结构随目标而定，本文不固化字段；详见 `service/http/proxy/proxy.go`。

### 返回字段与请求字段的映射关系

本接口为**透传代理**，请求 `path`/`data` 原样转发到目标后端，响应 `apiGwResponse.data` 是后端原始返回，结构与目标后端协议绑定，**不存在固定的"请求字段 → 返回字段"映射关系**。请求方需按目标后端的数据格式解析 `data` 字段。
