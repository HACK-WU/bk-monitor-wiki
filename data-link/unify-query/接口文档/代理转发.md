## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/proxy` |
| Handler | `proxy.HandleProxy` |
| 鉴权 | `MetaData` + `JwtAuth`（公共分组） |
| 用途 | 将请求透传到后端存储/网关，并统一封装为 `apiGwResponse`（含 `unify_response_process` 透传支持） |

代理接口路径由配置驱动（默认 `/proxy`）。当请求上下文携带 `unify_response_process` 标记时，响应数据经 `ContextKeyResponseData` 透传，由网关层统一包装；否则直接返回 `apiGwResponse`（`code`/`data`/`message`/`trace_id` 等）。失败返回 `apiGwResponse` 错误体（HTTP 400）。

## 请求与响应说明

请求为透传体（按目标后端协议构造，通常含目标地址与原始负载），由代理层转发。

成功响应（`apiGwResponse`）：

```json
{
  "code": 0,
  "data": { "...后端原始响应...": "" },
  "message": "",
  "trace_id": "a9b0c1d2"
}
```

> 代理转发的是具体存储/网关能力，请求/响应结构随目标而定，本文不固化字段；详见 `service/http/proxy/proxy.go`。
