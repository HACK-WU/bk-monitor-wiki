## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/api/v1/relation/multi_resource_range` |
| Handler | `HandlerAPIRelationMultiResourceRange` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 在 `[start_time, end_time]` 区间内按 `step` 查询源到目标资源的关系变化（时序化关系） |

与 [关系多资源查询.md](关系多资源查询.md) 的区别在于请求携带 `start_time`/`end_time`/`step`，响应 `target_list` 带时间戳（`MatchersWithTimestamp`）。

- [service/http/api/register.go](file://bkmonitor-datalink/pkg/unify-query/service/http/api/register.go#L16-L19)

## 请求示例

```json
{
  "query_list": [
    {
      "start_time": 1657848000,
      "end_time": 1657851600,
      "step": "1m",
      "source_type": "HOST",
      "source_info": {"bk_target_ip": "10.0.0.1"},
      "target_type": "SET",
      "look_back_delta": "1h"
    }
  ]
}
```
