## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/api/v1/relation/multi_resource_range` |
| Handler | `HandlerAPIRelationMultiResourceRange` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 在 `[start_time, end_time]` 区间内按 `step` 查询源到目标资源的关系变化（时序化关系） |

与 [关系多资源查询.md](关系多资源查询.md) 的区别在于请求携带 `start_time`/`end_time`/`step`，响应 `target_list` 带时间戳（`MatchersWithTimestamp`）。

## 请求字段说明

请求体为 `RelationMultiResourceRangeRequest`（`cmdb/struct.go#L78-L94`），外层仅一个 `query_list` 数组；与[关系多资源查询](关系多资源查询.md)相比，数组项以 `start_time`/`end_time`/`step` 取代单点 `timestamp`，字段如下：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| query_list | array | 是 | 查询项列表 |
| query_list[].start_time | int64 | 是 | 区间开始时刻（Unix 秒） |
| query_list[].end_time | int64 | 是 | 区间结束时刻（Unix 秒） |
| query_list[].step | string | 是 | 采样步长，如 `"1m"`、`"5m"` |
| query_list[].source_type | string(Resource) | 是 | 源资源类型，CMDB 资源类型标识，如 `HOST`、`SET`、`MODULE`、`BIZ`、`SERVICE` 等 |
| query_list[].source_info | object(Matcher) | 是 | 源资源维度键值对 |
| query_list[].source_expand_info | object(Matcher) | 否 | 源资源扩展维度键值对 |
| query_list[].target_type | string(Resource) | 是 | 目标资源类型，取值同 `source_type` |
| query_list[].target_info_show | bool | 否 | 是否返回目标资源的详细信息 |
| query_list[].path_resource | array(Resource) | 否 | 期望经过的资源类型路径 |
| query_list[].look_back_delta | string | 否 | 关系回溯时间窗，如 `"1h"` |

> `Matcher` 即 `map[string]string`；`Resource` 即 `string`（CMDB 资源类型标识），以实际 CMDB 模型为准。

## 返回字段说明

响应为 `RelationMultiResourceRangeResponse`（`cmdb/struct.go#L110-L113`），外层 `trace_id` + `data` 数组；单项 `RelationMultiResourceRangeResponseData`（`cmdb/struct.go#L97-L107`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| trace_id | string | 请求追踪 ID |
| data | array | 与请求 `query_list` 一一对应的结果列表 |
| data[].code | int | 该项处理结果码，`0` 表示成功 |
| data[].source_type | string(Resource) | 回显源资源类型 |
| data[].source_info | object(Matcher) | 回显源资源维度 |
| data[].target_type | string(Resource) | 回显目标资源类型 |
| data[].target_list | array(MatchersWithTimestamp) | 区间内按 `step` 采样的目标资源列表，每项含 `timestamp`（采样时刻）与 `items`（维度键值对数组） |
| data[].path | array(string) | 源到目标实际经过的资源类型路径 |
| data[].message | string | 该项处理消息，失败时为错误描述 |

### 返回字段与请求字段的映射关系

返回为 `RelationMultiResourceRangeResponse`，与 [关系多资源查询接口](关系多资源查询.md#返回字段与请求字段的映射关系) 一致：`data` 数组与请求 `query_list` 一一对应。差异在于本接口的 `target_list` 为 `MatchersWithTimestamp`，按请求的 `start_time`/`end_time`/`step` 在区间内采样：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `data[].source_type` / `source_info` / `target_type` | 回显请求 `query_list[]` 对应字段 |
| `data[].target_list[].timestamp` | 区间内的采样时刻，由请求 `step` 推进（起止由 `start_time`/`end_time`） |
| `data[].target_list[].items` | 该采样时刻匹配到的目标资源维度键值对，由 `source_info` 经 CMDB 关系查出 |
| `data[].path` | 实际经过的资源类型路径，受 `path_resource` 约束 |
