## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/api/v1/relation/multi_resource` |
| Handler | `HandlerAPIRelationMultiResource` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 由源资源瞬时查询其与目标资源的拓扑/关系（多资源批量） |

路径由配置驱动（默认 `/api/v1/relation/multi_resource`）。背景与设计见 [关系查询.md](关系查询.md)。

## 请求字段说明

请求体为 `RelationMultiResourceRequest`：`cmdb/struct.go#L42-L56`，外层仅一个 `query_list` 数组，数组项字段如下：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| query_list | array | 是 | 查询项列表 |
| query_list[].timestamp | int64 | 是 | 查询时刻（Unix 秒） |
| query_list[].source_type | string(Resource) | 是 | 源资源类型，CMDB 资源类型标识，如 `HOST`、`SET`、`MODULE`、`BIZ`、`SERVICE` 等 |
| query_list[].source_info | object(Matcher) | 是 | 源资源维度键值对，如 `{"bk_target_ip":"10.0.0.1","bk_target_cloud_id":"0"}` |
| query_list[].source_expand_info | object(Matcher) | 否 | 源资源扩展维度键值对 |
| query_list[].target_type | string(Resource) | 是 | 目标资源类型，取值同 `source_type` |
| query_list[].target_info_show | bool | 否 | 是否返回目标资源的详细信息 |
| query_list[].path_resource | array(Resource) | 否 | 期望经过的资源类型路径，如 `["MODULE","SET"]`；为空则不限定路径 |
| query_list[].look_back_delta | string | 否 | 关系回溯时间窗，如 `"1h"`，用于在 timestamp 附近放宽匹配 |

> `Matcher` 即 `map[string]string`（维度键值对）；`Resource` 即 `string`（CMDB 资源类型标识），无代码层枚举约束，以实际 CMDB 模型为准。

## 返回字段说明

响应为 `RelationMultiResourceResponse`（`cmdb/struct.go#L72-L75`），外层 `trace_id` + `data` 数组；单项 `RelationMultiResourceResponseData`（`cmdb/struct.go#L59-L69`）：

| 字段 | 类型 | 说明 |
|------|------|------|
| trace_id | string | 请求追踪 ID |
| data | array | 与请求 `query_list` 一一对应的结果列表 |
| data[].code | int | 该项处理结果码，`0` 表示成功 |
| data[].source_type | string(Resource) | 回显源资源类型 |
| data[].source_info | object(Matcher) | 回显源资源维度 |
| data[].target_type | string(Resource) | 回显目标资源类型 |
| data[].target_list | array(Matchers) | 匹配到的目标资源列表，每项为维度键值对 |
| data[].path | array(string) | 源到目标实际经过的资源类型路径，如 `["HOST","MODULE","SET"]` |
| data[].message | string | 该项处理消息，失败时为错误描述 |

### 返回字段与请求字段的映射关系

返回为 `RelationMultiResourceResponse`，`data` 数组与请求 `query_list` **一一对应**，是"由源查目标"的拓扑展开：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `data[].source_type` / `source_info` | 回显请求 `query_list[].source_type` / `source_info` |
| `data[].target_type` | 回显请求 `query_list[].target_type` |
| `data[].target_list` | 由请求 `source_info` 经 CMDB 关系查出的目标资源列表（受 `target_type`/`path_resource` 约束）；每项为维度键值对 |
| `data[].path` | 源到目标实际经过的资源类型路径，受请求 `path_resource` 约束（为空则不限定） |
| `data[].code` / `message` | 该项处理状态与消息 |

> 即请求描述"从哪个源资源找哪类目标"，返回给出"实际匹配到的目标资源及其路径"。
