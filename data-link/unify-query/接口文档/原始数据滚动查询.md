## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/raw_with_scroll` |
| Handler | `HandlerQueryRawWithScroll` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 在 `/query/ts/raw` 基础上启用 Scroll 游标翻页，适合超大数据量明细导出 |

请求体复用 `QueryTs`（`scroll`/`slice_max` 控制滚动）。响应为 `ListData`，通过持续翻页直到 `done=true`；失败 `ErrResponse`（HTTP 400）。

## 请求字段说明

请求体复用 `QueryTs`（与 [结构体查询接口](结构体查询.md#请求字段说明) 一致）。本接口在原始数据查询基础上使用 `scroll`/`slice_max` 控制滚动：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `space_uid` | string | 否 | 空间 UID；可由 `X-Bk-Scope-Space-Uid` 头注入覆盖 |
| `query_list` | array[Query] | 否 | 子查询列表 |
| `start_time` / `end_time` | string | 否 | 起止时间（秒级时间戳） |
| `step` | string | 否 | 步长，如 `"1m"` |
| `scroll` | string | 否 | 滚动游标超时时间，如 `"1m"`（未传使用默认值） |
| `slice_max` | int | 否 | 最大切片数量（未传使用默认值） |
| `limit` | int | 否 | 单批点数上限（未传使用默认值） |
| `clear_cache` | bool | 否 | 是否强制清理已存在的缓存会话（从头重新查询） |

子查询项 `Query`、过滤条件、聚合方法、可枚举 `data_source` 的完整定义见 [结构体查询接口](结构体查询.md#请求字段说明)。

## 返回字段说明

成功响应为 `ListData`（`service/http/response.go#L60-L70`），HTTP 200、直接返回数据对象。字段与 [原始数据查询接口](原始数据查询.md#返回字段说明) 一致：

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | int64 | 数据总数 |
| `list` | array[object] | 原始数据点列表（每行一个 map） |
| `done` | bool | 是否查询完成；持续翻页直到 `done=true` |
| `trace_id` | string | 链路 ID |
| `status` | object | 状态信息 |
| `result_table_id` | array[string] | 结果表 ID 列表（始终返回，无路由时为空数组） |
| `result_table_options` | object | 结果表选项（可选，`omitempty`） |

失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为 `ListData`，字段映射同 [原始数据查询接口](原始数据查询.md#返回字段与请求字段的映射关系)：`list[]` 为扁平原始数据点，维度作为每行 map 的字段（由 `query_list[].dimensions` 决定）；`total` 为总点数。本接口差异：`scroll`/`slice_max`/`limit` 控制滚动批次大小，`done` 表示 scroll 是否到达末尾（持续翻页直到 `done=true`）。
