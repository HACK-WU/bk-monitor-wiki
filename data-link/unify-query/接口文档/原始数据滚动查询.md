## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/raw_with_scroll` |
| Handler | `HandlerQueryRawWithScroll` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 在 `/query/ts/raw` 基础上启用 Scroll 游标翻页，适合超大数据量明细导出 |

请求体复用 `QueryTs`（`scroll`/`slice_max` 控制滚动）。响应为 `ListData`，通过持续翻页直到 `done=true`；失败 `ErrResponse`（HTTP 400）。

## 请求示例

```json
{
  "space_uid": "bkcc__2",
  "query_list": [
    {
      "reference_name": "a",
      "table_id": "system.cpu_summary",
      "field_name": "usage"
    }
  ],
  "start_time": "1657848000",
  "end_time": "1657851600",
  "step": "1m",
  "scroll": "1m",
  "slice_max": 500
}
```
