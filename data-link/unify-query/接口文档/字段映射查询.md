## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/info/field_map` |
| Handler | `HandlerFieldMap` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 返回指标名到字段/标签的映射关系，便于前端展示字段的可选维度 |

请求体为 `Params`。响应直接返回数据对象（HTTP 200，结构为 `DataResponse{data, trace_id}`）；失败 `ErrResponse`（HTTP 400）。

## 请求字段说明

请求体为 `Params`（`infos.go#L30-L51`），用于声明要查询字段映射的指标与时间范围：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| tsdb_map | map[string]TsDBs | 否 | 查询路由匹配中的 tsDB 列表，key 为 `reference_name` |
| data_source | string | 是 | 数据源类型，可枚举：`bk_monitor`、`bkmonitor`、`custom`、`bkdata`、`bklog`、`bkapm`（详见[结构体查询-请求字段说明](结构体查询.md#请求字段说明)） |
| table_id | string(TableID) | 否 | 结果表 ID，如 `system.cpu_summary` |
| metric_name | string | 是 | 指标名，如 `usage` |
| is_regexp | bool | 否 | 指标名是否按正则匹配，默认 `false` |
| conditions | object(Conditions) | 否 | 维度过滤条件，含 `field`/`op`/`value`，`op` 可枚举见[结构体查询-请求字段说明](结构体查询.md#请求字段说明) |
| table_id_conditions | object(AllConditions) | 否 | 表标签条件，未指定 `table_id`/`data_label` 全空间扫表时按结果表 Labels 收窄候选 RT |
| keys | array(string) | 否 | 指定需返回的字段 / 标签键 |
| limit | int | 否 | 限制返回条数 |
| slimit | int | 否 | 限制返回序列数 |
| start_time | string | 是 | 开始时间（Unix 秒字符串），如 `"1657848000"` |
| end_time | string | 是 | 结束时间（Unix 秒字符串） |
| timezone | string | 否 | 时区，如 `Asia/Shanghai` |

## 返回字段说明

响应为 `DataResponse`（`response.go#L91-L94`），HTTP 200，直接返回数据对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| data | object | 指标名到字段映射的字典：`{ "<指标名>": { "field_type": "<字段类型>", "tag_keys": ["<标签键>", ...] } }` |
| data.<指标名>.field_type | string | 该指标字段的数据类型，如 `double` |
| data.<指标名>.tag_keys | array(string) | 该指标可用的标签（维度）键列表 |
| trace_id | string | 请求追踪 ID |

### 返回字段与请求字段的映射关系

返回为 `DataResponse`，其 `data` 由请求指定的指标直接驱动：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `data` 的键（指标名） | 来自请求 `metric_name`（若 `is_regexp=true` 则为匹配到的多个指标名） |
| `data.<指标>.field_type` | 该指标字段的数据类型，由 `data_source`/`table_id`/`metric_name` 定位的指标元数据决定 |
| `data.<指标>.tag_keys` | 该指标可用的标签（维度）键列表，来自指标元数据；若请求指定 `keys` 则仅返回其中的子集 |
| `trace_id` | 请求追踪 ID |

> 请求 `data_source`/`table_id` 决定去哪个数据源/结果表查该指标；`conditions`/`table_id_conditions` 仅用于收窄候选范围，不影响返回的字段结构。
