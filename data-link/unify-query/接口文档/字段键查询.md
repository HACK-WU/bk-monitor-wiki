## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/info/field_keys` |
| Handler | `HandlerFieldKeys` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 查询指定结果表/指标的字段键（如 `usage`/`load5` 等可查指标名） |

请求体为 `Params`（`data_source`/`table_id`/`metric_name`/`is_regexp`/`conditions`/`start_time`/`end_time` 等）。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求示例

```json
{
  "data_source": "bk_monitor",
  "table_id": "system.cpu_summary",
  "metric_name": "",
  "is_regexp": false,
  "conditions": {"field_list": []},
  "start_time": "1657848000",
  "end_time": "1657851600"
}
```
