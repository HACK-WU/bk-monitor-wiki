## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/info/series` |
| Handler | `HandlerSeries` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 返回满足条件的时序序列（维度组合）列表，用于下拉/多选场景 |

请求体为 `Params`。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求示例

```json
{
  "data_source": "bk_monitor",
  "table_id": "system.cpu_summary",
  "metric_name": "usage",
  "conditions": {"field_list": [{"field": "bk_target_ip", "operator": "=", "value": ["10.0.0.1"]}]},
  "start_time": "1657848000",
  "end_time": "1657851600",
  "limit": 50
}
```

## 请求字段说明

请求体为 `Params`（`service/http/infos.go#L30-L51`）。主要字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data_source` | string | 是 | 数据源。枚举：`bk_monitor`（别名 `bkmonitor`）、`custom`、`bkdata`、`bklog`、`bkapm` |
| `table_id` | string | 是 | 数据实体 ID，格式 `{db}.{measurement}` |
| `metric_name` | string | 是 | 指标名 |
| `is_regexp` | bool | 否 | 指标是否正则查询 |
| `conditions` | object | 否 | 过滤条件 `Conditions`：`field_list`/`condition_list`（枚举 `and`/`or`） |
| `table_id_conditions` | array[array] | 否 | 表标签条件（AllConditions：内层 AND、外层 OR） |
| `keys` | array[string] | 否 | 查询的键列表 |
| `limit` / `slimit` | int | 否 | 限制数量 / 维度限制 |
| `start_time` / `end_time` | string | 是 | 起止时间（秒级时间戳） |
| `timezone` | string | 否 | 时区，如 `"Asia/Shanghai"` |

`ConditionField.op` 枚举：`eq`(等于)、`ne`(不等于)、`req`(正则匹配)、`nreq`(正则不匹配)、`contains`(包含)、`ncontains`(不包含)、`existed`(存在)、`nexisted`(不存在)。

## 响应说明

成功返回序列（数据对象直接返回 `SeriesData`，`service/http/info.go#L35-L40`）：

```json
{
  "trace_id": "f2a3b4c5",
  "measurement": "system.cpu_summary",
  "keys": ["bk_target_ip", "bk_target_cloud_id"],
  "series": [["10.0.0.1", "0"]]
}
```

> `keys` 为维度顺序，`series` 为二维数组，每个内层数组按 `keys` 顺序给出一组维度值。失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为 `SeriesData`，由请求指定的指标与过滤条件直接决定：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `measurement` | 来自请求 `table_id`（结果表 measurement 部分） |
| `keys` | 该 `metric_name` 在 `table_id`/`data_source` 下的维度（标签）键列表（顺序即 `series` 内层数组的列顺序） |
| `series` | 满足 `conditions` 与 `start_time`/`end_time` 的维度组合列表，每个内层数组按 `keys` 顺序给出一组维度值；`limit`/`slimit` 限制数量 |
| `trace_id` | 请求追踪 ID |
