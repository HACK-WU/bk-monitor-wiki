## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/reference` |
| Handler | `HandlerQueryReference` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 仅解析与路由展开，返回每个子查询命中的结果表（`result_table_id`），不下发真实指标查询 |

`space_uid` 可由请求体或 `X-Bk-Scope-Space-Uid` 头注入。响应约定同主查询：成功直接返回 `PromData`（HTTP 200），其 `result_table_id` 暴露路由解析出的结果表列表；失败 `ErrResponse`（HTTP 400）。

## 请求字段说明

请求体复用 `QueryTs`（与 [结构体查询接口](结构体查询.md#请求字段说明) 完全一致）。本接口常用字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `space_uid` | string | 否 | 空间 UID；可由 `X-Bk-Scope-Space-Uid` 头注入并覆盖 |
| `query_list` | array[Query] | 否 | 子查询列表 |
| `metric_merge` | string | 否 | 多子查询二次运算表达式，本接口常直接设为子查询别名，如 `"a"` |
| `start_time` / `end_time` | string | 否 | 起止时间，单位秒级时间戳 |
| `step` | string | 否 | 步长，如 `"1m"` |

子查询项 `Query`、过滤条件 `Conditions`/`ConditionField`（含 `op` 枚举）、聚合方法 `AggregateMethod`、以及可枚举字段 `data_source` 的完整定义，见 [结构体查询接口](结构体查询.md#请求字段说明)。

## 返回字段说明

成功响应为 `PromData`（`service/http/prom_data.go#L22-L32`），HTTP 200、无 `code/data` 包裹：

| 字段 | 类型 | 说明 |
|------|------|------|
| `series` | array[TablesItem] | 时序数据表列表（本接口仅做路由展开，通常为 `[]`） |
| `status` | object | 状态信息 |
| `trace_id` | string | 链路 ID |
| `is_partial` | bool | 是否为部分数据 |
| `result_table_id` | array[string] | 路由解析出的结果表 ID 列表（本接口核心返回） |

`TablesItem` 字段及失败响应 `ErrResponse` 见 [结构体查询接口](结构体查询.md#返回字段说明)。

### 返回字段与请求字段的映射关系

返回为 `PromData`，但本接口仅做路由展开、不下发真实查询，因此 `series` 通常为 `[]`，核心返回是 `result_table_id`：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `result_table_id` | 由请求 `query_list[].table_id`（结合 `space_uid`/`data_source`）经 `QueryReference` 路由解析出的结果表列表；与请求一一对应 |
| `series` | 通常为空 `[]`（未实际查询指标） |
| `trace_id` / `is_partial` / `status` | 链路与状态信息，同主查询 |

> 其余 `TablesItem` 字段的详细映射见 [结构体查询接口](结构体查询.md#返回字段与请求字段的映射关系)。
