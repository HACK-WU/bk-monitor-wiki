## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/reference` |
| Handler | `HandlerQueryReference` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 仅解析与路由展开，返回每个子查询命中的结果表（`result_table_id`），不下发真实指标查询 |

`space_uid` 可由请求体或 `X-Bk-Scope-Space-Uid` 头注入。响应约定同主查询：成功直接返回 `PromData`（HTTP 200），其 `result_table_id` 暴露路由解析出的结果表列表；失败 `ErrResponse`（HTTP 400）。
