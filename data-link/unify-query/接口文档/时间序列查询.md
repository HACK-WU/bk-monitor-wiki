## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/info/time_series` |
| Handler | `HandlerTimeSeries` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 返回序列对应的时间序列点位（小规模预览），区别于主查询的全量聚合 |

请求体为 `Params`。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求字段说明

请求体为 `Params`（`service/http/infos.go#L30-L51`）。主要字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data_source` | string | 是 | 数据源。枚举：`bk_monitor`（别名 `bkmonitor`）、`custom`、`bkdata`、`bklog`、`bkapm` |
| `table_id` | string | 是 | 数据实体 ID，格式 `{db}.{measurement}` |
| `metric_name` | string | 是 | 指标名 |
| `is_regexp` | bool | 否 | 指标是否正则查询 |
| `conditions` | object | 否 | 过滤条件 `Conditions`：`field_list`/`condition_list`（枚举 `and`/`or`） |
| `table_id_conditions` | array[array] | 否 | 表标签条件（AllConditions：内层 AND、外层 OR） |
| `keys` | array[string] | 否 | 查询的键列表 |
| `limit` / `slimit` | int | 否 | 限制数量 / 维度限制 |
| `start_time` / `end_time` | string | 是 | 起止时间（秒级时间戳） |
| `timezone` | string | 否 | 时区，如 `"Asia/Shanghai"` |

`ConditionField.op` 枚举：`eq`(等于)、`ne`(不等于)、`req`(正则匹配)、`nreq`(正则不匹配)、`contains`(包含)、`ncontains`(不包含)、`existed`(存在)、`nexisted`(不存在)。

## 响应说明

成功返回时间序列点位（数据对象直接返回 `InfoData`，`service/http/info.go#L68-L71`；**仅含 `series`，无 `trace_id`**）：

```json
{
  "series": [
    {
      "name": "_result0",
      "metric_name": "system.cpu_summary.usage",
      "columns": ["_time", "_value"],
      "types": ["time", "double"],
      "group_keys": [],
      "group_values": [],
      "values": [[1657848000, 12.5]]
    }
  ]
}
```

> `InfoData` 仅包含 `series`（`*TablesItem` 列表），结构与主查询 `PromData.series` 元素一致，但**不含 `trace_id`**。`TablesItem` 字段见 [结构体查询接口](结构体查询.md#返回字段说明)。失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为 `InfoData`（仅 `series`，无 `trace_id`），是请求指标的**小规模时间点位预览**，其 `series` 元素结构与主查询 `PromData.series` 一致：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `series[].group_keys` / `group_values` | 由请求 `dimensions`（及 `conditions` 固定维度）决定，同 [结构体查询接口](结构体查询.md#返回字段与请求字段的映射关系) |
| `series[].columns` / `values` | 仅 `_time`/`_value`（维度在 `group_values`） |
| `series[].metric_name` | 来自请求 `table_id`+`field_name` |

> 区别在于本接口为预览（默认小 `limit`），不做全量聚合；`trace_id` 不在响应中（见 [结构体查询接口](结构体查询.md#返回字段说明) 的说明）。
