## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/info/tag_values` |
| Handler | `HandlerTagValues` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 查询指定标签键的取值列表（如 `bk_target_ip` 下的所有 IP） |

请求体为 `Params`（`keys` 指定要取值的标签键，`conditions` 收窄范围）。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求示例

```json
{
  "data_source": "bk_monitor",
  "table_id": "system.cpu_summary",
  "metric_name": "usage",
  "keys": ["bk_target_ip"],
  "conditions": {"field_list": []},
  "start_time": "1657848000",
  "end_time": "1657851600",
  "limit": 100
}
```

## 请求字段说明

请求体为 `Params`（`service/http/infos.go#L30-L51`）。主要字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data_source` | string | 是 | 数据源。枚举：`bk_monitor`（别名 `bkmonitor`）、`custom`、`bkdata`、`bklog`、`bkapm` |
| `table_id` | string | 是 | 数据实体 ID，格式 `{db}.{measurement}` |
| `metric_name` | string | 是 | 指标名 |
| `is_regexp` | bool | 否 | 指标是否正则查询 |
| `conditions` | object | 否 | 过滤条件 `Conditions`：`field_list`/`condition_list`（枚举 `and`/`or`） |
| `table_id_conditions` | array[array] | 否 | 表标签条件（AllConditions：内层 AND、外层 OR） |
| `keys` | array[string] | 是 | 取值的标签键列表，如 `["bk_target_ip"]` |
| `limit` / `slimit` | int | 否 | 限制数量 / 维度限制 |
| `start_time` / `end_time` | string | 是 | 起止时间（秒级时间戳） |
| `timezone` | string | 否 | 时区，如 `"Asia/Shanghai"` |

`ConditionField.op` 枚举：`eq`(等于)、`ne`(不等于)、`req`(正则匹配)、`nreq`(正则不匹配)、`contains`(包含)、`ncontains`(不包含)、`existed`(存在)、`nexisted`(不存在)。

## 响应说明

成功返回标签值（数据对象直接返回 `TagValuesData`，`service/http/info.go#L27-L30`）：

```json
{
  "trace_id": "e1f2a3b4",
  "values": {"bk_target_ip": ["10.0.0.1", "10.0.0.2"]}
}
```

> `values` 为 map：键为请求 `keys` 中的标签名，值为该标签的取值列表。失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为 `TagValuesData`，`values` 由请求的标签键直接驱动：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| `values` 的键 | 来自请求 `keys`（标签键列表，如 `["bk_target_ip"]`） |
| `values` 的值 | 该标签在 `table_id`/`data_source`/`metric_name` 下、满足 `conditions` 与 `start_time`/`end_time` 的全部取值 |
| `trace_id` | 请求追踪 ID |
