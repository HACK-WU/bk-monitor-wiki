## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/info/tag_keys` |
| Handler | `HandlerTagKeys` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 查询指标的维度（标签）键，如 `bk_target_ip`/`bk_target_cloud_id` |

请求体为 `Params`。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求示例

```json
{
  "data_source": "bk_monitor",
  "table_id": "system.cpu_summary",
  "metric_name": "usage",
  "conditions": {"field_list": []},
  "start_time": "1657848000",
  "end_time": "1657851600"
}
```

## 请求字段说明

请求体为 `Params`（`service/http/infos.go#L30-L51`）。主要字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data_source` | string | 是 | 数据源。枚举：`bk_monitor`（别名 `bkmonitor`）、`custom`、`bkdata`、`bklog`、`bkapm` |
| `table_id` | string | 是 | 数据实体 ID，格式 `{db}.{measurement}`，如 `"system.cpu_summary"` |
| `metric_name` | string | 是 | 指标名 |
| `is_regexp` | bool | 否 | 指标是否正则查询 |
| `conditions` | object | 否 | 过滤条件 `Conditions`：`field_list`/`condition_list`（枚举 `and`/`or`） |
| `table_id_conditions` | array[array] | 否 | 表标签条件（AllConditions：内层 AND、外层 OR） |
| `keys` | array[string] | 否 | 查询的键列表（`tag_keys` 可省略） |
| `limit` / `slimit` | int | 否 | 限制数量 / 维度限制 |
| `start_time` / `end_time` | string | 是 | 起止时间（秒级时间戳） |
| `timezone` | string | 否 | 时区，如 `"Asia/Shanghai"` |

`ConditionField.op` 枚举：`eq`(等于)、`ne`(不等于)、`req`(正则匹配)、`nreq`(正则不匹配)、`contains`(包含)、`ncontains`(不包含)、`existed`(存在)、`nexisted`(不存在)。

## 响应说明

成功返回标签键列表（数据对象直接返回，为裸字符串数组，无 `list`/`trace_id` 包裹）：

```json
["bk_target_ip", "bk_target_cloud_id", "bk_biz_id"]
```

失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为裸字符串数组（标签键列表），由请求指定的指标直接决定：

| 返回字段 | 与请求字段的映射关系 |
|---------|-------------------|
| 数组元素（标签键） | 来自请求 `metric_name` 在 `table_id`/`data_source` 下的维度（标签）定义；`conditions`/`table_id_conditions` 仅收窄候选范围 |
| （无 `trace_id`） | 该接口直接返回裸数组，无包裹字段 |
