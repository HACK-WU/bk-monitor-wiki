## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/exemplar` |
| Handler | `HandlerQueryExemplar` |
| 鉴权 | `MetaData` + `JwtAuth`（支持 `X-Bk-Scope-Skip-Space`） |
| 用途 | 查询 exemplar（示例）数据，主要用于 trace 指标列的批量关联查询（`field_list`） |

请求体复用 `QueryTs`（通过 `query_list[].field_list` 指定 trace 指标列）。响应为 `PromData`（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求示例

```json
{
  "space_uid": "bkcc__2",
  "query_list": [
    {
      "reference_name": "a",
      "table_id": "bk_apm_trace",
      "field_name": "duration",
      "field_list": ["trace_id", "span_id"],
      "function": [{"method": "MEAN"}]
    }
  ],
  "start_time": "1657848000",
  "end_time": "1657851600",
  "step": "1m"
}
```

## 请求字段说明

请求体复用 `QueryTs`（与 [结构体查询接口](结构体查询.md#请求字段说明) 一致）。本接口通过 `query_list[].field_list` 指定 trace 指标列（如 `trace_id`/`span_id`）用于批量关联查询：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `space_uid` | string | 否 | 空间 UID；可由 `X-Bk-Scope-Space-Uid` 头注入覆盖 |
| `query_list` | array[Query] | 否 | 子查询列表，其中 `field_list` 指定 trace 列 |
| `start_time` / `end_time` | string | 否 | 起止时间（秒级时间戳） |
| `step` | string | 否 | 步长，如 `"1m"` |

子查询项 `Query`（含 `field_list`/`function`/`conditions`）、过滤条件、聚合方法、可枚举 `data_source` 的完整定义见 [结构体查询接口](结构体查询.md#请求字段说明)。

## 返回字段说明

成功响应为 `PromData`（`service/http/prom_data.go#L22-L32`），HTTP 200、无 `code/data` 包裹：

| 字段 | 类型 | 说明 |
|------|------|------|
| `series` | array[TablesItem] | 时序数据表列表（含 trace 列） |
| `status` | object | 状态信息 |
| `trace_id` | string | 链路 ID |
| `is_partial` | bool | 是否为部分数据 |

`TablesItem` 字段见 [结构体查询接口](结构体查询.md#返回字段说明)。失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为 `PromData`，字段映射同 [结构体查询接口](结构体查询.md#返回字段与请求字段的映射关系)：`group_keys`/`group_values` 由请求 `dimensions` 决定；`columns`/`values` 仅含 `_time`/`_value`。本接口特有：`query_list[].field_list` 指定的 trace 列（如 `trace_id`/`span_id`）会作为维度标签出现在 `group_keys` 中，对应取值落在 `group_values`。
