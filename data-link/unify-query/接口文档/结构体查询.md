## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts` |
| Handler | `HandlerQueryTs` |
| 鉴权 | `MetaData` + `JwtAuth`（公共分组） |
| 用途 | 以结构化指标/维度/过滤条件发起时序查询，支持多子查询与 `metric_merge` 二次运算 |

## 请求示例

```json
{
  "space_uid": "bkcc__2",
  "query_list": [
    {
      "reference_name": "a",
      "table_id": "system.cpu_summary",
      "field_name": "usage",
      "function": [{"method": "MEAN", "dimensions": ["bk_target_ip"]}],
      "time_aggregation": {"method": "SUM", "window": "1m"},
      "conditions": {"field_list": [{"field": "bk_target_ip", "operator": "=", "value": ["10.0.0.1"]}]},
      "dimensions": ["bk_target_ip", "bk_target_cloud_id"]
    }
  ],
  "metric_merge": "a",
  "start_time": "1657848000",
  "end_time": "1657851600",
  "step": "1m",
  "down_sample_range": "5m",
  "timezone": "Asia/Shanghai",
  "instant": false,
  "reference": true,
  "order_by": ["-_time"],
  "limit": 0,
  "from": 0
}
```

## 响应示例

成功时直接返回 `PromData`（HTTP 200，无 `code/data` 包裹）：

```json
{
  "series": [
    {
      "name": "_result0",
      "metric_name": "system.cpu_summary.usage",
      "columns": ["_time", "_value", "bk_target_ip"],
      "types": ["time", "double", "string"],
      "group_keys": ["bk_target_ip"],
      "group_values": ["10.0.0.1"],
      "values": [
        [1657848000, 12.5, "10.0.0.1"],
        [1657848060, 13.1, "10.0.0.1"]
      ],
      "stat": {"avg": 12.8, "max": 13.1, "min": 12.5, "count": 2}
    }
  ],
  "status": {"series_limit_reached": false, "is_partial": false},
  "trace_id": "a1b2c3d4",
  "is_partial": false,
  "result_table_id": ["system.cpu_summary"]
}
```

错误响应（`ErrResponse`，HTTP 400）：

```json
{"trace_id": "a1b2c3d4", "error": "space_uid not found"}
```
