## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/cluster_metrics` |
| Handler | `HandlerQueryTsClusterMetrics` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 面向集群视角的聚合指标查询，由 `QueryTsClusterMetrics` 内部聚合后返回 |

请求体复用 `QueryTs`。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。

## 请求字段说明

请求体复用 `QueryTs`（与 [结构体查询接口](结构体查询.md#请求字段说明) 一致）。本接口常用字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `space_uid` | string | 否 | 空间 UID；可由 `X-Bk-Scope-Space-Uid` 头注入覆盖 |
| `query_list` | array[Query] | 否 | 子查询列表（面向集群聚合指标，如 `kubernetes.cluster.cpu`） |
| `start_time` / `end_time` | string | 否 | 起止时间（秒级时间戳） |
| `step` | string | 否 | 步长，如 `"1m"` |
| `add_dimensions` | array[string] | 否 | 额外聚合维度 |

子查询项 `Query`、过滤条件、聚合方法、可枚举 `data_source` 的完整定义见 [结构体查询接口](结构体查询.md#请求字段说明)。

## 返回字段说明

成功响应为 `PromData`（`service/http/prom_data.go#L22-L32`），HTTP 200、无 `code/data` 包裹：

| 字段 | 类型 | 说明 |
|------|------|------|
| `series` | array[TablesItem] | 时序数据表列表 |
| `status` | object | 状态信息 |
| `trace_id` | string | 链路 ID |
| `is_partial` | bool | 是否为部分数据 |

`TablesItem` 字段见 [结构体查询接口](结构体查询.md#返回字段说明)。失败响应 `ErrResponse`：`{"trace_id": "...", "error": "..."}`。

### 返回字段与请求字段的映射关系

返回为 `PromData`，其 `TablesItem` 字段与 [结构体查询接口](结构体查询.md#返回字段与请求字段的映射关系) 完全一致：`group_keys`/`group_values` 由请求 `query_list[].dimensions`（及 `function[].dimensions`、`add_dimensions`）指定的分组维度驱动；`columns`/`values` 仅含 `_time`/`_value`（维度在 `group_values`）；`metric_name` 来自 `table_id`+`field_name`（本接口为集群聚合指标，如 `kubernetes.cluster.cpu.usage`）；`result_table_id` 来自路由解析；`stat` 由点集计算。区别在于本接口面向集群聚合指标，请求 `query_list` 多为 `kubernetes.*` 类指标。
