## 接口说明

| 项 | 值 |
|----|----|
| 方法 / 路径 | POST `/query/ts/cluster_metrics` |
| Handler | `HandlerQueryTsClusterMetrics` |
| 鉴权 | `MetaData` + `JwtAuth` |
| 用途 | 面向集群视角的聚合指标查询，由 `QueryTsClusterMetrics` 内部聚合后返回 |

请求体复用 `QueryTs`。响应直接返回数据对象（HTTP 200）；失败 `ErrResponse`（HTTP 400）。
