# UnifyQuery 使用流程

## 流程 1：时序数据查询（最常用）

### 业务目标

查询指定主机/业务在某个时间范围内的时序指标数据（如 CPU 使用率、端口存活状态等）。

### 调用顺序

```
load_data_source → data_source_class(...) → UnifyQuery → query_data(start_time, end_time)
```

### 示例

查询某业务下所有主机的 `system.proc_port` 端口存活状态（3 分钟聚合窗口）：

```python
from bkmonitor.data_source import load_data_source, UnifyQuery
from bkmonitor.data_source.data_source import DataSourceLabel, DataTypeLabel

# Step 1: 获取数据源类
data_source_class = load_data_source(DataSourceLabel.BK_MONITOR_COLLECTOR, DataTypeLabel.TIME_SERIES)

# Step 2: 构造查询描述对象
data_source = data_source_class(
    bk_biz_id=bk_biz_id,
    interval=180,
    metrics=[{"field": "proc_exists", "method": "AVG", "alias": "A"}],
    table="system.proc_port",
    group_by=["bk_host_id", "bk_target_ip", "bk_target_cloud_id", "display_name"],
)

# Step 3: 构造 UnifyQuery 并执行
query = UnifyQuery(data_sources=[data_source], bk_biz_id=bk_biz_id, expression="a")
records = query.query_data(start_time=start_time, end_time=end_time)

# 返回结构：
# [{"_time_": 1716946200000, "_result_": 1, "bk_host_id": 1, "display_name": "nginx", ...}, ...]
```

### 事务边界

- `query_data()` 内部是一次 HTTP 请求（或下推到数据源的原生查询）
- 不需要显式开启/关闭事务

### 预期结果

- 在每个 `(group_by 组合, step 步长)` 的时间点上，返回聚合后的指标值
- `AVG` 方法行为：先 `avg_over_time(window)` 跨时间聚合 → 再 `mean` 跨 series 聚合
- 返回 `list[dict]`，每行含 `_time_`（毫秒时间戳）、`_result_`（聚合值）、各维度字段

### 错误处理

- 返回空 `[]`：检查 `table`/`field` 是否存在、时间范围是否有数据
- 聚合值异常：检查 `method` 是否匹配指标语义（counter 型指标应选 `SUM` 而非 `AVG`）
- 维度缺失：确认 `group_by` 字段确实存在于表定义中

## 流程 1b：instant 瞬态查询（快照）

### 业务目标

取某一个时刻（`end_time`）的瞬时聚合值。与非 instant 的区别在于：非 instant 返回整个时间区间的采样序列，而 instant 仅返回 `end_time` 单点。

### 调用顺序

```
load_data_source → data_source_class(...) → UnifyQuery → query_data(start_time, end_time, instant=True)
```

### 示例

```python
# 查询 end_time 时刻的端口存活状态（单点）
query = UnifyQuery(data_sources=[data_source], bk_biz_id=bk_biz_id, expression="a")
records = query.query_data(start_time=query_start, end_time=query_end, instant=True)
# records: [{"_time_": query_end_ms, "_result_": 1, ...}]  # 只返回一条
```

### 关键差异

- `step` 被强制覆盖为 `"1m"`（不管 `interval` 设了什么）
- **保留 `end_time` 的边界数据点**（非 instant 会丢弃该点）
- 返回只有一条或多条（不同维度组合各一条）记录
- `start_time` 不会被重算，但 instant 只看 end_time 单点

### 何时用 instant vs 非 instant

| 场景 | 选用 |
|------|------|
| 折线图、趋势曲线 | 非 instant（取多个采样点） |
| "当前值"数字卡片、单值指示器 | instant（取 end_time 单点） |
| 告警策略评估 | instant（只看当前时刻） |

## 流程 2：日志/事件查询

### 业务目标

查询原始日志数据或事件记录，不需要聚合。

### 调用顺序

```
load_data_source(BK_LOG_SEARCH, LOG) → data_source_class(...) → UnifyQuery → query_log(start_time, end_time, limit, offset)
```

### 示例

```python
# 日志查询与时序查询只有 entry point 不同
data_source_class = load_data_source(DataSourceLabel.BK_LOG_SEARCH, DataTypeLabel.LOG)
data_source = data_source_class(
    bk_biz_id=bk_biz_id,
    table="2_bklog_xxx",
    metrics=[{"field": "log", "method": "COUNT", "alias": "A"}],
)
query = UnifyQuery(data_sources=[data_source], bk_biz_id=bk_biz_id, expression="a")
records, total = query.query_log(start_time=start_time, end_time=end_time, limit=100, offset=0)
```

### 关键差异

- `query_log` 内部会剥离 `function`、`field_name`、`time_aggregation`
- 调用 `POST /query/ts/raw` 而非 `/query/ts`
- 返回 `(list[dict], total)` 二元组（`total` 在统一查询路径下恒为 `0`）
- 不支持 `instant` 参数

## 流程 3：维度值查询

### 业务目标

查询某个维度字段的所有可能取值（如下拉框选项）。

### 调用顺序

```
load_data_source → data_source_class(...) → UnifyQuery → query_dimensions(dimension_field)
```

### 示例

```python
data_source = data_source_class(
    bk_biz_id=bk_biz_id,
    interval=180,
    metrics=[{"field": "cpu_usage_pct", "method": "AVG", "alias": "A"}],
    table="system.proc",
    group_by=["display_name"],
)
query = UnifyQuery(data_sources=[data_source], bk_biz_id=bk_biz_id, expression="a")
dimension_values = query.query_dimensions("display_name")  # ["nginx", "java", ...]
```

### 关键差异

- 单数据源时走 `/query/ts/info/tag_values` 端点（高效），多数据源时退化全量拉取（低效）
- 不需要传 `start_time`/`end_time` 参数
- 返回维度的 distinct 值列表

---

## 六入口对照表

| 维度 | query_data | with_stat | reference | log | dimensions |
|------|-----------|-----------|-----------|-----|------------|
| HTTP/目标 | `/query/ts` | `/query/ts` | `/query/ts/reference` | `/query/ts/raw` | `/query/ts/info/tag_values` |
| 返回 | `list` | `{series, stat}` | `list` | `(list, total)` | `list` |
| instant 支持 | ✅（step→1m，保留边界点） | ✅同 | ✅（step→1m） | ❌ | — |
| 聚合行为 | 有 | 有 | 有 | 剥离聚合 | 无（维度查询） |
| 适用场景 | 时序图表 | 带统计的图表 | 最新值引用 | 日志列表 | 下拉选项 |
