# Issue 数据流向与消费

## 数据实体总览

| 数据实体 | 来源接口/写入方 | 去向 | 消费方（模块级） | 业务用途 |
|----------|----------------|------|----------------|----------|
| Issue 文档 | `IssueAggregationProcessor`、状态变更 Resource | ES 索引 `bkfta_issue` | Issue Web API、告警详情页、周期任务、TAPD 集成 | 问题聚合与跟踪的主数据 |
| Issue 活动日志 | `IssueDocument` 状态机方法、Resource 操作 | ES 索引 `bkfta_fta_issue_act` | Issue 详情页活动流 | 审计与操作追溯 |
| 告警关联关系 | `IssueAggregationProcessor._associate_alert` | `AlertDocument.issue_id` 字段 | Issue 详情、影响范围重算 | 建立告警 ↔ Issue 归属 |
| 活跃 Issue 缓存 | `_persist_and_cache(active=True)` | Redis `issue_active_content:{fingerprint}` | processor 快速查找、周期任务 | 加速活跃 Issue 命中 |
| Issue 合并关系 | `IssueMergeResolver.merge/split` | MySQL `bkmonitor_issue_merge_relation` | 合并/拆分接口、详情页 | 记录主 Issue 与子 Issue 关系 |
| TAPD 关联关系 | `CreateTapdResource`、`_save_relation` | MySQL `bkmonitor_issue_tapd_relation` | TAPD 集成接口、详情页 | Issue ↔ TAPD 单据关联 |
| TAPD 用户态 token | OAuth 回调、授权流程 | Redis `tapd_uat:{tenant}:{user}` | TAPD 接口调用 | 用户级 TAPD API 授权凭证 |
| TAPD 工作区解绑 tombstone | `UnbindTapdWorkspaceResource` | MySQL `bkmonitor_tapd_workspace_manual_unbind` | 周期任务、重绑接口 | 阻断自动回绑 |

## 各数据实体详细说明

### 1. Issue 文档（`bkfta_issue`）

- **来源接口**：`IssueAggregationProcessor.process()` 创建；各类状态变更 Resource 修改。
- **去向**：ES 索引 `bkfta_issue`，按创建时间分片。
- **消费方**：
  - Issue Web API（列表/详情/导出）
  - 告警详情页（通过 `AlertDocument.issue_id` 反查）
  - 周期任务 `sync_issue_alert_stats`
  - TAPD 集成模块
- **业务用途**：问题聚合与跟踪的主数据实体。

### 2. Issue 活动日志（`bkfta_fta_issue_act`）

- **来源接口**：`IssueDocument` 状态机方法（`assign`、`resolve`、`archive` 等）调用后返回活动文档。
- **去向**：ES 索引 `bkfta_fta_issue_act`。
- **消费方**：Issue 详情页活动流、审计查询。
- **业务用途**：记录 Issue 全生命周期操作，支持审计与回溯。

### 3. 告警关联关系（`AlertDocument.issue_id`）

- **来源接口**：`IssueAggregationProcessor._associate_alert`。
- **去向**：`AlertDocument` 的 `issue_id` 字段。
- **消费方**：
  - Issue 详情页拉取关联告警
  - 影响范围重算
  - 周期任务漏关联补偿
- **业务用途**：建立告警到 Issue 的归属关系。

### 4. 活跃 Issue 缓存（Redis）

- **来源接口**：`_persist_and_cache(active=True)`。
- **去向**：Redis `issue_active_content:{fingerprint}`。
- **消费方**：
  - processor 快速查找活跃 Issue
  - 周期任务扫描
- **业务用途**：减少 ES 查询，加速聚合入口。

### 5. Issue 合并关系（MySQL）

- **来源接口**：`IssueMergeResolver.merge/split`。
- **去向**：`bkmonitor_issue_merge_relation` 表。
- **消费方**：
  - 合并/拆分接口
  - Issue 详情页展示合并来源
- **业务用途**：记录主 Issue 与子 Issue 关系，支持拆分恢复。

### 6. TAPD 关联关系（MySQL）

- **来源接口**：`CreateTapdResource`、`_save_relation`。
- **去向**：`bkmonitor_issue_tapd_relation` 表。
- **消费方**：
  - TAPD 集成接口
  - Issue 详情页 TAPD 信息展示
- **业务用途**：Issue 与 TAPD 单据的持久化关联。

### 7. TAPD 用户态 token（Redis）

- **来源接口**：TAPD OAuth 回调处理。
- **去向**：Redis `tapd_uat:{tenant}:{user}`，加密存储。
- **消费方**：所有 `TAPD_ENDPOINTS` 接口调用前校验。
- **业务用途**：用户级 TAPD API 授权凭证。

### 8. TAPD 工作区解绑 tombstone（MySQL）

- **来源接口**：`UnbindTapdWorkspaceResource`。
- **去向**：`bkmonitor_tapd_workspace_manual_unbind` 表。
- **消费方**：
  - 周期任务自动同步
  - 重绑接口
- **业务用途**：阻断周期任务自动回绑已手动解绑的工作区。
