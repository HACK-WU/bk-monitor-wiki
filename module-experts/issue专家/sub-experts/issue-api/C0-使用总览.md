# 使用总览：Issue API 子专家

> 契约快照生成于 2026-07-31。
> 若使用中发现行为与契约不符，可能代码已变更——expert-lookup 会自动增量修正，或用 expert-team 全量重建。

## 能力清单

Issue API 子专家覆盖 Issue 模块的 RESTful 接口层、权限控制、序列化与批量操作框架：

- **Issue 列表与详情**：按状态、优先级、负责人、策略、维度、影响范围等条件查询 Issue 列表；查看单个 Issue 的元数据、告警摘要、活动日志、历史 Issue。
- **统计分析**：TopN 维度统计、Issue 趋势统计、最近使用负责人聚合。
- **状态变更**：指派/改派、解决、重开、归档、恢复、修改优先级、重命名、添加/编辑跟进评论。
- **合并与拆分**：将多个 Issue 合并到主 Issue，或将子 Issue 从主 Issue 拆分恢复为独立 Issue。
- **批量操作**：对多个 Issue 并发执行同一操作，单条失败隔离，返回成功/失败明细。
- **辅助接口**：告警 enrich、日志内容批量查询、导出。
- **TAPD 集成接口**：工作区列表、字段定义、单据搜索、创建/关联 TAPD 单、工作区解绑/重绑、撤销授权（TAPD 集成子专家负责深度契约）。

## 能力边界

本模块不直接处理以下事项：

- 不实现告警聚合到 Issue 的指纹计算与状态机持久化（由 Issue 状态聚合子专家覆盖）。
- 不实现 ES 查询 DSL 的复杂构建与时间分片细节（由 Issue 查询子专家覆盖）。
- 不实现 TAPD OAuth 与 API 调用的底层细节（由 TAPD 集成子专家覆盖）。
- 不维护策略 Issue 聚合配置本身（配置层由策略管理模块负责）。

## 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|------|----------|----------|
| 批量操作部分失败 | 单条 Issue 状态不允许目标动作，或 Issue 已被合并冻结 | `_run_batch` 返回 `succeeded`/`failed` 数组；前端按失败明细提示，不中断整体流程 |
| `issue/search` 权限校验失败 | `bk_biz_ids` 未传或 IAM 无 `VIEW_EVENT` 权限 | `IssueBusinessActionPermission` 支持从 `bk_biz_ids` 列表提取业务 ID；确认业务列表与权限 |
| 写操作报无权限 | `MANAGE_EVENT` 权限不足，或批量写操作中某条 `bk_biz_id` 无权限 | 检查调用用户是否拥有目标业务的告警管理权限 |
| TAPD 接口返回 403 未授权 | 用户未在 TAPD 完成 OAuth 授权或 token 过期 | 先调用 `tapd/user_workspace` 携带 `success_url` 获取 `auth_url` 完成授权 |
| 合并后的源 Issue 无法单独操作 | 源 Issue 已被冻结在主 Issue 下 | 合并 member 的状态只能随主 Issue 级联变更；如需独立操作，先走拆分流程 |
| `export` 导出结果为空 | 查询条件与列表查询不一致，或 ES 数据尚未刷新 | 使用与 `issue/search` 相同的过滤条件；确认 `end_time`/`start_time` 语义 |
