## 流程 1：Issue 列表查询

### 业务目标
按状态、优先级、负责人等条件查询 Issue 列表。

### 调用顺序
```
resource.issue.search_issue(bk_biz_ids, status, priority, ...) → IssueBusinessActionPermission 校验 → IssueQueryHandler.search() → IssueQueryTransformer
```

### 事务边界
- 只读查询，无事务。
- 默认排序 `-first_alert_time, priority, status`。

### 预期结果
- 返回当前用户有权限的业务下的 Issue 列表。
- 虚拟状态 `MY_ASSIGNEE` / `NO_ASSIGNEE` 会被转换为具体 ES 查询条件。

### 错误处理
- `bk_biz_ids` 为空或权限不足：由 `IssueBusinessActionPermission` 拦截。
- 非法查询参数：由 `IssueSearchSerializer` 序列化器拦截。

### 使用示例
```python
from core.drf_resource import resource

result = resource.issue.search_issue(
    bk_biz_ids=[2],
    status=["unresolved"],
    priority=["P0", "P1"],
    page=1,
    page_size=20,
)
issues = result["list"]
total = result["total"]
```

## 流程 2：批量解决 Issue

### 业务目标
将多个未解决 Issue 标记为已解决。

### 调用顺序
```
resource.issue.resolve_issue(issues=[...]) → IssueBusinessActionPermission 校验 → _run_batch() → IssueDocument.resolve()
```

### 事务边界
- 每条 Issue 独立一个线程任务并发执行。
- 单条失败不影响其他条目。

### 预期结果
- 成功条目的 Issue 状态变为 `resolved`，并记录 `status_change` 活动日志。
- 失败条目返回 `issue_id` 与错误信息。

### 错误处理
- 状态不允许（如已归档）会进入 `failed` 列表。
- IAM 无 `MANAGE_EVENT` 权限时整体请求被拦截。

### 使用示例
```python
from core.drf_resource import resource

result = resource.issue.resolve_issue(
    issues=[
        {"bk_biz_id": 2, "issue_id": "1751234567a1b2c3d4"},
        {"bk_biz_id": 2, "issue_id": "1751234567e5f6g7h8"},
    ],
)
# succeeded 中为 action_fn 原始返回值（此处为活动日志列表）
for activities in result["succeeded"]:
    print(len(activities), activities[0]["issue_id"])
for item in result["failed"]:
    print(item["bk_biz_id"], item["issue_id"], item["message"])
```

## 流程 3：Issue 合并

### 业务目标
将多个同一问题衍生的 Issue 合并到主 Issue，统一跟踪。

### 调用顺序
```
resource.issue.merge_issue(bk_biz_id, main_issue_id, source_issue_ids) → IssueMergeResolver.merge()
```

### 事务边界
- 合并操作会修改多个 Issue 文档，使用 ES UPSERT 持久化。
- 合并后源 Issue 标记为合并进主 Issue，不可再单独操作。

### 预期结果
- 主 Issue 继承被合并 Issue 的告警关联。
- 被合并 Issue 状态冻结，并记录 `MERGED_INTO` 活动日志。

### 错误处理
- 任一目标 Issue 已归档/已解决会抛 `IssueFrozenError`。
- 主 Issue 为合并 member 时报错。

### 使用示例
```python
from core.drf_resource import resource

main_issue = resource.issue.merge_issue(
    bk_biz_id=2,
    main_issue_id="1751234567main0001",
    source_issue_ids=["1751234567sub0001", "1751234567sub0002"],
)
print(main_issue["id"], main_issue["alert_count"])
```

## 流程 4：导出 Issue 列表

### 业务目标
将查询结果导出为文件。

### 调用顺序
```
resource.issue.export_issue(bk_biz_ids, status, ..., export_format="xlsx") → IssueQueryHandler.search() → 文件生成 → 返回下载信息
```

### 事务边界
- 只读查询，无事务。
- 导出数据量受后端限制，超限时可能分页或报错。

### 预期结果
- 返回导出文件下载 URL 或文件内容。

### 错误处理
- 查询条件非法：序列化器拦截。
- 导出数据量过大：后端可能返回错误码提示缩小范围。

### 使用示例
```python
from core.drf_resource import resource

result = resource.issue.export_issue(
    bk_biz_ids=[2],
    status=["unresolved"],
    export_format="xlsx",
)
print(result["download_url"])
```
