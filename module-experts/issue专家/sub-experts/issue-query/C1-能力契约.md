## 入口类

### `SearchIssueResource`

契约来源：`SearchIssueResource`（`fta_web.issue.resources`）

#### `request(request_data)`

- **用途**：查询 Issue 列表，支持过滤、分页、排序、聚合与趋势。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_ids` | `list[int]` | 否 | 业务 ID 列表；`[-1]` 表示全部授权业务；不传表示只查当前用户负责的 Issue |
  | `space_uids` | `list[str]` | 否 | 空间 UID 列表，会与 `bk_biz_ids` 合并转换 |
  | `status` | `list[str]` | 否 | 状态过滤；除 `pending_review`/`unresolved`/`resolved`/`archived` 外，支持虚拟状态 `MY_ASSIGNEE`（当前用户负责）和 `NO_ASSIGNEE`（未分派） |
  | `conditions` | `list[dict]` | 否 | 结构化过滤条件，每项含 `key`、`value`、`method`（`eq/neq/include/exclude/gt/gte/lt/lte`）、`condition`（`and/or`） |
  | `query_string` | `str` | 否 | query_string 查询串，支持字段语法（如 `name:"xxx"`）与中文显示名（如 `status:未解决`） |
  | `start_time` | `int` | 否 | 起始 Unix 时间戳（秒） |
  | `end_time` | `int` | 否 | 结束 Unix 时间戳（秒）；超过当前时间会收敛到当前时间 + 60 秒 |
  | `fingerprint` | `str` | 否 | 按指纹精确过滤，用于定位同一具体问题的全部 Issue（含历史） |
  | `ordering` | `list[str]` | 否 | 排序字段列表；`-` 前缀倒序；默认 `[-first_alert_time, priority, status]` |
  | `page` | `int` | 否 | 页码，从 1 开始，默认 1 |
  | `page_size` | `int` | 否 | 每页大小，最大 500，默认 10；传 0 可只查聚合 |
  | `show_aggs` | `bool` | 否 | 是否返回高级筛选聚合（优先级、状态、负责人、是否回归），默认 `True` |
  | `show_dsl` | `bool` | 否 | 是否在响应中返回 ES DSL，默认 `False` |
  | `show_trend` | `bool` | 否 | 是否为每行 Issue 填充告警趋势，默认 `True`；关闭可减少 AlertDocument 查询；开启后 `trend_start_time` / `trend_end_time` 可不传，默认使用本页 Issue 的告警时间范围 |
  | `trend_start_time` | `int` | 否 | 趋势图起始时间，默认使用本页 Issue 的最早首次告警时间 |
  | `trend_end_time` | `int` | 否 | 趋势图结束时间，默认使用本页 Issue 的最近告警时间 |

- **返回**：`dict`
  - `issues`: `list[dict]` — Issue 列表，每项含 `id`、`name`、`status`、`priority`、`assignee`、`strategy_id`、`strategy_name`、`bk_biz_id`、`labels`、`is_regression`、`alert_count`、`first_alert_time`、`last_alert_time`、`create_time`、`update_time`、`resolved_time`、`fingerprint`、`dimension_values`、`impact_scope`、`duration`、`status_display`、`priority_display`、`is_resolved`、`trend`、`anomaly_message`、`merge_status`、`split_info`、`tapd_count` 等字段（取决于开关）。
  - `total`: `int` — 命中总数。
  - `aggs`: `list[dict]` — 当 `show_aggs=True` 时返回，结构见下方示例。
  - `dsl`: `dict` — 当 `show_dsl=True` 时返回。
- **异常**：
  - `CustomException` — 请求参数校验失败。
  - 查询异常时仍会返回部分结果（`issues`/`total`），并把异常挂载在 `.data` 上抛出。
- **约束**：
  - `query_string` 全字段模式下单条件值数量上限 10，超限抛校验错误。
  - `end_time` 若大于当前时间会被收敛。
  - 虚拟状态 `MY_ASSIGNEE`/`NO_ASSIGNEE` 仅在 `status` 列表中生效，不会出现在 `status` 字段真实值里。
- **使用示例**：

  ```python
  from core.drf_resource import resource

  result = resource.issue.search_issue.request({
      "bk_biz_ids": [2, 3],
      "status": ["MY_ASSIGNEE", "unresolved"],
      "query_string": "name:\"CPU 使用率\"",
      "start_time": 1751222400,
      "end_time": 1751308800,
      "page": 1,
      "page_size": 20,
      "show_aggs": True,
      "show_trend": False,
  })
  print(result["total"], result["issues"][0]["id"])
  ```

### `IssueTopNResource`

契约来源：`IssueTopNResource`（`fta_web.issue.resources`）；内部通过 `IssueTopNResultResource` 作为时间分片子资源并行调用。

#### `request(request_data)`

- **用途**：对 Issue 做字段级 TopN 聚合统计，支持大时间范围分片并行。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_ids` | `list[int]` | 否 | 同 `SearchIssueResource`；不传则只统计当前用户负责的 Issue |
  | `status` / `conditions` / `query_string` / `start_time` / `end_time` / `fingerprint` | - | 否 | 过滤语义同 `SearchIssueResource` |
  | `fields` | `list[str]` | 是 | 聚合字段列表；支持 `+` 升序、`-` 降序前缀；支持 `impact_dimensions`、`impact_scope.{维度}`、`dimension_values.{key}` 等特殊字段 |
  | `size` | `int` | 否 | 每个字段返回桶数上限，默认 10，最大 10000 |
  | `need_time_partition` | `bool` | 否 | 是否启用时间分片；默认 `True`；时间跨度 ≤7 天时会自动关闭 |

- **返回**：`dict`
  - `doc_count`: `int` — 命中的 Issue 总数。
  - `fields`: `list[dict]` — 每个字段的聚合结果，每项含 `field`、`is_char`、`bucket_count`、`buckets`；`buckets` 中每项含 `id`、`name`、`count`。
- **异常**：
  - `CustomException` — 请求参数校验失败。
- **约束**：
  - 入口会对 `fields` 去重，重复字段不会导致 count 虚高。
  - 时间分片下桶按 `(id, name)` 合并并累加 `count`。
  - `bk_biz_id` 会补齐授权业务中 count 为 0 的桶。
- **使用示例**：

  ```python
  from core.drf_resource import resource

  result = resource.issue.issue_top_n.request({
      "bk_biz_ids": [2],
      "fields": ["-priority", "impact_dimensions", "impact_scope.host"],
      "size": 5,
      "start_time": 1751222400,
      "end_time": 1751308800,
  })
  for field in result["fields"]:
      print(field["field"], field["bucket_count"])
  ```

### `IssueTrendResource`

契约来源：`IssueTrendResource`（`fta_web.issue.resources`）

#### `request(request_data)`

- **用途**：按指定 Issue ID 批量查询告警趋势时间序列。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_ids` | `list[int]` | 是 | 业务 ID 列表；不支持 `-1` |
  | `issue_ids` | `list[str]` | 是 | Issue ID 列表，最多 500 个 |
  | `trend_start_time` | `int` | 是 | 趋势图起始 Unix 时间戳（秒） |
  | `trend_end_time` | `int` | 是 | 趋势图结束 Unix 时间戳（秒）；必须大于起始时间，且跨度 ≤7 天 |

- **返回**：`dict[str, list[list[int]]]` — key 为原请求 `issue_id`，value 为 `[[timestamp_ms, count], ...]` 时间序列；无数据时返回全零序列。
- **异常**：
  - `CustomException` — 参数校验失败（如 `bk_biz_ids` 含 `-1`、时间跨度超限、起止时间非法）。
- **约束**：
  - 合并展开后的查询 Issue 数量不能超过 1000，否则抛 `ValueError`。
  - member 的趋势会计入对应主 Issue。
- **使用示例**：

  ```python
  from core.drf_resource import resource

  result = resource.issue.issue_trend.request({
      "bk_biz_ids": [2],
      "issue_ids": ["1751222400abc12345"],
      "trend_start_time": 1751222400,
      "trend_end_time": 1751308800,
  })
  print(result["1751222400abc12345"])
  ```

## 内部能力类（供 Resource 内部使用，也可在扩展/单测中直接调用）

### `IssueQueryHandler`

契约来源：`IssueQueryHandler`（`fta_web.issue.handlers.issue`）

#### `__init__(...)`

- **用途**：构造一个 Issue 查询上下文；所有搜索/TopN/趋势方法共享同一套过滤条件。
- **关键参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_ids` | `list[int]` | 否 | 业务范围；`None` 表示只查当前用户负责 |
  | `username` | `str` | 否 | 负责人判定依据；默认从当前请求取 |
  | `status` | `list[str]` | 否 | 支持虚拟状态 `MY_ASSIGNEE` / `NO_ASSIGNEE` |
  | `conditions` | `list[dict]` | 否 | 结构化条件；会经 `IssueQueryTransformer` 转换字段名 |
  | `query_string` | `str` | 否 | query_string 查询串 |
  | `ordering` | `list[str]` | 否 | 排序字段；默认 `[-first_alert_time, priority, status]` |
  | `page` / `page_size` | `int` | 否 | 分页参数 |
  | `fingerprint` | `str` | 否 | 指纹精确过滤 |

- **约束**：
  - 构造时会立即解析业务权限；`authorized_bizs` / `unauthorized_bizs` 后续不再变化。
  - `end_time` 会被收敛到 `min(now + 60, end_time)`。

#### `search(show_aggs=False, show_dsl=False, show_trend=True)`

- **用途**：执行 Issue 列表查询并返回完整结果。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `show_aggs` | `bool` | 否 | 是否计算并返回高级筛选聚合 |
  | `show_dsl` | `bool` | 否 | 是否在结果中附带 ES DSL |
  | `show_trend` | `bool` | 否 | 是否为每行填充 `trend` / `alert_count` / `anomaly_message` |

- **返回**：`dict` — 同 `SearchIssueResource` 的返回结构。
- **异常**：查询失败时会返回空结果并把异常带在 `exc.data` 上抛出。
- **使用示例**：

  ```python
  from fta_web.issue.handlers.issue import IssueQueryHandler

  handler = IssueQueryHandler(
      bk_biz_ids=[2],
      status=["unresolved"],
      page=1,
      page_size=10,
  )
  result = handler.search(show_aggs=True, show_trend=False)
  ```

#### `top_n(fields, size=10, translators=None, char_add_quotes=True)`

- **用途**：按字段聚合 TopN 桶。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `fields` | `list[str]` | 是 | 聚合字段列表；带 `+/-` 前缀控制排序 |
  | `size` | `int` | 否 | 每个字段返回桶数；超过 10000 会被截断 |
  | `translators` | `dict[str, AbstractTranslator]` | 否 | 字段翻译器；默认包含 status/priority/bk_biz_id/strategy_id |
  | `char_add_quotes` | `bool` | 否 | 字符字段的桶 id 是否加双引号 |

- **返回**：`dict` — 同 `IssueTopNResource`。
- **使用示例**：

  ```python
  handler = IssueQueryHandler(bk_biz_ids=[2])
  result = handler.top_n(fields=["priority", "bk_biz_id"], size=5)
  ```

#### `get_alert_trend(issue_ids)`

- **用途**：查询指定 Issue ID 的趋势时间序列。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `issue_ids` | `list[str]` | 是 | 待查询 Issue ID 列表 |

- **返回**：`dict[str, list[list[int]]]` — key 为原请求 `issue_id`。
- **约束**：
  - 需在构造时传入 `trend_start_time` / `trend_end_time`。
  - 合并展开后 Issue 数量不能超过 1000。
- **使用示例**：

  ```python
  handler = IssueQueryHandler(
      bk_biz_ids=[2],
      trend_start_time=1751222400,
      trend_end_time=1751308800,
  )
  result = handler.get_alert_trend(["1751222400abc12345"])
  ```

### `IssueQueryTransformer`

契约来源：`IssueQueryTransformer`（`fta_web.issue.handlers.issue`）

#### `transform_query_string(query_string, context=None)` / `transform_condition_fields(conditions)` / `transform_ordering_fields(ordering)`（继承自 `BaseQueryTransformer`）

- **用途**：把前端 query_string / 结构化条件 / 排序字段转换为 ES 可执行的 query_string 或 DSL。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `query_string` | `str` | 是 | 原始查询串 |
  | `context` | `dict` | 否 | 语法树遍历上下文 |

- **返回**：`str` 或 `dict` — 字符串表示可直接用于 ES `query_string` 查询；字典表示含嵌套字段，已降级为 DSL。
- **约束**：
  - `status:未解决` 会被翻译为 `status:unresolved`。
  - `priority` 同理支持中文显示名翻译。
  - 条件与排序字段通过 `transform_field_to_es_field` 映射；排序会按 `for_agg=True` 解析为聚合字段。

## 虚拟状态说明

Issue 真实状态存储为 `pending_review` / `unresolved` / `resolved` / `archived`。查询层额外提供两个虚拟状态，仅在 `status` 过滤参数中生效：

| 虚拟状态 | 语义 | 转换后的 ES 条件 |
|----------|------|------------------|
| `MY_ASSIGNEE` | 当前请求用户为负责人 | `assignee = request_username` |
| `NO_ASSIGNEE` | Issue 未分派 | `assignee` 字段不存在 |

契约来源：`IssueQueryHandler.get_search_object`（`fta_web.issue.handlers.issue`）

## 字段查询速查

| 前端字段 | ES 实际字段 | 查询方式 |
|----------|-------------|----------|
| `name` | `name.raw` | terms / wildcard（包含时） |
| `strategy_name` | `strategy_name.raw` | terms / wildcard |
| `fingerprint` | `fingerprint` | term |
| `impact_scope.{dim}` | `impact_scope.{dim}.instance_list.{id_field}` | exists / terms |
| `dimension_values.{key}` | `dimension_values.{key}` | terms |
| `impact_dimensions` | 多维度 exists filters | filters 聚合 |

契约来源：`IssueQueryTransformer.KEYWORD_FIELD_MAPPING`、`IssueQueryHandler.parse_condition_item`、`IssueQueryHandler.add_agg_bucket`（`fta_web.issue.handlers.issue`）
