## Issue 列表搜索流程

- **业务目标**：按业务、状态、时间等条件检索 Issue 列表，并展示聚合统计。
- **调用顺序**：
  1. 调用 `resource.issue.search_issue()` 传入过滤与分页参数。
  2. Resource 使用 `IssueSearchSerializer` 校验参数并构造 `IssueQueryHandler`。
  3. Handler 调用 `search()` 执行 ES 查询、聚合、结果后处理与趋势填充。
  4. 调用方消费返回的 `issues`、`total`、`aggs`。
- **事务边界**：无数据库事务；异常时返回部分结果并把异常挂在 `exc.data` 上。
- **预期结果**：返回当前用户可见的 Issue 列表与命中总数；`show_aggs=True` 时附带高级筛选聚合。
- **错误处理**：参数校验失败直接抛 `CustomException`；ES 查询失败则返回空列表并把异常带在返回数据中抛出。
- **使用示例**：

  ```python
  from core.drf_resource import resource

  result = resource.issue.search_issue.request({
      "bk_biz_ids": [2, 3],
      "status": ["unresolved", "MY_ASSIGNEE"],
      "conditions": [
          {"key": "priority", "value": ["P0", "P1"], "method": "eq", "condition": "or"},
      ],
      "query_string": "name:\"CPU\"",
      "start_time": 1751222400,
      "end_time": 1751308800,
      "ordering": ["-first_alert_time"],
      "page": 1,
      "page_size": 20,
      "show_aggs": True,
      "show_trend": False,
  })
  for issue in result["issues"]:
      print(issue["id"], issue["name"], issue["status_display"])
  ```

## Issue TopN 聚合流程

- **业务目标**：统计 Issue 在指定字段上的分布，如优先级占比、影响范围维度分布。
- **调用顺序**：
  1. 调用 `resource.issue.issue_top_n()` 传入 `fields`、`size` 与过滤条件。
  2. `IssueTopNResource` 解析业务权限、去重 `fields`、判断是否启用时间分片。
  3. 若时间跨度 ≤7 天，直接单次 ES 聚合；若 >7 天，切分为多个时间片并行查询后合并桶。
  4. 返回每个字段的 TopN 桶与命中总数。
- **事务边界**：无数据库事务；分片查询通过 `bulk_request` 多线程执行，单分片失败会抛异常。
- **预期结果**：返回 `doc_count` 与 `fields` 列表，每个字段含 `bucket_count` 与 `buckets`。
- **错误处理**：参数校验失败抛 `CustomException`；分片全部失败时抛首个异常；部分失败由 `bulk_request` 决定。
- **使用示例**：

  ```python
  from core.drf_resource import resource

  result = resource.issue.issue_top_n.request({
      "bk_biz_ids": [2],
      "fields": ["-priority", "impact_dimensions", "impact_scope.host"],
      "size": 10,
      "start_time": 1751222400,
      "end_time": 1751308800,
      "need_time_partition": True,
  })
  for field in result["fields"]:
      print(f"{field['field']}: total buckets {field['bucket_count']}")
      for bucket in field["buckets"]:
          print("  ", bucket["name"], bucket["count"])
  ```

## Issue 趋势统计流程

- **业务目标**：查看一个或多个 Issue 在指定时间范围内的告警数量变化趋势。
- **调用顺序**：
  1. 调用 `resource.issue.issue_trend()` 传入 `bk_biz_ids`、`issue_ids`、`trend_start_time`、`trend_end_time`。
  2. `IssueTrendResource` 先过滤出当前用户可见的 Issue ID。
  3. `IssueQueryHandler.get_alert_trend()` 加载合并上下文，将主 Issue 展开为 `[main, ...members]`。
  4. 按 100 个 Issue 一批查询 `IssueAlertDateHistogramResultResource.date_histogram`。
  5. 按 display_id 折叠 member 数据到主 Issue，返回每个原请求 ID 的时间序列。
- **事务边界**：无数据库事务。
- **预期结果**：返回 `dict[issue_id, list[[timestamp_ms, count]]]`；无数据时返回对应时间粒度的全零序列。
- **错误处理**：
  - `bk_biz_ids` 含 `-1`、时间跨度 >7 天、起止时间非法会抛 `CustomException`。
  - 合并展开后超过 1000 个 Issue 抛 `ValueError`。
- **使用示例**：

  ```python
  from core.drf_resource import resource

  result = resource.issue.issue_trend.request({
      "bk_biz_ids": [2],
      "issue_ids": [
          "1751222400abc12345",
          "1751222500def67890",
      ],
      "trend_start_time": 1751222400,
      "trend_end_time": 1751308800,
  })
  for issue_id, series in result.items():
      print(issue_id, series)
  ```

## 流程对比

| 流程 | 核心 Resource | 主要输出 | 是否支持时间分片 | 是否涉及 AlertDocument |
|------|---------------|----------|------------------|------------------------|
| Issue 列表搜索 | `SearchIssueResource` | Issue 列表 + 聚合 + 趋势 | 否（趋势内部可分片） | 是（当 `show_trend=True`） |
| Issue TopN | `IssueTopNResource` | 字段分布桶 | 是 | 否 |
| Issue 趋势 | `IssueTrendResource` | 时间序列 | 是 | 是 |
