## IssueQueryTransformer

```python
class IssueQueryTransformer(BaseQueryTransformer):
    """将前端查询参数转换为 ES DSL"""
    
    FIELD_MAP = {
        "name": "name.raw",           # 精确查询
        "strategy_name": "strategy_name.raw",  # 精确查询
        "fingerprint": "fingerprint", # 本身是 keyword
        "impact_scope.{dim}": "impact_scope.{dim}.instance_list.{id_field}",  # exists 查询
    }
```

## 排序规则

## 虚拟状态处理

- `MY_ASSIGNEE`：当前用户为负责人的 Issue
- `NO_ASSIGNEE`：未指派的 Issue

在 `IssueQueryHandler` 中转换为 ES 查询条件。
