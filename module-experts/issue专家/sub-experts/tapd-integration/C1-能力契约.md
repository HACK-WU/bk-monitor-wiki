## 授权 URL 生成

### `generate_auth_url`

契约来源：`fta_web.issue.utils.tapd.generate_auth_url`

- **用途**：生成 TAPD 用户态 OAuth 授权 URL，前端引导用户跳转完成授权。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 蓝鲸业务 ID，用于写入 signed_state |
  | `bk_tenant_id` | str | 是 | 租户 ID，写入 signed_state 并在回调时定位 token 存储 |
  | `initiator` | str | 是 | 发起授权的用户名，回调时校验与当前登录用户一致 |
  | `success_url` | str | 是 | 授权成功后 302 重定向的前端地址（可含 `#`） |
  | `error_url` | str | 是 | 授权失败/取消后重定向的前端地址，缺省时回退到 `success_url` |
  | `backend_callback` | str | 是 | 后端 OAuth 回调绝对地址，需与 TAPD 应用白名单一致 |

- **返回**：`str` — TAPD 授权 URL，携带 `client_id`、`redirect_uri`、`scope`、`state`。
- **异常**：`ValidationError("backend_callback is empty")` — 回调地址为空。
- **约束**：
  - `state` 为自包含 signed_state，TTL 15 分钟。
  - `scope` 固定为 `story#read story#write bug#read bug#write`。
  - `redirect_uri` 与 `state` 均经过 URL 编码。

**使用示例**：

```python
from django.urls import reverse
from bkmonitor.utils.request import get_request
from fta_web.issue.utils.tapd import generate_auth_url

request = get_request()
bk_biz_id = 2
bk_tenant_id = "default"
username = request.user.username
backend_callback = request.build_absolute_uri(reverse("fta_web:tapd_user_oauth_callback"))

auth_url = generate_auth_url(
    bk_biz_id=bk_biz_id,
    bk_tenant_id=bk_tenant_id,
    initiator=username,
    success_url="/fta/issue/?tab=tapd#success",
    error_url="/fta/issue/?tab=tapd#error",
    backend_callback=backend_callback,
)
# 前端使用：window.location.href = auth_url
```

### `generate_install_url`

契约来源：`fta_web.issue.utils.tapd.generate_install_url`

- **用途**：生成 TAPD 应用态授权（`open_app_install`）URL，用于项目级应用安装/重新授权。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 蓝鲸业务 ID |
  | `bk_tenant_id` | str | 是 | 租户 ID |
  | `space_uid` | str | 是 | 业务空间 UID |
  | `initiator` | str | 是 | 发起人，回调时写入 binding 的 `create_user` |
  | `success_url` | str | 是 | 安装成功后 302 重定向地址 |
  | `error_url` | str | 是 | 安装失败后重定向地址 |
  | `backend_callback` | str | 是 | 后端应用安装回调绝对地址 |

- **返回**：`str` — TAPD `open_app_install` URL，末尾保留 `#selected_workspace_id={workspace_id}` 占位。
- **异常**：`ValidationError("backend_callback is empty")` — 回调地址为空。
- **约束**：
  - `test` 参数：生产环境传 `0`，其余环境传 `1`。
  - `show_installed=1` 表示在列表中展示已授权项目。
  - `cb` 参数仅包含 scheme+host+path，便于白名单配置。

**使用示例**：

```python
from django.urls import reverse
from bkmonitor.utils.request import get_request
from fta_web.issue.utils.tapd import generate_install_url

request = get_request()
backend_callback = request.build_absolute_uri(reverse("fta_web:tapd_app_install_callback"))
install_url = generate_install_url(
    bk_biz_id=2,
    bk_tenant_id="default",
    space_uid="bkcc__2",
    initiator=request.user.username,
    success_url="/fta/issue/?tab=tapd#success",
    error_url="/fta/issue/?tab=tapd#error",
    backend_callback=backend_callback,
)
```

## 用户态授权

### `save_tapd_token`

契约来源：`fta_web.issue.utils.tapd.save_tapd_token`

- **用途**：将 TAPD 用户态 access_token 加密后写入 Redis。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `tenant_id` | str | 是 | 租户 ID |
  | `username` | str | 是 | 用户名，与 tenant_id 共同组成 Redis key |
  | `token_data` | dict | 是 | TAPD 原始 token 响应，必须含 `access_token` |
  | `expires_in` | int | 否 | 过期秒数，默认 7200 |
  | `cipher` | AESCipher | 否 | 可选加密器，默认使用 `SECRET_KEY` 构造 |

- **返回**：`None`
- **异常**：无显式抛错；参数缺失或 `access_token` 为空时仅记录 warning 并返回。
- **约束**：Redis key 为 `tapd_uat:{tenant_id}:{username}`；token 经 AES 加密存储。

### `get_tapd_token`

契约来源：`fta_web.issue.utils.tapd.get_tapd_token`

- **用途**：从 Redis 取出并解密 TAPD 用户态 token。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_tenant_id` | str | 是 | 租户 ID |
  | `username` | str | 是 | 用户名 |

- **返回**：`dict` — 包含 `access_token`、`type`、`user_id`、`expires_at`；未找到或解密失败返回 `{}`。
- **约束**：解密失败会自动删除脏数据，避免重复失败。

### `delete_tapd_token`

契约来源：`fta_web.issue.utils.tapd.delete_tapd_token`

- **用途**：删除 Redis 中的 TAPD 用户态 token（解绑/重新授权/撤销授权时调用）。
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `tenant_id` | str | 是 | 租户 ID |
  | `username` | str | 是 | 用户名 |

- **返回**：`None`

**使用示例**：

```python
from fta_web.issue.utils.tapd import save_tapd_token, get_tapd_token, delete_tapd_token

save_tapd_token(
    tenant_id="default",
    username="admin",
    token_data={
        "access_token": "fake_token_example",
        "type": "user",
        "user_id": "12345",
    },
    expires_in=7200,
)

token = get_tapd_token("default", "admin")
print(token.get("access_token"))

delete_tapd_token("default", "admin")
```

## 应用态授权

### `tapd_app_install_callback`（视图）

契约来源：`fta_web.issue.resources.tapd_app_install_callback`

- **用途**：处理 TAPD `open_app_install` 回调，建立/更新 `TapdWorkspaceBinding`。
- **入口**：`GET /fta/issue/tapd/app_install_callback/?code=...&resource=...&state=...`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `state` | str | 是 | signed_state，验签后提取业务/租户/空间/发起人/回调地址 |
  | `resource` | JSON str | 否 | 包含 `workspace_id` |
  | `code` | str | 是 | 授权码（当前未实际使用，由 TAPD 规范传入） |

- **返回**：`HttpResponseRedirect` — 成功跳 `success_url`，失败跳 `error_url`，state 缺失跳 `/`。
- **约束**：
  - 必须校验 signed_state 签名与过期时间。
  - 使用 `set_local_username(initiator)` 确保审计字段正确。
  - 以 `workspace_id` 为字符串写入模型。

## 工作区查询

### `ListTapdWorkspaceResource`

契约来源：`fta_web.issue.resources.ListTapdWorkspaceResource`

- **用途**：查询当前业务已授权（应用态）的 TAPD 项目列表，并补充项目详细信息。
- **端点**：`POST /fta/issue/tapd/workspace/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `workspace_id` | int | 否 | 按项目 ID 过滤 |
  | `created` | str | 否 | 创建时间，格式 `YYYY-MM-DD`，支持范围查询 |
  | `limit` | int | 否 | 返回数量限制，默认 30，最大 200 |
  | `page` | int | 否 | 页码，默认 1 |
  | `order` | str | 否 | 排序规则，如 `created desc` |
  | `fields` | str | 否 | 返回字段，逗号分隔 |

- **返回**：`list[dict]` — 每个项目含 `workspace_id`、`workspace_name`、`pretty_name`、`created`、`creator`、`description`、`status`、`category`。
- **约束**：内部并发查询每个 workspace 的详细信息，最大并发 10。

### `ListUserTapdWorkspaceResource`

契约来源：`fta_web.issue.resources.ListUserTapdWorkspaceResource`

- **用途**：查询当前用户可见的 TAPD 项目列表，并返回授权引导 URL。
- **端点**：`POST /fta/issue/tapd/user_workspace/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `success_url` | str | 是 | 授权成功后的前端重定向地址；未授权时接口返回 403 + `auth_url` |
  | `error_url` | str | 否 | 授权失败后的前端重定向地址，缺省回退到 `success_url` |

- **返回**：`dict` — `{"total": int, "items": [...], "install_url": str, "method": "GET"}`
  - `items` 每项含 `workspace_id`、`workspace_name`、`is_bound`。
  - `is_bound` 取值：`bound`、`importable`、`stale`、`unbound`、`manually_unbound`。
  - `install_url` 仅在存在 `unbound` 或 `stale` 时生成。
- **异常**：
  - 未授权且携带 `success_url`：返回 code=403、data.auth_url。
  - 未授权且无 `success_url`：返回 code=403、提示先完成授权。
- **约束**：
  - 用户态 token 失效（422）时自动清理 token 并重新引导授权。
  - `importable` 项目会静默尝试建立本地 binding；若存在 tombstone 则标记为 `manually_unbound`。

**使用示例**：

```python
import requests

resp = requests.post(
    "http://bkmonitor.example.com/fta/issue/tapd/user_workspace/",
    json={
        "bk_biz_id": 2,
        "success_url": "/fta/issue/?tab=tapd#success",
        "error_url": "/fta/issue/?tab=tapd#error",
    },
    cookies={"bk_ticket": "..."},
)
data = resp.json()
if not data["result"] and data["code"] == 403 and data["data"].get("auth_url"):
    # 前端跳转授权
    print(data["data"]["auth_url"])
else:
    print(data["data"]["items"])
```

## TAPD 字段与单据搜索

### `GetTapdFieldsResource`

契约来源：`fta_web.issue.resources.GetTapdFieldsResource`

- **用途**：获取 TAPD story/bug 的核心字段定义（仅默认模板）。
- **端点**：`POST /fta/issue/issue/get_tapd_fields/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `workspace_id` | int | 是 | TAPD 项目 ID |
  | `tapd_type` | str | 是 | `story` 或 `bug` |
  | `template_id` | int | 否 | 模板 ID，当前仅支持 `0` |

- **返回**：`list[dict]` — 每个字段含 `field_id`、`field_name`、`field_type`、`options`、`is_core_field`、`is_selected`、`is_required`。
- **异常**：
  - 不支持的 `tapd_type` → 400。
  - `template_id != 0` → 400。
- **约束**：
  - story 核心字段：`name`、`description`、`owner`、`priority_label`、`iteration_id`。
  - bug 核心字段：`title`、`description`、`current_owner`、`priority_label`、`iteration_id`、`te`；返回时 `title` 映射为 `name`，`current_owner` 映射为 `owner`。

### `SearchTAPDItemsResource`

契约来源：`fta_web.issue.resources.SearchTAPDItemsResource`

- **用途**：在 TAPD 项目中搜索已有的 story/bug 单据。
- **端点**：`POST /fta/issue/issue/search_tapd_items/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `workspace_id` | int | 是 | TAPD 项目 ID |
  | `tapd_type` | str | 是 | `story` 或 `bug` |
  | `id` | str | 否 | 单据 ID，支持逗号分隔多 ID |
  | `name` | str | 否 | 标题模糊匹配；bug 类型实际映射为 `title` |
  | `limit` | int | 否 | 返回数量限制，默认 30，最大 200 |
  | `page` | int | 否 | 页码，默认 1 |
  | `order` | str | 否 | 排序规则，如 `created desc` |
  | `fields` | str | 否 | 返回字段，逗号分隔，默认 `id,name,status,created,priority_label` |

- **返回**：`list[dict]` — 每个单据含 `id`、`name`（bug 由 `title` 映射而来）、`status`、`created`、`priority_label`、`status_display_name`、`bk_biz_id`、`workspace_id`、`tapd_type`。
- **约束**：`order` 必须匹配 `"字段名 ASC|DESC"`。

**使用示例**：

```python

        "workspace_id": 10104801,
        "tapd_type": "bug",
        "name": "内存",
        "limit": 10,
    },
    cookies={"bk_ticket": "..."},
)
print(resp.json()["data"])
```

## Issue 与 TAPD 单据关联

### `CreateTapdResource`

契约来源：`fta_web.issue.resources.CreateTapdResource`

- **用途**：为指定 Issue 在 TAPD 创建 story/bug 单据，并建立本地关联。
- **端点**：`POST /fta/issue/issue/create_tapd/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `issue_id` | str | 是 | Issue ID |
  | `tapd_type` | str | 是 | `story` 或 `bug` |
  | `workspace_id` | int | 是 | TAPD 项目 ID |
  | `name` | str | 是 | 单据标题 |
  | `description` | str | 是 | 详细描述 |
  | `owner` | str | 是 | 处理人，支持多成员 `aaa;bbb;` |
  | `priority_label` | str | 是 | 优先级 |
  | `iteration_id` | str | 是 | 迭代 ID |
  | `te` | str | 否 | 测试人员；**bug 类型必填** |
  | `sync_status` | bool | 是 | TAPD 单据完成时是否自动同步 Issue 状态 |

- **返回**：`dict` — 创建的 TAPD 单据信息，含 `tapd_id`、`tapd_type`、`name`、`description`、`owner`、`priority_label`、`iteration_id`、`te`（bug）、`bk_biz_id`、`issue_id`、`workspace_id`、`sync_status`、`activities`。
- **异常**：
  - Issue 不存在或归属错误 → 404。
  - Issue 处于合并冻结状态 → `MERGE_FREEZE_VIOLATION`。
  - bug 类型未传 `te` → 400。
- **约束**：
  - 调用 TAPD API 创建单据后写入 `IssueTapdRelation`，`link_mode` 为 `create`。
  - 同步在 ES 写入 `CREATE_TAPD` 活动日志，失败会重试一次，仍失败不影响主流程但活动日志不会出现在返回中。

**使用示例**：

```python
import requests

resp = requests.post(
    "http://bkmonitor.example.com/fta/issue/issue/create_tapd/",
    json={
        "bk_biz_id": 2,
        "issue_id": "2026073100000001abc12345",
        "tapd_type": "bug",
        "workspace_id": 10104801,
        "name": "【监控告警】CPU 使用率异常",
        "description": "关联告警已聚合为 Issue，详见监控平台。",
        "owner": "zhangsan",
        "priority_label": "高",
        "iteration_id": "123456789",
        "te": "lisi",
        "sync_status": True,
    },
    cookies={"bk_ticket": "..."},
)
print(resp.json()["data"])
```

### `LinkIssueToTapdResource`

契约来源：`fta_web.issue.resources.LinkIssueToTapdResource`

- **用途**：将 Issue 与已有的 TAPD 单据建立关联。
- **端点**：`POST /fta/issue/issue/link_tapd/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `issue_id` | str | 是 | Issue ID |
  | `workspace_id` | int | 是 | TAPD 项目 ID |
  | `tapd_items` | list | 是 | TAPD 单据列表，每项 `{tapd_id, tapd_type, tapd_title}`；1~200 条 |
  | `sync_status` | bool | 是 | 是否同步单据状态 |

- **返回**：`dict` — `{"info": [...], "activities": [...]}`；`info` 为关联结果列表，每项含 `relation_id`、`bk_biz_id`、`issue_id`、`workspace_id`、`tapd_id`、`tapd_type`、`tapd_title`、`sync_status`。
- **异常**：
  - Issue 不存在/归属错误/合并冻结 → 报错。
  - TAPD 项目未与当前业务关联 → 400。
  - 单据不存在或不属于该项目 → 400。
  - `tapd_items` 内 `tapd_id` 重复 → 400。
- **约束**：
  - 已存在的关联会更新 `sync_status`，不会重复创建。
  - 仅对实际新建的关联记录写入 `TAPD_LINK` 活动日志。

**使用示例**：

```python
import requests

resp = requests.post(
    "http://bkmonitor.example.com/fta/issue/issue/link_tapd/",
    json={
        "bk_biz_id": 2,
        "issue_id": "2026073100000001abc12345",
        "workspace_id": 10104801,
        "tapd_items": [
            {"tapd_id": "12345", "tapd_type": "story", "tapd_title": "需求示例"},
            {"tapd_id": "12346", "tapd_type": "bug", "tapd_title": "缺陷示例"},
        ],
        "sync_status": False,
    },
    cookies={"bk_ticket": "..."},
)
print(resp.json()["data"])
```

## 工作区解绑/重绑/撤销授权

### `UnbindTapdWorkspaceResource`

契约来源：`fta_web.issue.resources.UnbindTapdWorkspaceResource`

- **用途**：手动解除 TAPD 项目与当前业务的关联。
- **端点**：`POST /fta/issue/tapd/unbind_workspace/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `workspace_id` | str | 是 | TAPD 项目 ID |

- **返回**：`{"success": True}`
- **异常**：
  - 项目未关联 → 404。
  - 存在活跃（待审核/未解决）Issue 关联该项目 → 400。
- **约束**：
  - 在同一事务中写入 tombstone（`TapdWorkspaceManualUnbind`）并删除 `TapdWorkspaceBinding`。
  - 不撤回 TAPD 侧的应用授权。

**使用示例**：

```python
import requests

resp = requests.post(
    "http://bkmonitor.example.com/fta/issue/tapd/unbind_workspace/",
    json={"bk_biz_id": 2, "workspace_id": "10104801"},
    cookies={"bk_ticket": "..."},
)
print(resp.json()["data"])
```

### `RebindTapdWorkspaceResource`

契约来源：`fta_web.issue.resources.RebindTapdWorkspaceResource`

- **用途**：重新关联已手动解绑的 TAPD 项目。
- **端点**：`POST /fta/issue/tapd/rebind_workspace/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID |
  | `workspace_id` | str | 是 | TAPD 项目 ID |

- **返回**：`{"success": True, "workspace": {"id": ..., "name": ...}}`
- **异常**：
  - 用户态 token 失效 → code=403。
  - 当前用户无权访问该 TAPD 项目 → 由 TAPD API 报错。
  - 应用态授权已失效 → code=403。
- **约束**：
  - 在同一事务中删除 tombstone 并创建/复用 `TapdWorkspaceBinding`。
  - 若 binding 已存在，仅清理 tombstone 后返回现有 binding。

**使用示例**：

```python
import requests

resp = requests.post(
    "http://bkmonitor.example.com/fta/issue/tapd/rebind_workspace/",
    json={"bk_biz_id": 2, "workspace_id": "10104801"},
    cookies={"bk_ticket": "..."},
)
print(resp.json()["data"])
```

### `RevokeTapdUserAuthResource`

契约来源：`fta_web.issue.resources.RevokeTapdUserAuthResource`

- **用途**：撤销当前用户的 TAPD 用户态授权。
- **端点**：`POST /fta/issue/tapd/revoke_auth/`
- **参数**：

  | 参数名 | 类型 | 必填 | 含义与行为语义 |
  |--------|------|------|----------------|
  | `bk_biz_id` | int | 是 | 业务 ID，用于定位租户 |

- **返回**：`{"success": True, "message": "授权已撤销"}`
- **约束**：仅清除 Redis token，不删除 `TapdWorkspaceBinding` 和 `IssueTapdRelation`。
