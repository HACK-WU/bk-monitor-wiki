## 简介

TAPD 集成对外暴露两类入口：

1. Issue ViewSet 下的 RESTful Resource 端点（`views.py` + `resources.py`）。
2. 独立的 OAuth/应用安装回调视图（`urls.py` 直接注册）。

所有写操作需要 IAM `MANAGE_EVENT`，只读操作需要 `VIEW_EVENT`；TAPD 相关接口额外前置校验用户态 token。

章节来源：[Issue 视图与权限](file://bkmonitor/packages/fta_web/issue/views.py#L1-L247)

## 契约示例

### 用户态授权引导

**请求**：

```bash
curl -X POST "http://bkmonitor.example.com/fta/issue/tapd/user_workspace/" \
  -H "Content-Type: application/json" \
  -b "bk_ticket=..." \
  -d '{"bk_biz_id": 2, "success_url": "/fta/issue/?tab=tapd#success"}'
```

**未授权响应**（HTTP 200，业务 code=403）：

```json
{
  "result": false,
  "code": 403,
  "message": "TAPD 用户态授权未生效",
  "data": {
    "auth_url": "https://tapd.example.com/oauth?response_type=code&..."
  }
}
```

## TAPD 端点清单

本模块通过 `api.tapd.*` 调用 TAPD 平台接口，核心端点如下：

| 内部调用 | TAPD action | 方法 | 认证 | 用途 |
|----------|-------------|------|------|------|
| `api.tapd.get_granted_workspaces` | `app_auth/get_granted_workspaces` | GET | Basic Auth | 应用态已授权项目 |
| `api.tapd.get_participant_projects` | `workspaces/get_participant_projects` | GET | Bearer Token | 用户态参与项目 |
| `api.tapd.get_workspace_info` | `workspaces/get_workspace_info` | GET | Basic/Bearer | 项目信息 |
| `api.tapd.get_story_fields_info` | `stories/get_fields_info` | GET | Basic Auth | 需求字段定义 |
| `api.tapd.get_bug_fields_info` | `bugs/get_fields_info` | GET | Basic Auth | 缺陷字段定义 |
| `api.tapd.get_stories` | `stories` | GET | Basic Auth | 需求列表 |
| `api.tapd.get_bugs` | `bugs` | GET | Basic Auth | 缺陷列表 |
| `api.tapd.add_story` | `stories` | POST | Basic Auth | 创建需求 |
| `api.tapd.add_bug` | `bugs` | POST | Basic Auth | 创建缺陷 |
| `api.tapd.user_oauth_token` | `tokens/request_token` | POST | Basic Auth | code 换 token |

## 错误码

| 码 | 含义 | 触发条件 |
|----|------|----------|
| 200 | 业务成功 | 正常处理 |
| 400 | 请求参数错误 | 序列化器校验失败、字段不支持、单据不存在等 |
| 403 | 权限/授权相关 | IAM 无权限、TAPD 用户态未授权、应用态未授权、token 失效 |
| 404 | 资源不存在 | Issue 不存在、工作区未绑定 |
| 500 | 服务端错误 | TAPD API 异常、ES 写入失败等 |

特殊业务码：

| 码 | 含义 | 来源 |
|----|------|------|
| `MERGE_FREEZE_VIOLATION` | Issue 处于合并冻结状态，禁止操作 | `IssueMergeResolver.assert_not_frozen` |

## 版本与鉴权

- **版本**：当前接口未显式携带版本号，统一走 `/fta/issue/` 前缀。
- **IAM**：基于 `bkmonitor.iam` 的 `IssueBusinessActionPermission`，对批量操作从 `issues[*].bk_biz_id` 提取业务 ID 分别校验。
- **TAPD 用户态鉴权**：`TAPDAuthPermission` 校验 Redis `tapd_uat:{tenant}:{user}`；未授权时 `tapd/user_workspace` 返回 `auth_url`，其余接口仅提示未授权。
- **TAPD 应用态鉴权**：通过 `settings.TAPD_APP_ID` + `settings.TAPD_APP_SECRET` 生成 Basic Auth 调用 TAPD API。
- **回调安全**：`signed_state` 使用 HMAC-SHA256 签名 + 15 分钟过期，防止篡改与重放。

章节来源：[Issue 视图与权限](file://bkmonitor/packages/fta_web/issue/views.py#L1-L247)、[TAPD 工具函数](file://bkmonitor/packages/fta_web/issue/utils/tapd.py#L151-L205)

## 结论

- TAPD 集成的接口权限分层清晰：IAM 负责业务权限，TAPDAuthPermission 负责 TAPD 用户态授权，Basic/Bearer 负责 TAPD 平台鉴权。
- 所有写操作均为同步外部调用，TAPD API 延迟直接影响响应时间；批量场景（如并发查 workspace 详情）已做并发优化。
- 回调接口均标记 `csrf_exempt`，安全完全依赖 `signed_state` 验签，需确保 `SECRET_KEY` 安全。
