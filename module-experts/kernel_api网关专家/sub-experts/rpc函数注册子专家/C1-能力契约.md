# C1-能力契约：RPC 函数注册子专家

> 黑盒契约。代码示例为使用方代码（经 `KernelRPCResource` 的调用协议）。

## 1. KernelRPCRegistry 注册 API

### register(func_name, *, summary, description, params_schema=None, example_params=None)
- **用途**：装饰器工厂，把 handler 函数注册为 RPC 函数并原样返回。
- **参数行为语义**：`func_name` 禁止为 `__meta__`；`params_schema`/`example_params` 可选，供 `__meta__` detail 披露。
- **返回**：装饰器（用于 `@KernelRPCRegistry.register(...)`）。
- **异常**：`func_name` 为空抛 `ValueError`；为 `__meta__` 抛 `ValueError`。
- **契约来源**：`kernel_api.rpc.registry.KernelRPCRegistry.register`

### register_function(*, func_name, handler, summary, description, ...)
- **用途**：直接注册 handler 为 RPC 函数。
- **契约来源**：`kernel_api.rpc.registry.KernelRPCRegistry.register_function`

### register_resource(*, func_name, resource_cls, summary, description=None, ...)
- **用途**：把现成 `Resource` 子类包装为 RPC 函数（handler 为 `lambda params: resource_cls().request(params)`）。
- **参数行为语义**：`description` 缺省取 `resource_cls.__doc__`；`params_schema` 缺省由 `build_resource_params_schema` 从 RequestSerializer 反射生成 `{resource, request_serializer, request_params}`。
- **契约来源**：`kernel_api.rpc.registry.KernelRPCRegistry.register_resource`

### register_resource_list(resource_rpcs)
- **用途**：批量 `register_resource`，供 `RESOURCE_RPCS` 列表机制使用。
- **契约来源**：`kernel_api.rpc.registry.KernelRPCRegistry.register_resource_list`

## 2. 元协议与执行

### list_functions() / get_function_detail(func_name)
- **用途**：返回全部函数摘要列表 / 单个函数详情（含 `params_schema`）。
- **参数行为语义**：`func_name="__meta__"` 时 `get_function_detail` 返回内置元协议说明。
- **返回**：摘要列表 `[{func_name, summary}]` / 详情 dict 或 `None`。
- **契约来源**：`kernel_api.rpc.registry.KernelRPCRegistry.list_functions/get_function_detail`

### execute(func_name, params)
- **用途**：按名执行 RPC 函数。
- **参数行为语义**：`func_name` 未注册时抛 `CustomException`（message 提示先查 `__meta__`）。
- **返回**：handler 的返回值（结构因函数而异）。
- **约束**：调用前应经 `inject_bk_tenant_id` 注入租户（`KernelRPCResource.perform_request` 已处理）。
- **契约来源**：`kernel_api.rpc.registry.KernelRPCRegistry.execute`

### KernelRPCResource（对外统一入口）
- **用途**：HTTP 暴露 RPC 调用（views/v4/kernel_rpc.py 的 `KernelRPCViewSet` 挂载）。
- **请求**：`{func_name, params}`。
  - `func_name="__meta__"` → `params.action` 为 `list`（返回函数列表）或 `detail`（`params.target_func_name` 必填）。
  - 其他 → `params` 经 `inject_bk_tenant_id` 注入租户后执行。
- **响应**：`{func_name, protocol, result}`，`protocol` 为 `meta` 或 `call`。
- **异常**：`__meta__` 不支持的 action 抛 `CustomException`；detail 未找到抛 `CustomException`。
- **契约来源**：`kernel_api.resource.kernel_rpc.KernelRPCResource`

### 使用示例（HTTP 调用 RPC）
```python
import requests
headers = {"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>", "X-Bk-Tenant-Id": "default"}

# 1) 查函数列表
resp = requests.post("https://<host>/api/v4/call/",
                     json={"func_name": "__meta__", "params": {"action": "list"}}, headers=headers)
print(resp.json()["data"]["result"]["functions"])

# 2) 查函数详情（参数 schema）
resp = requests.post("https://<host>/api/v4/call/",
                     json={"func_name": "__meta__", "params": {"action": "detail", "target_func_name": "admin.cluster_info.list"}},
                     headers=headers)
print(resp.json()["data"]["result"]["function"]["params_schema"])

# 3) 正式调用（bk_tenant_id 可省略，自动按 bk_biz_id 反查）
resp = requests.post("https://<host>/api/v4/call/",
                     json={"func_name": "admin.cluster_info.list", "params": {"bk_biz_id": 2}},
                     headers=headers)
print(resp.json()["data"]["result"])
```

## 3. BkmCliOpRegistry（op 白名单）

### resolve(op_id)
- **用途**：op_id → `BkmCliOpFunction` 解析。
- **参数行为语义**：先 `KernelRPCRegistry.ensure_loaded()`；未命中抛 `BkmCliOpNotFound`（code 404，extra 注入 `code=404`）。
- **返回**：`BkmCliOpFunction`（含 `func_name` / `capability_level` / `risk_level` / `requires_confirmation` / `audit_tags`）。
- **契约来源**：`kernel_api.rpc.bkm_cli_registry.BkmCliOpRegistry`

### BkmCliOpCallResource（bkm-cli 服务端入口）
- **用途**：HTTP 暴露 op 调用（views/v4/bkm_cli.py 的 `BkmCliViewSet` 挂载）。
- **请求**：`{op_id, params}`——客户端**只能传 op_id，不能指定 func_name**（防绕过白名单）。
- **响应**：`{op_id, func_name, protocol: "bkm_cli_op_call", result, audit}`；result 经 `json.dumps(default=str)` 统一 JSON-safe 归一。
- **异常**：op_id 未注册抛 404（`BkmCliOpNotFound`）。
- **契约来源**：`kernel_api.resource.bkm_cli.BkmCliOpCallResource`

## 4. 租户推断（rpc/tenant.py）

### inject_bk_tenant_id(params)
- **用途**：入参归一化：显式 `bk_tenant_id` 优先；否则按标识字段反查唯一租户并回填。
- **返回**：新 dict（不改原 params）。
- **行为语义**：反查不唯一（多租户）抛 `CustomException`；查不到不注入。
- **契约来源**：`kernel_api.rpc.tenant.inject_bk_tenant_id`

### infer_bk_tenant_id(params)
- **用途**：从标识字段反查租户。
- **支持字段**：`bk_biz_id(s)`（`bk_biz_id_to_bk_tenant_id`）、`space_uid(s)`（Space 表）、`bk_data_id(s)`（DataSource 表）、`table_id(s)`（ResultTable 表，经 `reformat_table_id` 归一）、`time_series_group_id(s)`（TimeSeriesGroup 表）。
- **异常**：单字段多租户或跨字段租户不一致抛 `CustomException`。
- **契约来源**：`kernel_api.rpc.tenant.infer_bk_tenant_id`
