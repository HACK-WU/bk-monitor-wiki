# C2-使用流程：RPC 函数注册子专家

## 流程 1：新增一个 admin 巡检函数

**业务目标**：新增 `admin.xxx.yyy` 运维巡检函数。

**调用顺序**：
1. 在 `rpc/functions/admin/{domain}.py` 定义 handler + `@KernelRPCRegistry.register(func_name="admin.{domain}.{op}", summary=..., description=...)`。
2. 确认 `admin/__init__.py` 已 import 该模块（`load_builtin_functions` 按子包 `__init__.py` 触发导入期注册）。
3. 补 `rpc/tests/test_admin_*.py` 用例。

**事务边界**：函数为只读语义，不做写库。

**预期结果**：`__meta__` list 出现新函数；调用返回结构化 dict。

**代码示例**：
```python
# rpc/functions/admin/example.py
from kernel_api.rpc import KernelRPCRegistry

@KernelRPCRegistry.register(
    func_name="admin.example.overview",
    summary="示例巡检：集群概览",
    description="返回集群内存/CPU 概览。",
    example_params={"bk_biz_id": 2},
)
def example_overview(params: dict):
    # 用 get_bk_tenant_id(params) 取租户（admin/common.py）
    return {"clusters": [], "total": 0}
```

## 流程 2：新增一个 bkm-cli 只读命令

**业务目标**：新增 bkm-cli op（带审计元数据）。

**调用顺序**：
1. 在 `rpc/functions/bkm_cli/{module}.py` 用 `KernelRPCRegistry.register(func_name="bkm_cli.xxx", ...)` 注册函数。
2. 用 `BkmCliOpRegistry.register(op_id=..., func_name=..., capability_level=..., risk_level=..., ...)` 登记 op_id 白名单。
3. 客户端经 `BkmCliOpCallResource`（`{op_id, params}`）调用。

**约束**：只读命令需通过 `platform_catalog/_lint.py` AST 只读守卫（若走 platform_catalog）。

**代码示例**：
```python
# rpc/functions/bkm_cli/example.py
from kernel_api.rpc import KernelRPCRegistry
from kernel_api.rpc.bkm_cli_registry import BkmCliOpRegistry

@KernelRPCRegistry.register(
    func_name="bkm_cli.inspect_example",
    summary="巡检示例配置",
    description="只读巡检，返回配置摘要。",
)
def inspect_example(params: dict):
    return {"status": "ok"}

BkmCliOpRegistry.register(
    op_id="inspect-example",
    func_name="bkm_cli.inspect_example",
    capability_level="read",
    risk_level="low",
    requires_confirmation=False,
    audit_tags=["example"],
)
```

## 流程 3：调用方使用 RPC（KernelRPCResource）

**业务目标**：客户端渐进式发现并调用 RPC 函数。

**调用顺序**：见 [C1-能力契约.md#2-元协议与执行](C1-能力契约.md#2-元协议与执行)——`__meta__` list → `__meta__` detail → 正式 call。

**错误处理**：`未找到可调用函数` → 函数名错误或未注册；租户推断冲突 → 显式传 `bk_tenant_id`。
