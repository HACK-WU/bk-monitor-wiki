## 注册表实现

`KernelRPCRegistry` 为全 classmethod 注册中心：
- `_functions: dict[str, KernelRPCFunction]`（dataclass：`func_name/summary/description/handler/params_schema/example_params`）。
- `_loaded` 惰性标志；`ensure_loaded()` 幂等触发 `load_builtin_functions()`。
- `register()` 是装饰器工厂：`def decorator(handler): cls.register_function(...); return handler`。
- `register_resource()` 包 handler：`lambda params: resource_cls().request(params)`；schema 由 `build_resource_params_schema` 反射 `_search_serializer_class()` 生成。
- `execute()`：查表 → `function.handler(params)`；未命中抛 `CustomException`。

章节来源：[rpc/registry.py](file://bkmonitor/kernel_api/rpc/registry.py)（关键符号：`KernelRPCFunction` / `register` / `execute`）

## 元协议实现

`KernelRPCResource.perform_request`（resource/kernel_rpc.py）：
- `func_name == "__meta__"` → `_handle_meta_protocol`：
  - `action=list` → `{protocols: [{func_name: "__meta__", ...}], functions: list_functions()}`。
  - `action=detail` → `target_func_name` 必填，`get_function_detail` 返回或抛 `CustomException`。
  - 其他 action → 抛 `CustomException`（仅支持 list/detail）。
- 其他 func_name → `params = inject_bk_tenant_id(params)` → `KernelRPCRegistry.execute(func_name, params)` → 返回 `{func_name, protocol: "call", result}`。

章节来源：[resource/kernel_rpc.py](file://bkmonitor/kernel_api/resource/kernel_rpc.py)（关键符号：`KernelRPCResource.perform_request` / `_handle_meta_protocol`）

## 租户推断实现

`rpc/tenant.py`：
- `inject_bk_tenant_id`：显式 `bk_tenant_id` 优先；否则 `infer_bk_tenant_id` 反查并回填。
- `infer_bk_tenant_id`：`_collect_identifier_values` 收集 `bk_biz_id(s)/space_uid(s)/bk_data_id(s)/table_id(s)/time_series_group_id(s)` → 逐字段 `_query_tenant_ids`：
  - `bk_biz_id` → `bk_biz_id_to_bk_tenant_id`。
  - `space_uid` → Space 表 `space_type_id__space_id`。
  - `bk_data_id` → DataSource 表。
  - `table_id` → ResultTable 表（`reformat_table_id` 归一 `xxx__yyy` 形式）。
  - `time_series_group_id` → TimeSeriesGroup 表。
- 一致性检查：任一字段多租户、或跨字段租户集不一致 → 抛 `CustomException`。

章节来源：[rpc/tenant.py](file://bkmonitor/kernel_api/rpc/tenant.py)（关键符号：`inject_bk_tenant_id` / `_query_tenant_ids`）

## bkm-cli op 调用实现

`BkmCliOpCallResource.perform_request`（resource/bkm_cli.py）：
1. `op = BkmCliOpRegistry.resolve(op_id)`——**只接受 op_id**，客户端不能指定 func_name（防绕过白名单）。
2. `params = inject_bk_tenant_id(params)`。
3. `raw_result = KernelRPCRegistry.execute(op.func_name, params)`。
4. `result = json.loads(json.dumps(raw_result, default=str))`——出口统一 JSON-safe 归一（根治 datetime/Decimal 序列化崩溃）。
5. 返回 `{op_id, func_name, protocol: "bkm_cli_op_call", result, audit}`（audit 含 `capability_level/risk_level/requires_confirmation/audit_tags`）。

章节来源：[resource/bkm_cli.py](file://bkmonitor/kernel_api/resource/bkm_cli.py)（关键符号：`BkmCliOpCallResource.perform_request`）

## 结论

RPC 层 = 注册中心（装饰器/列表双轨）+ 元协议披露 + 租户注入 + op 白名单。对外统一走 `KernelRPCResource`（func_name 协议）或 `BkmCliOpCallResource`（op_id 协议）。
