# C1-能力契约：v4 API 视图子专家

> 黑盒契约：每个 ViewSet 的 endpoint → URL + Resource 契约。代码示例为调用方代码。

## 1. 告警与事件（alert.py / event.py）

### AlertViewSet
- **用途**：全量事件中心兼容接口（endpoint 带 `/` 前缀）。
- **endpoint**：`POST alert/search`、`POST alert/export`、`GET alert/detail`、`GET alert/log`、`POST event/search`、`POST action/search`、`POST alert/close`（`CloseAlertResource`）、`POST allowed_biz`、`POST search_history`、`POST strategy_snapshot`、`POST list_index_by_host` 等。
- **返回**：对应查询结果（`{result, data}` envelope）。
- **契约来源**：`kernel_api.views.v4.alert.AlertViewSet`

### SearchAlertViewSet（MCP）
- **用途**：MCP 告警管理（复用 `kernel_api/resource/alert.py`）。
- **endpoint**：`POST search_alert`、`POST list_alert`（ListAlertResource）、`POST alert_top_n`（ListAlertTopNResource）、`POST get_strategy_snapshot`、`GET get_strategy_detail`、`POST get_alert_events`、`POST get_alert_event_ts`、`POST get_alert_event_tag_detail`、`GET get_alert_k8s_target`、`GET get_alert_host_target`、`POST get_alert_traces`、`GET get_alert_log_relations`；MCP 策略/屏蔽/通知组/套餐系列。
- **约束**：MCP 请求需认证（见认证子专家）。
- **契约来源**：`kernel_api.views.v4.alert.SearchAlertViewSet`

### EventViewSet
- **用途**：事件查询与确认。
- **endpoint**：`search_event`（SearchEvent）、`search_event_log`（SearchEventLog）、`ack_event`（AckEvent）等。
- **契约来源**：`kernel_api.views.v4.event.EventViewSet`

### 使用示例（查询告警）
```python
import requests
resp = requests.post(
    "https://<host>/api/v4/alert/search/",
    json={"bk_biz_id": 2, "condition": [], "page": 1, "page_size": 10},
    headers={"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>", "X-Bk-Tenant-Id": "default"},
)
data = resp.json()["data"]  # {"list": [...], "total": N}
```

## 2. Issue 功能（issue.py）

- **IssueViewSet** + 12 个独立 Resource，每个对应一个状态流转/操作 endpoint：
  - `assign`（AssignResource）、`resolve`（ResolveResource）、`archive`（ArchiveResource）、`reopen`（ReopenResource）、`restore`（RestoreResource）、`update_priority`（UpdatePriorityResource）、`rename`（RenameResource）、`add_follow_up`（AddFollowUpResource）、`edit_follow_up`（EditFollowUpResource）、`merge`（MergeResource）、`split`（SplitResource）、`regenerate_title`（RegenerateTitleResource）。
- **异常**：`rename` 重名抛 `IssueRenameConflictError`（code 3327001）→ kernel_api 恒 200 + body.code；web 端识别转 409。
- **契约来源**：`kernel_api.views.v4.issue.IssueViewSet` / `RenameResource`
- **完整 Issue 契约**见 [Issue 专家](../../../issue专家/C0-使用总览.md)。

### 使用示例（Issue 重命名）
```python
resp = requests.post("https://<host>/api/v4/issue/rename/",
                     json={"issue_id": "xxx", "name": "新标题", "bk_biz_id": 2},
                     headers={"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>"})
body = resp.json()
if body.get("code") == 3327001:
    print("重名冲突:", body["message"])
```

## 4. 处理套餐与动作（action_config.py / action.py）

- **ActionConfigViewSet**：`save`（SaveActionConfigResource）、`detail`（GetActionConfigResource）、`search`（ListActionConfigResource）、`edit`（EditActionConfigResource）、`delete`（DeleteActionConfigResource）。
- **ActionInstanceViewSet**：`itsm_callback`（ITSM 回调）、`batch_create_action`、`get_action_params_by_config`、`get_demo_action_context`。
- **SearchActionViewSet**：`search_action`。
- **契约来源**：`kernel_api.views.v4.action_config.ActionConfigViewSet` 等

## 5. 内核 RPC / bkm-cli / 运营指标

- **KernelRPCViewSet**：挂载 `KernelRPCResource`，endpoint `call`（`POST /api/v4/call/`，`{func_name, params}` 协议）。
- **BkmCliViewSet**：挂载 `BkmCliOpCallResource`，endpoint `op/call`（`POST /api/v4/op/call/`，`{op_id, params}` 协议）。
- **OperationViewSet**：挂载三个 Resource，endpoint 分别为 `list_operation_metrics`（ListOperationMetricsResource）、`get_operation_metric`（GetOperationMetricResource）、`get_operation_overview`（GetOperationOverviewResource）——`POST /api/v4/list_operation_metrics/`、`/api/v4/get_operation_metric/`、`/api/v4/get_operation_overview/`。
- **契约来源**：`kernel_api.views.v4.kernel_rpc.KernelRPCViewSet` / `bkm_cli.BkmCliViewSet` / `operation.OperationViewSet`
- **协议详情**见 [RPC 子专家](../rpc函数注册子专家/C1-能力契约.md) 与 [内部 Resource 子专家](../内部resource复用子专家/C1-能力契约.md)。
