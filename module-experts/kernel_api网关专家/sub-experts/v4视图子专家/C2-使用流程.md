# C2-使用流程：v4 API 视图子专家

## 流程 1：新增一个 v4 endpoint

**业务目标**：在 `/api/v4/` 下新增接口。

**调用顺序**：
1. 定义 Resource（业务逻辑）——优先复用内部 Resource 或挂载 app 的 Resource。
2. 在 `views/v4/{module}.py` 定义 `ResourceViewSet` + `ResourceRoute`。
3. `views/v4/__init__.py` 导出模块。

**事务边界**：无跨 endpoint 事务；写操作在 Resource 内自行管理。

**预期结果**：`POST /api/v4/{endpoint}/` 可用。

**代码示例**：
```python
# views/v4/example.py
from core.drf_resource.viewsets import ResourceRoute, ResourceViewSet

class ExampleViewSet(ResourceViewSet):
    resource_routes = [ResourceRoute("POST", GetExampleResource, endpoint="get_example")]
```
```python
# views/v4/__init__.py 追加
from .example import *  # noqa
```

## 流程 2：Issue 状态流转

**业务目标**：对告警聚合的 Issue 做状态流转（assign/resolve/archive/merge/split/rename）。

**调用顺序**：直接 POST 对应 endpoint，参数含 `issue_id` + 流转特定参数（如 assign 需 `assignee`，rename 需 `name`）。

**错误处理**：rename 重名 → body.code 3327001；merge/split 参数校验失败 → ValidationError。

**代码示例**：
```python
import requests
headers = {"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>"}

# 认领
requests.post("https://<host>/api/v4/issue/assign/",
              json={"issue_id": "I-1", "assignee": "user1", "bk_biz_id": 2}, headers=headers)
# 重命名
resp = requests.post("https://<host>/api/v4/issue/rename/",
                     json={"issue_id": "I-1", "name": "新标题", "bk_biz_id": 2}, headers=headers)
```

## 流程 3：告警事件中心查询

**业务目标**：查询告警、事件、动作记录。

**调用顺序**：`alert/search` → `event/search` → `action/search`。

**代码示例**：
```python
resp = requests.post("https://<host>/api/v4/alert/search/",
                     json={"bk_biz_id": 2, "condition": [], "page": 1, "page_size": 20},
                     headers={"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>", "X-Bk-Tenant-Id": "default"})
list_ = resp.json()["data"]["list"]
```
