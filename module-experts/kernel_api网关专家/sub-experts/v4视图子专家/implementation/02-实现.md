## 简介

v4 视图层实现有三种典型模式，本文各举一例拆解。

章节来源：[views/v4/](file://bkmonitor/kernel_api/views/v4/)（关键符号：`ResourceViewSet`）

## 独立 Resource 模式（Issue）

`views/v4/issue.py`（源码 confirmed）：
- 12 个独立 Resource 与 ViewSet 同文件定义：`AssignResource` / `ResolveResource` / `ArchiveResource` / `ReopenResource` / `RestoreResource` / `UpdatePriorityResource` / `RenameResource` / `AddFollowUpResource` / `EditFollowUpResource` / `MergeResource` / `SplitResource` / `RegenerateTitleResource`。
- `RenameResource` 捕获 `IssueNameDuplicatedError` → 重抛 `IssueRenameConflictError`（code 3327001 + 中文 message）——专有错误码链路（见记忆《三层错误传播链路与专有错误码》）。
- `IssueViewSet` 用 `ResourceRoute("POST", RenameResource, endpoint="rename")` 等挂载全部流转。

章节来源：[views/v4/issue.py](file://bkmonitor/kernel_api/views/v4/issue.py)（关键符号：`RenameResource` / `IssueViewSet`）

## 内部复用模式（MCP 告警）

`views/v4/alert.py`（源码 confirmed）：
- `SearchAlertViewSet` 的 `resource_routes` 大量引用 `kernel_api.resource.alert` 的 Resource（`ListAlertResource` / `ListAlertTopNResource` / MCP 策略屏蔽系列）。
- `AlertInfoViewSet` 引用 `resource.alert.*`（`search_alert_by_event` / `list_alert_tags`）。
- `AlertViewSet` 提供全量事件中心兼容 endpoint（`alert/search` 等），`CloseAlertResource` 为同文件独立 Resource。
- `QosViewSet` 引用 `resource.qos`（`FailurePublishResource` / `FailureRecoveryResource`）。

章节来源：[views/v4/alert.py](file://bkmonitor/kernel_api/views/v4/alert.py)（关键符号：`SearchAlertViewSet` / `AlertViewSet`）

## 自实现 Resource 模式（策略/套餐）

- `strategy_v2.py`：`SaveStrategyResource` / `SearchStrategyResource` 为同文件独立 Resource，`AlarmStrategyV2ViewSet` 挂载。
- `strategy_v3.py`：`SearchStrategyWithoutBizResource(GetStrategyListV2Resource)`（继承复用）+ `QosCheckResource` + `AlarmStrategyV3ViewSet`。
- `action_config.py`：`Save/Get/List/Edit/DeleteActionConfigResource` 五件套 + `ActionConfigViewSet`。

> 这些 Resource 的 `perform_request` 直接调用挂载 app（fta_web 等）的下游能力；具体实现按文件阅读。

章节来源：[views/v4/strategy_v2.py](file://bkmonitor/kernel_api/views/v4/strategy_v2.py)（关键符号：`SaveStrategyResource`）；[views/v4/action_config.py](file://bkmonitor/kernel_api/views/v4/action_config.py)（关键符号：`ActionConfigViewSet`）

## 结论

v4 视图层 = 独立 Resource（Issue/策略/套餐）+ 内部复用（MCP 告警）+ 继承挂载 app（APM/告警V2）三种模式。新增接口时按业务归属选对应模式。
