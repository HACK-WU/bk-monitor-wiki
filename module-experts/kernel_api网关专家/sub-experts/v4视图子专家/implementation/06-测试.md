## 简介

章节来源：[tests/](file://bkmonitor/kernel_api/tests/)

## 测试位置与覆盖

| 测试文件 | 覆盖的 v4 域 |

| test_alert_mcp.py（26KB） | SearchAlertViewSet / MCP 告警端点（间接，重点在内部 Resource） |

## 运行方式

```bash
cd /root/bk-monitor/bkmonitor
/root/bk-monitor/bkmonitor/.venv/bin/python -m pytest bkmonitor/kernel_api/tests/ \
    --override-ini "filterwarnings=" -o addopts=""
```

## 测试可执行性

- ⚠️ **依赖外部环境**（PROJECT.md 标注）；视图级测试依赖 Django settings + DB mock。

## 测试缺口

- 策略（strategy_v2/v3）、屏蔽（shield）、分派（assign）、处理套餐（action_config）、事件（event/event_v2）等 ViewSet 无单测。
- 协议入口（kernel_rpc / bkm_cli / operation）的视图层无单测（逻辑在内部 Resource / RPC 层覆盖）。
- 继承类 ViewSet（APM / AlertV2）依赖挂载 app 测试，本层无专属用例。

## 结论

v4 视图层测试覆盖集中在 MCP 告警与 Issue；策略/屏蔽/套餐/事件等域为测试缺口。视图层为薄装配，逻辑测试应下沉到内部 Resource 与挂载 app。
