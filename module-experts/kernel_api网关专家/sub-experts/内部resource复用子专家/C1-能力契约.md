# C1-能力契约：内部 Resource 复用子专家

> 黑盒契约。代码示例为使用方代码（在 ViewSet/其他 Resource 中复用，或 HTTP 经 ViewSet 暴露）。

## 1. MCP 告警管理（resource/alert.py）

> 该类 Resource 主要供 MCP/AI 请求使用，也经 `views/v4/alert.py` 的 `SearchAlertViewSet` 暴露。

### ListAlertResource
- **用途**：查询告警列表（内部调用 `SearchAlertResource` 等下游并做参数适配）。
- **参数**：`bk_biz_id`（必填，业务范围）+ 告警查询条件（时间/状态/标签等）。
- **返回**：告警列表（`{list, total}` 结构）。
- **约束**：业务范围由 `bk_biz_id` 限定。
- **契约来源**：`kernel_api.resource.alert.ListAlertResource`

### ListAlertTopNResource
- **用途**：告警 TopN 统计。
- **返回**：TopN 排行数据。
- **契约来源**：`kernel_api.resource.alert.ListAlertTopNResource`

### AlertRelatedResource 及其子类（ListAlertEventsResource / ListAlertEventTSResource / ListAlertEventTagDetailResource / ListAlertK8sTargetResource / ListAlertHostTargetResource / ListAlertTracesResource / ListAlertLogRelationsResource）
- **用途**：告警关联数据查询——事件列表、事件时序、事件标签、K8s 目标、主机目标、链路、日志关联。
- **参数**：共享 `AlertRelatedRequestSerializer`（`bk_biz_id` + 告警标识 + 时间范围）。
- **返回**：对应关联数据。
- **约束**：`ConfirmedBusinessScopedSerializer` 用于需确认业务范围的场景。
- **契约来源**：`kernel_api.resource.alert.AlertRelatedResource`

### SearchAlarmStrategiesResource / GetAlarmStrategyResource / CreateAlarmStrategyResource / UpdateAlarmStrategyResource
- **用途**：MCP 告警策略 CRUD 查询。
- **参数**：策略查询/创建/更新参数（`bk_biz_id` 必填）。
- **返回**：策略列表 / 单策略 / 创建/更新结果。
- **契约来源**：`kernel_api.resource.alert.SearchAlarmStrategiesResource` 等

### SearchAlarmShieldsResource / GetAlarmShieldResource / CreateAlarmShieldResource / UpdateAlarmShieldResource / DisableAlarmShieldResource
- **用途**：MCP 告警屏蔽查询/创建/更新/停用。
- **参数**：屏蔽规则参数（含维度条件 `dimension_conditions`，见告警屏蔽专家）。
- **返回**：屏蔽列表 / 单屏蔽 / 操作结果。
- **契约来源**：`kernel_api.resource.alert.SearchAlarmShieldsResource` 等

### SearchNoticeGroupsResource / UpdateNoticeGroupResource / SearchActionConfigsResource / GetMCPActionConfigResource / UpdateMCPActionConfigResource
- **用途**：MCP 通知组 / 处理套餐（action config）查询更新。
- **契约来源**：`kernel_api.resource.alert.SearchNoticeGroupsResource` 等

### 使用示例（在 ViewSet 中复用）
```python
# views/v4/alert.py 的 SearchAlertViewSet 内
from core.drf_resource.viewsets import ResourceRoute
from kernel_api.resource.alert import ListAlertResource, ListAlertTopNResource

class SearchAlertViewSet(ResourceViewSet):
    resource_routes = [
        ResourceRoute("POST", ListAlertResource, endpoint="list_alert"),
        ResourceRoute("POST", ListAlertTopNResource, endpoint="alert_top_n"),
    ]
    # HTTP POST /api/v4/list_alert/
```

## 4. 运营指标（resource/operation/）

### ListOperationMetricsResource
- **用途**：运营指标目录。
- **参数**：`bk_biz_id`（必填，鉴权用）、`category`（可选：base/storage/apm/log/aiops）。
- **返回**：`{list: [指标元信息], total}`，含 `programmable`/`supported_envs`。
- **约束**：`OPERATION_MCP_ENV` 环境门控会隐藏本环境不存在的指标。
- **契约来源**：`kernel_api.resource.operation.resources.ListOperationMetricsResource`

### GetOperationMetricResource
- **用途**：按 `metric_key` 取单个指标值。
- **参数**：`bk_biz_id`、`metric_key`、`end_time`（可选；显式传入则旁路缓存查历史点）。
- **返回**：`{key, name, unit, category, handler_type, note, value}`。
- **异常**：未知 `metric_key` / 环境不支持抛 `ValidationError`。
- **约束**：`cache_ttl>0` 且未传 `end_time` 时走 `operation_mcp:metric:*` 缓存。
- **契约来源**：`kernel_api.resource.operation.resources.GetOperationMetricResource`

### GetOperationOverviewResource
- **用途**：按分类批量取值。
- **参数**：`bk_biz_id`、`category`、`include_slow`（默认 False 跳过慢查询）、`end_time`。
- **返回**：`{list: [{key, value, error}], total}`；单指标失败降级到 `error` 字段不影响整批。
- **契约来源**：`kernel_api.resource.operation.resources.GetOperationOverviewResource`

### 使用示例（HTTP 调用运营指标）
```python
import requests
headers = {"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>"}
# endpoint：list_operation_metrics / get_operation_metric / get_operation_overview
resp = requests.post("https://<host>/api/v4/list_operation_metrics/",
                     json={"bk_biz_id": 2, "category": "base"},
                     headers=headers)
print(resp.json()["data"]["result"]["list"])
```
