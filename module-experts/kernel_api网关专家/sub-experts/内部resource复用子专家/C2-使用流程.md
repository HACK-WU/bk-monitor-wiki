# C2-使用流程：内部 Resource 复用子专家

## 流程 1：MCP 告警查询链路

**业务目标**：AI/MCP 客户端查询告警列表与关联数据。

**调用顺序**：
1. 经 `SearchAlertViewSet`（views/v4/alert.py）POST `/api/v4/list_alert/`。
2. `ListAlertResource` 内部适配参数并调用下游 `SearchAlertResource`。
3. 关联数据经 `AlertRelatedResource` 子类（如 `/api/v4/get_alert_events/`）查询。

**事务边界**：全部只读查询。

**预期结果**：蓝鲸标准 envelope + 告警/关联数据。

**错误处理**：时间跨度超限抛 `ValidationError`（`TimeSpanValidationPassThroughSerializer`）。

**代码示例**：
```python
import requests
headers = {"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>", "X-Bkapi-Mcp-Server-Name": "bkmonitor-mcp"}

# 先查告警列表
resp = requests.post("https://<host>/api/v4/list_alert/",
                     json={"bk_biz_id": 2, "start_time": 1690000000, "end_time": 1690003600},
                     headers=headers)
alerts = resp.json()["data"]
```

## 流程 2：日志检索

**业务目标**：按索引集/场景检索日志并分析字段。

**调用顺序**：
1. `GetIndexSetListResource` 查索引集 → `ListLogScenesResource` 查场景。
2. `SearchLogResource` 检索 → `FieldAnalyzeResource` 字段分析。

**代码示例**：
```python
# 复用（在其他 Resource 的 perform_request 中）
from kernel_api.resource.log_search import SearchLogResource

result = SearchLogResource().request({
    "bk_biz_id": 2,
    "index_set_id": "xxx",
    "start_time": "2024-01-01 00:00:00",
    "end_time": "2024-01-01 01:00:00",
    "query_string": "ERROR",
})
```

## 流程 3：运营指标取值

**业务目标**：获取平台运营指标值。

**调用顺序**：
1. `ListOperationMetricsResource` 查目录（可选按 category 过滤）。
2. `GetOperationMetricResource` 按 `metric_key` 取值；或 `GetOperationOverviewResource` 批量取。

**错误处理**：未知 key / 环境不支持 → `ValidationError`；慢查询需 `include_slow=true`。

**代码示例**：
```python
# HTTP 调用（operation ViewSet 暴露，endpoint=get_operation_metric）
resp = requests.post("https://<host>/api/v4/get_operation_metric/",
                     json={"bk_biz_id": 2, "metric_key": "strategy_enabled_count"},
                     headers={"X-Bkapi-From": "apigw", "X-Bkapi-Jwt": "<jwt>"})
print(resp.json()["data"]["value"])
```

## 流程 4：新增一个被多 ViewSet 复用的内部 Resource

**业务目标**：抽公共查询逻辑为内部 Resource。

**调用顺序**：
1. 在 `resource/{module}.py` 定义 `XxxResource(Resource)`，`perform_request` 内部调用下游 Resource 或公共框架。
2. 在需要的 ViewSet 中 `ResourceRoute("POST", XxxResource, endpoint="xxx")`。

**代码示例**：
```python
# resource/common.py —— 内部复用 Resource
from core.drf_resource import Resource

class ListFooResource(Resource):
    def perform_request(self, validated_request_data):
        # 复用下游能力
        return resource.bar.search_foo(validated_request_data)

# views/v4/foo.py —— 对外暴露
class FooViewSet(ResourceViewSet):
    resource_routes = [ResourceRoute("POST", ListFooResource, endpoint="list_foo")]
```
