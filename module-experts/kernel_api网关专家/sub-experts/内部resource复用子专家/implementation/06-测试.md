## 测试可执行性

- ⚠️ **依赖外部环境**（PROJECT.md 标注）；测试 mock 外部依赖，运行需 Django settings 初始化（api 角色）+ `.venv` + 环境变量。

## 测试缺口

- **operation/**：`ListOperationMetricsResource` / `GetOperationMetricResource` / `GetOperationOverviewResource` 无对应单测（运营指标是 MCP 新能力，建议补）。
- **协议入口**：`KernelRPCResource` / `BkmCliOpCallResource` 的协议分支（`__meta__` / op 404 / JSON-safe 归一）无 kernel_api/tests 级单测（部分在 rpc/tests/test_bkm_cli_rpc.py 覆盖）。
- **ai_repo / openclaw / metrics / query / event**：无独立单测。

## 结论

MCP 告警与日志类是主要覆盖点；operation 运营指标与协议入口是测试缺口。
