# C1-能力契约：认证与安全子专家

> 黑盒契约。代码示例为使用方代码。

## 1. BkJWTClient（apigw JWT 验签）

- **用途**：解析并验证 API 网关透传的 JWT。
- **构造**：`BkJWTClient(request, public_keys)`，`public_keys` 为 `{kid: public_key}` 映射。
- **方法**：`validate() -> tuple[bool, str]`。
  - **参数行为语义**：从 `request.META["HTTP_X_BKAPI_JWT"]` 读取 JWT；算法取自 header `alg`（默认 RS512）；按 header `kid` 找公钥。
  - **返回**：`(True, "")` 成功；`(False, 错误消息)` 失败（空内容 / header 解析失败 / 公钥缺失 / decode 失败）。
  - **成功后副作用**：`client.is_valid=True`、`client.app`（含 `app_code`，兼容 `bk_app_code`）、`client.user`（含 `username`）。
- **异常**：不抛异常，一律返回 `(False, msg)`。
- **约束**：需要 apigw 公钥已获取（`get_apigw_public_keys`）。
- **契约来源**：`kernel_api.middlewares.authentication.BkJWTClient`

## 2. AuthenticationMiddleware（统一认证入口）

- **用途**：Django 中间件，`process_view` 完成请求认证与上下文注入。
- **认证选择顺序**（行为语义，前一条件满足则走对应分支）：
  1. 视图 `login_exempt=True` → 跳过认证。
  2. `X-Bkapi-From: apigw` 且带 JWT → apigw JWT 认证。
  3. `X-Bkapi-Mcp-Server-Name` / 旧头 `X-Bk-Request-Source` / app_code 匹配 → **MCP 认证**（需 `bk_biz_id` + IAM 权限动作）。
  4. `Authorization: Bearer <token>` → **API Token 认证**。
  5. 兜底：app_code 白名单（`is_match_api_token`）+ 用户自动创建。
- **认证成功副作用**：`request.user` 必设；MCP 分支额外设 `request.biz_id` / `request.skip_check`；Token 分支设 `request.token`；as_code/grafana/entity 类型 Token 会替换请求用户并 `auth.login`。
- **返回**：通过返回 `None`；失败返回 `HttpResponseForbidden`。
- **约束**：多租户开启时，apigw JWT 认证要求 `X-Bk-Tenant-Id` 请求头；`/grafana/` 路径且无 app_code 时用 `admin` 豁免。
- **契约来源**：`kernel_api.middlewares.authentication.AuthenticationMiddleware.process_view`

### 使用示例（API Token 调用内核 API）
```python
import requests
resp = requests.post(
    "https://<host>/api/v4/query_es/",
    json={"bk_biz_id": 2, "query": {...}},
    headers={"Authorization": f"Bearer {api_token}", "Content-Type": "application/json"},
)
if resp.status_code == 403:
    print("token 无效/过期/命名空间不允许:", resp.text)
else:
    data = resp.json()
```

### 使用示例（MCP 请求认证）
```python
# MCP 服务端转发时携带（认证 + 权限动作）
headers = {
    "X-Bkapi-From": "apigw",
    "X-Bkapi-Jwt": jwt_str,
    "X-Bk-Tenant-Id": "default",
    "X-Bkapi-Mcp-Server-Name": "bkmonitor-mcp",
    "X-Bkapi-Permission-Action": "mcp_view_alerts",
}
resp = requests.post("https://<host>/api/v4/search_alert/",
                     json={"bk_biz_id": 2, ...}, headers=headers)
# 403 = 缺 bk_biz_id / 权限不足 / 工具不在白名单
```

## 3. is_match_api_token(request, bk_tenant_id, app_code)

- **用途**：app_code 命名空间授权判断（白名单兜底分支）。
- **参数行为语义**：
  - 请求无 `biz_id` 且 app_code 不是 `AIDEV_AGENT_MCP_REQUEST_AGENT_CODE` → 直接放行 `True`。
  - app_code 不在 `ApiAuthToken` 记录的授权表 → 放行 `True`（未配置即开放）。
  - 授权表命中的 app_code → 仅当 namespaces 含 `biz#all` 或 `biz#{request.biz_id}` 时放行。
- **返回**：`bool`。
- **约束**：依赖 `ApiAuthToken` 表（`AuthType.API`）+ `APP_CODE_TOKENS` 缓存（300~400s 刷新）。
- **契约来源**：`kernel_api.middlewares.authentication.is_match_api_token`

## 4. AppWhiteListModelBackend.authenticate(request=None, username=None, bk_tenant_id=DEFAULT_TENANT_ID)

- **用途**：认证后端，自动创建/更新 `User` 并返回可认证用户。
- **参数行为语义**：
  - `username=None` → 返回 `None`（不认证）。
  - 单租户模式：用户 `tenant_id` 统一为 `DEFAULT_TENANT_ID`。
  - 多租户模式：用户 `tenant_id != bk_tenant_id` 时，若为租户虚拟管理用户或经 `bk_login.batch_query_user_display_info` 确认属于当前租户 → 更新 `tenant_id`，否则保持。
- **返回**：`User` 对象或 `None`（异常/不可认证）。
- **约束**：`user_can_authenticate` 判定 `is_active` 为真或未设置。
- **契约来源**：`kernel_api.middlewares.authentication.AppWhiteListModelBackend`

## 5. get_apigw_public_keys()

- **用途**：获取 apigw JWT 公钥映射 `{api_name: public_key}`。
- **参数行为语义**：按 `settings.FROM_APIGW_NAME`（逗号分隔）逐个获取；公钥为空时缓存 120s 防抖，成功则长期缓存（`login_db` cache）。
- **返回**：`dict[str, str]`；`FROM_APIGW_NAME` 未配置时返回 `{}`。
- **异常**：`api.bk_apigateway.get_public_key` 抛 `BKAPIError` 时记录日志返回空公钥。
- **契约来源**：`kernel_api.middlewares.authentication.AuthenticationMiddleware.get_apigw_public_keys`

## 6. KernelSessionAuthentication / 相关配置

- **用途**：DRF 会话认证（`REST_FRAMEWORK.DEFAULT_AUTHENTICATION_CLASSES`），关闭 CSRF 强制校验。
- **契约来源**：`kernel_api.middlewares.authentication.KernelSessionAuthentication`
- **关联配置**：`AUTHENTICATION_BACKENDS`（AppWhiteListModelBackend + UserBackend）、`AUTH_USER_MODEL = "account.User"`。
