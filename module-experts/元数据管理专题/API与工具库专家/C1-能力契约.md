## 一、核心 Resource 类 API

### 1.1 数据源相关 Resource

#### CreateDataIDResource — 创建数据源 ID

- **文件**: `resources/resources.py`
- **请求参数**:
  - `bk_tenant_id` (str): 租户 ID
  - `bk_biz_id` (int, optional): 业务 ID
  - `data_name` (str, required): 数据源名称
  - `etl_config` (str, required): 清洗模板配置
  - `operator` (str, required): 操作者
  - `bk_data_id` (int, optional): 数据源 ID（指定则复用）
  - `mq_cluster` (int, optional): 消息集群 ID
  - `mq_config` (dict, optional): 消息队列配置
  - `data_description` (str, optional): 数据源描述
  - `is_custom_source` (bool, default=True): 是否用户自定义
  - `source_label` (str, required): 数据源标签
  - `type_label` (str, required): 数据类型标签
  - `option` (dict, optional): 配置项
  - `space_uid` (str, optional): 空间 UID
  - `is_platform_data_id` (bool, default=False): 是否平台级 ID
- **返回**: `bk_data_id` (int)
- **实现**: 解析 `space_uid` → 调用 `models.DataSource.create_data_source()`

#### GetOrCreateAgentEventDataIdResource — 获取/创建 Agent 事件 DataID

- **请求参数**: `bk_tenant_id`, `bk_biz_id`
- **返回**: `{"bk_data_id": int}`
- **实现**: 先查后建，使用 `EtlConfigs.BK_MULTI_TENANCY_AGENT_EVENT_ETL_CONFIG`

#### ModifyDatasourceResultTable — 切换结果表与数据源关联

- **请求参数**: `bk_tenant_id`, `table_id`, `bk_data_id`
- **实现**: 调用 `models.DataSourceResultTable.modify_table_id_datasource()`

### 1.2 结果表相关 Resource

#### CreateResultTableResource — 创建结果表

- **请求参数**:
  - `bk_tenant_id`, `bk_data_id`, `table_id`, `table_name_zh`
  - `is_custom_table`, `schema_type`, `operator`, `default_storage`
  - `field_list` (list[FieldSerializer]): 字段列表
  - `query_alias_settings` (list): 查询别名设置
  - `bk_biz_id` (default=0), `label`, `external_storage`, `option`
  - `is_time_field_only`, `time_alias_name`, `time_option`
  - `is_sync_db` (default=True), `data_label`, `labels`
- **返回**: `table_id` (str)
- **实现**: 先处理 `query_alias_settings` → 调用 `models.ResultTable.create_result_table()`

#### ListResultTableResource — 查询结果表列表

- **请求参数**:
  - `bk_tenant_id`, `datasource_type` (optional), `bk_biz_id` (optional)
  - `with_option` (default=True), `is_public_include` (optional)
  - `is_config_by_user` (default=True)
  - 分页: `page` (default=1), `page_size` (default=0=不分页)
- **返回**: 分页模式 `{"count": int, "info": list}` / 非分页 `list`
- **实现**: 排除 BCS DataID → 按条件过滤 → 批量序列化

### 1.3 集群相关 Resource

参考 [`resources/cluster.py`](file://bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/resources/cluster.py)

参考 [`resources/entity_relation.py`](file://bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/resources/entity_relation.py)

## 四、BCS 模型 API

### 4.1 BCSClusterInfo

- **文件**: `models/bcs/cluster.py`
- **关键字段**: cluster_id, bk_biz_id, bk_tenant_id, project_id, status, domain_name, port, K8sMetricDataID, CustomMetricDataID, K8sEventDataID
- **关键方法**:
  - `init_resource(is_fed_cluster)` — 初始化集群资源（创建 DataID + 结果表）
  - `api_client` (property) — 获取 K8S API 客户端
  - `create_custom_metric_data_id()` — 创建自定义指标 DataID
  - `create_k8s_metric_data_id()` — 创建 K8S 指标 DataID
  - `create_k8s_event_data_id()` — 创建 K8S 事件 DataID

### 4.2 BCSResource (抽象基类)

- **文件**: `models/bcs/resource.py`
- **关键字段**: cluster_id, namespace, name, bk_data_id, is_custom_resource, is_common_data_id
- **子类**: `ServiceMonitorInfo`, `PodMonitorInfo`, `LogCollectorInfo`
- **关键方法**:
  - `make_bcs_client(cluster_id)` (static) — 创建 BCS K8S 客户端
  - `should_refresh_own_dataid()` — 判断是否需要刷新 DataID

### 4.3 ReplaceConfig

- **文件**: `models/bcs/replace.py`
- **用途**: 管理 BCS 资源的替换配置
