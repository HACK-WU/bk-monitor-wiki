## 一、Resource 请求处理流程

### 1.1 完整调用链

[`resources/base.py`](file://bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/resources/base.py) 中 `Resource.request()` 方法实现：

```
1. 合并 request_data 和 kwargs
2. validate_request_data(request_data)
   ├── 无 RequestSerializer → 原样返回
   └── 有 RequestSerializer → 实例化 → is_valid() → 返回 validated_data
3. perform_request(validated_request_data)  ← 子类实现
4. validate_response_data(response_data)
   ├── 无 ResponseSerializer → 原样返回
   └── 有 ResponseSerializer → 实例化 → is_valid() → 返回 validated_data
5. 异常捕获 → 统一转换为 BkApiError
```

### 1.2 线程安全设计

```python
def __call__(self, *args, **kwargs) -> Any:
    # 每次调用创建新实例，避免并发请求共享状态
    tmp_resource = self.__class__()
    return tmp_resource.request(*args, **kwargs)
```

### 1.3 异常处理

所有异常统一转换为 `BkApiError`：

```python
except Exception as e:
    raise BkApiError(
        module="metadata_resource",
        action=self.get_resource_name(),
        method="",
        url=self.get_resource_name(),
        message=str(e),
        status_code=HTTPStatus.BAD_REQUEST,
    ) from e
```

### 1.4 序列化器错误格式化

`format_serializer_errors()` 递归遍历 DRF Serializer errors，将字段名替换为 label，生成人类可读的错误信息。

## 二、核心 Resource 实现

### 2.1 CreateDataIDResource

**文件**: `resources/resources.py`

**核心流程**:
1. 解析 `space_uid`（格式: `{space_type_id}__{space_id}`），拆分为 `space_type_id` 和 `space_id`
2. 从 request 获取 `bk_app_code` 作为 `source_system`
3. 调用 `models.DataSource.create_data_source(**validated_request_data)`
4. 返回 `bk_data_id`

**关键代码路径**:
```python
space_uid = validated_request_data.pop("space_uid", None)
if space_uid:
    space_type_id, space_id = space_uid.split(SPACE_UID_HYPHEN)
    validated_request_data["space_type_id"] = space_type_id
    validated_request_data["space_id"] = space_id
    validated_request_data["space_uid"] = space_uid

# 获取请求来源
bk_app_code = get_app_code_by_request(request) if request else None
validated_request_data["source_system"] = bk_app_code or "unknown"

# 创建数据源
new_data_source = models.DataSource.create_data_source(**validated_request_data)
return new_data_source.bk_data_id
```

### 2.2 GetOrCreateAgentEventDataIdResource

**核心流程**:
1. 构造 `space_uid = f"BKCC__{bk_biz_id}"`
2. 使用 `EtlConfigs.BK_MULTI_TENANCY_AGENT_EVENT_ETL_CONFIG` 查询已有数据源
3. 不存在则创建: `data_name = f"base_{bk_biz_id}_agent_event"`
4. 返回 `{"bk_data_id": int}`

### 2.3 CreateResultTableResource

**核心流程**:
1. 提取 `query_alias_settings`，调用 `ESFieldQueryAliasOption.manage_query_alias_settings()`
2. 调用 `models.ResultTable.create_result_table(**validated_request_data)`
3. 返回 `table_id`

### 2.4 ListResultTableResource

**核心流程**:
1. 通过 `get_bcs_dataids()` 获取 BCS 相关 DataID，用于排除
2. 排除 BCS DataID 的结果表
3. 按 `datasource_type`、`bk_biz_id`、`is_public_include`、`is_config_by_user` 过滤
4. 分页处理: `page_size > 0` 时返回 `{"count": n, "info": [...]}`
5. 拼接预计算指标（`get_record_rule_metrics_by_biz_id`）

## 三、Service 关键方法

### 3.1 数据源服务

**`stop_or_enable_datasource(bk_tenant_id, data_id_list, is_enabled)`**:
1. 校验所有 data_id 存在
2. 批量更新 `is_enable` 字段
3. 停用时删除 Consul 配置；启用时刷新 GSE 路由

**`modify_data_id_source(bk_tenant_id, data_id_list, source_type)`**:
1. 校验 data_id 存在
2. 更新 `created_from` 字段
3. `bkdata` 来源：删除 Consul 配置
4. `bkgse` 来源：刷新 GSE 路由

**`modify_kafka_cluster_id(bk_data_id, topic, partition)`**:
1. 查询 DataSource → 获取 mq_cluster
2. 通过 Kafka API 创建 topic/partition
3. 更新 `KafkaTopicInfo` 记录
4. 刷新 DataSource 的 Consul 配置

### 3.2 存储详情服务

**`ResultTableAndDataSource.get_detail()`**:
1. 获取数据源基本信息（`get_basic_detail`）
2. 获取 table_id ↔ data_id 映射（`get_table_id_data_id`）
3. 对每个结果表组装：
   - 数据源信息（含 BCS 集群 ID）
   - 结果表信息
   - 业务信息（含 CMDB 查询）
   - 存储集群配置（ES/InfluxDB/Kafka/VM）
   - InfluxDB 实例集群信息

**`StorageClusterDetail.get_detail()`**:
- 按集群类型分发：Kafka（broker+topics）、InfluxDB/ES/VM（基本信息）

### 3.3 元数据同步服务

**`sync_kafka_metadata(bk_tenant_id, kafka_info, ds, bk_data_id)`**:
1. 查找或创建 Kafka ClusterInfo
2. 更新 KafkaTopicInfo（topic/partition）
3. 更新 DataSource 的 mq_cluster_id/mq_config_id

**`sync_vm_metadata(bk_tenant_id, vm_info)`**:
1. 遍历 VM 结果表
2. 查找或创建 VM ClusterInfo
3. 更新 AccessVMRecord 的 vm_cluster_id

### 3.4 空间 Redis 服务

**`push_and_publish_es_aliases(bk_tenant_id, data_label)`**:
1. 解析 data_label 列表
2. 查询 ResultTable 获取 table_id 列表
3. 多租户模式：key 格式 `{data_label}|{bk_tenant_id}`
4. 写入 Redis Hash + 发布 PubSub 消息

## 四、Utils 核心工具函数

### 4.1 HashConsul — 哈希比对写入

**文件**: `utils/consul_tools.py`

核心逻辑：
1. 获取 Consul 上当前值
2. 计算旧值 MD5 和新值 MD5
3. 哈希相同 → 跳过写入（减少 Consul 压力）
4. 哈希不同 → 写入新值

```python
old_hash = hash_util.object_md5(json.loads(old_value["Value"]))
new_hash = hash_util.object_md5(value)
if old_hash == new_hash:
    return True  # 跳过
return consul_client.kv.put(key=key, value=json.dumps(value))
```

### 4.2 RedisTools — Redis 操作封装

**文件**: `utils/redis_tools.py`

- 懒加载客户端：首次使用时通过 `setup_client()` 初始化
- 支持 Hash/Set/String/PubSub 操作
- `hkeys()` 自动将 bytes 解码为 str

### 4.3 share_lock — 分布式锁

**文件**: `utils/lock.py`

基于 Django Cache 的 `set(key, token, nx=True)` 实现：
- `ttl`: 锁超时时间（默认 600s）
- `identify`: 自定义锁标识（避免函数名冲突）
- 自动释放：finally 中比对 token 后删除

### 4.4 TenantIdField — 租户 ID 自动注入

**文件**: `utils/serializers.py`

```python
class TenantIdField(serializers.CharField):
    def run_validation(self, data=empty):
        if self.prefer_request_tenant or not data:
            request_tenant_id = get_request_tenant_id(peaceful=True)
            if request_tenant_id:
                data = request_tenant_id
        return super().run_validation(data)
```

### 4.6 时间工具

**文件**: `utils/time_tools.py`

核心函数：
- `localtime(value)`: 转为本地时区 datetime
- `biz2utc_str(local_time)`: 业务时间字符串 → UTC 字符串
- `utc2biz_str(utc_time)`: UTC 字符串 → 业务时间字符串
- `parse_time_range(time_range)`: 解析时间范围 → 时间戳对
- `hms_string(sec_elapsed)`: 秒数 → 人类可读（1d 12h 3m）
- `time_interval_align(timestamp, interval)`: 时间对齐

### 4.7 BCS 工具

**文件**: `utils/bcs.py`

**`get_bcs_dataids(bk_biz_ids, cluster_ids, mode)`**:
1. 查询 BCSClusterInfo 获取 K8sMetricDataID / CustomMetricDataID
2. 支持按 bk_biz_id 或 cluster_id 过滤
3. 支持 mode: "k8s" / "custom" / "both"
4. 补充 ServiceMonitorInfo / PodMonitorInfo 的 DataID
5. 处理跨空间授权场景

**`BcsKubeClient`**:
- 封装 BCS API Gateway 的 K8S 客户端
- 支持超时控制（10s）
- 处理 404/403 等异常
