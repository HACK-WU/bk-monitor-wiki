## 一、典型请求链路

### 1.1 创建数据源完整链路

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant GW as API 网关
    participant Res as CreateDataIDResource
    participant Ser as RequestSerializer
    participant DS as DataSource.create_data_source()
    participant DB as MySQL
    participant Consul as Consul

    Client->>GW: POST /api/metadata/create_data_id/
    GW->>Res: Resource()(request_data)
    Res->>Ser: validate_request_data()
    Ser->>Ser: TenantIdField 自动注入租户ID
    Ser-->>Res: validated_data
    Res->>Res: 解析 space_uid
    Res->>Res: 获取 bk_app_code
    Res->>DS: create_data_source(**data)
    DS->>DB: INSERT DataSource
    DS->>DB: INSERT DataSourceOption
    DS->>DB: INSERT KafkaTopicInfo
    DS->>Consul: 写入 GSE 路由配置
    DS-->>Res: DataSource 实例
    Res-->>GW: bk_data_id
    GW-->>Client: {"bk_data_id": 12345}
```

**关键步骤**:
1. `TenantIdField` 自动从 request 注入 `bk_tenant_id`
2. `space_uid` 解析为 `space_type_id` + `space_id`
3. `bk_app_code` 作为 `source_system`
4. `DataSource.create_data_source()` 内部事务创建数据源及相关配置

### 1.2 查询结果表详情链路

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Res as ListResultTableResource
    participant BCS as get_bcs_dataids()
    participant DSRT as DataSourceResultTable
    participant RT as ResultTable
    participant RR as get_record_rule_metrics

    Client->>Res: request(bk_tenant_id, bk_biz_id, ...)
    Res->>BCS: get_bcs_dataids()
    BCS-->>Res: {data_id: cluster_id, ...}
    Res->>DSRT: 查询 table_id（排除 BCS DataID）
    DSRT-->>Res: [table_id, ...]
    Res->>RT: filter(table_id__in=...)
    RT-->>Res: QuerySet
    Res->>Res: 按 datasource_type/bk_biz_id 过滤
    Res->>RR: get_record_rule_metrics_by_biz_id()
    RR-->>Res: [预计算指标, ...]
    Res->>RT: batch_to_json(table_id_list)
    RT-->>Res: [结果表 JSON, ...]
    Res-->>Client: {"count": n, "info": [...]}
```

### 1.3 存储详情查询链路

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Res as ResultTableAndDataSource
    participant DS as DataSource
    participant DSRT as DataSourceResultTable
    participant RT as ResultTable
    participant CMDB as CMDB API
    participant ES as ESStorage
    participant Influx as InfluxDBStorage
    participant VM as AccessVMRecord

    Client->>Res: get_detail()
    Res->>DS: get_data_source(bk_data_id)
    DS-->>Res: 数据源信息 + BCS 集群ID
    Res->>DSRT: get_table_id_data_id()
    DSRT-->>Res: {table_id: bk_data_id}

    loop 每个结果表
        Res->>RT: get_table_id(table_id)
        RT-->>Res: 结果表信息
        Res->>CMDB: search_business(bk_biz_id)
        CMDB-->>Res: 业务名称
        Res->>ES: consul_config
        ES-->>Res: ES 配置
        Res->>Influx: consul_config
        Influx-->>Res: InfluxDB 配置
        Res->>VM: 查询 VM 记录
        VM-->>Res: VM 配置
    end

    Res-->>Client: [完整详情, ...]
```

## 二、数据源启停链路

```mermaid
sequenceDiagram
    participant Res as Resource
    participant Svc as stop_or_enable_datasource()
    participant DS as DataSource
    participant Consul as HashConsul
    participant GSE as GSE

    Res->>Svc: (bk_tenant_id, [data_id], is_enabled=False)
    Svc->>DS: filter(bk_data_id__in=[...])
    DS-->>Svc: QuerySet
    Svc->>DS: update(is_enable=False)

    loop 每个数据源
        Svc->>Consul: delete(consul_config_path)
        Consul-->>Svc: 删除成功
    end

    Note over Svc: 如果是启用操作
    Svc->>DS: update(is_enable=True)
    loop 每个数据源
        Svc->>DS: refresh_outer_config()
        DS->>GSE: 下发路由
    end
```

## 三、BCS 集群注册 → 数据链路

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Res as BCS 注册 Resource
    participant BCS as BCSClusterInfo
    participant DS as DataSource
    participant RT as ResultTable
    participant TSG as TimeSeriesGroup
    participant EG as EventGroup
    participant Consul as Consul

    Client->>Res: 注册 BCS 集群
    Res->>BCS: create(cluster_id, bk_biz_id, ...)
    BCS->>BCS: init_resource()

    par K8S 指标 DataID
        BCS->>DS: create_data_source(etl_config="bk_standard_v2_time_series")
        DS-->>BCS: K8sMetricDataID
        BCS->>RT: create_result_table()
        BCS->>TSG: create(bk_data_id=K8sMetricDataID)
    and 自定义指标 DataID
        BCS->>DS: create_data_source(etl_config="bk_standard_v2_time_series")
        DS-->>BCS: CustomMetricDataID
        BCS->>RT: create_result_table()
        BCS->>TSG: create(bk_data_id=CustomMetricDataID)
    and K8S 事件 DataID
        BCS->>DS: create_data_source(etl_config="bk_standard_v2_event")
        DS-->>BCS: K8sEventDataID
        BCS->>RT: create_result_table()
        BCS->>EG: create(bk_data_id=K8sEventDataID)
    end

    BCS->>Consul: 下发 DataID 配置
    BCS-->>Res: 集群注册完成
```

## 四、ES 别名推送链路

```mermaid
sequenceDiagram
    participant Svc as push_and_publish_es_aliases()
    participant RT as ResultTable
    participant Redis as RedisTools
    participant Sub as 订阅者

    Svc->>Svc: 解析 data_label 列表
    Svc->>RT: filter(data_label__contains=...)
    RT-->>Svc: QuerySet

    loop 每个结果表
        Svc->>Svc: 拆分 data_label
        Svc->>Svc: reformat_table_id()
    end

    Svc->>Svc: 组装 {data_label|tenant_id: [table_ids]}
    Svc->>Redis: hmset_to_redis(DATA_LABEL_TO_RESULT_TABLE_KEY, values)
    Svc->>Redis: publish(DATA_LABEL_TO_RESULT_TABLE_CHANNEL, keys)
    Redis-->>Sub: PubSub 消息
```

## 六、关键数据转换点

| 转换点 | 输入 | 输出 | 位置 |
|--------|------|------|------|
| space_uid 解析 | `"BKCC__123"` | `space_type_id="BKCC"`, `space_id="123"` | `CreateDataIDResource.perform_request()` |
| 租户 ID 注入 | 空/None | 当前请求的 bk_tenant_id | `TenantIdField.run_validation()` |
| table_id 格式化 | `"100147_bkcc_system_cpu_summary"` | 去掉前缀的 table_id | `reformat_table_id()` |
| 时间范围解析 | `"2024-01-01 -- 2024-01-02"` | `(start_timestamp, end_timestamp)` | `parse_time_range()` |
| DataID → Token | `(metric_id, trace_id, log_id, biz_id)` | AES 加密字符串 | `transform_data_id_to_token()` |
| 对象 → MD5 | dict/list/str | 32 位 hex 字符串 | `object_md5()` |
| 秒数 → 可读 | `90061` | `"1d 1h 1m 1s"` | `hms_string()` |
| 空间 UID → 租户 ID | `"BKCC__123"` | `"system"` | `space_uid_to_bk_tenant_id()` |
