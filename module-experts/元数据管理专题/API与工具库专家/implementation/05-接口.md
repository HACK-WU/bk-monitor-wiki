## 一、Resource RESTful 端点

### 1.1 数据源相关

| Resource 类 | 功能 | 关键参数 |
|------------|------|---------|
| `CreateDataIDResource` | 创建数据源 ID | data_name, etl_config, operator, source_label, type_label, space_uid |
| `GetOrCreateAgentEventDataIdResource` | 获取/创建 Agent 事件 DataID | bk_biz_id |
| `ModifyDatasourceResultTable` | 切换结果表与数据源关联 | table_id, bk_data_id |

### 1.2 结果表相关

| Resource 类 | 功能 | 关键参数 |
|------------|------|---------|
| `CreateResultTableResource` | 创建结果表 | bk_data_id, table_id, table_name_zh, is_custom_table, schema_type, default_storage, field_list |
| `ListResultTableResource` | 查询结果表列表 | datasource_type, bk_biz_id, with_option, page, page_size |

### 1.3 集群相关

| Resource 类 | 功能 | 关键参数 |
|------------|------|---------|
| `RegisterCluster` | 注册集群 | cluster_name, cluster_type, domain, port, username, password |
| `ModifyCluster` | 修改集群 | cluster_id + 可修改字段 |
| `DeleteCluster` | 删除集群 | cluster_id |
| `ListClusters` | 查询集群列表 | cluster_type, page, page_size |
| `GetStorageClusterDetail` | 获取集群详情 | cluster_id |

### 1.4 实体关系

| Resource 类 | 功能 | 关键参数 |
|------------|------|---------|
| EntityHandler.apply | 创建/更新实体 | metadata: {namespace, name, labels}, spec |
| EntityHandler.get | 获取实体 | namespace, name |
| EntityHandler.list | 列出实体 | namespace |
| EntityHandler.delete | 删除实体 | namespace, name |

### 1.5 数据链路

| Resource 类 | 文件 | 功能 |
|------------|------|------|
| 数据链路 CRUD | `bkdata_link.py` | 计算平台数据链路管理 |
| 链路操作 | `datalink_operation.py` | 链路启停/迁移 |
| 日志链路 | `log_datalink.py` | 日志数据链路管理 |
