## 一、Resource 层总览

### 1.1 架构定位

Resource 层是元数据模块的 API 入口，位于 API 网关和 Service 层之间：

```
客户端 → API 网关(api/metadata/default.py) → Resource 层 → Service 层 → Model 层
        内核 API(kernel_api/) ──────────────→ Resource 层（直连）
```

### 1.2 Resource 基类

所有 Resource 继承自 [`resources/base.py`](file://bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/resources/base.py) 的 `Resource` 抽象基类。

**使用模式**：
```python
class XxxResource(Resource):
    @final
    class RequestSerializer(serializers.Serializer):
        bk_tenant_id = TenantIdField(label="租户ID")
        # ...

    @override
    def perform_request(self, validated_request_data):
        # 业务逻辑
        return result
```

**调用方式**：
```python
# Resource 实例化后直接调用（线程安全）
result = XxxResource()(bk_tenant_id="system", data_name="test", ...)
```

### 1.3 Resource 文件导航

| 文件 | 用途 | 何时使用 |
|------|------|---------|
| `resources.py` | 核心元数据 CRUD | 创建数据源、结果表、字段管理 |
| `cluster.py` | 集群管理 | 注册/查询/修改存储集群 |
| `bkdata_link.py` | 计算平台链路 | 管理计算平台数据链路 |
| `datalink_operation.py` | 链路操作 | 链路启停/迁移 |
| `entity_relation.py` | 实体关系 | 声明式管理实体关系 |
| `log_datalink.py` | 日志链路 | 管理日志数据链路 |
| `space.py` | 空间管理 | 空间 CRUD |
| `vm.py` | VM 存储 | VM 接入管理 |

## 二、Service 层总览

### 2.1 服务调用方式

Service 层函数由 Resource 层直接调用，不对外暴露 HTTP 接口：

```python
# Resource 中调用 Service
from bk_monitor_base.metadata.service.data_source import stop_or_enable_datasource
stop_or_enable_datasource(bk_tenant_id, data_id_list, is_enabled)
```

### 2.2 服务导航

| 服务 | 何时使用 |
|------|---------|
| `data_source.py` | 修改 Kafka 集群、启停数据源、切换来源 |
| `storage_details.py` | 查询结果表与数据源详情、集群详情 |
| `sync_metadata.py` | 同步 Kafka/ES/VM 元数据 |
| `space_redis.py` | 空间配置缓存、ES 别名推送 |
| `es_storage.py` | ES 索引查询、过期索引清理 |
| `vm_storage.py` | InfluxDB→VM 路由切换、VM 链路查询 |
