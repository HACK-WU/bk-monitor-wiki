### consul_tools.py

```python
def refresh_router_version() -> None: ...

class HashConsul:
    def __init__(self, host="127.0.0.1", port=8500, scheme="http", verify=None, default_force=False): ...
    def delete(self, key: str, recurse=None) -> None: ...
    def get(self, key: str) -> tuple: ...
    def list(self, key: str) -> tuple: ...
    def put(self, key: str, value, is_force_update: bool = False, bk_data_id: int | None = None, *args, **kwargs) -> bool: ...
```

**HashConsul.put() 核心逻辑**:
1. 获取 Consul 上当前值
2. 计算旧值 MD5 和新值 MD5
3. 哈希相同 → 跳过写入
4. 哈希不同 → 写入新值
