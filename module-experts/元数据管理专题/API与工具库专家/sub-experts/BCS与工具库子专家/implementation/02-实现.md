## 一、HashConsul — 哈希比对写入

**文件**: `utils/consul_tools.py`

### 核心逻辑

```python
def put(self, key: str, value, is_force_update: bool = False, bk_data_id: int | None = None, *args, **kwargs):
    consul_client = consul.BKConsul(...)

    # 0. 强制刷新
    if self.default_force or is_force_update:
        return consul_client.kv.put(key=key, value=json.dumps(value))

    # 1. 获取 Consul 上当前值
    old_value = consul_client.kv.get(key)[1]
    if old_value is None:
        return consul_client.kv.put(key=key, value=json.dumps(value))

    # 2. 计算新旧 MD5
    old_hash = hash_util.object_md5(json.loads(old_value["Value"]))
    new_hash = hash_util.object_md5(value)

    # 3. 哈希相同 → 跳过写入
    if old_hash == new_hash:
        return True

    # 4. 哈希不同 → 写入新值
    return consul_client.kv.put(key=key, value=json.dumps(value))
```

**设计意图**: 减少 Consul 不必要的配置刷新，通过 MD5 比对避免重复写入相同内容。

### hkeys() 的 bytes→str 解码

```python
@classmethod
def hkeys(cls, key: str) -> list[str]:
    raw_fields = cls().client.hkeys(key)
    return [f.decode("utf-8") if isinstance(f, bytes) else f for f in raw_fields]
```

## 三、share_lock — 分布式锁

**文件**: `utils/lock.py`

### 核心实现

基于 Django Cache 的 `set(key, token, nx=True)` 实现：

```python
def share_lock(ttl: int = 600, identify: str | None = None):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            lock_key = f"celery_{identify or func.__name__}"
            token = str(uuid.uuid4())
            # 尝试获取锁
            acquired = cache.set(lock_key, token, timeout=ttl, nx=True)
            if not acquired:
                raise LockAcquireError(f"lock {lock_key} already acquired")
            try:
                return func(*args, **kwargs)
            finally:
                # 比对 token 后释放
                current = cache.get(lock_key)
                if current == token:
                    cache.delete(lock_key)
        return wrapper
    return decorator
```

**关键设计**:
- `nx=True` 保证原子性（仅当 key 不存在时设置）
- `token` 防止误删其他进程的锁
- `ttl` 防止死锁（默认 600s）

## 四、TenantIdField — 租户 ID 自动注入

**文件**: `utils/serializers.py`

```python
class TenantIdField(serializers.CharField):
    def run_validation(self, data=empty):
        if self.prefer_request_tenant or not data:
            request_tenant_id = get_request_tenant_id(peaceful=True)
            if request_tenant_id:
                data = request_tenant_id
        return super().run_validation(data)
```

**使用方式**:
```python
class SomeResource(Resource):
    class RequestSerializer(serializers.Serializer):
        bk_tenant_id = TenantIdField(label="租户ID")
        # 调用时无需显式传入 bk_tenant_id，自动从 request 注入
```

### get_bcs_dataids()

核心流程：
1. 查询 `BCSClusterInfo` 获取 K8sMetricDataID / CustomMetricDataID
2. 支持按 `bk_biz_id` 或 `cluster_id` 过滤
3. 支持 mode: "k8s" / "custom" / "both"
4. 补充 `ServiceMonitorInfo` / `PodMonitorInfo` 的 DataID
5. 处理跨空间授权场景（`SpaceDataSource`）

def api_client(self) -> k8s_client.ApiClient:

    configuration.host = f"{bcs_api_gateway}/clusters/{self.cluster_id}"
