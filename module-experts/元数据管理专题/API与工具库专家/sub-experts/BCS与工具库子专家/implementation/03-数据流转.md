## 一、HashConsul 写入流程

```mermaid
sequenceDiagram
    participant Caller as 调用方
    participant HC as HashConsul
    participant Consul as Consul KV
    participant Hash as hash_util

    Caller->>HC: put(key, value)
    HC->>HC: 检查 default_force / is_force_update
    alt 强制更新
        HC->>Consul: kv.put(key, value)
        Consul-->>HC: True
    else 非强制
        HC->>Consul: kv.get(key)
        Consul-->>HC: old_value
        alt old_value 为空
            HC->>Consul: kv.put(key, value)
        else
            HC->>Hash: object_md5(old_value)
            Hash-->>HC: old_hash
            HC->>Hash: object_md5(new_value)
            Hash-->>HC: new_hash
            alt old_hash == new_hash
                HC-->>Caller: True (跳过)
            else
                HC->>Consul: kv.put(key, value)
                Consul-->>HC: True
            end
        end
    end
    HC-->>Caller: True/False
```

## 三、share_lock 分布式锁流程

```mermaid
sequenceDiagram
    participant W1 as Worker 1
    participant W2 as Worker 2
    participant Cache as Django Cache (Redis)

    W1->>Cache: SET celery_task_xxx token1 NX EX 600
    Cache-->>W1: OK (获取锁成功)
    W2->>Cache: SET celery_task_xxx token2 NX EX 600
    Cache-->>W2: None (获取锁失败)

    W1->>W1: 执行业务逻辑...

    W1->>Cache: GET celery_task_xxx
    Cache-->>W1: token1
    W1->>W1: 比对 token == token1
    W1->>Cache: DEL celery_task_xxx
    Cache-->>W1: 1 (释放锁)

    W2->>Cache: SET celery_task_xxx token2 NX EX 600
    Cache-->>W2: OK (获取锁成功)
```

## 四、BCS 集群注册 → 数据链路

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Res as BCS 注册 Resource
    participant BCS as BCSClusterInfo
    participant DS as DataSource
    participant RT as ResultTable
    participant TSG as TimeSeriesGroup
    participant EG as EventGroup
    participant Consul as HashConsul

    Client->>Res: 注册 BCS 集群
    Res->>BCS: create(cluster_id, bk_biz_id, ...)
    BCS->>BCS: init_resource()

    par K8S 指标 DataID
        BCS->>DS: create_data_source(etl_config="bk_standard_v2_time_series")
        DS-->>BCS: K8sMetricDataID
        BCS->>RT: create_result_table()
        BCS->>TSG: create(bk_data_id=K8sMetricDataID)
    and 自定义指标 DataID
        BCS->>DS: create_data_source(etl_config="bk_standard_v2_time_series")
        DS-->>BCS: CustomMetricDataID
        BCS->>RT: create_result_table()
        BCS->>TSG: create(bk_data_id=CustomMetricDataID)
    and K8S 事件 DataID
        BCS->>DS: create_data_source(etl_config="bk_standard_v2_event")
        DS-->>BCS: K8sEventDataID
        BCS->>RT: create_result_table()
        BCS->>EG: create(bk_data_id=K8sEventDataID)
    end

    BCS->>Consul: put(consul_config_path, config)
    BCS-->>Res: 集群注册完成
```

## 五、get_bcs_dataids 查询流程

```mermaid
sequenceDiagram
    participant Caller as 调用方
    participant BCS as get_bcs_dataids()
    participant CI as BCSClusterInfo
    participant SM as ServiceMonitorInfo
    participant PM as PodMonitorInfo
    participant SDS as SpaceDataSource

    Caller->>BCS: get_bcs_dataids(bk_biz_ids=[...], mode="both")
    BCS->>CI: objects.all().only(cluster_id, K8sMetricDataID, CustomMetricDataID)
    CI-->>BCS: QuerySet

    BCS->>BCS: 按 bk_biz_ids / cluster_ids 过滤

    loop 每个集群
        BCS->>BCS: 收集 K8sMetricDataID + CustomMetricDataID
    end

    BCS->>SM: filter(cluster_id__in=[...], is_common_data_id=False)
    SM-->>BCS: [bk_data_id, cluster_id, ...]
    BCS->>PM: filter(cluster_id__in=[...], is_common_data_id=False)
    PM-->>BCS: [bk_data_id, cluster_id, ...]

    opt 有 bk_biz_ids
        BCS->>SDS: filter(space_type_id=BKCC, space_id__in=[...])
        SDS-->>BCS: 跨空间授权的 data_id
        BCS->>BCS: 合并跨空间 data_id
    end

    BCS-->>Caller: (data_ids, data_id_cluster_map)
```

## 六、BcsKubeClient K8S API 调用流程

```mermaid
sequenceDiagram
    participant Caller as 调用方
    participant BKC as BcsKubeClient
    participant BCS_API as BCS API Gateway
    participant K8S as K8S API

    Caller->>BKC: BcsKubeClient(cluster_id)
    BKC->>BKC: 构造 auth (host + api_key)
    BKC->>BKC: 创建 ApiClient

    Caller->>BKC: api.list_namespaced_deployment(namespace)
    BKC->>BKC: client_request(api.list_namespaced_deployment, namespace=...)
    BKC->>BCS_API: GET /clusters/{cluster_id}/apis/apps/v1/namespaces/{ns}/deployments
    BCS_API->>K8S: 代理请求
    K8S-->>BCS_API: 响应
    BCS_API-->>BKC: 响应

    alt 超时
        BKC-->>Caller: None (TimeoutError)
    alt 404
        BKC-->>Caller: None (warning)
    alt 403
        BKC-->>Caller: None (warning)
    else 成功
        BKC-->>Caller: 响应数据
    end
```

## 七、TenantIdField 自动注入流程

```mermaid
sequenceDiagram
    participant Res as Resource
    participant Ser as RequestSerializer
    participant TIF as TenantIdField
    participant Req as request.py

    Res->>Ser: is_valid()
    Ser->>TIF: run_validation(data=empty)
    TIF->>TIF: prefer_request_tenant or not data?
    TIF->>Req: get_request_tenant_id(peaceful=True)
    Req-->>TIF: bk_tenant_id (from thread local)
    TIF->>TIF: data = bk_tenant_id
    TIF->>TIF: super().run_validation(data)
    TIF-->>Ser: validated bk_tenant_id
    Ser-->>Res: validated_data (含 bk_tenant_id)
```

## 八、关键数据转换点

| 转换点 | 输入 | 输出 | 位置 |
|--------|------|------|------|
| 对象 → MD5 | dict/list/str | 32 位 hex 字符串 | `object_md5()` |
| 秒数 → 可读 | `90061` | `"1d 1h 1m 1s"` | `hms_string()` |
| 空间 UID → 租户 ID | `"BKCC__123"` | `"system"` | `space_uid_to_bk_tenant_id()` |
| 时间范围解析 | `"2024-01-01 -- 2024-01-02"` | `(start_ts, end_ts)` | `parse_time_range()` |
| DataID → Token | `(metric_id, trace_id, log_id, biz_id)` | AES 加密字符串 | `transform_data_id_to_token()` |
| Consul 值比对 | `old_value, new_value` | 是否写入 | `HashConsul.put()` |
| 集群 ID → K8S 客户端 | `cluster_id` | `ApiClient` | `BcsKubeClient.auth` |
| 业务/集群 → DataID 集合 | `bk_biz_ids, cluster_ids` | `(data_ids, cluster_map)` | `get_bcs_dataids()` |
