## 四、BCS 模型

### 4.1 BCSClusterInfo

**文件**: [`models/bcs/cluster.py`](file://bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/models/bcs/cluster.py)

**核心字段**:

| 字段 | 类型 | 说明 |
|------|------|------|
| `cluster_id` | CharField(128) | BCS 集群 ID（db_index） |
| `bcs_api_cluster_id` | CharField(128) | bcs-api 集群 ID（db_index） |
| `bk_biz_id` | IntegerField | 业务 ID（db_index） |
| `bk_tenant_id` | CharField(256) | 租户 ID |
| `bk_cloud_id` | IntegerField | 云区域 ID |
| `project_id` | CharField(128) | 项目 ID |
| `status` | CharField(50) | 集群状态（running/deleted/init_failed） |
| `domain_name` | CharField(512) | 集群域名 |
| `port` | IntegerField | 集群端口 |
| `server_address_path` | CharField(512) | 集群请求根路径 |
| `api_key_type` | CharField(128) | 认证类型（默认 "authorization"） |
| `api_key_content` | CharField(128) | 认证信息 |
| `api_key_prefix` | CharField(128) | 认证前缀（默认 "Bearer"） |
| `is_skip_ssl_verify` | BooleanField | 是否跳过 SSL（默认 True） |
| `cert_content` | TextField | 认证证书 |
| `K8sMetricDataID` | IntegerField | K8S 指标 DataID（默认 0） |
| `CustomMetricDataID` | IntegerField | 自定义指标 DataID（默认 0） |
| `K8sEventDataID` | IntegerField | K8S 事件 DataID（默认 0） |

**状态常量**:
```python
CLUSTER_STATUS_RUNNING = "running"
CLUSTER_STATUS_DELETED = "deleted"
CLUSTER_STATUS_INIT_FAILED = "init_failed"
CLUSTER_RAW_STATUS_RUNNING = "RUNNING"
CLUSTER_RAW_STATUS_DELETED = "DELETED"
```

**数据类型常量**:
```python
DATA_TYPE_K8S_METRIC = "k8s_metric"
DATA_TYPE_K8S_EVENT = "k8s_event"
DATA_TYPE_CUSTOM_METRIC = "custom_metric"
```

**DATASOURCE_REGISTER_INFO 配置**:

| 类型 | etl_config | report_class | is_split_measurement | is_system | usage |
|------|-----------|-------------|---------------------|-----------|-------|
| k8s_metric | bk_standard_v2_time_series | TimeSeriesGroup | True | True | metric |
| custom_metric | bk_standard_v2_time_series | TimeSeriesGroup | True | False | metric |
| k8s_event | bk_standard_v2_event | EventGroup | — | True | event |

### 4.2 BCSResource（抽象基类）

**文件**: [`models/bcs/resource.py`](file://bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/models/bcs/resource.py)

**核心字段**:

| 字段 | 类型 | 说明 |
|------|------|------|
| `cluster_id` | CharField(128) | 集群 ID |
| `namespace` | CharField(512) | K8S 命名空间 |
| `name` | CharField(128) | 资源名 |
| `bk_data_id` | BigIntegerField | 数据源 ID（db_index） |
| `is_custom_resource` | BooleanField | 是否自定义资源（默认 True） |
| `is_common_data_id` | BooleanField | 是否使用公共 DataID（默认 True） |
| `record_create_time` | DateTimeField | 记录创建时间 |
| `resource_create_time` | DateTimeField | 资源在集群中创建时间 |

**唯一约束**: `(cluster_id, namespace, name)`

**类级属性**:
```python
GROUP: str = "monitoring.coreos.com"
VERSION: str = "v1"
PLURAL: str = None       # 资源复数名
USAGE: str = None         # 用途
```
