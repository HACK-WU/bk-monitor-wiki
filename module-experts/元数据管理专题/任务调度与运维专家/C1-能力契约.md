## 二、管理命令参数

### 2.1 空间管理

```bash
# 同步 CMDB 业务空间
python manage.py sync_cmdb_space --bk_tenant_id=system

# 初始化空间数据
python manage.py init_space_data \
    --init_type=True \      # 初始化空间类型
    --sync_bkcc=True \      # 同步 BKCC 业务
    --sync_bcs=True \       # 同步 BCS 项目
    --init_redis=True       # 推送空间至 Redis
```

### 2.2 数据源/结果表

```bash
# 接入计算平台 VM
python manage.py access_bkdata_vm \
    --space_type=bkcc \           # 空间类型（必填）
    --space_id=2 \                # 空间ID（必填）
    --table_ids="table1;table2" \ # 结果表ID列表（分号分隔）
    --partition=1 \               # partition 数量（默认1）
    --vm_cluster_name="" \        # VM 集群名称
    --vm_retention_time=90d       # 数据保留时间（默认90d）

# 切换 Kafka 集群
python manage.py switch_kafka_for_data_id \
    --data_ids=1001 1002 \        # data_id 列表
    --bk_data_ids="1001,1002" \   # 逗号分隔的 data_id
    --kind=frontend \             # frontend 或 backend（必填）
    --kafka_cluster_id=1          # Kafka 集群ID（必填）
```

### 2.3 数据链路

```bash
# 数据链路健康检查
python manage.py check_datalink_health \
```

## 三、Redis 锁 API

### 3.1 DistributedLock 类

文件：`tools/redis_lock.py`

```python
class DistributedLock:
    """
    Redis 分布式锁

    构造参数:
        redis_client: Redis 客户端实例
        lock_name: 锁名称（标识）
        timeout: 锁过期时间（秒），默认取自 settings.metadata.bkbase_redis_watch_lock_expire_seconds

    方法:
        acquire() -> bool  # 非阻塞获取锁，返回是否成功
        release()          # 释放锁
        renew()            # 手动续约锁（重置过期时间）
    """
```

### 3.2 share_lock 装饰器

文件：`utils/lock.py`（由 API与工具库专家覆盖）

```python
@share_lock(ttl=3600, identify="metadata_lock_identifier")
def my_task():
    """被 share_lock 保护的函数，保证同一时刻只有一个实例执行"""
```

**常用 TTL 值**:
- `PERIODIC_TASK_DEFAULT_TTL` — 默认周期任务 TTL
- `1800` — 30 分钟（InfluxDB 路由刷新）
- `3600` — 60 分钟（VM 接入检测、CMDB 关系同步、实体关系刷新）
