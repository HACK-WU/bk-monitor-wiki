## 一、DataSource 核心 API 契约

### 1.1 创建数据源

**方法**: `DataSource.create_data_source()`

**文件**: `bk-monitor-base/src/bk_monitor_base/metadata/models/data_source.py` 行 499-700

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `data_name` | str | 是 | 数据源名称，与 bk_tenant_id 联合唯一 |
| `etl_config` | str | 是 | 清洗配置，如 `bk_standard`、`bk_standard_v2_time_series` |
| `operator` | str | 是 | 操作者 |
| `source_label` | str | 是 | 数据源标签，需在 Label 中存在 |
| `type_label` | str | 是 | 数据类型标签，需在 Label 中存在 |
| `bk_tenant_id` | str | 否 | 租户ID，默认 `"system"` |
| `bk_data_id` | int | 否 | 数据源ID，None 则自动分配 |
| `mq_cluster` | int | 否 | Kafka 集群ID，None 则使用默认集群 |
| `mq_config` | dict | 否 | Kafka 配置 `{"topic": "xxx", "partition": 1}` |
| `data_description` | str | 否 | 数据源描述 |
| `is_custom_source` | bool | 否 | 是否自定义数据源，默认 True |
| `is_refresh_config` | bool | 否 | 是否刷新外部依赖配置，默认 True |
| `option` | dict | 否 | 额外配置项 |
| `space_type_id` | str | 否 | 空间类型 |
| `space_id` | str | 否 | 空间ID |
| `is_platform_data_id` | bool | 否 | 是否平台级数据源 |
| `authorized_spaces` | list | 否 | 授权使用的空间列表 |
| `space_uid` | str | 否 | 空间 UID |
| `created_from` | str | 否 | 数据源来源，默认 `BKGSE` |
| `bk_biz_id` | int | 否 | 业务ID |

**返回值**: `DataSource` 实例

**异常**:
- `ValueError("标签[xxx]不存在")` — 标签未注册
- `ValueError("数据源名称[xxx]在租户[xxx]下已经存在")` — 名称重复
- `ValueError("缺少数据源MQ集群信息")` — 无默认 Kafka 集群
- `ValueError("数据源ID生成异常")` — DataID 超出范围

| `space_type_id` | str | 否 | 空间类型 |

## 八、约束条件

### 8.1 唯一性约束

| 模型 | 约束字段 |
|------|---------|
| DataSource | `(data_name, bk_tenant_id)` |
| ResultTable | `(table_id, bk_tenant_id)` |
| DataSourceResultTable | `(bk_data_id, table_id, bk_tenant_id)` |
| ResultTableField | `(table_id, field_name, bk_tenant_id)` |
| EntityMeta 子类 | `(namespace, name)` |

### 8.2 命名约束

- 全业务结果表（bk_biz_id=0）不得以数字下划线开头
- 结果表 table_id 会自动转为小写
- EntityMeta 空 namespace 归一化为 `"__all__"`

### 8.3 Schema 约束

- `fixed` schema 结果表不允许新增字段（`is_force_add=False` 时）
- `free` schema 结果表修改字段时会先清理旧字段再重建
