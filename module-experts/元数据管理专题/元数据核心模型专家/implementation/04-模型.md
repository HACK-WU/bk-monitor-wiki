### 1.2 索引与约束

| 约束 | 字段 |
|------|------|
| 主键 | `bk_data_id` |
| 唯一索引 | `(data_name, bk_tenant_id)` |
| 普通索引 | `bk_tenant_id`, `data_name`, `space_type_id`, `created_from` |

### 1.3 Meta 配置

```python
class Meta:
    db_table = "metadata_datasource"
    verbose_name = "数据源管理"
    verbose_name_plural = "数据源管理表"
    unique_together = ("data_name", "bk_tenant_id")
```
