## 一、DataSource 核心 API 契约

### 1.1 创建数据源

**方法**: `DataSource.create_data_source()`

**文件**: `bk-monitor-base/src/bk_monitor_base/metadata/models/data_source.py` 行 499-700

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `data_name` | str | 是 | — | 数据源名称，与 bk_tenant_id 联合唯一 |
| `etl_config` | str | 是 | — | 清洗配置，如 `bk_standard`、`bk_standard_v2_time_series` |
| `operator` | str | 是 | — | 操作者 |
| `source_label` | str | 是 | — | 数据源标签，需在 Label 中存在 |
| `type_label` | str | 是 | — | 数据类型标签，需在 Label 中存在 |
| `bk_tenant_id` | str | 否 | `"system"` | 租户ID |
| `bk_data_id` | int | 否 | None | 数据源ID，None 则自动分配 |
| `mq_cluster` | int | 否 | None | Kafka 集群ID，None 则使用默认集群 |
| `mq_config` | dict | 否 | None | Kafka 配置 `{"topic": "xxx", "partition": 1}` |
| `data_description` | str | 否 | `""` | 数据源描述 |
| `is_custom_source` | bool | 否 | True | 是否自定义数据源 |
| `is_refresh_config` | bool | 否 | True | 是否刷新外部依赖配置 |
| `option` | dict | 否 | None | 额外配置项 |
| `space_type_id` | str | 否 | None | 空间类型 |
| `space_id` | str | 否 | None | 空间ID |
| `is_platform_data_id` | bool | 否 | False | 是否平台级数据源 |
| `authorized_spaces` | list | 否 | None | 授权使用的空间列表 |
| `space_uid` | str | 否 | None | 空间 UID |
| `created_from` | str | 否 | `"bkgse"` | 数据源来源（`bkgse` / `bkdata`） |
| `bk_biz_id` | int | 否 | None | 业务ID |
| `bcs_cluster_id` | str | 否 | None | BCS 集群 ID |

**返回值**: `DataSource` 实例

**异常**:
- `ValueError("标签[xxx | yyy]不存在，请确认后重试")` — 标签未注册
- `ValueError("数据源名称[xxx]在租户[xxx]下已经存在，请确认后重试")` — 名称重复
- `ValueError("缺少数据源MQ集群信息，请联系管理员协助处理")` — 无默认 Kafka 集群
- `ValueError("数据源ID生成异常，请联系管理员协助处理")` — DataID 超出范围
- `ValueError("数据源ID分配达到最大上限，请联系管理员协助处理")` — 超过 MAX_DATA_ID
- `ValueError("kafka cluster xxx is not registered to bkbase")` — V4 链路 Kafka 未注册

### 1.2 更新数据源

**方法**: `DataSource.update_config()`

**文件**: `data_source.py` 行 800-920

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `operator` | str | 是 | 操作者 |
| `data_name` | str | 否 | 新数据源名称 |
| `mq_cluster_id` | int | 否 | 新 Kafka 集群 ID |
| `etl_config` | str | 否 | 新清洗配置 |
| `data_description` | str | 否 | 新描述 |
| `option` | dict | 否 | 选项更新 |
| `is_enable` | bool | 否 | 启用/停用（仅 BKGSE 来源有效） |
| `is_platform_data_id` | bool | 否 | 是否平台级 |
| `space_type_id` | str | 否 | 空间类型 |
| `space_uid` | str | 否 | 空间 UID |
| `created_from` | str | 否 | 数据源来源 |
| `authorized_spaces` | list | 否 | 授权空间 |

**返回值**: `True`

**异常**:
- `ValueError("集群配置不存在，请确认")` — Kafka 集群不存在
- `ValueError("数据源名称已存在，请确认")` — 名称重复

### 1.3 刷新外部配置

**方法**: `DataSource.refresh_outer_config()`

**文件**: `data_source.py` 行 1250-1270

刷新 GSE ZK 配置和 Consul 配置。仅对 `is_enable=True` 且 `created_from=BKGSE` 的数据源生效。

**返回值**: `True`

### 1.4 刷新 Consul 配置

**方法**: `DataSource.refresh_consul_config()`

**文件**: `data_source.py` 行 1200-1250

将数据源配置写入 Consul，路径为 `{CONSUL_PATH}/data_id/{transfer_cluster_id}/{data_id}`。跳过 `IGNORED_CONSUL_SYNC_DATA_IDS` 中的数据源。

### 1.5 刷新 GSE 配置

**方法**: `DataSource.refresh_gse_config()`

**文件**: `data_source.py` 行 1150-1200

同步路由配置到 GSE ZK。流程：查询 GSE 现有路由 → MD5 比对 → 不一致则调用 `api.gse.update_route()` 更新。

### 1.6 注册到计算平台

**方法**: `DataSource.register_to_bkbase()`

**文件**: `data_source.py` 行 350-380

将数据源注册到计算平台（BkData），更新 `created_from` 为 `BKDATA`。

**参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `bk_biz_id` | int | 业务ID |
| `namespace` | str | 命名空间（如 `bk_monitor`） |
| `bkbase_data_name` | str | 计算平台数据名称 |

### 1.7 序列化

**方法**: `DataSource.to_json(is_consul_config=False, with_rt_info=True)`

**文件**: `data_source.py` 行 220-300

**参数**:
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `is_consul_config` | bool | False | 是否 Consul 配置格式 |
| `with_rt_info` | bool | True | 是否包含结果表信息 |

**返回值**: dict，包含：
- 基础信息：`bk_data_id`, `bk_tenant_id`, `data_name`, `token`
- MQ 配置：`mq_config`（topic, partition, batch_size, cluster_config）
- ETL 配置：`etl_config`, `option`
- 结果表列表：`result_table_list`（当 `with_rt_info=True`）

## 六、约束条件

### 6.1 唯一性约束

| 模型 | 约束字段 |
|------|---------|
| DataSource | `(data_name, bk_tenant_id)` |
| DataSourceResultTable | `(bk_data_id, table_id, bk_tenant_id)` |
| Label | `label_id`（主键） |

### 6.2 命名约束

- `data_name` 在租户下唯一
- `space_uid` 格式：`{space_type_id}__{space_id}`（双下划线分隔）

### 6.3 状态约束

- 仅 `created_from=BKGSE` 的数据源支持 `is_enable` 切换
- 停用数据源会自动删除 Consul 配置
- V4 链路数据源（`created_from=BKDATA`）不支持停用
