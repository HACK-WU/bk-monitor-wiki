## 一、create_data_source 完整流程

**文件**: `data_source.py` 行 499-700

### 1.1 流程概览

```
create_data_source() 7 步流程:
┌──────────────────────────────────────────────────┐
│ 步骤1: 前置校验                                    │
│   ├── 校验 source_label 和 type_label 存在性       │
│   └── 校验 data_name 在租户下唯一                   │
├──────────────────────────────────────────────────┤
│ 步骤2: 获取 Kafka 集群                             │
│   ├── mq_cluster 已提供 → 直接使用                  │
│   └── mq_cluster 未提供 → 查询默认集群              │
│       └── ClusterInfo.objects.get(                 │
│           cluster_type=DEFAULT_MQ_TYPE,            │
│           is_default_cluster=True                  │
│         )                                          │
├──────────────────────────────────────────────────┤
│ 步骤3: 分配 DataID                                 │
│   ├── is_assign_dataid_by_gse=True:               │
│   │   ├── V4 链路条件满足 → apply_for_data_id_from_bkdata() │
│   │   │   └── created_from = BKDATA               │
│   │   └── 否则 → apply_for_data_id_from_gse()      │

│   ├── 创建 KafkaTopicInfo → 回填 mq_config_id      │

├──────────────────────────────────────────────────┤
│ 步骤6: 刷新外部配置（is_refresh_config=True）        │
│   └── refresh_outer_config()                       │
│       ├── refresh_gse_config()                     │
```

### 1.4 步骤3：分配 DataID

```python
# data_source.py 行 572-630
if bk_data_id is None and settings.metadata.is_assign_dataid_by_gse:

    if (settings.metadata.enable_v2_vm_data_link

            event_type=event_type,

        # V3 链路：从 GSE 申请

```

**V4 链路额外条件**:
- `settings.metadata.enable_v2_vm_data_link` 为 True
- `etl_config` 在 `ENABLE_V4_DATALINK_ETL_CONFIGS` 列表中
- Kafka 集群已注册到 BkBase（`mq_cluster.registered_to_bkbase`）

### 1.5 步骤4：事务内创建

```python
# data_source.py 行 635-680
with atomic(config.DATABASE_CONNECTION_NAME):
    # 4a. 创建 DataSource 记录（mq_config_id 先填 0）
    data_source = cls.objects.create(
        bk_data_id=bk_data_id,
        data_name=data_name,
        bk_tenant_id=bk_tenant_id,
        etl_config=etl_config,
        creator=operator,
        mq_cluster_id=mq_cluster.cluster_id,
        mq_config_id=0,  # 占位符
        # ... 其他字段
    )
    
    # 4b. DataID 范围校验（仅自增模式）
    if not settings.metadata.is_assign_dataid_by_gse:
        if data_source.bk_data_id < config.MIN_DATA_ID:
            # 尝试使用最小 ID
            if not cls.objects.filter(bk_data_id=config.MIN_DATA_ID).exists():
                data_source.delete()
                data_source.bk_data_id = config.MIN_DATA_ID
                data_source.save()
            else:
                raise ValueError("数据源ID生成异常")
        
        if data_source.bk_data_id > config.MAX_DATA_ID:
            raise ValueError("数据源ID分配达到最大上限")
    
    # 4c. 创建 KafkaTopicInfo 并回填 mq_config_id
    mq_config = cls.MQ_CONFIG_DICT[mq_cluster.cluster_type].create_info(
        bk_data_id=data_source.bk_data_id, **mq_config
    )
    data_source.mq_config_id = mq_config.id
    data_source.save()
    
    # 4d. 设置 space_uid
    if space_uid:
        space_type_id, space_id = space_uid.split(SPACE_UID_HYPHEN)
        data_source.space_uid = space_uid
        data_source.space_type_id = space_type_id
        data_source.save()
    elif bk_biz_id:
        # 从业务ID推导空间
        if bk_biz_id > 0:
            space = Space.objects.get(space_type_id=SpaceTypes.BKCC.value, space_id=str(bk_biz_id))
        else:
            space = Space.objects.get(id=-bk_biz_id)
        data_source.space_uid = space.space_uid
        data_source.save()
    
    # 4e. 创建 DataSourceOption
    option = {} if option is None else option
    option.update({DataSourceOption.OPTION_DROP_METRICS_ETL_CONFIGS: True})
    for option_name, option_value in list(option.items()):
        DataSourceOption.create_option(
            bk_data_id=data_source.bk_data_id,
            name=option_name,
            value=option_value,
            creator=operator
        )
    
    # 添加时间相关 option
    cls._add_time_unit_options(operator, data_source.bk_data_id, etl_config)
```

## 二、update_config 逐项更新流程

**文件**: `data_source.py` 行 800-920

### 2.1 流程概览

```
update_config() 逐项检查并更新:
1. etl_config → 直接赋值
2. mq_cluster_id → 校验集群存在 → 赋值
3. data_name → 校验唯一性 → 赋值
4. data_description → 直接赋值
5. option → create_or_update 逐项处理
6. is_enable → 仅 BKGSE 来源有效 → 停用时删除 Consul
7. is_platform_data_id → 直接赋值
8. space_type_id → 直接赋值
9. space_uid → 直接赋值
10. created_from → 直接赋值
11. 如果有变更 → save() + refresh_outer_config()
12. authorized_spaces → 处理授权空间关系
```

### 2.2 is_enable 处理细节

```python
# data_source.py 行 870-885
if is_enable is not None and (
    self.created_from == DataIdCreatedFromSystem.BKGSE.value
    or created_from == DataIdCreatedFromSystem.BKGSE.value
):
    consul_client = consul.BKConsul()
    self.is_enable = is_enable
    
    if not is_enable:
        # 停用：删除 Consul 配置
        consul_client.kv.delete(self.consul_config_path)
```

**关键约束**: 仅 BKGSE 来源的数据源支持 `is_enable` 切换。V4 链路（BKDATA）数据源不支持停用。

```python
    }
    
    if with_rt_info:
        # 批量查询结果表信息
        result_table_id_list = [...]
        real_table_ids = {...}  # 过滤 is_deleted=False, is_enable=True
        table_id_option_dict = ResultTableOption.batch_result_table_option(...)
        table_field_dict = ResultTableField.batch_get_fields(...)
        
        result_config["result_table_list"] = [
            {
```

### 3.2 批量查询优化

为避免 N+1 查询，`to_json` 中使用了批量查询：
- `ResultTableOption.batch_result_table_option()` — 批量获取结果表选项
- `ResultTableField.batch_get_fields()` — 批量获取字段信息
- `DataSourceResultTable.objects.filter()` — 一次查询获取所有关联

### 4.1 refresh_outer_config

```python
# data_source.py 行 1250-1270
def refresh_outer_config(self):
    if not self.can_refresh_consul_and_gse():
        return True  # 跳过
    
    self.refresh_gse_config()    # GSE ZK 路由
    self.refresh_consul_config() # Consul ETL 配置
    return True
```

### 4.2 can_refresh_consul_and_gse

```python
# data_source.py 行 1230-1245
def can_refresh_consul_and_gse(self):
    return self.is_enable and self.created_from == DataIdCreatedFromSystem.BKGSE.value
```

### 4.3 refresh_gse_config

```python
# data_source.py 行 1150-1200
def refresh_gse_config(self):
    if not self.can_refresh_consul_and_gse():
        return
    self.refresh_gse_config_to_gse()
```

`refresh_gse_config_to_gse()` 流程：
1. 查询 GSE 现有路由配置
2. MD5 比对新旧配置
3. 不一致则调用 `api.gse.update_route()` 更新

### 4.4 refresh_consul_config

```python
# data_source.py 行 1200-1250
def refresh_consul_config(self):
    # 跳过 IGNORED_CONSUL_SYNC_DATA_IDS
    if self.bk_data_id in IGNORED_CONSUL_SYNC_DATA_IDS:
        return
    
    consul_path = self.consul_config_path
    consul_config = self.to_json(is_consul_config=True)
    hash_consul.put(consul_path, consul_config)
```

```python
@classmethod
def create_option(cls, bk_data_id, name, value, creator, bk_tenant_id=DEFAULT_TENANT_ID):
    val, val_type = cls._parse_value(value)
    return cls.objects.create(
```

### 5.2 create_or_update

```python
# data_source.py 行 1325-1350
@classmethod
def create_or_update(cls, bk_data_id, name, value, creator, bk_tenant_id=DEFAULT_TENANT_ID):
    val, val_type = cls._parse_value(value)
    option, created = cls.objects.update_or_create(
        bk_data_id=bk_data_id,
        name=name,
        bk_tenant_id=bk_tenant_id,
        defaults={
            "value_type": val_type,
            "value": val,
            "creator": creator,
        }
    )
    return option
```
