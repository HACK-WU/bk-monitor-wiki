### 2.3 同步实现

```python
# data_source.py 行 1200-1250
def refresh_consul_config(self):
    # 跳过黑名单中的数据源
    if self.bk_data_id in IGNORED_CONSUL_SYNC_DATA_IDS:
        logger.info("data_id->[%s] is in ignored list, skip consul sync", self.bk_data_id)
        return
    
    consul_path = self.consul_config_path
    consul_config = self.to_json(is_consul_config=True)
    
    # 写入 Consul
    hash_consul.put(consul_path, consul_config)
```

## 三、GSE 路由同步

### 3.1 同步流程

```mermaid
sequenceDiagram
    participant DS as "DataSource"
    participant GSE as "GSE API"
    participant ZK as "GSE ZK"

    DS->>GSE: 查询现有路由配置
    GSE-->>DS: 返回当前路由 JSON
    DS->>DS: MD5 比对新旧配置
    alt 配置不一致
        DS->>GSE: api.gse.update_route(新配置)
        GSE->>ZK: 写入 ZK
    else 配置一致
        DS->>DS: 跳过更新
    end
```

### 3.2 路由配置结构

```python
# data_source.py 行 1090-1120
@property
def gse_route_config(self):
    return {
        "name": f"stream_to_{plat_name}_{mq_type}_{topic}",
        "stream_to": {
            "stream_to_id": self.bk_data_id,
            "kafka": {
                "topic_name": self.mq_config.topic,
                "partition": self.mq_config.partition,
            }
        }
    }
```

### 3.3 同步实现

```python
# data_source.py 行 1150-1200
def refresh_gse_config_to_gse(self):
    # 1. 查询 GSE 现有路由
    existing_routes = api.gse.get_route()
    
    # 2. 构建新路由配置
    new_route = self.gse_route_config
    
    # 3. MD5 比对
    existing_md5 = md5(json.dumps(existing_routes))
    new_md5 = md5(json.dumps(new_route))
    
    if existing_md5 != new_md5:
        # 4. 更新路由
        api.gse.update_route(new_route)
```

## 五、空间归属数据流

### 5.1 空间关系建立

```mermaid
sequenceDiagram
    participant DS as "DataSource"
    participant Space as "Space 表"
    participant SDS as "SpaceDataSource 表"

    DS->>DS: create_data_source()
    
    alt space_uid 直接提供
        DS->>DS: 解析 space_type_id__space_id
    else 从 bk_biz_id 推导
        alt bk_biz_id > 0
            DS->>Space: get(space_type_id=bkcc, space_id=str(bk_biz_id))
        else bk_biz_id <= 0
            DS->>Space: get(id=-bk_biz_id)
        end
        Space-->>DS: space.space_uid
    end
    
    DS->>SDS: _save_space_datasource()
    Note over SDS: 创建归属空间记录<br/>(from_authorization=False)
    
    opt authorized_spaces 提供
        DS->>SDS: 创建授权空间记录<br/>(from_authorization=True)
    end
```

### 5.2 _save_space_datasource 实现

```python
# data_source.py 行 1435-1480
def _save_space_datasource(self, creator, space_type_id, space_id,
                            bk_tenant_id, bk_data_id, authorized_spaces=None):
    # 创建归属空间记录
    SpaceDataSource.objects.get_or_create(
        bk_data_id=bk_data_id,
        bk_tenant_id=bk_tenant_id,
        from_authorization=False,
        defaults={
            "space_id": space_id,
            "space_type_id": space_type_id,
        }
    )
    
    # 处理授权空间
    if authorized_spaces:
        for auth_space in authorized_spaces:
            SpaceDataSource.objects.get_or_create(
                bk_data_id=bk_data_id,
                bk_tenant_id=bk_tenant_id,
                space_id=auth_space["space_id"],
                space_type_id=auth_space["space_type_id"],
                from_authorization=True,
            )
```

## 六、Consul 配置消费端

### 6.1 Transfer 消费流程

```mermaid
sequenceDiagram
    participant Transfer as "Transfer 进程"
    participant Consul as "Consul"
    participant Kafka as "Kafka"
    participant Storage as "存储后端"

    loop 定期拉取
        Transfer->>Consul: 读取 data_id 配置
        Consul-->>Transfer: ETL配置 + 结果表 + 字段 + 存储路由
    end
    
    Transfer->>Kafka: 消费数据
    Transfer->>Transfer: 按 ETL 配置清洗
    Transfer->>Storage: 按存储路由写入
```

### 6.2 配置变更感知

Transfer 通过 Consul Watch 机制感知配置变更，无需重启即可应用新的 ETL 配置。
