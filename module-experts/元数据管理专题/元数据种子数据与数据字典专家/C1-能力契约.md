```json
        "value_type": "string",
        "value": "ms",
        "name": "timestamp_precision"
```

### 1.2 init_resulttable.json — 结果表种子

**契约来源**: [init_resulttable.json](file:///root/bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/data/init_resulttable.json) L1-L8542

```json
[
  {
    "table_id": "apache.net",            // 结果表 ID（格式：database.table_name）
    "table_name_zh": "apache.net",       // 中文表名
    "is_custom_table": false,            // 是否自定义表
    "schema_type": "fixed",              // schema 类型（fixed/free）
    "default_storage": "influxdb",       // 默认存储（influxdb/elasticsearch）
    "bk_biz_id": 0,                      // 业务 ID（0=全局）
    "data_label": "",                    // 数据标签
    "label": "component",                // 结果表分类标签
    "option_list": [],                   // 结果表选项
    "bk_data_id": 1004,                  // 关联的数据源 ID
    "field_list": [                      // 字段列表
      {
        "field_name": "ip",              // 字段名
        "field_type": "string",          // 字段类型（string/int/float/double/timestamp）
        "description": "采集器IP",        // 字段描述
        "unit": "",                      // 单位
        "tag": "dimension",              // 角色标签（metric/dimension/timestamp）
        "alias_name": "",                // 别名
        "option_list": []                // 字段选项
      },
      {
        "field_name": "total_accesses_min",
        "field_type": "int",
        "description": "请求数",
        "unit": "次",
        "tag": "metric",
        "alias_name": "",
        "option_list": []
      }
    ]
  }
]
```

**关键约束**：
- `table_id` 使用点号分隔（`database.table_name`）
- `field_list` 中 `tag` 字段决定字段角色：`metric`（可聚合）、`dimension`（分组过滤）、`timestamp`（时间）
- `default_storage` 决定创建 InfluxDB 还是 ES 存储

### 1.3 description_unit.json — 指标描述与单位

**契约来源**: [description_unit.json](file:///root/bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/data/description_unit.json) L1-L2684

```json
[

    "conversion": 1.0,                         // 转换系数
```

**关键约束**：

- `item_display` 写入 `ResultTableField.description`
- `conversion_unit` 写入 `ResultTableField.unit`

## 三、与 UnifyQuery 的对接契约

### 3.1 查询链路映射

**契约来源**: [cmdb.py](file:///root/bk-monitor/bkmonitor/packages/monitor_web/cc/resources/cmdb.py) L52-L58

UnifyQuery 查询时，以下参数与种子数据的映射关系：

| UnifyQuery 参数 | 种子数据来源 | 匹配字段 |
|----------------|-------------|---------|
| `load_data_source("bk_monitor", "time_series")` | `init_datasource.json` | `source_label="bk_monitor"` + `type_label="time_series"` |
| `table="system.cpu_summary"` | `init_resulttable.json` | `table_id="system.cpu_summary"` |
| `field="usage"` | `init_resulttable.json` → `field_list` | `field_name="usage"` + `tag="metric"` |
| `usage` 的单位 `%` | `description_unit.json` | `result_table_id="system_cpu_summary"` + `item="usage"` → `conversion_unit` |
| `usage` 的中文描述 | `description_unit.json` | `result_table_id="system_cpu_summary"` + `item="usage"` → `item_display` |

### 3.2 实际代码示例

```python
# 来源: bkmonitor/packages/monitor_web/cc/resources/cmdb.py L52-L58
data_source_class = load_data_source(DataSourceLabel.BK_MONITOR_COLLECTOR, DataTypeLabel.TIME_SERIES)
data_source = data_source_class(
    bk_biz_id=bk_biz_id,
    interval=180,
    metrics=[{"field": "usage", "method": "AVG", "alias": "A"}],
    table="system.cpu_summary",
    group_by=["bk_host_id", "bk_target_ip", "bk_target_cloud_id"],
)
query = UnifyQuery(data_sources=[data_source], bk_biz_id=bk_biz_id, expression="a")
records = query.query_data(start_time=now - 180000, end_time=now, instant=True)
```

### 3.3 数据字典层角色

种子数据在 UnifyQuery 查询链路中充当"数据字典"层：

1. **数据源匹配**：`source_label` + `type_label` → 确定数据源类型
2. **表匹配**：`table_id` → 确定结果表
3. **字段匹配**：`field_name` + `tag="metric"` → 确定可查询的指标字段
4. **单位与描述**：`result_table_id` + `item` → 获取 `conversion_unit` 和 `item_display`

## 四、依赖关系

| 依赖 | 方式 | 说明 |
|------|------|------|
| `Label` 模型 | Django ORM bulk_create | init_label.json → Label 表 |
| `DataSource` 模型 | Django ORM create | init_datasource.json → DataSource 表 |
| `ResultTable` 模型 | Django ORM create | init_resulttable.json → ResultTable 表 |
| `ResultTableField` 模型 | Django ORM create/update | init_resulttable.json + description_unit.json → ResultTableField 表 |
| `DataSourceResultTable` 模型 | Django ORM create | 关联关系 |
| `ClusterInfo` 模型 | Django ORM create | init_cluster_info.json → ClusterInfo 表 |
| `InfluxDBStorage` 模型 | Django ORM create | 默认存储为 influxdb 时创建 |
| `ESStorage` 模型 | Django ORM create | 默认存储为 elasticsearch 时创建 |
| `KafkaStorage` 模型 | Django ORM create | init_storage.json 中列出的表 |
| `TimeSeriesGroup` / `EventGroup` 模型 | Django ORM bulk_create | init_ts_or_event_group.json |
| `migration_util` 工具函数 | Python import | add_datasource, add_resulttable, add_resulttablefield 等 |
