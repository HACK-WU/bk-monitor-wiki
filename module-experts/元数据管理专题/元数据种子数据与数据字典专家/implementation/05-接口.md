### 3.1 GetK8sEventListResource — K8s 事件查询

**位置**: [resources.py](file:///root/bk-monitor/bkmonitor/metadata/resources/resources.py) L978

```python
from bkmonitor.utils.k8s_metric import get_built_in_k8s_events, get_built_in_k8s_metrics

class GetK8sEventListResource(Resource):
    def _compose_in_event(self, event_query_set: QuerySet) -> list:
        built_events = get_built_in_k8s_events()
        built_event_map = {event["event_name"]: event for event in built_events}
        # 仅针对 k8s 事件添加内置事件
        for qs in event_query_set:
            if not data["event_group_name"].startswith("bcs_BCS-K8S-"):
                continue
            # 补充缺失的内置事件
            for event_name in set(built_event_map.keys()) - set(event_name_list):
                event_info_list.append(built_event_map.get(event_name))
```

**调用关系**：
- `get_built_in_k8s_events()` 获取 26 个内置事件
- 仅对 `event_group_name` 以 `bcs_BCS-K8S-` 开头的事件组补充内置事件
- 使用 `set` 差集计算缺失的内置事件

### 3.2 GetK8sMetricListResource — K8s 指标查询

**位置**: [resources.py](file:///root/bk-monitor/bkmonitor/metadata/resources/resources.py) L1965-L1988

```python
class GetK8sMetricListResource(Resource):
    def perform_request(self, validated_request_data):
        k8s_metrics = get_built_in_k8s_metrics()

        # 业务id为0时，获取 k8s 系统内置指标
        if bk_biz_ids and 0 in bk_biz_ids and not (dimension_name and dimension_value):
            self._refine_built_in_metric_dimensions(metric_datas, k8s_metrics)

        built_in_metric_field_list = [metric["field_name"] for metric in k8s_metrics]
        # 获取自定义及内置指标
        self._refine_metric_dimensions_from_redis(
            bk_tenant_id, bk_biz_ids, cluster_ids,
            dimension_name, dimension_value, metric_datas, built_in_metric_field_list,
        )
```

**调用关系**：
- `get_built_in_k8s_metrics()` 获取所有内置指标
- `bk_biz_ids` 包含 `0` 时，补充内置指标维度
- `built_in_metric_field_list` 用于从 Redis 获取自定义指标时去重
