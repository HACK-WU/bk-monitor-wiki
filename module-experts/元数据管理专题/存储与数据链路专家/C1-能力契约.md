## 一、Storage 核心 API

### 1.1 ClusterInfo — 集群信息管理

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `create_cluster` | `(bk_tenant_id, cluster_type, domain_name, port, registered_system, operator, ...) -> ClusterInfo` | 创建集群，含冲突检测、集群初始化、ES 集群同步到 BKBase |
| `modify` | `(operator, ...) -> None` | 修改集群配置，支持部分字段更新 |
| `consul_config` | `@property -> dict` | 返回 Consul 存储配置（含 SSL 证书 base64 编码） |
| `cluster_detail` | `@property -> dict` | 返回集群完整详情（含 auth_info、label、default_settings） |
| `cluster_init` | `() -> None` | ES 集群初始化（禁用 write_ 开头的自动索引创建） |
| `refresh_consul_storage_config` | `@classmethod -> None` | 刷新所有集群的 Consul 配置 |
| `to_dict` | `(fields, exclude) -> dict` | 序列化为字典 |

### 1.2 StorageResultTable — 存储基类（Mixin）

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `create_table` | `@classmethod (table_id, is_sync_db, **kwargs) -> Storage` | 抽象方法，创建存储记录 |
| `get_client` | `() -> Any` | 抽象方法，获取存储客户端 |
| `add_field` | `(field) -> None` | 抽象方法，添加字段 |
| `consul_config` | `() -> dict` | 返回 Consul 配置 |
| `storage_type` | `@property -> str` | 返回存储类型 |
| `storage_cluster` | `@property -> ClusterInfo` | 返回关联的集群信息（含缓存） |
| `update_storage` | `(**kwargs) -> bool` | 更新存储配置，ES 类型自动处理集群迁移记录 |

### 1.3 InfluxDBStorage — 时序存储

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `create_table` | `(table_id, is_sync_db, storage_cluster_id, database, real_table_name, source_duration_time, proxy_cluster_name, influxdb_proxy_storage_id, **kwargs) -> InfluxDBStorage` | 创建 InfluxDB 存储，支持 proxy 路由 |
| `get_influxdb_storage` | `(influxdb_proxy_storage_id, proxy_cluster_name, storage_cluster_id) -> InfluxDBProxyStorage` | 获取 proxy 与后端存储映射 |
| `influxdb_proxy_storage` | `@property -> InfluxDBProxyStorage` | 关联的 proxy storage 记录 |
| `export_data` / `import_data` | `@classmethod` | 数据导入导出 |

### 1.4 ESStorage — ES 存储

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `create_table` | `(table_id, bk_tenant_id, is_sync_db, date_format, slice_size, slice_gap, index_settings, mapping_settings, cluster_id, retention, warm_phase_days, warm_phase_settings, time_zone, **kwargs) -> ESStorage` | 创建 ES 存储，支持索引分片、暖数据迁移 |
| `create_es_index` | `(is_sync_db) -> None` | 创建 ES 索引（同步或 Celery 异步） |
| `refresh_consul_table_config` | `@classmethod -> None` | 刷新 ES 表 Consul 配置 |
| `is_index_enable` | `() -> bool` | 判断索引是否启用 |

### 1.5 KafkaStorage — Kafka 存储

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `create_table` | `(table_id, bk_tenant_id, is_sync_db, storage_cluster_id, topic, partition, retention, use_default_format, **kwargs) -> KafkaStorage` | 创建 Kafka 存储，默认 topic 格式 `{prefix}_{table_id}` |

### 1.6 DorisStorage — Doris 存储

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `create_table` | `(table_id, is_sync_db, bk_tenant_id, source_type, bkbase_table_id, index_set, table_type, field_config_mapping, expire_days, storage_cluster_id, **kwargs) -> DorisStorage` | 创建 Doris 存储，支持主键模型和明细模型 |

### 1.7 StorageClusterRecord — 集群迁移记录

| 字段 | 说明 |
|------|------|
| `table_id` | 结果表 ID |
| `cluster_id` | 集群 ID |
| `is_current` | 是否当前集群 |
| `enable_time` | 启用时间 |
| `disable_time` | 停用时间 |

## 二、DataLink 核心 API

### 2.1 DataLink — 链路编排器

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `apply_data_link` | `(data_source, table_id, bk_biz_id, storage_cluster_name, ...) -> DataLink` | 链路上线主流程：组装配置 → 下发 BKBase → 同步元数据 |
| `delete_data_link` | `() -> None` | 删除链路：逆序清理组件 → 删除自身 |
| `compose_configs` | `(...) -> list[dict]` | 策略分发，根据 data_link_strategy 调用对应 compose_*_configs |
| `sync_metadata` | `(data_source, table_id, storage_cluster_name) -> None` | 同步普通链路元数据（BkBaseResultTable + AccessVMRecord） |
| `sync_basereport_metadata` | `(...) -> None` | 同步基础采集链路元数据 |
| `apply_data_link_with_retry` | `(configs) -> None` | 带重试（4 次指数退避）下发 BKBase API |

### 2.2 DataLinkResourceConfigBase — 配置基类

| 方法/属性 | 签名 | 说明 |
|----------|------|------|
| `compose_config` | `@classmethod (*args, **kwargs) -> dict` | 抽象方法，渲染组件配置 |
| `delete_config` | `() -> None` | 删除 BKBase 组件 + 本地记录 |
| `component_status` | `@property -> str` | 组件实时状态（BKBase 查询） |
| `component_config` | `@property -> dict` | 组件完整配置（BKBase 查询） |
| `datalink_biz_ids` | `@property -> list` | 数据链路业务 ID |

### 2.3 service.py — 服务入口

| 函数 | 签名 | 说明 |
|------|------|------|
| `apply_data_id_v2` | `(bk_tenant_id, data_name, bk_biz_id, namespace, is_base, event_type, prefer_kafka_cluster_name) -> bool` | 申请 DataId 组件并落库 |
| `get_data_id_v2` | `(bk_tenant_id, data_name, namespace, is_base, with_detail) -> dict` | 获取 data_id 与状态，Ok 时回填 bk_data_id |
| `get_data_link_component_status` | `(bk_tenant_id, kind, component_name, namespace) -> str` | 获取组件状态（带重试） |
| `get_data_link_component_config` | `(bk_tenant_id, kind, component_name, namespace) -> dict` | 获取组件完整配置 |

### 2.4 relation.py — 关联重建

| 函数 | 签名 | 说明 |
|------|------|------|
| `rebuild_databus_relation` | `(databus, dry_run) -> DataLink | dict | None` | 以单个 DataBus 为单位重建组件关联 |
| `rebuild_bkbase_v4_datalink_relation` | `(bk_tenant_id, namespace) -> None` | 批量重建 BKBase V4 组件关联关系 |

## 五、依赖关系

| 依赖 | 方式 | 说明 |
|------|------|------|
| `ResultTable` | 外键 (table_id) | 所有 Storage 模型依赖结果表 |
| `DataSource` | 外键 (bk_data_id) | DataLink 依赖数据源 |
| `DataSourceResultTable` | 外键 | DataLink 依赖数据源-结果表关系 |
| `ClusterInfo` | 外键 (storage_cluster_id) | 所有 Storage 模型依赖集群信息 |
| `api.bkdata` | HTTP API | DataLink 下发/删除/查询 BKBase 组件 |
| `consul_tools.HashConsul` | Consul KV | 集群配置、ES 表配置刷新 |
| `RedisTools` | Redis | InfluxDB 路由推送、VM 路由刷新 |
