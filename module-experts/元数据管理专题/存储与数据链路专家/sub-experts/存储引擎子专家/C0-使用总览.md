## 一、存储引擎概览

bk-monitor 支持 7 种存储引擎，通过统一的 `ClusterInfo` 模型管理集群信息，通过各自的 Storage 模型管理结果表级存储配置。

| 存储引擎 | 模型类 | 存储类型 | 适用场景 | 数据特征 |
|---------|--------|---------|---------|---------|
| InfluxDB | `InfluxDBStorage` | `influxdb` | 时序指标 | 支持降样、tag 分区、proxy 路由 |
| Elasticsearch | `ESStorage` | `elasticsearch` | 日志/事件 | 索引分片、暖数据迁移、快照备份 |
| Kafka | `KafkaStorage` | `kafka` | 实时告警流 | 短期保留（30 分钟） |
| VictoriaMetrics | `AccessVMRecord` | `victoria_metrics` | 新时序引擎 | 替代 InfluxDB、BCS 集群指标 |
| Redis | `RedisStorage` | `redis` | 缓存/临时数据 | 键值存储 |
| Argus | `ArgusStorage` | `argus` | Argus 监控 | 专用监控存储 |
| Doris | `DorisStorage` | `doris` | OLAP 分析 | 主键模型/明细模型 |

## 二、集群管理

### 2.1 ClusterInfo 统一入口

所有存储引擎的集群信息通过 `ClusterInfo` 统一管理，支持：
- 8 种集群类型（InfluxDB/Kafka/Redis/ES/Argus/VM/Doris/BkData）
- SSL/TLS 证书管理（加密存储）
- SASL 认证（Kafka 场景）
- GSE 注册
- Consul 配置自动刷新
- BKBase 集群同步（ES 类型）

### 2.2 InfluxDB 集群拓扑

```
InfluxDBProxyStorage: Proxy 集群 ↔ 后端 InfluxDB 实例映射
InfluxDBClusterInfo: 集群拓扑信息
InfluxDBHostInfo: 集群主机健康状态
InfluxDBTagInfo: Tag 分区路由配置
```

## 三、典型使用场景

### 场景 1：创建时序指标存储

1. 注册 InfluxDB 集群（`ClusterInfo.create_cluster`）
2. 配置 Proxy 映射（`InfluxDBProxyStorage`）
3. 创建存储（`InfluxDBStorage.create_table`）
4. 自动推送路由到 Redis

### 场景 2：创建日志存储

1. 注册 ES 集群
2. 创建存储（`ESStorage.create_table`）
3. 创建索引（`ESStorage.create_es_index`）
4. 可选：配置暖数据迁移、快照备份

### 场景 3：ES 集群迁移

1. 更新 ESStorage 的 `storage_cluster_id`
2. `update_storage` 自动创建 `StorageClusterRecord`
3. 自动刷新 Consul 路由

### 场景 4：VM 数据接入

1. 注册 VM 集群
2. 创建 `AccessVMRecord`（记录 result_table_id → vm_result_table_id 映射）
3. 刷新 VM 路由到 Redis
