# C1-能力契约

> **子专家**: 存储引擎子专家
> **层级**: 契约层（能力契约）
> **最后更新**: 2026-07-28

---

## 一、ClusterInfo 核心 API

| 方法 | 签名 | 说明 |
|------|------|------|
| `create_cluster` | `(bk_tenant_id, cluster_type, domain_name, port, registered_system, operator, ...) -> ClusterInfo` | 创建集群，含冲突检测、ES 集群初始化、BKBase 同步 |
| `modify` | `(operator, display_name, description, username, password, ...) -> None` | 修改集群配置 |
| `consul_config` | `@property -> dict` | Consul 存储配置（含 SSL 证书 base64 编码） |
| `cluster_detail` | `@property -> dict` | 集群完整详情 |
| `cluster_init` | `() -> None` | ES 集群初始化（禁用 write_ 自动索引） |
| `refresh_consul_storage_config` | `@classmethod -> None` | 批量刷新 Consul |
| `to_dict` | `(fields, exclude) -> dict` | 序列化 |

## 二、StorageResultTable 基类 API

| 方法 | 说明 |
|------|------|
| `create_table(cls, table_id, is_sync_db, **kwargs)` | 抽象方法，创建存储记录 |
| `get_client(self)` | 抽象方法，获取存储客户端 |
| `add_field(self, field)` | 抽象方法，添加字段 |
| `consul_config(self)` | 返回 Consul 配置 |
| `storage_type` (property) | 返回存储类型 |
| `storage_cluster` (property) | 返回关联 ClusterInfo（含缓存） |
| `update_storage(self, **kwargs)` | 更新存储配置，ES 类型自动处理集群迁移 |
