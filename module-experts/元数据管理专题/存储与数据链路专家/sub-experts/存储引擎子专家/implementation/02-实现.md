位置：[storage.py#L827-L1027](/root/bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/models/storage.py#L827)

核心流程：
1. 未指定 `storage_cluster_id` 时使用默认 InfluxDB 集群
2. 校验 `table_id` 唯一性
3. 从 `table_id` 按 `.` 分割解析 `database` 和 `real_table_name`
4. 未指定 `influxdb_proxy_storage_id` 时通过 `get_influxdb_storage` 查找

6. 通过 `InfluxDBTool.push_to_redis` 推送路由

## 八、BKBase 配置渲染

位置：[config.py](/root/bk-monitor/bk-monitor-base/src/bk_monitor_base/metadata/models/vm/config.py)

`BkDataClean` 使用 Jinja2 渲染清洗配置：
- `extract` 阶段：JSON 解析
- `branch` 阶段：分叉处理 dimensions / metrics / time
- `conf` 阶段：时间格式、时区、时间戳长度

`BkDataStorage` 渲染存储配置：
- `storage_type: "vm"`
- `expires`: 数据保留时间
- `storage_cluster`: VM 集群名
