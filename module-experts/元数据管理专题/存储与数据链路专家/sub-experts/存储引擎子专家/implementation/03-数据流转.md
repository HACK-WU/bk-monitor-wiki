# 03-数据流转

> **子专家**: 存储引擎子专家
> **层级**: 实现层
> **最后更新**: 2026-07-28

---

## 一、存储配置写入链路

```
ResultTable (元数据核心模型)
  └── table_id
        └── Storage.create_table()
              ├── InfluxDBStorage → Redis 路由推送
              ├── ESStorage → 索引创建 + Consul 刷新
              ├── KafkaStorage → Topic 确保
              ├── DorisStorage → StorageClusterRecord 创建
              └── AccessVMRecord → VM 路由刷新
```

## 二、Consul 配置刷新链路

### 2.1 集群配置

```
ClusterInfo.refresh_consul_storage_config()
  ├── 查询所有 ClusterInfo
  ├── 写入 Consul: {CONSUL_PATH}/unify-query/data/storage/{cluster_id}
  └── 更新版本: {CONSUL_PATH}/unify-query/version/storage
```

### 2.2 ES 表配置

```
ESStorage.refresh_consul_table_config()
  ├── 查询所有 ESStorage
  ├── 过滤已启用表
  ├── 写入 Consul: {CONSUL_PATH}/unify-query/data/es/info/{table_id}
  ├── 清理已废弃表
  └── 更新版本
```

### 2.3 InfluxDB 配置

```
InfluxDBTagInfo → Consul: {CONSUL_PATH}/influxdb_info/tag_info
InfluxDBClusterInfo → Consul: {CONSUL_PATH}/influxdb_info/cluster_info
InfluxDBHostInfo → Consul: {CONSUL_PATH}/influxdb_info/host_info
```

## 三、Redis 路由推送链路

### 3.1 InfluxDB 路由

```
InfluxDBStorage.create_table()
  └── InfluxDBTool.push_to_redis(key, table_id, route_json)
        ├── hset → {INFLUXDB_KEY_PREFIX}:{key}
        └── publish → {INFLUXDB_KEY_PREFIX} channel
```

### 3.2 VM 路由

```
AccessVMRecord.refresh_vm_router()
  └── InfluxDBTool.push_to_redis(QUERY_VM_STORAGE_ROUTER_KEY, table_id, route_json)
        └── publish → {INFLUXDB_KEY_PREFIX} channel
```

### 3.3 ES 路由

```
StorageResultTable.update_storage() [ES 集群迁移]
  └── SpaceTableIDRedis.push_es_table_id_detail()
        └── 刷新 RESULT_TABLE_DETAIL（含虚拟 RT）
```

## 四、ES 索引生命周期

```
创建: ESStorage.create_table() → create_es_index()
分片: slice_size (GB) / slice_gap (分钟)
暖数据: warm_phase_days 天后迁移到 warm 节点
过期: retention 天后删除
快照: EsSnapshot 管理备份
集群迁移: update_storage() → StorageClusterRecord
```

## 五、InfluxDB 数据路由

```
数据写入 → InfluxDB Proxy
  ├── 查询 InfluxDBProxyStorage 映射
  ├── 查询 InfluxDBTagInfo 分区
  └── 路由到后端 InfluxDB 集群
```

## 六、VM 数据接入链路

```
BCS 集群 / 用户自定义指标
  └── AccessVMRecord (记录映射)
        ├── result_table_id → vm_result_table_id
        └── refresh_vm_router() → Redis
              └── 查询模块读取 Redis 路由 → VM 查询
```
