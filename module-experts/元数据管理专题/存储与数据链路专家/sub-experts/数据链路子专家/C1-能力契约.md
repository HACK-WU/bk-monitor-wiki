# C1-能力契约

> **子专家**: 数据链路子专家
> **层级**: 契约层（能力契约）
> **最后更新**: 2026-07-28

---

## 一、DataLink 核心 API

| 方法 | 签名 | 说明 |
|------|------|------|
| `apply_data_link` | `(data_source, table_id, bk_biz_id, storage_cluster_name, ...) -> DataLink` | 链路上线主流程 |
| `delete_data_link` | `() -> None` | 删除链路（逆序清理） |
| `compose_configs` | `(...) -> list[dict]` | 策略分发 |
| `sync_metadata` | `(data_source, table_id, storage_cluster_name) -> None` | 同步普通链路元数据 |
| `sync_basereport_metadata` | `(...) -> None` | 同步基础采集链路元数据 |
| `apply_data_link_with_retry` | `(configs) -> None` | 带重试下发（4 次指数退避） |

## 二、DataLinkResourceConfigBase API

| 方法/属性 | 说明 |
|----------|------|
| `compose_config(cls, *args, **kwargs) -> dict` | 抽象方法，渲染组件配置 |
| `delete_config(self) -> None` | 删除 BKBase 组件 + 本地记录 |
| `component_status` (property) | 组件实时状态（BKBase 查询） |
| `component_config` (property) | 组件完整配置（BKBase 查询） |
| `datalink_biz_ids` (property) | 数据链路业务 ID |

## 三、service.py API

| 函数 | 签名 | 说明 |
|------|------|------|
| `apply_data_id_v2` | `(bk_tenant_id, data_name, bk_biz_id, namespace, is_base, event_type, prefer_kafka_cluster_name) -> bool` | 申请 DataId |
| `get_data_id_v2` | `(bk_tenant_id, data_name, namespace, is_base, with_detail) -> dict` | 获取 data_id 与状态 |
| `get_data_link_component_status` | `(bk_tenant_id, kind, component_name, namespace) -> str` | 获取组件状态（带重试） |
| `get_data_link_component_config` | `(bk_tenant_id, kind, component_name, namespace) -> dict` | 获取组件完整配置 |

## 四、relation.py API

| 函数 | 签名 | 说明 |
|------|------|------|
| `rebuild_databus_relation` | `(databus, dry_run) -> DataLink | dict | None` | 单个 DataBus 关联重建 |
| `rebuild_bkbase_v4_datalink_relation` | `(bk_tenant_id, namespace) -> None` | 批量重建 BKBase V4 关联 |

## 五、utils.py API

| 函数 | 说明 |
|------|------|
| `compose_bkdata_table_id(table_id, strategy)` | 组装 BKBase 结果表 ID（40 字符限制） |
| `compose_bkdata_data_id_name(data_name, strategy)` | 组装 BKBase 数据源名称 |
| `compose_config(tpl, render_params, err_msg_prefix)` | 渲染 Jinja2 模板并转 JSON |
| `generate_result_table_field_list(table_id, bk_tenant_id)` | 生成结果表字段列表 |
| `get_bkbase_raw_data_id_name(data_source, table_id)` | 获取 BKBase raw_data_name（兼容 V3→V4） |
| `get_data_source_related_info(bk_data_id)` | 获取数据源关联信息 |
| `is_k8s_metric_data_id(data_name)` | 判断是否为 K8S 指标数据源 |
