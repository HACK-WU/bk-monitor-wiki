# 01-架构

> **子专家**: 数据链路子专家
> **层级**: 实现层
> **最后更新**: 2026-07-28

---

## 一、整体架构

```
DataLink (编排器)
  ├── STRATEGY_RELATED_COMPONENTS: 策略→组件映射
  ├── STORAGE_TYPE_MAP: 策略→存储类型映射
  ├── compose_configs: 策略分发
  │   ├── compose_standard_time_series_configs
  │   ├── compose_bk_plugin_time_series_config
  │   ├── compose_bcs_federal_proxy_time_series_configs
  │   ├── compose_bcs_federal_subset_time_series_configs
  │   ├── compose_basereport_time_series_configs
  │   ├── compose_base_event_configs
  │   ├── compose_system_proc_configs
  │   ├── compose_log_configs
  │   └── compose_custom_event_configs
  └── apply_data_link: 链路上线主流程
```

## 二、组件配置模型层次

```
DataLinkResourceConfigBase (抽象基类)
├── DataIdConfig          (kind=DataId)
├── ResultTableConfig     (kind=ResultTable)
├── VMStorageBindingConfig (kind=VmStorageBinding)
├── ESStorageBindingConfig (kind=ElasticSearchBinding)
├── DorisStorageBindingConfig (kind=DorisBinding)
├── DataBusConfig         (kind=Databus)
├── ConditionalSinkConfig (kind=ConditionalSink)
└── ClusterConfig         (集群注册到 BKBase)
```

## 三、组件关联关系

### 3.1 运行视角

```
DataId → DataBus → {VMStorageBinding → ResultTable}
                 → {ESStorageBinding → ResultTable}
                 → {DorisBinding → ResultTable}
                 → {ConditionalSink → VMStorageBinding → ResultTable}
```

### 3.2 关联键

- **本地模型层**: `data_link_name` 归组同链路组件；`(bk_tenant_id, namespace, name)` 唯一键
- **BKBase 配置层**: `Databus.spec.sources[].name` → DataId；`Databus.spec.sinks[].name` → Binding

## 四、策略分流

不同策略在 `Databus.sinks` 上的差异是链路分流核心：

```
直接 VM Sink: BK_STANDARD_V2_TIME_SERIES、BK_EXPORTER_TIME_SERIES、BK_STANDARD_TIME_SERIES
直接 ES Sink: BASE_EVENT_V1、BK_STANDARD_V2_EVENT
直接 Doris Sink: BK_LOG（与 ES 共存）
条件路由: BASEREPORT_TIME_SERIES_V1、BCS_FEDERAL_SUBSET_TIME_SERIES
```

## 五、生命周期架构

```
创建: compose_configs → update_or_create 本地 → compose_config 渲染 → BKBase API 下发 → sync_metadata
删除: 逆序遍历组件 → delete_config (BKBase + 本地) → 删除 DataLink
查询: component_status / component_config → BKBase API 实时查询
```

## 六、关联重建架构

`relation.py` 用于 BKBase V4 迁移场景：
1. 以 DataBus 为单位遍历
2. 通过 sink_names 找到存储绑定
3. 通过 bkbase_result_table_name 找到 ResultTableConfig
4. 通过 data_id_name 找到 DataIdConfig
5. 补充 data_link_name 并创建 DataLink
