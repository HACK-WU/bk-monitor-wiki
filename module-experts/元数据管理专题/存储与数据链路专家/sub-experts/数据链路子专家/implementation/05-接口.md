## 二、DataLinkResourceConfigBase

```python
class DataLinkResourceConfigBase(models.Model):
    kind: str
    name: str
    namespace: str
    status: str
    data_link_name: str
    bk_biz_id: int
    bk_tenant_id: str

    @classmethod
    def compose_config(cls, *args, **kwargs) -> dict

    def delete_config(self) -> None

    @property
    def component_status(self) -> str

    @property
    def component_config(self) -> dict

    @property
    def datalink_biz_ids(self) -> list
```
