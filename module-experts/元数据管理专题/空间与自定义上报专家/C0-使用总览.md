# C0-使用总览

## 一、能力清单

### 1.1 空间隔离能力

Space 模块提供多租户业务空间管理，支持四种空间类型：

| 空间类型 | 标识 | 隔离方式 | 典型场景 |
|---------|------|---------|---------|
| BKCC | `bkcc` | 按 `bk_biz_id` 过滤 | 标准业务监控 |
| BCS | `bcs` | 按 `bcs_cluster_id` + `namespace` 过滤 | 容器监控 |
| BKCI | `bkci` | 按 `projectId` 过滤 + 关联 BKCC 业务数据 | 蓝盾 CI 监控 |
| BKSAAS | `bksaas` | 按集群维度过滤 + 非集群数据无过滤 | SaaS 应用监控 |

核心能力：
- 空间 CRUD：创建/查询/修改/停用空间，支持批量创建
- 空间路由推送：将空间关联的结果表路由推送到 Redis，通过 Pub/Sub 通知消费者
- 数据标签路由：按 data_label 维度推送结果表映射
- 结果表详情路由：推送结果表的存储类型、集群、指标字段等详情
- 多租户支持：所有路由键支持租户 ID 拼接，确保跨租户隔离

### 1.2 自定义上报能力

CustomReport 模块提供三种自定义上报类型：

| 类型 | 核心类 | 存储引擎 | 数据模型 |
|------|--------|---------|---------|
| 时序 | `TimeSeriesGroup` | InfluxDB / VM | TimeSeriesGroup → TimeSeriesScope → TimeSeriesMetric |
| 事件 | `EventGroup` | Elasticsearch | EventGroup → Event（event_name + dimension_list） |
| 日志 | `LogGroup` | 计算平台 | LogGroup（无子指标模型） |

核心能力：
- 创建自定义上报组：pre_check → _create → create_result_table → 配置更新
- 修改自定义上报组：支持修改名称、标签、启用状态、指标/维度、上报速率
- 删除自定义上报组：标记删除 + 关联结果表废弃
- 指标自动发现：时序支持从 Redis/BkData 自动同步指标和维度
- 单指标单表：时序支持 `is_split_measurement` 模式，每个指标独立结果表

### 1.3 记录规则能力

RecordRule 模块提供预计算规则管理：

- 规则配置解析：YAML 规则 → PromQL → BKSQL 转换
- 源表自动发现：通过指标反查结果表，支持显式指定和自动查找两种模式
- 计算平台集成：组装 stream_source → promql_v2 → vm_storage 三节点数据流
- 生命周期管理：创建/启动/停止/删除数据流

## 二、能力边界

**本专家负责**：
- Space/SpaceType/SpaceDataSource/SpaceResource 模型定义与 CRUD
- SpaceTableIDRedis 的 Redis 路由推送逻辑
- CustomGroupBase 及其子类（TimeSeriesGroup/EventGroup/LogGroup）的完整生命周期
- RecordRule/ResultTableFlow 的规则管理与计算平台对接
- 空间与自定义上报相关的常量定义

**本专家不负责**：
- `service/space_redis.py` 的接口契约（归专家5），但实现细节由空间管理子专家覆盖
- 数据源（DataSource）和结果表（ResultTable）的核心模型定义（归专家1）
- 存储引擎配置（InfluxDB/ES/VM）的创建和管理（归专家2）
- 后台异步任务调度（归专家4）
- API Resource 层的接口暴露（归专家5）

## 三、已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|------|---------|---------|
| 空间路由推送后消费者未收到更新 | `is_publish=False` 时只写 Redis 不发 Pub/Sub | 需要通知消费者时设置 `is_publish=True` |
| 自定义时序指标不显示 | 指标过期（超过 `time_series_metric_expired_seconds`） | 确认数据上报正常，检查 Redis 中指标时间戳 |
| BKCC 空间类型下自定义时序查询范围放大 | 平台级数据源未正确设置过滤条件 | 检查 `_is_need_filter_for_bkcc` 逻辑，确认 `is_platform_data_id` 和 `space_uid` |
| 记录规则数据流创建失败 | 未授权源结果表 | 先调用 `batch_add_permission` 授权 |
| 多租户模式下路由键不匹配 | 未拼接租户 ID | 确认 `enable_multi_tenancy` 开关和键名拼接逻辑 |
| 事件组 ES 文档 ID 配置缺失 | 未设置 `OPTION_ES_DOCUMENT_ID` | 创建事件组时自动添加 `event/target/dimensions/event_name/time` 字段 |
