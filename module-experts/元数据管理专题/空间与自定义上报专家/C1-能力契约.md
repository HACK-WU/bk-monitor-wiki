# C1-能力契约

> **覆盖度声明**：本契约基于采样分析 space/（6 文件）、custom_report/（5 文件）、record_rule/（4 文件）的核心公开类和方法。超大文件 `space_table_id_redis.py`(74KB) 和 `time_series.py`(106KB) 采用聚焦核心方法策略。

## 一、Space API

### 1.1 Space 模型

**契约来源**：`Space` (models/space/space.py)

#### `Space.space_uid` (属性)
- **用途**：获取空间唯一标识，格式 `{space_type_id}__{space_id}`
- **返回**：`str`
- **约束**：连接符为 `SPACE_UID_HYPHEN`（`__`）

```python
# 获取空间 UID
space = Space.objects.get(space_type_id="bkcc", space_id="2")
uid = space.space_uid  # "bkcc__2"
```

#### `Space.to_dict(fields, exclude)`
- **用途**：将空间实例转为字典，自动添加 `space_uid` 和 `bk_tenant_id`
- **参数**：`fields` (list|None) — 需要包含的字段；`exclude` (list|None) — 需要排除的字段
- **返回**：`dict[str, Any]`
- **约束**：DateTimeField 自动格式化为 `%Y-%m-%d %H:%M:%S`

```python
space = Space.objects.get(space_type_id="bkcc", space_id="2")
data = space.to_dict(fields=["space_type_id", "space_id", "space_name"])
# {"space_type_id": "bkcc", "space_id": "2", "space_name": "xxx", "space_uid": "bkcc__2", "bk_tenant_id": "system"}
```

#### `Space.bulk_create_space(bk_tenant_id, space_type_id, space_list)`
- **用途**：批量创建同类型空间
- **参数**：`bk_tenant_id` (str) — 租户 ID；`space_type_id` (str) — 空间类型；`space_list` (list) — 空间列表，每项含 `space_id` 和 `space_name`
- **异常**：数据库唯一约束冲突时抛 IntegrityError

#### `Space.get_bk_biz_id()`
- **用途**：获取空间对应的业务 ID
- **返回**：`int` — BKCC 类型返回 `int(space_id)`，其他类型返回 `-pk`
- **约束**：正数表示 BKCC 业务，负数表示非 BKCC 空间

### 1.2 SpaceManager

**契约来源**：`SpaceManager` (models/space/managers.py)

#### `SpaceManager.compose_space_uid(space_type_id, space_id)`
- **用途**：组装空间唯一标识
- **参数**：`space_type_id` (str)、`space_id` (str)
- **返回**：`str` — 格式 `"{space_type_id}__{space_id}"`

#### `SpaceManager.split_space_uid(space_uid)`
- **用途**：拆分空间唯一标识
- **参数**：`space_uid` (str)
- **返回**：`tuple[str, str]` — `(space_type_id, space_id)`
- **异常**：格式无效时抛 Exception

#### `SpaceManager.list_all_spaces(bk_tenant_id, ...)`
- **用途**：分页查询空间列表，支持模糊/精确过滤
- **参数**：
  - `bk_tenant_id` (str) — 租户 ID（必填）
  - `space_type_id` (str|None) — 空间类型过滤
  - `space_id` (str|None) — 空间 ID 过滤
  - `space_name` (str|None) — 空间名称过滤
  - `is_exact` (bool) — 是否精确查询，默认 False
  - `page` (int) — 页码，默认 1
  - `page_size` (int) — 每页数量，默认 1000
  - `exclude_platform_space` (bool) — 是否排除平台级空间，默认 True
- **返回**：`dict` — `{"count": int, "list": [...]}`，每项含 `id/space_uid/space_type_id/space_id/space_name/status/display_name` 等

#### `SpaceManager.get_biz_id_by_space(space_type, space_id)`
- **用途**：通过空间类型和空间 ID 获取业务 ID
- **返回**：`int|None` — BKCC 返回 `int(space_id)`，其他返回 `-id`

### 1.3 SpaceTableIDRedis

**契约来源**：`SpaceTableIDRedis` (models/space/space_table_id_redis.py)

#### `SpaceTableIDRedis.push_space_table_ids(space_type, space_id, is_publish)`
- **用途**：推送单个空间的结果表路由到 Redis
- **参数**：`space_type` (str)、`space_id` (str)、`is_publish` (bool) — 是否发布 Pub/Sub 通知
- **约束**：多租户模式下键名拼接 `{space_type}__{space_id}|{bk_tenant_id}`

#### `SpaceTableIDRedis.push_multi_space_table_ids(spaces, is_publish)`
- **用途**：批量推送多个空间的结果表路由
- **参数**：`spaces` (list[Space])、`is_publish` (bool)
- **约束**：先逐个推送数据，最后统一发布通知

#### `SpaceTableIDRedis.push_data_label_table_ids(data_label_list, table_id_list, is_publish, bk_tenant_id)`
- **用途**：推送数据标签与结果表的映射关系
- **参数**：`data_label_list` (list|None)、`table_id_list` (list|None) — 过滤条件；`is_publish` (bool)；`bk_tenant_id` (str)

#### `SpaceTableIDRedis.push_table_id_detail(table_id_list, is_publish, include_es_table_ids, bk_tenant_id)`
- **用途**：推送结果表详情（存储类型、集群、指标字段等）
- **参数**：`table_id_list` (list|None)、`is_publish` (bool)、`include_es_table_ids` (bool)、`bk_tenant_id` (str)

## 二、CustomReport API

### 2.1 TimeSeriesGroup

**契约来源**：`TimeSeriesGroup` (models/custom_report/time_series.py)

#### `TimeSeriesGroup.create_time_series_group(bk_data_id, bk_biz_id, time_series_group_name, label, operator, bk_tenant_id, ...)`
- **用途**：创建自定义时序上报组
- **参数**：
  - `bk_data_id` (int) — 数据源 ID
  - `bk_biz_id` (int) — 业务 ID
  - `time_series_group_name` (str) — 时序组名称
  - `label` (str) — 结果表标签
  - `operator` (str) — 操作者
  - `bk_tenant_id` (str) — 租户 ID
  - `metric_info_list` (list|None) — 指标列表
  - `table_id` (str|None) — 指定结果表 ID，默认自动生成
  - `is_split_measurement` (bool) — 是否单指标单表，默认 True
  - `is_builtin` (bool) — 是否内置
  - `default_storage_config` (dict|None) — 存储配置
  - `additional_options` (dict|None) — 结果表选项
  - `data_label` (str|None) — 数据标签
- **返回**：`TimeSeriesGroup`
- **异常**：标签不存在、data_id 已被占用、同名组已存在时抛 ValueError
- **约束**：创建后自动刷新 Consul 配置触发 Transfer 更新

```python
# 创建自定义时序上报组
group = TimeSeriesGroup.create_time_series_group(
    bk_data_id=1001,
    bk_biz_id=2,
    time_series_group_name="my_custom_metrics",
    label="application_check",
    operator="admin",
    bk_tenant_id="system",
    metric_info_list=[
        {"field_name": "cpu_usage", "tag_list": [{"field_name": "hostname"}]}
    ],
)
```

#### `TimeSeriesGroup.modify_time_series_group(operator, time_series_group_name, label, is_enable, field_list, enable_field_black_list, metric_info_list, data_label, options)`
- **用途**：修改自定义时序组
- **参数**：所有参数可选，仅传入需要修改的字段
- **返回**：`True`
- **异常**：已删除的组不可修改，抛 ValueError

#### `TimeSeriesGroup.delete_time_series_group(operator)`
- **用途**：删除自定义时序组（标记删除 + 关联结果表废弃）
- **返回**：`True`

#### `TimeSeriesGroup.update_time_series_metrics()`
- **用途**：从远端存储（Redis/BkData）同步时序指标和维度
- **返回**：`bool` — 是否有更新

#### `TimeSeriesGroup.get_metric_info_list()`
- **用途**：获取时序组下所有有效指标信息
- **返回**：`list[dict]` — 含 field_name/table_id/tag_list 等

#### `TimeSeriesGroup.make_table_id(bk_biz_id, bk_data_id, table_name, bk_tenant_id)`
- **用途**：生成结果表 ID
- **返回**：`str` — 格式 `{bk_biz_id}_bkmonitor_time_series_{bk_data_id}.__default__`（多租户模式加租户前缀）

## 三、RecordRule API

### 3.1 RecordRule

**契约来源**：`RecordRule` (models/record_rule/rules.py)

#### `RecordRule.transform_bk_sql_and_metrics(rule_config)`
- **用途**：将 YAML 规则配置转换为计算平台 BKSQL
- **参数**：`rule_config` (str) — YAML 格式规则配置
- **返回**：`dict` — `{"bksql": [...], "metrics": [...], "rule_metrics": {...}}`
- **约束**：PromQL 表达式通过 `refine_bk_sql_and_metrics` 转换

#### `RecordRule.get_src_table_ids(space_type, space_id, metrics)`
- **用途**：通过指标和空间反查源 VM 结果表
- **参数**：`space_type` (str)、`space_id` (str)、`metrics` (list[str]|set[str])
- **返回**：`list[str]` — VM 结果表 ID 列表
- **约束**：通过 ResultTableField → TimeSeriesGroup → TimeSeriesMetric 链路过滤，过期指标被排除

#### `RecordRule.get_dst_table_id(table_id)`
- **用途**：生成目标 VM 结果表名
- **返回**：`str` — 格式 `{default_bkdata_biz_id}_{rule_table_id}`

### 3.2 ResultTableFlow

**契约来源**：`ResultTableFlow` (models/record_rule/rules.py)

#### `ResultTableFlow.create_flow(bk_tenant_id, table_id, waiting_time, expires, schemaless)`
- **用途**：创建计算平台数据流（stream_source → promql_v2 → vm_storage）
- **参数**：`bk_tenant_id` (str)、`table_id` (str)、`waiting_time` (int, 默认 30s)、`expires` (int, 默认 30 天)、`schemaless` (bool, 默认 True)
- **返回**：`bool`
- **约束**：创建前先调用 `batch_add_permission` 授权源结果表

#### `ResultTableFlow.start_flow(bk_tenant_id, flow_id, consuming_mode)`
- **用途**：启动数据流
- **参数**：`consuming_mode` (str) — 消费模式，默认 `Current`（尾部消费，避免历史数据积压）

#### `ResultTableFlow.stop_flow(bk_tenant_id, flow_id)`
- **用途**：停止数据流

#### `ResultTableFlow.delete_flow(bk_tenant_id, flow_id)`
- **用途**：删除数据流
