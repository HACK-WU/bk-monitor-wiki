# C0-使用总览

## 一、能力清单

### 1.1 空间类型管理

支持四种空间类型，每种类型的隔离方式和适用场景不同：

| 空间类型 | 标识 | 隔离方式 | 典型场景 |
|---------|------|---------|---------|
| BKCC | `bkcc` | 按 `bk_biz_id` 过滤 | 标准业务监控 |
| BCS | `bcs` | 按 `bcs_cluster_id` + `namespace` 过滤 | 容器监控 |
| BKCI | `bkci` | 按 `projectId` 过滤 + 关联 BKCC 业务数据 | 蓝盾 CI 监控 |
| BKSAAS | `bksaas` | 按集群维度过滤 + 非集群数据无过滤 | SaaS 应用监控 |

### 1.2 空间生命周期管理

- **创建空间**：`create_space()` — 支持关联资源（BKCC/BCS/BKSAAS），自动授权数据源
- **更新空间**：`update_space()` — 修改名称、空间编码、绑定资源
- **合并空间**：`merge_space()` — 将源空间的数据源和资源合并到目标空间，禁用源空间
- **禁用空间**：`disable_space()` — 设置状态为 disabled
- **批量创建**：`bulk_create_space()` / `create_bkcc_spaces()` / `create_bcs_spaces()`

### 1.3 空间路由推送

SpaceTableIDRedis 是空间路由推送的核心类，将空间关联的结果表映射写入 Redis 三个哈希键：

| Redis 键 | 内容 | 通道 |
|----------|------|------|
| `SPACE_TO_RESULT_TABLE_KEY` | `{space_uid: {table_id: {filters: [...]}}}` | `SPACE_TO_RESULT_TABLE_CHANNEL` |
| `DATA_LABEL_TO_RESULT_TABLE_KEY` | `{data_label: [table_id, ...]}` | `DATA_LABEL_TO_RESULT_TABLE_CHANNEL` |
| `RESULT_TABLE_DETAIL_KEY` | `{table_id: {db, measurement, storage_type, fields, ...}}` | `RESULT_TABLE_DETAIL_CHANNEL` |

### 1.4 空间查询能力

- **列表查询**：`list_spaces()` — 支持分页、模糊/精确过滤、详情模式
- **详情查询**：`get_space_detail()` — 包含关联资源和数据源
- **业务 ID 互转**：`get_biz_id_by_space()` / `get_space_info_by_biz_id()`
- **空间 UID 操作**：`compose_space_uid()` / `split_space_uid()`
- **关联查询**：`get_related_spaces()` — 查询 BKCC 关联的 BKCI 空间

### 1.5 数据源授权

- **授权数据源**：`authorize_data_id_list()` — 批量授权数据源给空间
- **平台级数据源**：`get_platform_data_id_list()` — 获取所有空间类型可访问的数据源
- **空间级数据源**：`get_space_data_id_list()` — 获取同类型空间可访问的数据源
- **BKCI 特殊授权**：自动授权 1001 数据源

## 二、能力边界

**本子专家负责**：
- Space/SpaceType/SpaceDataSource/SpaceResource/SpaceStickyInfo/BkAppSpaceRecord 模型定义
- SpaceManager/SpaceTypeManager/SpaceResourceManager 的查询逻辑
- SpaceTableIDRedis 的 Redis 路由推送（按空间类型的差异化处理）
- `space/utils.py` 中的空间 CRUD 工具函数
- `space/constants.py` 中的常量、枚举、Redis 键空间定义

**本子专家不负责**：
- 自定义上报（TimeSeriesGroup/EventGroup/LogGroup）的创建和管理（归自定义上报子专家）
- 记录规则（RecordRule）的规则管理和计算平台对接（归自定义上报子专家）
- `service/space_redis.py` 的接口契约（归专家5）
- 数据源（DataSource）和结果表（ResultTable）的核心模型定义（归专家1）

## 三、已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|------|---------|---------|
| 空间路由推送后消费者未收到更新 | `is_publish=False` 时只写 Redis 不发 Pub/Sub | 需要通知消费者时设置 `is_publish=True` |
| BKCC 空间类型下自定义时序查询范围放大 | 平台级数据源未正确设置过滤条件 | 检查 `_is_need_filter_for_bkcc` 逻辑 |
| 多租户模式下路由键不匹配 | 未拼接租户 ID | 确认 `enable_multi_tenancy` 开关和键名拼接逻辑 |
| 空间合并失败 | 相同资源类型下资源 ID 不一致 | 确保源和目标空间同类型资源 ID 一致 |
| BKCI 空间创建后无数据 | 未授权 1001 数据源或未关联 BKCC 业务 | 检查 `BKCI_AUTHORIZED_DATA_ID_LIST` 和 SpaceResource |
| BKSAAS 空间资源创建失败 | 蓝鲸应用无集群命名空间 | 确认应用已绑定集群 |
| `get_biz_id_by_space` 返回 None | 空间不存在于数据库 | 确认空间已创建且未被删除 |
