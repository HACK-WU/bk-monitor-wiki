## 一、Space 模型 API

### 1.1 Space

**契约来源**：`Space` (models/space/space.py:41-100)

#### `Space.space_uid` (属性)
- **用途**：获取空间唯一标识
- **返回**：`str` — 格式 `"{space_type_id}__{space_id}"`
- **约束**：连接符为 `SPACE_UID_HYPHEN`（`__`），不可修改

```python
space = Space.objects.get(space_type_id="bkcc", space_id="2")
uid = space.space_uid  # "bkcc__2"
```

#### `Space.to_dict(fields, exclude)`
- **用途**：将空间实例转为字典，自动添加 `space_uid` 和 `bk_tenant_id`
- **参数**：
  - `fields` (list|None) — 需要包含的字段名列表
  - `exclude` (list|None) — 需要排除的字段名列表
- **返回**：`dict[str, Any]`
- **约束**：DateTimeField 自动格式化为 `%Y-%m-%d %H:%M:%S`

```python
space = Space.objects.get(space_type_id="bkcc", space_id="2")
data = space.to_dict(fields=["space_type_id", "space_id", "space_name"])
# {"space_type_id": "bkcc", "space_id": "2", "space_name": "xxx", "space_uid": "bkcc__2", "bk_tenant_id": "system"}
```

#### `Space.bulk_create_space(bk_tenant_id, space_type_id, space_list)`
- **用途**：批量创建同类型空间
- **参数**：
  - `bk_tenant_id` (str) — 租户 ID
  - `space_type_id` (str) — 空间类型
  - `space_list` (list) — 空间列表，每项含 `space_id`(str) 和 `space_name`(str)
- **异常**：数据库唯一约束冲突时抛 IntegrityError

#### `Space.get_bk_biz_id()`
- **用途**：获取空间对应的业务 ID
- **返回**：`int` — BKCC 类型返回 `int(space_id)`，其他类型返回 `-pk`（负数）
- **约束**：正数表示 BKCC 业务，负数表示非 BKCC 空间

## 二、Manager API

### 2.1 SpaceManager

**契约来源**：`SpaceManager` (models/space/managers.py:24-170)

#### `SpaceManager.compose_space_uid(space_type_id, space_id)`
- **用途**：组装空间唯一标识
- **参数**：`space_type_id` (str)、`space_id` (str)
- **返回**：`str` — 格式 `"{space_type_id}__{space_id}"`

#### `SpaceManager.split_space_uid(space_uid)`
- **用途**：拆分空间唯一标识
- **参数**：`space_uid` (str)
- **返回**：`tuple[str, str]` — `(space_type_id, space_id)`
- **异常**：格式无效时抛 Exception

#### `SpaceManager.list_all_spaces(bk_tenant_id, space_type_id?, space_id?, space_name?, id?, is_exact?, page?, page_size?, exclude_platform_space?, space_type_id_name?)`
- **用途**：分页查询空间列表，支持模糊/精确过滤
- **参数**：
  - `bk_tenant_id` (str) — 租户 ID（必填）
  - `space_type_id` (str|None) — 空间类型过滤
  - `space_id` (str|None) — 空间 ID 过滤
  - `space_name` (str|None) — 空间名称过滤
  - `id` (int|None) — 自增 ID 过滤
  - `is_exact` (bool) — 是否精确查询，默认 False
  - `page` (int) — 页码，默认 1
  - `page_size` (int) — 每页数量，默认 1000
  - `exclude_platform_space` (bool) — 是否排除平台级空间，默认 True
  - `space_type_id_name` (dict|None) — 空间类型 ID→名称映射
- **返回**：`dict` — `{"count": int, "list": [...]}`，每项含 `id/space_uid/space_type_id/space_id/space_name/status/display_name` 等
- **约束**：`page=0` 时返回全量数据；`page * page_size >= count` 时返回空列表

```python
result = Space.objects.list_all_spaces(
    bk_tenant_id="system",
    space_type_id="bkcc",
    space_name="demo",
    is_exact=False,
    page=1,
    page_size=10,
)
# {"count": 5, "list": [{...}, ...]}
```

#### `SpaceManager.get_space_info_by_biz_id(bk_biz_id)`
- **用途**：通过业务 ID 获取空间类型和空间 ID
- **参数**：`bk_biz_id` (int) — 正数为 BKCC 业务 ID，负数为其他空间的自增 ID 取反
- **返回**：`dict[str, Any]` — `{"space_type": str, "space_id": str}`
- **异常**：`bk_biz_id < 0` 且对应空间不存在时抛 `DoesNotExist`；`bk_biz_id == 0` 时抛 ValueError

#### `SpaceManager.get_biz_id_by_space(space_type, space_id)`
- **用途**：通过空间类型和空间 ID 获取业务 ID
- **参数**：`space_type` (str)、`space_id` (str)
- **返回**：`int|None` — BKCC 返回 `int(space_id)`，其他返回 `-id`；空间不存在返回 None

## 四、空间工具函数 API

**契约来源**：`space/utils.py` (1161 行)

### 4.1 空间 CRUD

#### `create_space(bk_tenant_id, creator, space_id, space_type_id, space_name, resources?, space_code?)`
- **用途**：创建空间并关联资源
- **参数**：
  - `bk_tenant_id` (str) — 租户 ID
  - `creator` (str) — 创建者
  - `space_id` (str) — 空间 ID
  - `space_type_id` (str) — 空间类型
  - `space_name` (str) — 空间名称
  - `resources` (list|None) — 绑定的资源列表 `[{"resource_type": "xxx", "resource_id": "xxx"}]`
  - `space_code` (str|None) — 空间 Code（非空时开启 BCS）
- **返回**：`dict` — 空间详情（`to_dict()` 结果）
- **约束**：BKCI 类型自动授权 1001 数据源；BKSAAS 类型自动创建集群资源并授权 K8s 指标数据源

```python
space = create_space(
    bk_tenant_id="system",
    creator="admin",
    space_id="my_project",
    space_type_id="bkci",
    space_name="我的项目",
    resources=[{"resource_type": "bkcc", "resource_id": "2"}],
    space_code="project_123",
)
```

#### `update_space(updater, space_type_id, space_id, space_name, space_code, resources)`
- **用途**：更新空间信息
- **参数**：`updater` (str)、`space_type_id` (str)、`space_id` (str)、`space_name` (str)、`space_code` (str)、`resources` (list)
- **返回**：`dict` — 更新后的空间详情
- **约束**：`space_code` 非空时自动设置 `is_bcs_valid=True`

#### `merge_space(src_space_type_id, src_space_id, dst_space_type_id, dst_space_id)`
- **用途**：合并空间（源空间数据源和资源迁移到目标空间，源空间禁用）
- **参数**：源和目标的空间类型和 ID
- **异常**：相同资源类型下资源 ID 不一致时抛 ValueError

#### `disable_space(spaces)`
- **用途**：禁用空间（设置状态为 disabled）
- **参数**：`spaces` (list[dict]) — `[{"space_type_id": "bcs", "space_id": "testproject"}]`
- **返回**：`list[dict]` — 被禁用的空间详情列表

### 4.2 批量创建

#### `create_bkcc_spaces(biz_list, create_builtin_data_link_delay?)`
- **用途**：批量创建 BKCC 业务空间
- **参数**：`biz_list` (list) — 业务列表，每项含 `bk_biz_id/bk_biz_name/bk_tenant_id/time_zone`
- **返回**：`bool`
- **约束**：创建后异步初始化内置数据链路（basereport/event/system_proc）

#### `create_bcs_spaces(project_list)`
- **用途**：批量创建 BCS 容器空间
- **参数**：`project_list` (list) — 项目列表，每项含 `bk_tenant_id/project_id/project_code/name/bk_biz_id`
- **返回**：`bool`
- **约束**：自动关联 BKCC 业务资源、集群资源、授权数据源

### 4.3 查询函数

#### `list_spaces(bk_tenant_id, space_type_id?, space_id?, space_name?, id?, is_exact?, is_detail?, page?, page_size?, exclude_platform_space?, include_resource_id?)`
- **用途**：查询空间列表（增强版，支持详情和资源 ID）
- **返回**：`dict` — `{"count": int, "list": [...]}`
- **约束**：`is_detail=True` 时追加 `data_sources` 和 `resources` 字段

#### `get_space_detail(space_type_id?, space_id?, id?)`
- **用途**：查询空间详情（含关联资源和数据源）
- **返回**：`dict[str, Any]` — 空间完整信息

#### `get_related_spaces(space_type_id, space_id, target_space_type_id?)`
- **用途**：获取关联的目标类型空间 ID 列表
- **返回**：`list[str]` — 关联的空间 ID 列表
- **约束**：现阶段仅支持 BKCC → BKCI 的关联查询

#### `get_space_by_table_id(table_id, bk_tenant_id?)`
- **用途**：通过结果表反查空间信息
- **返回**：`dict` — `{"space_type_id": str|None, "space_id": str|None, "is_all_space": bool}`
- **异常**：结果表不存在或数据源不存在时抛 ValueError

### 4.4 数据源管理
