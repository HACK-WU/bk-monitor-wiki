## 简介

本章描述空间管理子专家覆盖的三条核心数据流：空间路由从 DB → Redis → 消费者的推送链路、空间创建从 API → 模型 → 资源关联的完整链路、空间合并的数据迁移链路。

## 空间路由推送数据流

### 整体流程

```mermaid
sequenceDiagram
    participant Trigger as "触发源<br/>(API/任务)"
    participant STR as "SpaceTableIDRedis"
    participant DB as "MySQL"
    participant Redis as "Redis"
    participant Consumer as "消费者<br/>(unify-query等)"

    Trigger->>STR: "push_space_table_ids(space_type, space_id)"
    STR->>DB: "查询 Space 对象"
    DB-->>STR: "返回 Space"
    STR->>DB: "查询 DataSource/ResultTable/DataSourceResultTable"
    DB-->>STR: "返回关联数据"
    STR->>STR: "按空间类型组装路由"
    
    alt BKCC
        STR->>STR: "_compose_bkcc_space_table_ids"
        Note over STR: 按 bk_biz_id 过滤<br/>判断 _is_need_filter_for_bkcc
    else BKCI
        STR->>STR: "_compose_bkci_space_table_ids"
        Note over STR: 集群+业务+构建机+其他
    else BKSAAS
        STR->>STR: "_compose_bksaas_space_table_ids"
        Note over STR: 集群+非集群数据
    end
    
    STR->>Redis: "HMSET SPACE_TO_RESULT_TABLE_KEY"
    STR->>Redis: "HMSET RESULT_TABLE_DETAIL_KEY"
    
    opt is_publish=True
        STR->>Redis: "PUBLISH SPACE_TO_RESULT_TABLE_CHANNEL"
        STR->>Redis: "PUBLISH RESULT_TABLE_DETAIL_CHANNEL"
    end
    
    Redis-->>Consumer: "收到变更通知"
    Consumer->>Redis: "HGET 拉取最新路由"
    Redis-->>Consumer: "返回路由数据"
```

### 三类路由数据流

| 路由类型 | 写入方法 | 写入 Redis 键 | 数据格式 | 消费者用途 |
|---------|---------|-------------|---------|-----------|
| 空间-结果表 | `push_space_table_ids` | `SPACE_TO_RESULT_TABLE_KEY` | `{space_uid: {table_id: {filters: [...]}}}` | 空间数据查询隔离 |
| 数据标签-结果表 | `push_data_label_table_ids` | `DATA_LABEL_TO_RESULT_TABLE_KEY` | `{data_label: [table_id, ...]}` | 按标签跨空间查询 |
| 结果表详情 | `push_table_id_detail` | `RESULT_TABLE_DETAIL_KEY` | `{table_id: {db, measurement, storage_type, fields, ...}}` | 结果表存储路由 |

## 空间合并数据流

```mermaid
sequenceDiagram

    participant Utils as "utils.py"

    Utils->>DB: "bulk_update SpaceResource<br/>(迁移到目标空间)"

```

## 结论

空间管理子专家的三条数据流覆盖了空间路由推送、空间创建和空间合并的完整链路。路由推送通过 Redis Pub/Sub 机制实现消费者实时感知空间变更，空间创建通过事务确保模型和资源的一致性，空间合并通过数据源差集计算和资源迁移实现无缝合并。
