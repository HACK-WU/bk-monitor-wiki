## SpaceType — 空间类型

| 字段 | 类型 | 说明 |
|------|------|------|

## Space — 空间信息

**表名**：`metadata_space`
**文件**：[space.py:41-100](file://bk-monitor-base/src/bk_monitor_base/metadata/models/space/space.py#L41-L100)

| 字段 | 类型 | 说明 |
|------|------|------|
| `space_type_id` | CharField(64) | 空间类型 ID |
| `space_id` | CharField(128) | 空间 ID（空间类型下唯一），使用 `db_collation` |
| `bk_tenant_id` | CharField(256) | 租户 ID，默认 "system" |
| `space_name` | CharField(256) | 空间中文名称（空间类型下唯一），使用 `db_collation` |
| `space_code` | CharField(64) | 空间英文名称（容器/研发类型额外存储），可空 |
| `status` | CharField(32) | 空间状态：`normal` / `disabled`，默认 `normal` |
| `time_zone` | CharField(32) | 时区，默认 "Asia/Shanghai" |
| `language` | CharField(16) | 默认语言，默认 "zh-hans" |
| `is_bcs_valid` | BooleanField | BCS 是否可用，默认 False |
| `is_global` | BooleanField | 跨业务管理可用，默认 False |

**唯一约束**：
- `(space_type_id, space_id)`
- `(space_type_id, space_name, bk_tenant_id)`

**Manager**：`SpaceManager`

**关键属性**：
- `space_uid`：`@property`，返回 `"{space_type_id}__{space_id}"`

**关键方法**：
- `to_dict(fields, exclude)` — 转字典，自动添加 `space_uid` 和 `bk_tenant_id`
- `bulk_create_space(bk_tenant_id, space_type_id, space_list)` — 批量创建
- `get_bk_biz_id()` — 获取业务 ID（BKCC 返回 `int(space_id)`，其他返回 `-pk`）

## SpaceDataSource — 空间与数据源关系

**表名**：`metadata_spacedatasource`
**文件**：[space.py:103-113](file://bk-monitor-base/src/bk_monitor_base/metadata/models/space/space.py#L103-L113)

| 字段 | 类型 | 说明 |
|------|------|------|
| `space_type_id` | CharField(64) | 空间类型 |
| `space_id` | CharField(128) | 空间 ID，索引 |
| `bk_tenant_id` | CharField(256) | 租户 ID，默认 "system" |
| `bk_data_id` | IntegerField | 数据源 ID，索引 |
| `from_authorization` | BooleanField | 是否来源于授权，默认 False |

**唯一约束**：`(space_type_id, space_id, bk_data_id)`

**关键语义**：
- `from_authorization=False`：空间专属数据源（创建时直接关联）
- `from_authorization=True`：授权数据源（从其他空间授权或平台级授权）

## SpaceResource — 空间资源信息

**表名**：`metadata_spaceresource`
**文件**：[space.py:116-137](file://bk-monitor-base/src/bk_monitor_base/metadata/models/space/space.py#L116-L137)

| 字段 | 类型 | 说明 |
|------|------|------|
| `space_type_id` | CharField(64) | 空间类型 |
| `space_id` | CharField(128) | 空间 ID |
| `bk_tenant_id` | CharField(256) | 租户 ID，默认 "system" |
| `resource_type` | CharField(128) | 资源类型（如 bkcc/bcs） |
| `resource_id` | CharField(64) | 资源唯一标识，可空 |
| `dimension_values` | JSONField | 关键维度值列表，默认空列表 |

**唯一约束**：`(space_type_id, space_id, resource_type, resource_id)`

**Manager**：`SpaceResourceManager`

**关键语义**：
- `resource_type` 对应 SpaceType 的 `type_id`
- `dimension_values` 存储关键维度值，如 `[{"cluster_id": "BCS-K8S-1000", "namespace": ["default", "prod"]}]`
- BKCI 空间通过 `resource_type=bkcc` 关联业务，通过 `resource_type=bcs` 关联集群

## 结论

空间管理子专家覆盖 6 个 Django Model 和 4 个核心枚举。模型间通过 `space_type_id`/`space_id`/`bk_tenant_id` 三元组实现多租户隔离，通过 `bk_data_id` 关联数据源，通过 `resource_type`/`resource_id` 关联外部资源。
