# C1-能力契约

> **覆盖度声明**：本契约基于 `custom_report/` 包全部 5 个文件和 `record_rule/` 包全部 4 个文件的完整分析。`time_series.py`(106KB) 采用聚焦核心方法策略。

## 一、CustomGroupBase API

**契约来源**：`CustomGroupBase` (models/custom_report/base.py)

### 创建/修改/删除

#### `CustomGroupBase.create_custom_group(bk_data_id, bk_biz_id, custom_group_name, label, operator, bk_tenant_id, metric_info_list?, table_id?, is_builtin?, is_split_measurement?, default_storage_config?, additional_options?, data_label?, bk_biz_id_alias?, **kwargs)`
- **用途**：创建自定义上报组（统一入口，子类通过包装方法调用）
- **参数**：
  - `bk_data_id` (int) — 数据源 ID
  - `bk_biz_id` (int) — 业务 ID
  - `custom_group_name` (str) — 自定义组名称
  - `label` (str) — 结果表标签
  - `operator` (str) — 操作者
  - `bk_tenant_id` (str) — 租户 ID
  - `metric_info_list` (list|None) — 指标/事件列表
  - `table_id` (str|None) — 指定结果表 ID，默认自动生成
  - `is_builtin` (bool) — 是否内置，默认 False
  - `is_split_measurement` (bool) — 是否单指标单表，默认 False
  - `default_storage_config` (dict|None) — 存储配置
  - `additional_options` (dict|None) — 结果表选项
  - `data_label` (str|None) — 数据标签
- **返回**：`Self` — 子类实例
- **异常**：标签不存在、data_id 已被占用、同名组已存在时抛 ValueError
- **约束**：创建后自动刷新 Consul 配置触发 Transfer 更新；清除历史 DataSourceResultTable 数据

```python
# 通过 TimeSeriesGroup 包装方法创建
group = TimeSeriesGroup.create_time_series_group(
    bk_data_id=1001,
    bk_biz_id=2,
    time_series_group_name="my_custom_metrics",
    label="application_check",
    operator="admin",
    bk_tenant_id="system",
    metric_info_list=[
        {"field_name": "cpu_usage", "tag_list": [{"field_name": "hostname"}]}
    ],
)
```

#### `CustomGroupBase.modify_custom_group(operator, custom_group_name?, label?, is_enable?, metric_info_list?, field_list?, max_rate?, enable_field_black_list?, data_label?, options?)`
- **用途**：修改自定义上报组
- **参数**：所有参数可选，仅传入需要修改的字段
- **返回**：`bool` — True
- **异常**：已删除的组不可修改，抛 ValueError

#### `CustomGroupBase.delete_custom_group(operator)`
- **用途**：删除自定义上报组（标记删除 + 关联结果表废弃）
- **返回**：`bool` — True

### 属性

#### `CustomGroupBase.custom_group_id` (属性)
- **用途**：获取自定义组 ID（通过 `GROUP_ID_FIELD` 动态获取）
- **返回**：`Any`

#### `CustomGroupBase.custom_group_name` (属性 getter/setter)
- **用途**：获取/设置自定义组名称（通过 `GROUP_NAME_FIELD` 动态获取/设置）

#### `CustomGroupBase.data_label` (属性)
- **用途**：获取数据标签（从关联的 ResultTable 读取）
- **返回**：`str` — 不存在时返回空字符串

### 内部方法

#### `CustomGroupBase.pre_check(label, bk_data_id, custom_group_name, bk_biz_id, bk_tenant_id)`
- **用途**：创建前校验（标签存在性、data_id 唯一性、同名组唯一性）
- **返回**：`dict` — filter_kwargs

#### `CustomGroupBase.make_table_id(bk_biz_id, bk_data_id, bk_tenant_id, table_name?)`
- **用途**：生成结果表 ID（子类必须实现）
- **返回**：`str`

#### `CustomGroupBase.update_metrics(metric_info)`
- **用途**：更新指标/事件（子类必须实现）
- **返回**：`NotImplementedError`

## 二、TimeSeriesGroup API

**契约来源**：`TimeSeriesGroup` (models/custom_report/time_series.py)

### 创建/修改/删除

#### `TimeSeriesGroup.create_time_series_group(bk_data_id, bk_biz_id, time_series_group_name, label, operator, bk_tenant_id, metric_info_list?, table_id?, is_split_measurement?, is_builtin?, default_storage_config?, additional_options?, data_label?)`
- **用途**：创建自定义时序上报组
- **返回**：`TimeSeriesGroup`
- **约束**：默认存储 InfluxDB；`is_split_measurement` 默认 True

#### `TimeSeriesGroup.modify_time_series_group(operator, time_series_group_name?, label?, is_enable?, field_list?, enable_field_black_list?, metric_info_list?, data_label?, options?)`
- **用途**：修改自定义时序组
- **返回**：`bool`

#### `TimeSeriesGroup.delete_time_series_group(operator)`
- **用途**：删除自定义时序组
- **返回**：`bool`

### 指标管理

#### `TimeSeriesGroup.update_time_series_metrics()`
- **用途**：从远端存储（Redis/BkData）同步时序指标和维度
- **返回**：`bool` — 是否有更新

#### `TimeSeriesGroup.get_metric_info_list()`
- **用途**：获取时序组下所有有效指标信息
- **返回**：`list[dict]` — 每项含 `field_name/table_id/tag_list` 等

#### `TimeSeriesGroup.get_metric_info_list_with_label(dimension_name, dimension_value)`
- **用途**：按维度过滤获取指标信息
- **返回**：`list`

#### `TimeSeriesGroup.get_ts_metrics_by_dimension(dimension_name, dimension_value)`
- **用途**：按维度名/值过滤指标
- **返回**：`list`

#### `TimeSeriesGroup.get_metrics_from_redis(expired_time?)`
- **用途**：从 Transfer Redis 的 ZSET 中拉取指标
- **返回**：`list`

#### `TimeSeriesGroup.get_metric_from_bkdata()`
- **用途**：从计算平台 API 获取指标
- **返回**：`list`

### 表 ID 生成

#### `TimeSeriesGroup.make_table_id(bk_biz_id, bk_data_id, table_name?, bk_tenant_id?)`
- **用途**：生成结果表 ID
- **返回**：`str` — 格式 `{bk_biz_id}_bkmonitor_time_series_{bk_data_id}.__default__`（多租户加前缀）

#### `TimeSeriesGroup.make_metric_table_id(field_name)`
- **用途**：生成单指标单表的 table_id
- **返回**：`str` — 格式 `bk_k8s_{group_name}_{field_name}`

### 维度与字段

#### `TimeSeriesGroup.update_tag_fields(table_id, tag_list, update_description?)`
- **用途**：更新维度信息
- **返回**：`bool`

#### `TimeSeriesGroup.update_metric_field(field_name, is_disabled)`
- **用途**：启用/禁用指标字段
- **返回**：`bool`

#### `TimeSeriesGroup.bulk_refresh_rt_fields(table_id, metric_info)`
- **用途**：批量刷新结果表字段
- **返回**：`None`

### 序列化

| 方法 | 签名 | 说明 |
|------|------|------|
| `to_json` | `() → dict` | 转为 JSON（含指标列表） |
| `to_json_v2` | `() → list` | V2 格式（按 scope 分组） |

## 五、RecordRule API

**契约来源**：`RecordRule` (models/record_rule/rules.py)

### RecordRule

#### `RecordRule.transform_bk_sql_and_metrics(rule_config)`
- **用途**：将 YAML 规则配置转换为计算平台 BKSQL
- **参数**：`rule_config` (str) — YAML 格式规则配置
- **返回**：`dict` — `{"bksql": [...], "metrics": [...], "rule_metrics": {...}}`
- **约束**：PromQL 表达式通过 `refine_bk_sql_and_metrics` 转换

#### `RecordRule.get_src_table_ids(space_type, space_id, metrics)`
- **用途**：通过指标和空间反查源 VM 结果表
- **参数**：`space_type` (str)、`space_id` (str)、`metrics` (list[str]|set[str])
- **返回**：`list[str]` — VM 结果表 ID 列表
- **约束**：通过 ResultTableField → TimeSeriesGroup → TimeSeriesMetric 链路过滤，过期指标被排除

#### `RecordRule.get_dst_table_id(table_id)`
- **用途**：生成目标 VM 结果表名
- **返回**：`str` — 格式 `{default_bkdata_biz_id}_{rule_table_id}`

### ResultTableFlow

#### `ResultTableFlow.create_flow(bk_tenant_id, table_id, waiting_time?, expires?, schemaless?)`
- **用途**：创建计算平台数据流（stream_source → promql_v2 → vm_storage）
- **参数**：`waiting_time` (int, 默认 30s)、`expires` (int, 默认 30 天)、`schemaless` (bool, 默认 True)
- **返回**：`bool`
- **约束**：创建前先调用 `batch_add_permission` 授权源结果表

#### `ResultTableFlow.start_flow(bk_tenant_id, flow_id, consuming_mode?)`
- **用途**：启动数据流
- **参数**：`consuming_mode` (str) — 默认 `Current`（尾部消费，避免历史数据积压）

#### `ResultTableFlow.stop_flow(bk_tenant_id, flow_id)`
- **用途**：停止数据流

#### `ResultTableFlow.delete_flow(bk_tenant_id, flow_id)`
- **用途**：删除数据流

### 内部方法

| 方法 | 签名 | 说明 |
|------|------|------|
| `compose_flow_name` | `@classmethod (table_id: str) → str` | 组装数据流名称 |
| `compose_source_node` | `@classmethod (vm_table_ids: list) → list[dict]` | 组装源节点 |
| `compose_process_node` | `@classmethod (bk_tenant_id, table_id, vm_table_ids, waiting_time?) → dict` | 组装处理节点 (promql_v2) |
| `compose_vm_storage` | `@classmethod (bk_tenant_id, table_id, process_id, expires?, schemaless?) → dict` | 组装存储节点 (vm_storage) |
