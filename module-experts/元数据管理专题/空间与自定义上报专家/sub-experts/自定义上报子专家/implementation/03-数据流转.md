## 简介

本章描述自定义上报子专家覆盖的四条核心数据流：自定义上报从接入→校验→存储→查询的完整链路、时序指标同步的双通道数据流、事件维度自动发现数据流、记录规则从配置→计算平台→结果存储的执行链路。

```mermaid
sequenceDiagram
    participant Agent as "采集器"
    participant Transfer as "Transfer"
    participant Redis as "Redis<br/>(指标缓存)"
    participant InfluxDB as "InfluxDB/VM"
    participant Metadata as "元数据服务"

    Note over Agent,Metadata: === 数据上报阶段 ===
    Agent->>Transfer: "上报时序数据"
    Transfer->>Transfer: "按 data_id 路由"
    Transfer->>Redis: "ZADD 指标名+时间戳"
    Transfer->>Redis: "HMSET 指标维度信息"
    Transfer->>InfluxDB: "写入时序数据"

    Note over Agent,Metadata: === 指标同步阶段 (Redis 通道) ===
    Metadata->>Redis: "ZRANGEBYSCORE 拉取指标"
    Metadata->>Redis: "HMGET 拉取维度"
    Metadata->>Metadata: "get_metrics_from_redis()"

    Note over Agent,Metadata: === 指标同步阶段 (BkData 通道) ===
    Metadata->>Metadata: "get_metric_from_bkdata()"
    Note over Metadata: 调用 query_metric_and_dimension API

    Note over Agent,Metadata: === 合并入库 ===
    Metadata->>Metadata: "合并双通道指标数据"
    Metadata->>Metadata: "update_time_series_metrics()"
    Metadata->>Metadata: "更新 TimeSeriesMetric 表"
```

```mermaid
sequenceDiagram

    participant Transfer as "Transfer"
    participant ES as "Elasticsearch"
    participant Metadata as "元数据服务"

    Note over Agent,Metadata: === 数据上报阶段 ===

    Metadata->>Metadata: "update_event_dimensions_from_es()"
```

## 记录规则数据流

### 规则创建到数据流启动

```mermaid
sequenceDiagram
    participant User as "用户/API"
    participant RRS as "RecordRuleService"
    participant RR as "RecordRule"
    participant RTF as "ResultTableFlow"
    participant BKData as "计算平台"
    participant VM as "VictoriaMetrics"

    User->>RRS: "create_record_rule(space, name, config)"
    
    RRS->>RR: "transform_bk_sql_and_metrics(config)"
    Note over RR: YAML → PromQL → BKSQL
    RR-->>RRS: "返回 BKSQL/指标/源表"

    RRS->>RR: "get_src_table_ids(space, metrics)"

    RRS->>RR: "get_dst_table_id(table_id)"

    RRS->>RRS: "创建结果表/字段/VM 映射"

    RRS->>RTF: "create_flow(table_id)"
    RTF->>RTF: "compose_source_node(vm_table_ids)"
```

## 结论

自定义上报子专家的四条数据流覆盖了从数据接入到存储查询的完整链路。时序上报通过 Redis+BkData 双通道实现指标自动发现，事件上报通过 ES 聚合查询实现维度自动发现，日志上报通过 Token 鉴权实现安全上报，记录规则通过计算平台三节点数据流实现 PromQL 预计算。
