## 框架与组织

- **运行器与断言**：Node 原生 `node:test` + `node:assert/strict`；命名惯例 `*.test.cjs`（少数 `.test.mjs`）；**直跑真实源码**（不经打包、不建测试双）：TS/TSX 经 `typescript.transpileModule`（CommonJS + ES2022）编译后用 `new Function('require', 'module', 'exports', ...)` 执行；`.vue` 用 `vue/compiler-sfc` 的 `parse` + `compileTemplate` 手动装配 render；依赖经自定义 `require` 映射注入桩，并对 `window` / `location` 等环境按用例注入。

  1. **纯函数直测**：`utils.ts` 的 `judgeIsIllegal` / `metricNameTransFrom`；`components/indicator-dimension/utils.ts` 的 `fieldUid` / `ensureDefaultGroup` / `normalizeField` / `flattenFields` / `filterFieldsByGroup` / `fuzzyMatch` / `getMetricCount` / `checkDimensionRelevance` / `moveCheckedFields` / `moveFieldToGroup` / `applyGroupRules` / `deleteGroup` / `createEmptyField` / `applyBatchFieldChanges` / `buildSaveMetricParams` / `getMetricTypeList` / `getExportMetricJson`——transpileModule 直跑即可，无需环境注入；
