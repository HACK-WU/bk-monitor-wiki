## 1. `resource.alert.search_alert(**params)` — 告警列表查询

**用途**：告警列表的核心入口，返回分页命中 + 总数 +（可选）总览与维度聚合。对应 HTTP `POST /rest/v2/alert/search`（`SearchAlertResource`）。

**参数**（`AlertSearchSerializer` + `SearchAlertResource.RequestSerializer`）：
- `bk_biz_ids: list[int]` — 业务 ID 列表，可含 `-1`（全业务哨兵，自动展开）
- `space_uids: list[str]`（可选）— 空间 UID，自动转 `bk_biz_ids` 并合并去重
- `status: list[str]`（可选）— 状态过滤，支持 `MINE` / `MY_ASSIGNEE` / `MY_APPOINTEE` / `MY_FOLLOW` / `SHIELDED_ABNORMAL` / `NOT_SHIELD_ABNORMAL` 及具体状态枚举
- `conditions: list[dict]`（可选）— 形如 `{key, value, method, condition}`，`method ∈ {eq,neq,include,exclude,gt,gte,lt,lte}`
- `query_string: str`（默认 `""`）— 全文/结构化检索
- `start_time: int` / `end_time: int`（必填）— 秒级时间戳
- `username: str`（可选）— 明确负责人时仅过滤该用户
- `ordering: list[str]`（默认 `[]`）— 排序字段，前缀 `-` 表示降序
- `page: int`（默认 `1`）/ `page_size: int`（默认 `10`，上限 `5000`）
- `show_overview: bool`（默认 `True`）/ `show_aggs: bool`（默认 `True`）/ `show_dsl: bool`（默认 `False`）
- `record_history: bool`（默认 `False`）/ `must_exists_fields: list[str]`（默认 `[]`）/ `replace_time_range: bool`（默认 `False`）

**返回**：`dict`
- `alerts: list[dict]` — 当前页命中（字段名已翻译为显示名）
- `total: int` — 命中总数（`track_total_hits=10000` 上限，超量不精确）
- `overview: dict`（当 `show_overview`）/ `aggs: dict`（当 `show_aggs`）/ `dsl: dict`（当 `show_dsl`）

**异常**：参数非法抛 `ValidationError`（`query_string` 条数超限、`AlertIDField` 非法 ID）；ES 异常时 `search()` fail-open 返回空响应并 `exc.data=result` 后重抛。

**约束**：必须带 `start_time`/`end_time`；`page_size` 上限 5000；`bk_biz_ids=-1` 会被展开（禁止裸用 `-1` 过滤）；`show_dsl=True` 仅用于调试。

**契约来源**：`SearchAlertResource`（`resources.py`）/ `AlertSearchSerializer`（`serializers.py`）

**真实代码示例**：
```python
# 例1：取某业务最近 1 小时告警总数（来自 monitor_web/scene_view/resources/view.py:758）
from core.drf_resource import resource

params = {
    "bk_biz_ids": [2],
    "start_time": now_ts - 3600,
    "end_time": now_ts,
    "status": ["ABNORMAL"],
}
event_counts = resource.alert.search_alert(**params)["total"]

# 例2：拉取告警列表做后续处理（来自 kernel_api/views/v4/event.py:97）
alerts = resource.alert.search_alert(
    bk_biz_ids=[2], start_time=s, end_time=e, page=1, page_size=100
)["alerts"]
```

## 2. `AlertQueryHandler(...).search(...)` — 直接构造处理器查询

**用途**：在 Python 内部直接调用查询管线，绕过 HTTP/Resource 层。多个内部模块（机器人、grafana、incident、assign 等）复用此入口。

**参数**（`__init__`）：
- `bk_biz_ids: list[int]`（默认 `None`）/ `username: str`（默认 `""`）
- `status: list[str] | str`（默认 `None`）/ `start_time: int` / `end_time: int`
- `ordering: list[str]` / `query_string: str` / `conditions: list[dict]`
- `page: int`（默认 `1`）/ `page_size: int`（默认 `10`）/ `is_time_partitioned: bool` / `is_finaly_partition: bool` / `need_bucket_count: bool`
- `**kwargs` — 透传 `must_exists_fields`、`context` 等

**返回**：`dict`（同 `search_alert`，含 `alerts` / `total` / `overview` / `aggs`）

**异常**：同 §1（`search()` 内置 fail-open）。

**约束**：构造期自动展开 `bk_biz_ids=-1` 并展开 `issue_id` 合并成员；默认排序 `["status", "-create_time", "-seq_id"]`；`status` 可传单字符串（内部自动包成列表）。

**契约来源**：`AlertQueryHandler.__init__` / `AlertQueryHandler.search`（`handlers/alert.py`）

**真实代码示例**：
```python
# 例1：查未屏蔽异常告警（来自 monitor_web/commons/robot/utils.py:93）
from fta_web.alert.handlers.alert import AlertQueryHandler

query_config = {"bk_biz_ids": [2], "start_time": s, "end_time": e}
handler = AlertQueryHandler(
    status=[AlertQueryHandler.NOT_SHIELD_ABNORMAL_STATUS_NAME], **query_config
)
alerts = handler.search(show_overview=False, show_aggs=False)["alerts"]

# 例2：最小构造（来自 monitor_web/search/handlers/alert.py:28）
handler = AlertQueryHandler(bk_biz_ids=bk_biz_ids, start_time=start_time, end_time=end_time)
```

## 3. `AlertQueryHandler(...).date_histogram(interval, group_by, bucket_size)` — 趋势聚合

**用途**：按 begin/end/init 三段时间桶统计告警状态分布，用于趋势图。

**参数**：
- `interval: str`（默认 `"auto"`）— 聚合周期，`auto` 按起止时间自动计算
- `group_by: list[str]`（默认 `["status"]`）— 聚合维度；`tags.` 字段最多 1 个（多则抛 `ValueError`）
- `bucket_size: int`（默认 `100`）

**返回**：`dict` — 以组合维度 tuple 为键的桶聚合结果（状态分布时间序列）。

**异常**：`group_by` 含多于 1 个 `tags.` 字段时抛 `ValueError`。

**约束**：同步执行（`search_object[:0].execute()` 仅取聚合）；`status` 会被单独处理；`interval` 经 `calculate_agg_interval` 规整。

**契约来源**：`AlertQueryHandler.date_histogram`（`handlers/alert.py`）

**真实代码示例**：
```python
handler = AlertQueryHandler(bk_biz_ids=[2], start_time=s, end_time=e)
series = handler.date_histogram(interval="1h", group_by=["status"])
```

## 4. `resource.alert.alert_top_n(**params)` — 维度 TopN

**用途**：按字段聚合 TopN（如按策略、按主机、按标签），支持时间分片并行。对应 HTTP `POST /rest/v2/alert/top_n`（`AlertTopNResource`）。

**参数**：
- 继承 `AlertSearchSerializer` 字段（`bk_biz_ids` / `status` / `conditions` / `query_string` / `start_time` / `end_time` 等）
- `fields: list[str]` — 聚合维度字段；`tags.` 字段一次最多 `MAX_NESTED_TOP_N_FIELDS=20` 个
- `size: int`（默认 `10`）— 每个维度返回条数
- `need_time_partition: bool`（默认 `True`）— 是否按时间切片并行

**返回**：`dict` — `{"doc_count": int, "fields": [{"field", "is_char", "buckets": [{"id","count", ...}]}]}`

**异常**：`tags.` 字段超 20 抛 `ValidationError`；ES 异常由底层 fail-open。

**约束**：`need_time_partition=True` 时按时间切片 `bulk_request` 并行后合并；`fields[0].buckets` 为第 1 个维度的桶。

**契约来源**：`AlertTopNResource`（`resources.py`）

**真实代码示例**：
```python
# 取自 resources.py:287 —— 取某业务 TopN 策略及其桶
params = {
    "bk_biz_ids": [2],
    "start_time": s,
    "end_time": e,
    "fields": ["strategy_id"],
    "size": 10,
}
buckets = resource.alert.alert_top_n(params)["fields"][0]["buckets"]
topn = {i["id"]: i["count"] for i in buckets}
```

## 5. `resource.alert.alert_date_histogram(**params)` — 趋势直方图

**用途**：告警分布直方图。对应 HTTP `POST /rest/v2/alert/date_histogram`（`AlertDateHistogramResource`）。

**参数**：继承 `AlertSearchSerializer` + `interval: str`（默认 `"auto"`）。

**返回**：`dict` — `{"series": [{"data": [[ts, cnt], ...], "name", "display_name"}, ...], "unit": ""}`，按 `EVENT_STATUS_DICT` 各状态一条序列。

**异常**：参数非法抛 `ValidationError`。

**约束**：内部按时间切片 `bulk_request` 调 `alert_date_histogram_result` 后合并；`interval` 经 `calculate_agg_interval` 规整。

**契约来源**：`AlertDateHistogramResource`（`resources.py`）

**真实代码示例**：
```python
result = resource.alert.alert_date_histogram(
    bk_biz_ids=[2], start_time=s, end_time=e, interval="1h"
)
for s in result["series"]:
    print(s["name"], s["display_name"], s["data"])
```

## 7. `resource.alert.search_event(**params)` — 关联事件

**用途**：查某告警下的关联事件。对应 HTTP `POST /rest/v2/event/search`（`SearchEventResource`）。

**参数**（`EventSearchSerializer` + `RequestSerializer`）：
- `alert_id: str`（必填，经 `AlertIDField` 校验）
- `ordering: list[str]` / `query_string: str`
- `page: int`（默认 `1`）/ `page_size: int`（默认 `10`，上限 `1000`）
- `show_dsl: bool` / `record_history: bool` / `show_raw: bool`

**返回**：`dict` — 事件列表 + `total` 等（关联告警会适配为事件）。

**异常**：`alert_id` 非法抛 `ValidationError`。

**约束**：关联告警会经 `search_composite_alerts` 适配；`show_raw=True` 返回原始事件。

**契约来源**：`SearchEventResource`（`resources.py`）

**真实代码示例**：
```python
result = resource.alert.search_event(alert_id="xxxx", page=1, page_size=50)
events = result["alerts"]  # 事件已适配为告警结构
```

## 13. `AlertQueryHandler.parse_biz_item(bk_biz_ids, **kwargs)` — 业务鉴权展开

**用途**：将 `bk_biz_ids`（可能含 `-1`）展开为授权业务集与未授权业务集。供需要手动展开 `-1` 的调用方使用（如 TopN / 处理记录资源）。

**参数**：`bk_biz_ids: list[int]`；`**kwargs` 可带 `authorized_bizs` / `unauthorized_bizs` 直接透传。

**返回**：`tuple[list[int], list[int]]` — `(authorized_bizs, unauthorized_bizs)`。

**异常**：无（无请求上下文时返回 `(bk_biz_ids, [])`）。

**约束**：`-1` 表示用户全部授权业务；非 `-1` 时取 `请求值 ∩ 用户授权业务`；无 `get_request()` 上下文（如 shell）直接返回原值。

**契约来源**：`BaseBizQueryHandler.parse_biz_item`（`handlers/base.py`）

**真实代码示例**：
```python
# 取自 resources.py:1920（SearchActionResource 内部展开）
from fta_web.alert.handlers.alert import AlertQueryHandler
authorized_bizs, unauthorized_bizs = AlertQueryHandler.parse_biz_item([2, -1])
```
