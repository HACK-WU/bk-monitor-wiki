## 配方 1：查询某业务未屏蔽异常告警（列表 + 处理器两种入口）

**业务目标**：拉取业务 2 最近 1 小时内「未屏蔽异常」告警，用于列表展示或后续处理。

**调用顺序**：
1. 构造查询参数（`bk_biz_ids` / `start_time` / `end_time` / `status`）
2. 经 HTTP 资源 `resource.alert.search_alert` 或内部 `AlertQueryHandler.search` 执行
3. 取 `alerts` / `total`（字段名已由处理器翻译为显示名）

**事务边界**：纯读，无事务。

**预期结果**：返回分页命中列表与总数；`status=NOT_SHIELD_ABNORMAL` 等价 `status=ABNORMAL AND is_shielded=false`。

**真实代码示例**：
```python
# 入口 A：HTTP 资源（推荐，自动鉴权 + 历史记录）
from core.drf_resource import resource
result = resource.alert.search_alert(
    bk_biz_ids=[2], start_time=now_ts - 3600, end_time=now_ts,
    status=[AlertQueryHandler.NOT_SHIELD_ABNORMAL_STATUS_NAME],
    page=1, page_size=100, show_overview=False, show_aggs=False,
)
alerts, total = result["alerts"], result["total"]

# 入口 B：内部直接调用（来自 monitor_web/commons/robot/utils.py:93）
from fta_web.alert.handlers.alert import AlertQueryHandler
handler = AlertQueryHandler(
    status=[AlertQueryHandler.NOT_SHIELD_ABNORMAL_STATUS_NAME],
    bk_biz_ids=[2], start_time=now_ts - 3600, end_time=now_ts,
)
alerts = handler.search(show_overview=False, show_aggs=False)["alerts"]
```

## 配方 2：按维度做 TopN 统计

**业务目标**：统计业务 2 最近 1 小时按「策略」维度的 TopN 告警分布。

**调用顺序**：
1. 组装 `fields=["strategy_id"]`、`size=10` 及时间/业务条件
2. 调用 `resource.alert.alert_top_n`
3. 取 `result["fields"][0]["buckets"]`，按 `id`/`count` 聚合

**事务边界**：纯读，无事务；`need_time_partition=True` 时内部按时间切片并行后合并。

**预期结果**：返回各维度桶；`fields[0].buckets` 为第 1 维度（本例 `strategy_id`）的 Top 桶。

**真实代码示例**：
```python
from core.drf_resource import resource
params = {
    "bk_biz_ids": [2], "start_time": s, "end_time": e,
    "fields": ["strategy_id"], "size": 10, "need_time_partition": True,
}
buckets = resource.alert.alert_top_n(params)["fields"][0]["buckets"]
topn = {i["id"]: i["count"] for i in buckets}   # 取自 resources.py:287
```

## 配方 3：导出全量告警为 CSV

**业务目标**：将业务 2 指定时间范围告警全量导出。

**调用顺序**：
1. 提供 `bk_biz_id`（导出归属）+ 查询条件，`page_size=0`（全量语义）
2. 调用 `resource.alert.export_alert`
3. 接收导出文件响应

**事务边界**：纯读，无事务；内部 `handler.export_with_docs()` 走 `scan()` 全量并补关联信息。

**预期结果**：返回 CSV 包响应。

**真实代码示例**：
```python
resp = resource.alert.export_alert(
    bk_biz_id=2, bk_biz_ids=[2], start_time=s, end_time=e, page_size=0
)
```

## 配方 4：告警详情页聚合（事件 + 处理记录 + 事件计数 + 关联信息）

**业务目标**：打开某告警详情时，并行补齐关联事件、处理记录、事件计数与 CMDB 关联信息。

**调用顺序**：
1. `resource.alert.search_event(alert_id=...)` 取关联事件
2. `resource.alert.search_action(bk_biz_ids=..., alert_ids=[...])` 取处理记录
3. `resource.alert.alert_event_count(ids=[...])` 取事件计数
4. `resource.alert.alert_related_info(ids=[...])` 取 CMDB 关联信息

**事务边界**：4 次独立读，可并行（如 `bulk_request` 或线程池）；任一失败不影响其余。

**预期结果**：组装出告警详情所需的全部关联数据。

**真实代码示例**：
```python
from core.drf_resource import resource
alert_id = "xxxx"
events = resource.alert.search_event(alert_id=alert_id, page=1, page_size=50)
actions = resource.alert.search_action(
    bk_biz_ids=[2], alert_ids=[alert_id], start_time=s, end_time=e
)
event_count = resource.alert.alert_event_count(ids=[alert_id])   # 取自 resources.py:2033
related = resource.alert.alert_related_info(ids=[alert_id]).get(alert_id, {})  # 取自 resources.py:667
```
