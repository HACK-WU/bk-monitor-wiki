## GetSceneResource
契约来源：`GetSceneResource`（`resources/view.py`）

### perform_request
- **用途**：获取业务下的监控场景列表（内置 + 自定义）
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
- **返回**：`list[dict]` — 每项含 `id`(场景ID), `name`(场景名称), `builtin`(是否内置)
- **异常**：无
- **约束**：无
- **使用示例**：
  ```python
  # 假设已初始化 resource 框架
  scenes = resource.scene_view.get_scene(bk_biz_id=2)
  # => [{"id": "host", "name": "主机监控", "builtin": True}, ...]
  ```

## GetSceneViewListResource
契约来源：`GetSceneViewListResource`（`resources/view.py`）

### perform_request
- **用途**：获取场景下的视图列表（含面板数量统计），支持 overview/detail 合并返回
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | scene_id | str | 是 | 场景分类 |
  | type | str | 否 | 视图类型（overview/detail），不传则合并返回 overview+detail |
  | apm_app_name | str | 否 | APM 应用名称（APM 场景变量） |
  | apm_service_name | str | 否 | APM 服务名称 |
  | start_time | int | 否 | 开始时间 |
  | end_time | int | 否 | 结束时间 |
- **返回**：`list[dict]` — 每项含 `id`, `name`, `mode`, `type`, `panel_count`(可选), `show_panel_count`(可选)
- **异常**：无
- **约束**：apm/kubernetes/alert 场景的 `type` 会被 `validate_scene_type` 强制置空
- **使用示例**：
  ```python
  # 获取主机场景的概览+详情视图列表
  views = resource.scene_view.get_scene_view_list(bk_biz_id=2, scene_id="host")
  # => [{"id": "host", "name": "主机概览", "mode": "auto", "type": "overview", "panel_count": 5}, ...]

  # 仅获取概览视图
  views = resource.scene_view.get_scene_view_list(bk_biz_id=2, scene_id="host", type="overview")
  ```

### get_panel_count (classmethod)
- **用途**：递归统计视图配置中的面板数量
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | view_config | dict | 是 | 视图配置（含 panels 列表） |
- **返回**：`int` — 面板数量（row 类型递归下钻，排除 tag-chart 类型）
- **约束**：无
- **使用示例**：
  ```python
  count = GetSceneViewListResource.get_panel_count(view_config)
  ```

## GetSceneViewResource
契约来源：`GetSceneViewResource`（`resources/view.py`）

### perform_request
- **用途**：获取单个视图的完整配置（panels/order/variables/options），支持分屏模式
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | scene_id | str | 是 | 场景分类 |
  | id | str | 是 | 视图ID |
  | type | str | 否 | 视图类型（overview/detail），默认空串 |
  | is_split | bool | 否 | 是否分屏，默认 False |
  | split_variables | list | 否 | 分屏变量配置，默认空列表 |
  | bk_host_innerip | str | 否 | 主机内网IP（主机场景变量） |
  | bk_cloud_id | str | 否 | 主机云区域ID |
  | bk_host_id | str | 否 | 主机ID |
  | apm_app_name | str | 否 | APM 应用名称 |
  | apm_service_name | str | 否 | APM 服务名称 |
  | bcs_cluster_id | str | 否 | K8S 集群ID |
  | start_time | int | 否 | 开始时间 |
  | end_time | int | 否 | 结束时间 |
  | view_switches | dict | 否 | 视图场景开关，默认空字典 |
- **返回**：`dict` — 视图配置 JSON，结构为 `{bk_biz_id, scene_id, id, name, variables, type, mode, order, panels, options}`
- **异常**：`Http404` — 视图不存在
- **约束**：调用前会先 `create_default_views` 补齐默认视图
- **使用示例**：
  ```python
  # 获取主机详情视图配置
  config = resource.scene_view.get_scene_view(
      bk_biz_id=2, scene_id="host", type="detail", id="host"
  )
  # => {"bk_biz_id": 2, "scene_id": "host", "id": "host", "name": "主机详情", "panels": [...], ...}
  ```

### process_split (classmethod)
- **用途**：处理分屏逻辑，将侧边栏选择器转换为变量
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | view_config | dict | 是 | 视图配置 |
  | split_variables | list[dict] | 是 | 分屏变量配置 |
- **返回**：`dict` — 处理后的视图配置（variables 扩展、selector_panel 置空）
- **约束**：无

## GetHostProcessListResource
契约来源：`GetHostProcessListResource`（`resources/host.py`）

### perform_request
- **用途**：获取主机进程列表（CMDB 进程信息 + 4 路并发 TSDB 查询聚合）
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | bk_host_id | int | 否 | 主机ID（与 bk_target_ip/bk_target_cloud_id 二选一） |
  | bk_target_ip | str | 否 | 主机IP |
  | bk_target_cloud_id | int | 否 | 云区域ID |
  | start_time | int | 否 | 开始时间（秒级时间戳，不传则默认最近三分钟） |
  | end_time | int | 否 | 结束时间（秒级时间戳） |
- **返回**：`list[dict]` — 每项含 `id`, `name`, `status`, `protocol`, `bindIp`, `port`, `portStatus`, `user`, `hostIp`, `cpuUsage`, `memRss`, `memUsage`, `uptime`, `fdNum`, `instanceCount`, `startCommand`
  - 运行时指标单位（映射自 `system.proc`）：`cpuUsage`=percentunit；`memRss`→`mem_res`=**字节**；`memUsage`→`mem_usage_pct`=**percentunit（0-1，0.58=58%）**；`fdNum`/`fdLimit`→`fd_num`/`fd_limit_soft`=个
- **异常**：无（TSDB 查询失败时降级返回空值）
- **约束**：`bk_host_id` 和 `bk_target_ip`+`bk_target_cloud_id` 必须有一个
- **使用示例**：
  ```python
  processes = resource.scene_view.get_host_process_list(
      bk_biz_id=2, bk_host_id=12345
  )
  # => [{"id": 1, "name": "nginx", "status": "running", "cpuUsage": 2.5, "memRss": 10240, ...}]
  ```
