> 契约快照生成于 2026-07-27（commit ca831622）。
> 若使用中发现行为与契约不符，可能代码已变更——expert-lookup 会自动增量修正，或用 expert-team 全量重建。

## 获取并渲染场景视图配置：前端加载监控页面的完整流程
- **调用顺序**：
  1. 调用 `resource.scene_view.get_scene(bk_biz_id=2)` 获取场景列表
  2. 调用 `resource.scene_view.get_scene_view_list(bk_biz_id=2, scene_id="host")` 获取视图列表（含面板数）
  3. 调用 `resource.scene_view.get_scene_view(bk_biz_id=2, scene_id="host", type="detail", id="host", bk_host_id="12345")` 获取完整视图配置
- **事务边界**：无事务要求（纯读操作，但内部会触发 `create_default_views` 补齐默认视图）
- **预期结果**：前端获得完整的视图配置 JSON（panels/order/variables/options），可直接渲染图表
- **错误处理**：视图不存在时返回 `Http404`；内置场景处理器未找到时返回 `TypeError`
- **使用示例**：
  ```python
  # Step 1: 获取场景列表
  scenes = resource.scene_view.get_scene(bk_biz_id=2)
  # => [{"id": "host", "name": "主机监控", "builtin": True}, ...]

  # Step 2: 获取视图列表
  views = resource.scene_view.get_scene_view_list(bk_biz_id=2, scene_id="host")
  # => [{"id": "host", "name": "主机概览", "panel_count": 5, "mode": "auto", "type": "overview"}, ...]

  # Step 3: 获取完整视图配置
  config = resource.scene_view.get_scene_view(
      bk_biz_id=2, scene_id="host", type="detail", id="host", bk_host_id="12345"
  )
  # => {"panels": [...], "order": [...], "variables": [...], "options": {...}}
  ```

## 创建自定义视图并调整排序：用户自定义监控视图
- **调用顺序**：
  1. 调用 `resource.scene_view.update_scene_view(bk_biz_id=2, scene_id="host", type="detail", name="我的视图", config={...})` 创建视图
  2. 调用 `resource.scene_view.bulk_update_scene_view_order_and_name(bk_biz_id=2, scene_id="host", type="detail", config=[...])` 调整排序
- **事务边界**：`bulk_update_scene_view_order_and_name` 内部使用 `bulk_update` 批量更新名称，排序使用 `update` 语句
- **预期结果**：新视图创建成功并返回 `view_id`，视图排序按传入顺序排列
- **错误处理**：`id` 不匹配 `^[0-9a-zA-Z_]+$` 时校验失败
- **使用示例**：
  ```python
  # Step 1: 创建自定义视图
  view_id = resource.scene_view.update_scene_view(
      bk_biz_id=2,
      scene_id="host",
      type="detail",
      name="我的主机视图",
      config={"mode": "custom", "panels": [{"id": "cpu", "type": "graph", "title": "CPU"}]},
  )
  # => "custom_42"

  # Step 2: 调整排序（将新视图放第一位）
  resource.scene_view.bulk_update_scene_view_order_and_name(
      bk_biz_id=2,
      scene_id="host",
      type="detail",
      config=[
          {"id": view_id, "name": "我的主机视图"},
          {"id": "host", "name": "主机详情"},
      ],
  )
  ```

## 获取主机进程列表：主机详情页加载进程面板
- **调用顺序**：
  1. 调用 `resource.scene_view.get_host_process_list(bk_biz_id=2, bk_host_id=12345)` 获取进程列表（含运行时指标）
  2. 可选：调用 `resource.scene_view.get_host_process_port_status(bk_biz_id=2, bk_host_id=12345, display_name="nginx")` 获取端口状态
- **事务边界**：无事务要求（纯读操作，内部并发 4 路 TSDB 查询）
- **预期结果**：返回进程列表，每项含 CMDB 信息 + TSDB 运行时指标（CPU/内存/FD/实例数/启动时间）
- **错误处理**：TSDB 查询失败时各指标降级为空值/None，不影响整体返回
- **使用示例**：
  ```python
  # 获取进程列表（默认最近三分钟数据）
  processes = resource.scene_view.get_host_process_list(
      bk_biz_id=2, bk_host_id=12345
  )
  # => [{"id": 1, "name": "nginx", "cpuUsage": 2.5, "memRss": 10240, "fdNum": 100, "instanceCount": 3, ...}]

  # 指定时间范围查询
  processes = resource.scene_view.get_host_process_list(
      bk_biz_id=2, bk_host_id=12345, start_time=1722000000, end_time=1722000180
  )
  ```

## 使用 PageListResource 构建表格列表接口：扩展新的列表类接口
- **调用顺序**：
  1. 定义 `TableFormat` 子类列表（`get_columns`），声明每列的格式化/排序/筛选逻辑
  2. 定义 `PageListResource` 子类，实现 `get_columns`/`get_sort_fields`/`get_filter_fields`
  3. 在 `perform_request` 中获取原始数据，调用 `self.get_pagination_data(data, params)` 编排
- **事务边界**：无事务要求
- **预期结果**：返回 `{columns, total, data}` 结构，前端可直接渲染表格
- **错误处理**：`format` 方法内 `KeyError` 会被捕获跳过（兼容指标获取失败场景）
- **使用示例**：
  ```python
  from monitor_web.scene_view.resources.base import PageListResource
  from monitor_web.scene_view.table_format import StringTableFormat, NumberTableFormat

  class MyListResource(PageListResource):
      def get_columns(self, column_type=None):
          return [
              StringTableFormat(id="name", name="名称", sortable=True, filterable=True),
              NumberTableFormat(id="value", name="值", unit="short"),
          ]

      def get_sort_fields(self):
          return ["name"]

      def get_filter_fields(self):
          return ["name"]

      class RequestSerializer(serializers.Serializer):
          bk_biz_id = serializers.IntegerField()
          page = serializers.IntegerField(default=1)
          page_size = serializers.IntegerField(default=10)

      def perform_request(self, params):
          raw_data = self.fetch_raw_data(params)  # 获取原始数据
          return self.get_pagination_data(raw_data, params)
  ```

## 查询视图可用维度与维度候选值：前端筛选器加载
- **调用顺序**：
  1. 调用 `resource.scene_view.get_scene_view_dimensions(bk_biz_id=2, scene_id="host", type="detail", id="host")` 获取可用维度列表
  2. 对需要的维度调用 `resource.scene_view.get_scene_view_dimension_value(bk_biz_id=2, scene_id="host", type="detail", id="host", field="bk_target_ip")` 获取候选值
- **事务边界**：无事务要求（纯读操作，内部通过 UnifyQuery 查询维度值）
- **预期结果**：维度列表含维度 ID/名称/类型，候选值列表含 ID/名称
- **错误处理**：不传时间范围时默认查最近 10 小时数据
- **使用示例**：
  ```python
  # Step 1: 获取可用维度
  dimensions = resource.scene_view.get_scene_view_dimensions(
      bk_biz_id=2, scene_id="host", type="detail", id="host"
  )
  # => [{"id": "bk_target_ip", "name": "IP", "type": "string"}, ...]

  # Step 2: 获取某维度的候选值
  values = resource.scene_view.get_scene_view_dimension_value(
      bk_biz_id=2, scene_id="host", type="detail", id="host", field="bk_target_ip"
  )
  # => [{"id": "10.0.0.1", "name": "10.0.0.1"}, ...]
  ```
