# C0-使用总览：CMDB 与容器资源专家

## 1. 能力清单

| 能力域 | 入口 | 说明 |
|--------|------|------|
| CMDB 主机/拓扑 | `api.cmdb.*` / `api.cmdb.client.*` | 主机查询（按拓扑/IP/ID/跨业务）、业务拓扑树、模块/集群/进程/服务实例、动态分组、对象属性 |
| CMDB 数据定义 | `api.cmdb.define` | 数据结构类（Business/Host/Module/Set/TopoTree/Process/ServiceInstance） |
| K8s 资源聚合 | `api.kubernetes.*` | 集群/节点/Pod/工作负载/Service/Ingress/容器列表、性能指标（promql）、监控端点、三方一致性校验（数据四路：promql/BCS storage/K8s SDK/DB） |
| BCS 集群 | `api.bcs.*` | 共享集群命名空间、项目、联邦集群 |
| 集群管理 | `api.bcs_cluster_manager.*` | 集群列表（项目内/共享/K8s 非共享） |
| 集群存储 | `api.bcs_storage.*` | 分页拉取资源（FetchPageResource/FetchResource + fetch_iterator 生成器） |
| 节点管理 | `api.node_man.*` | 配置模板、插件（注册/订阅/部署/调试）、任务、代理、包管理（36 接口） |

## 2. 能力边界

- **kubernetes 不走 APIResource**：`api/kubernetes/default.py` 直接继承 `Resource`/`CacheResource`（本地聚合层），数据来源为 promql/BCS storage/K8s SDK/DB 四路，非网关调用。
- **bcs 系列为独立网关**：bcs/bcs_cluster_manager/bcs_project/bcs_storage 各自 base_url 不同（`bcsapi/v4/{模块}/v1`），认证均为 Bearer token。
- **cmdb 双模式**：`use_apigw()`（`ENABLE_MULTI_TENANT_MODE` 或 `CMDB_USE_APIGW`）切换 apigw/compapi。

## 3. 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|------|----------|----------|
| CMDB 查询无结果返回空 list | 上游 `NoRelatedResourceError` | 基类 `perform_request` 已捕获并返回 `return_type()`（空 list）——非错误，是空结果 |
| bcs 请求 401 | Bearer token 缺失 | 确认 `settings.BCS_API_GATEWAY_TOKEN`；`BcsApiBaseResource.get_headers` 注入 |
| K8s 查询慢 | promql 多线程查询 | `FetchKubernetes*Resource` 内部用 `ThreadPool` + promql 多路并发；预期耗时较长 |
| node_man 超时 | 长时间任务 | `NodeManAPIGWResource.TIMEOUT=300`；批量/长任务用对应异步接口 |
| CMDB 数据缓存过期 | 主机变更后查不到 | 缓存 CacheType：`CC_BACKEND`（10min）/`CC_CACHE_ALWAYS`（1h 后台缓存）；可用 `mem_cache.clear()` 规避 |
