# C1-能力契约：CMDB 与容器资源专家

> 黑盒契约。调用方式：`api.{module}.{resource}`（全局入口）或直接实例化。代码示例为使用方代码。

## 1. CMDB（api.cmdb）

### client.py（HTTP 客户端层）
- **用途**：`CMDBBaseResource(APIResource)` 基类 + 22 个单例方法（`search_business`/`list_biz_hosts`/`list_biz_hosts_topo`/`get_biz_internal_module`/`search_module`/`search_set` 等），纯请求不加工。
- **关键行为**：`return_type=list`；`use_apigw()` 双模式；`full_request_data` 注入 `bk_supplier_account` + `validate_bk_biz_id` 空间校验；`perform_request` 捕获 `NoRelatedResourceError` 返回空 list。
- **使用示例**：`api.cmdb.client.list_biz_hosts_topo({"bk_biz_id": 2, "fields": ["bk_host_id"]})`
- **契约来源**：`api.cmdb.client.CMDBBaseResource`

### default.py（业务 Resource 层）
| 类名 | 用途 | 类型 |
|------|------|------|
| `GetHostByTopoNode` | 按拓扑节点批量查主机 | CacheResource |
| `GetHostByIP` | 按 IP/云区域查主机 | CacheResource |
| `GetHostById` | 按 bk_host_id 查主机 | Resource |
| `GetTopoTreeResource` | 业务拓扑树 | Resource |
| `GetBusiness` / `GetModule` / `GetSet` | 业务/模块/集群信息 | Resource |
| `GetHostWithoutBiz`/`GetHostWithoutBizV2` | 跨业务查主机 | CacheResource |
| `GetServiceInstanceByTopoNode`/`ByID` | 服务实例查询 | Resource |
| `GetProcess` / `SearchCloudArea` / `GetDynamicQuery` / `ExecuteDynamicGroup` 等 | 进程/云区域/动态分组 | 混合 |

### define.py（数据结构）
- `BaseNode` → `TopoNode` → `Business`/`Set`/`Module`/`TopoTree`；`Host(BaseNode)`（含 `Fields` 常量、`display_name`、`host_id` 等）；`Process`/`ServiceInstance`/`ServiceCategoryNode`/`ServiceCategoryTopo`；支持 `_extra_attr` 自定义属性。

### 使用示例
```python
from core.drf_resource import api
hosts = api.cmdb.get_host_by_ip({"bk_biz_id": 2, "ip": ["10.0.0.1"], "bk_cloud_id": 0})
topo = api.cmdb.get_topo_tree({"bk_biz_id": 2})
```

## 2. Kubernetes（api.kubernetes）

- **性质**：非 APIResource，继承 `Resource`/`CacheResource`；`cache_type = CacheType.BCS`（5min）。
- **数据四路**：promql 指标（`UnifyQuery`/`load_data_source(PROMETHEUS)` 多线程）→ BCS storage（`api.bcs_storage.fetch`）→ K8s SDK（`BCSCluster.api_client` 的 core_v1_api/apps_v1_api 等）→ 本地 DB（BCSBase/BCSCluster 模型）。
- **代表性 Resource**：
  - `FetchK8sClusterListResource` / `FetchK8sNodeListByClusterResource` / `FetchK8sPodListByClusterResource` / `FetchK8sWorkloadListByClusterResource`：按集群拉取资源列表。
  - `FetchK8sNodePerformanceResource` / `FetchNodeCpuUsage` / `FetchUsageRatio`：性能指标。
  - `FetchKubernetesConsistencyCheckResource` + 5 个子类（Workload/Pod/Node/Service/Endpoint）：三方一致性校验。
  - `FetchK8sServiceMonitorListByClusterResource` / `FetchK8sPodMonitorListByClusterResource`：监控配置。
- **使用示例**：
```python
from core.drf_resource import api
nodes = api.kubernetes.fetch_k8s_node_list_by_cluster({"bk_biz_id": 2, "cluster_id": "BCS-K8S-0001"})
```

## 3. BCS 系列

| 模块 | 基类 | base_url 模式 | 公开 Resource |
|------|------|---------------|---------------|
| bcs | `BcsApiBaseResource` | `BCS_APIGW_BASE_URL 或 api/bcs-api-gateway/prod/`，Bearer `BCS_API_GATEWAY_TOKEN` | `FetchSharedClusterNamespacesResource` / `GetProjectsResource` / `GetFederationClustersResource` |
| bcs_cluster_manager | `BcsClusterManagerBaseResource`（继承 `BcsApiGatewayBaseResource`） | `bcsapi/v4/clustermanager/v1` | `FetchClustersResource` / `GetProjectClustersResource` / `GetProjectK8sNonSharedClustersResource` / `GetSharedClustersResource` |
| bcs_project | `BcsProjectBaseResource` | `bcsapi/v4/bcsproject/v1` | `GetProjectsResource` |
| bcs_storage | `BcsStorageBaseResource` | `bcsapi/v4/storage/v1` 等 | `FetchPageResource` / `FetchResource` + 生成器 `fetch_iterator` |

- **关键行为**：均 `IS_STANDARD_FORMAT=False`，`get_request_url` 做 format，`render_response_data` 返回 `data` 字段；bcs_project 额外注入 `X-Project-Username`。
- **使用示例**：`api.bcs_cluster_manager.fetch_clusters({"bk_biz_id": 2})`
- **契约来源**：`api.bcs.default.BcsApiBaseResource` 等

## 4. 节点管理（api.node_man）

- **基类** `NodeManAPIGWResource`：`TIMEOUT=300`；base_url 双模式（apigw/compapi）；`full_request_data` 注入 `_origin_user` + `get_admin_username` 的 `bk_username` + `validate_bk_biz_id`。
- **代表性 Resource（全量 36 个）**：
  - 配置：`RenderConfigTemplateResource` / `CreateConfigTemplateResource` / `ReleaseConfigResource`
  - 插件：`RegisterPackageResource` / `ReleasePluginResource` / `PluginInfoResource` / `DeletePluginResource`
  - 订阅：`CreateSubscriptionResource` / `UpdateSubscriptionResource` / `RunSubscriptionResource` / `RetrySubscriptionResource` / `SubscriptionInstanceStatusResource`
  - 任务：`TaskResultResource` / `TaskResultDetailResource` / `TasksResource` / `BatchTaskResultResource`
  - 调试/部署：`StartDebugResource` / `QueryDebugResource` / `UploadResource` / `ExportRawPackageResource`
  - 代理/包：`GetProxiesResource` / `GetPackageInfoResource` / `GetProcessInfoResource`
- **使用示例**：`api.node_man.get_proxies({"bk_biz_id": 2})`
- **契约来源**：`api.node_man.default.NodeManAPIGWResource`
