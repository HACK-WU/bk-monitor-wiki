## CMDB client 分层实现

`client.py`（源码 confirmed）：
- `CMDBBaseResource(APIResource)`：`module_name="cmdb"`、`return_type=list`、`INSERT_BK_USERNAME_TO_REQUEST_DATA=False`。
- `use_apigw()`：`ENABLE_MULTI_TENANT_MODE` 或 `CMDB_USE_APIGW`；`base_url` property 双模式。
- `get_request_url`：补 `bk_supplier_account` 并对 URL format。
- `full_request_data`：注入 `bk_supplier_account` + `validate_bk_biz_id`（bkm_space 空间关联校验）。
- `perform_request`：捕获 `NoRelatedResourceError` 返回 `return_type()` 空 list。
- `action`/`method` 部分为 property 双模式切换（如 `SearchBizInstTopo` GET/POST 动态）。
- 模块级 22 个单例方法（`search_business` 等）。

`ipchooser.py`：`IpChooserApi(AbstractBkApi)` 静态方法转发 `client.*`，分页接口用 `batch_request` 封装 `bulk_list_biz_hosts`/`bulk_search_set` 等。

章节来源：[api/cmdb/client.py](file://bkmonitor/api/cmdb/client.py)（关键符号：`CMDBBaseResource.perform_request`）；[api/cmdb/ipchooser.py](file://bkmonitor/api/cmdb/ipchooser.py)（关键符号：`IpChooserApi`）

## kubernetes 聚合实现

- 基类 `FetchKubernetesGrafanaMetricRecords(Resource, abc.ABC)`：promql 查询抽象，子类覆写指标定义。
- SDK 访问入口：`BCSCluster.api_client`（`cached_property`）→ `Configuration(host=.../clusters/{cluster_id}，带 Bearer token)` → `core_v1_api`/`custom_objects_api`/`apps_v1_api`/`batch_v1_api`。
- 典型调用：`cluster_model.core_v1_api.list_pod_for_all_namespaces()` 等；`ApiException` 统一捕获。
- 指标查询：`request_graph_unify_query()`/`request_performance_data()` 用 `ThreadPool` 多线程并发 promql。

章节来源：[api/kubernetes/default.py](file://bkmonitor/api/kubernetes/default.py)（关键符号：`FetchKubernetesGrafanaMetricRecords` / `BCSCluster.api_client`）

## bcs_storage fetch_iterator 实现

`bcs_storage/default.py`（源码 confirmed）：
- `BcsStorageBaseResource`：`get_request_url` 含 prod/debug 环境适配与 field 参数拼接；`get_headers` 注入 Bearer token；`render_response_data` 返回 `data`。
- `FetchPageResource`/`FetchResource`：单页/单条拉取。
- 模块级生成器 `fetch_iterator`：按页码迭代拉取全量资源（供 kubernetes 等消费）。

章节来源：[api/bcs_storage/default.py](file://bkmonitor/api/bcs_storage/default.py)（关键符号：`FetchPageResource` / `fetch_iterator`）

## 结论

CMDB 用 client 分层（HTTP 客户端 + 业务 Resource + 数据结构）分离关注点；kubernetes 是本地聚合（四路数据源）；bcs 系列为独立网关；node_man 为 36 接口的大网关。排查问题先判断所属形态（网关 vs 聚合）。
