## 测试位置

- **该模块无单测目录**：`api/` 下无 `tests/`。
- 唯一测试辅助：`api/cmdb/mock.py` 提供模拟 CMDB 返回数据（`BUSINESS`/`SPACE_BUSINESS`/`BUSINESSES`/`MODULES` 等，用 define 类构造），供**上层逻辑**测试（非本模块单测）。

## 测试可执行性

- 不适用（无本模块测试可执行）。

## 测试缺口

- cmdb/kubernetes/node_man 封装层无单测；`api/cmdb/mock.py` 的存在说明上游测试依赖 CMDB 数据 mock，但封装本身未覆盖。
- kubernetes 四路聚合（promql/SDK/DB/BCS storage）为复杂逻辑，无测试覆盖，风险高。
- 补测建议：mock 远端（CMDB/BCS/node_man）验证 URL/认证头/错误包装；kubernetes 可 mock SDK 与 promql 数据源验证聚合逻辑。
