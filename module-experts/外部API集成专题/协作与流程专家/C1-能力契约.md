# C1-能力契约：协作与流程专家

> 黑盒契约。调用方式：`api.{module}.{resource}`。代码示例为使用方代码。

## 1. TAPD（api.tapd）

- **基类** `TapdAPIResource`：`base_url=TAPD_API_BASE_URL`；`IS_STANDARD_FORMAT=False`；Basic/Bearer 双认证；`render_response_data` 适配 `{status, info, data}`（status!="1" 抛 BKAPIError）。
- **代表性 Resource**：
  - `GetGrantedWorkspacesResource`：已授权项目列表
  - `GetParticipantProjects`：用户参与项目（Bearer）
  - `GetWorkspaceInfoResource`：项目信息
  - `AddStoryResource` / `AddBugResource` / `AddTaskResource`：建需求/缺陷/任务
  - `AddWebhookSettingResource`：建 webhook
  - `UserOauthTokenResource`：code 换 access_token（Basic + form body）
  - 另有模板/字段/列表类（GetStoryTemplateListResource、GetStories/Bugs/TasksResource 等）
- **使用示例**：
```python
from core.drf_resource import api
workspaces = api.tapd.get_granted_workspaces({})
# 携带 access_token（仅用于认证头，不污染 body）
bug = api.tapd.add_bug({"workspace_id": "123", "title": "缺陷", "access_token": "<token>"})
```

## 2. Issue（api.issue）

- **基类** `IssueAPIResource(KernelAPIResource)`：`base_url` 为 bk-monitor 自身网关；`TIMEOUT=300`。
- **全量 12 类**：`AssignResource`（指派）、`ResolveResource`（解决）、`ReopenResource`（重开）、`ArchiveResource`（归档）、`RestoreResource`（恢复）、`UpdatePriorityResource`（优先级）、`RenameResource`（重命名，重名抛专有错误码）、`AddFollowUpResource`/`EditFollowUpResource`（跟进）、`MergeResource`（合并）、`SplitResource`（拆分）、`RegenerateTitleResource`（重跑 LLM 标题）。
- **使用示例**：`api.issue.assign({"issue_id": "I-1", "assignee": "user1", "bk_biz_id": 2})`

## 3. ITSM（api.itsm）

- **基类** `ITSMBaseResource`：`base_url=api/c/compapi/v2/itsm/`；`full_request_data` 注入 `_origin_user` + `bk_username=COMMON_USERNAME`。
- **全量 5 类**：`CreateFastApprovalTicketResource`（快速审批）、`TicketApproveResultResource`（审批结果）、`TicketRevokeResource`（撤销，注入 action_type=WITHDRAW）、`TokenVerifyResource`（token 校验）、`GetTicketStatusResource`（单状态）。
- **使用示例**：`api.itsm.create_fast_approval_ticket({"creator": "user1", "bk_biz_id": 2, ...})`

## 4. cmsi（api.cmsi）

- **基类** `CMSIBaseResource`：`base_url` property 在 apigw/esb/自定义间动态切换。
- **代表性 Resource（8 通道）**：`SendMsg`（通用）、`SendWeixin`（微信）、`SendMail`（邮件，内外部用户 `@tai` 分流）、`SendSms`（短信）、`SendVoice`（语音）、`SendWecomRobot`/`SendWecomAPP`（企微）、`SendRtx`、`GetMsgType`（通知类型，补虚拟通道）。
- **使用示例**：`api.cmsi.send_mail({"receivers": [...], "title": "...", "content": "..."})`（消费方：`bkmonitor/utils/send.py`）

## 5. sops（api.sops）

- **基类** `SopsBaseResource`：`base_url` property（apigw/esb 切换）；`get_request_url` apigw 下 URL format；`perform_request` assignee 兜底 + 权限码 3599999 重试；`full_request_data` `validate_bk_biz_id`。
- **全量 10 类**：`GetUserProjectDetailResource`、`GetTemplateListResource`/`GetTemplateInfoResource`、`PreviewTaskTreeIResource`、`CreateTaskResource`/`StartTaskResource`、`GetTaskStatusResource`、`ImportProjectTemplate`、`GetCommonTemplateListResource`/`GetCommonTemplateInfoResource`。
- **使用示例**：`api.sops.get_template_list({"bk_biz_id": 2})`

## 6. job（api.job）

- **基类** `JobBaseResource`：`base_url` property（apigw `api/v3/system/` / esb compapi/v2/jobv3/）；`perform_request` assignee 兜底 + `APIPermissionDeniedError` 重试。
- **全量 8 类**：`GetJobPlanListResource`（batch_request 分页）、`GetJobListResource`（旧版，补 bk_job_id）、`GetJobPlanDetailResource`、`ExecuteJobPlanResource`、`GetJobInstanceStatusResource`、`FastExecuteScriptResource`、`GetJobInstanceIpLogResource`。
- **使用示例**：`api.job.fast_execute_script({"bk_biz_id": 2, "script_content": "...", "ip_list": [...]})`

## 7. devops（api.devops）

- **基类** `DevopsBaseResource`：`request` 取 Cookie `bk_ticket`；`full_request_data` 注入 bk_ticket；`get_headers` 注入 BKCI app 凭证；未部署抛 `DevopsNotDeployedError`。
- **全量 4 类**：`ListUserProjectResource`/`UserProjectCreateResource`（用户态）、`ListAppProjectResource`（应用态）、`ListPipelineResource`（流水线，URL 模板 project_id）。

## 8. bkchat（api.bkchat）

- **基类** `BkchatAPIGWResource`：`base_url=BKCHAT_API_BASE_URL`。
- **全量 3 类**：`GetNoticeGroup`、`GetNoticeGroupDetail`、`SendNoticeGroupMsg`（覆写 perform_request 归一化成功/失败结构）。
- **使用示例**：`api.bkchat.send_notice_group_msg({"msg_type": "text", "content": "..."})`

## 9. bk_incident（api.bk_incident）

- **基类** `IncidentBaseResource`：`base_url` property（APIGW/compapi）；`perform_request` 自动 `bk_biz_id→scope_value`、`bk_biz_id_list→scope_id_list` 参数转换。
- **代表性 Resource**：`GetTemplateListResource`（执行流程）、`CreateTaskResource`（故障分析任务）、`OperateTaskResource`（启动）、`GetTaskStatusResource`、`GetIncidentDiagnosisResource`（诊断面板）、`GetPanelDetailResource`、`GetIncidentDetailResource`/`UpdateIncidentDetailResource`、`GetConfigResource`/`CreateListConfigResource`、`FetchGlobalVariablesResource`。
- **使用示例**：`api.bk_incident.get_incident_diagnosis({"bk_biz_id": 2, "incident_id": "xxx"})`
