# C1-能力契约：基础平台与网关专家

> 黑盒契约。调用方式：`api.{module}.{resource}`（全局入口，自动序列化）或直接实例化。代码示例为使用方代码。

## 1. 用户/租户（api.bk_login）

### BkUserApiResource（基类）
- **用途**：bk-user 用户中心 API 基类。
- **关键行为**：`use_apigw()` = `ENABLE_MULTI_TENANT_MODE`；`base_url` 按模式切换（apigw：`BK_USER_API_BASE_URL` / compapi：`api/c/compapi/v2/usermanage/`）；URL 支持 `format(**params)`。
- **契约来源**：`api.bk_login.default.BkUserApiResource`

### 公开 Resource 清单
| 类名 | 用途 | action |
|------|------|--------|
| `ListTenantResource` | 租户列表 | `/api/v3/open/tenants/` |
| `GetAllUserResource` | 用户列表（cache USER） | `/list_users/` 或 apigw `/api/v3/...` |
| `ListDepartmentsResource` | 部门列表 | `/api/v3/open/tenant/departments/` |
| `ListProfileDepartmentsResource` | 用户部门 | 随 use_apigw 变化 |
| `GetUserInfo` | 用户信息 | `/api/v3/open/tenant/users/{bk_username}/` |
| `BatchLookupVirtualUserResource` | 批量虚拟用户查询 | — |
| `ListTenantVariablesResource` | 租户变量列表 | — |
| `BatchQueryUserDisplayInfoResource` | 批量用户展示信息（cache USER） | — |
| `UnityUserBaseResource.GetUserSensitiveInfo` | 用户敏感信息（unity-user 基类） | — |

### 使用示例
```python
from core.drf_resource import api

tenants = api.bk_login.list_tenant({"bk_tenant_id": "default"})
users = api.bk_login.get_all_user({})           # 全量用户（有缓存）
info = api.bk_login.batch_query_user_display_info({"bk_usernames": ["u1", "u2"], "bk_tenant_id": "default"})
```

## 2. 应用信息（api.bk_paas）

- **基类** `BkPaaSAPIGWResource`：`base_url = PAASV3_APIGW_BASE_URL 或 compapi/v2/bk_paas/`；URL format。
- **`GetAppClusterNamespaceResource`**：获取蓝鲸应用集群数据，action `/system/bkapps/applications/{app_code}/cluster_namespaces/`。
- **使用示例**：`api.bk_paas.get_app_cluster_namespace({"app_code": "bk_monitorv3"})`
- **契约来源**：`api.bk_paas.default.GetAppClusterNamespaceResource`

## 3. 插件能力（api.bk_plugin）

- **基类**：`BkPluginBaseResource`（插件侧，注入 `BK_PLUGIN_APP_INFO`）；`BkPluginSystemResource`（系统侧，覆写 get_headers 替换插件凭证，`IS_STANDARD_FORMAT=False`）。
- **公开 Resource**：
  - `BkPluginMetaResource`：插件版本列表 `/bk_plugin/meta`（覆写 render_response_data）
  - `BkPluginDetailResource`：版本表单 `/bk_plugin/detail/{version}`
  - `BkPluginInvokeResource`：执行插件任务 `/invoke/{version}`（POST）
  - `BkPluginScheduleResource`：按 trace_id 取结果 `/bk_plugin/schedule/{trace_id}`
  - `BkPluginListResource`：插件列表 `/system/bk_plugins`
  - `BkPluginDeployedInfoResource`：部署信息 `/system/bk_plugins/{plugin_code}`
  - `BkPluginDeployedInfoBatchResource`：批量部署信息 `/system/bk_plugins/batch/detailed`
- **约束**：插件凭证来自 `settings.BK_PLUGIN_APP_INFO`。
- **契约来源**：`api.bk_plugin.default.*`

## 4. 权限中心（api.iam）

- **基类** `IAMBaseResource`：`base_url = BK_IAM_APIGATEWAY_URL`。
- **`BatchInstance`**：批量实例授权，action `authorization/batch_instance/`，POST。
- **使用示例**：`api.iam.batch_instance({...})`（消费方：`bkmonitor/iam/upgrade.py`）
- **契约来源**：`api.iam.default.BatchInstance`

## 5. API 网关（api.bk_apigateway）

- **基类** `BkApiGatewayResource`：`base_url = APIGATEWAY_API_BASE_URL 或 api/bk-apigateway/prod/`；URL format。
- **`GetPublicKeyResource`**：获取 public_key，action `/api/v1/apis/{api_name}/public_key/`（cache USER）。
- **使用示例**（kernel_api 认证依赖）：
```python
from core.drf_resource import api
key = api.bk_apigateway.get_public_key({"api_name": "bk-monitor", "bk_tenant_id": "default"})["public_key"]
```
- **契约来源**：`api.bk_apigateway.default.GetPublicKeyResource`

## 6. 文档中心（api.docs）

- **基类** `BKDocsCenterResource`：`base_url = BK_PAAS_HOST + "/o/bk_docs_center/api/v1/"`。
- **`GetDocLinkByPath`**：按路径取文档链接，action `/get_doc_link_by_path/`。
- **契约来源**：`api.docs.default.GetDocLinkByPath`

## 7. 公共基类（api/common）

### CommonBaseResource
- **用途**：动态 URL + 统一异常处理的通用 API 基类模板。
- **关键行为**：
  - `__init__` 用 Jinja2Renderer 渲染 url 占位符：`self.url`（占位符置空，用于报错展示）、`self.base_url`（用 `BK_COMPONENT_API_URL`/`BK_PAAS_HOST`/`BK_ITSM_V4_API_URL` 替换，用于实际请求）。
  - `perform_request` 注入 `_origin_user=get_global_user()`；捕获 `BKAPIError` 后以 `system_name=plugin_key, url=url_path` 重写异常。
  - `get_request_url` 直接返回完整渲染的 `self.base_url`。
- **契约来源**：`api.common.default.CommonBaseResource`
