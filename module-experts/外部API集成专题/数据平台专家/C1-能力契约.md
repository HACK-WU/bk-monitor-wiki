# C1-能力契约：数据平台专家

> 黑盒契约。调用方式：`api.{module}.{resource}`。代码示例为使用方代码。

## 1. BKData（api.bkdata）

### 基类
- `BkDataAPIGWResource`：`base_url = BKDATA_API_BASE_URL 或 api/bk-base/prod/`；`TIMEOUT=300s`；`full_request_data` 注入 `bk_app_code=SAAS_APP_CODE`。
- `BkDataQueryAPIGWResource`：查询类，`base_url = BKDATA_QUERY_API_BASE_URL`。
- `DataAccessAPIResource`：数据接入类，注入 `_origin_user` + 默认 `bk_username=BK_DATA_PROJECT_MAINTAINER`。
- `UseSaaSAuthInfoMixin`：注入 SaaS 侧认证（`full_request_data` + `get_headers` 双处）。

### 代表性 Resource
| 类名 | 用途 |
|------|------|
| `ListResultTableResource` | 查询监控结果表（分页+按存储过滤） |
| `BulkListResultTableResource` | 按业务批量拉结果表元信息 |
| `GetResultTableResource` | 查询指定结果表 |
| `GetDataLinkMetadataResource` | 数据链路元数据 |
| `QueryDataResource` | 同步查询数据（SQL，token/user 双鉴权） |
| `AuthResultTable` | 给项目加结果表权限（管理员） |
| `QueryAuthProjectsData` | 批量检查项目结果表权限 |
| `CreateDataFlow`/`GetDataFlow` | 创建/查询 DataFlow |

另有约 60 类（数据接入 AccessDeployPlan/DatabusCleans、降精度 CreateDataHubForDownsample、QueryTsMetrics/QueryTsDimensions、GetIncidentList 等）。

### 使用示例
```python
from core.drf_resource import api
# SQL 查询（默认 token/user 自动选择）
data = api.bkdata.query_data({"query_string": "SELECT * FROM xxx WHERE dt=...", "bk_biz_id": 2})
tables = api.bkdata.list_result_table({"bk_biz_id": 2, "storage_type": "elasticsearch"})
```

## 2. 监控元数据（api.metadata）

- **基类** `MetaDataAPIGWResource(KernelAPIResource)`：`base_url = NEW_MONITOR_API_BASE_URL 或 api/bk-monitor/{APIGW_STAGE}/`；module_name=`metadata_v3`；action 形如 `/app/metadata/...`。
- **代表性 Resource**：`CreateDataIdResource`（创建数据源）/ `CreateResultTableResource` / `ListResultTableResource` / `GetResultTableResource` / `QueryResultTableStorageDetailResource` / `GetDataIdResource` / `QueryDataSourceResource` / `QueryClusterInfoResource` / `CreateEventGroupResource` / `QueryTimeSeriesGroupResource`（CacheResource + batch_request）。
- **序列化**：`MetadataBaseSerializer`（去 None 字段）、`UsernameSerializer`（自动补用户名）。
- **使用示例**：`api.metadata.list_result_table({"bk_biz_id": 2})`（消费方：`alarm_backends/core/cache/result_table.py`）

## 3. 统一查询（api.unify_query）

- **基类** `UnifyQueryAPIResource(Resource)`：**非 APIResource**，`requests` 直接 HTTP 调 unify-query；按 `space_uid` 经 `get_unify_query_url` 路由（`UNIFY_QUERY_ROUTING_RULES`）；注入 `Bk-Query-Source`/`X-Bk-Scope-Space-Uid`/`X-Bk-Tenant-Id`；超时 60s。
- **全量 Resource（18 类）**：`QueryDataResource` / `QueryRawResource` / `QueryReferenceResource` / `QueryClusterMetricsDataResource` / `QueryDataByPromqlResource` / `CheckQueryTsResource` / `CheckQueryTsByPromqlResource` / `PromqlToStructResource` / `StructToPromqlResource` / `GetDimensionDataResource` / `GetPromqlLabelValuesResource` / `GetTagKeysResource` / `QueryDataByExemplarResource` / `QueryDataByTableResource` / `QuerySeriesResource` / `GetKubernetesRelationResource` / `QueryMultiResourceRange` / `QueryMultiResource`。
- **使用示例**：`api.unify_query.query_data({"query_list": [...], "bk_biz_ids": [2], "space_uid": "bkcc__2"})`

## 4. 日志检索（api.log_search）

- **基类** `LogSearchAPIGWResource`：`base_url` property（`BKLOGSEARCH_API_BASE_URL`/`BKLOGSEARCH_API_GW_BASE_URL`，多租户走 `/api/bk-log-search/prod/`，否则 compapi）；module_name=`bk_log`。
- **全量 Resource（约 30 类）**：检索（`ESQueryDslResource`/`ESQuerySearchResource`/`SearchIndexSetLogResource`/`SearchIndexSetContext`）、索引集（`SearchIndexSetResource`/`CreateIndexSetResource`/`Update/Delete/ReplaceIndexSetResource`/`SearchIndexFieldsResource`/`LogSearchIndexSetResource`/`GetUserFavorite/RecentIndexSetResource`）、场景（`ListScenesResource`/`SceneSearchResource`/`SceneFieldsResource`/`SceneDimensionValuesResource`）、采集（`ListCollectorsResource`/`DataBusCollectorsResource`/`Start/StopCollectorsResource`）、上报（`Create/UpdateCustomReportResource`）、Grafana（`BkLogSearchQuery/Metric/Dimension/QueryLogResource`）、日志抽取（`QueryLogExtractHostsResource`/`CreateLogExtractTaskResource`）。
- **使用示例**：`api.log_search.search_index_set_log({"bk_biz_id": 2, "index_set_id": "xxx", "start_time": ..., "end_time": ...})`

## 5. AIOps 推理（api.aiops_sdk）

- **基类** `SdkResource(APIResource)`：`TIMEOUT=300`；忽略 `"SDK模型预测历史依赖"` 错误。
- **动作基类**：`SdkPredictResource` / `SdkGroupPredictResource` / `SdkInitDependResource`（action 取 `settings.AIOPS_*_SDK`，POST）。
- **分支**：`TfSdkResource`（时序 `AIOPS_SERVER_TF_URL`）/ `KpiSdkResource`（异常检测 `AIOPS_SERVER_KPI_URL`）/ `AcdSdkResource`（离群 `AIOPS_SERVER_ACD_URL`）。
- **灰度**：`BKFaraGrayMixin` 按 `serving_config.grey_to_bkfara` 切换请求地址与 action 路径。
- **全量 9 类**：`Tf/Kpi/Acd + Predict/GroupPredict/InitDepend`。
- **使用示例**：`api.aiops_sdk.kpi_predict({...})`
