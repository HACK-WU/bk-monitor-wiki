# C0-使用总览：监控生态专家

## 1. 能力清单

| 能力域 | 入口 | 说明 |
|--------|------|------|
| 监控自身网关 | `api.monitor.*` | 采集配置/拨测任务/报表/自定义指标/处理任务/告警经验（13 接口，走 `/app/...` apigw 路径） |
| Grafana | `api.grafana.*` | 仪表盘 CRUD/导入、数据源、组织/文件夹、搜索、收藏（22 接口，非 APIResource 直连） |
| Grafana 导出 | `api.grafana.exporter` | `DashboardExporter`：仪表盘模板化导出（`$DS_xxx` 占位符 + `__inputs`/`__requires`） |
| APM | `api.apm_api.*` | 应用 CRUD、数据源、拓扑/调用链查询、eBPF/profiling、BkData Flow |
| RUM | `api.rum_api.*` | RUM 应用生命周期、数据源、上报 Token、配置发布（12 接口） |
| AI 开发平台 | `api.aidev.*` | LLM 对话（OpenAI 兼容）、知识库检索/问答（3 接口，含流式） |
| 监控 Worker | `api.bmw.*` | 常驻任务创建/重载/列表/删除（4 接口） |

## 2. 能力边界

- **`api.monitor` module_name 为 `mointor_v3`**（注意拼写 mointor）——调用方 `api.mointor_v3.xxx` 实际是 monitor。
- **grafana 非 APIResource**：`GrafanaApiResource(Resource)` 直连 `settings.GRAFANA_URL`，注入 `X-WEBAUTH-USER`/`X-Grafana-Org-Id`。
- **apm_api/rum_api 能力面不同**：apm_api 含拓扑/链路/性能分析；rum_api 仅生命周期 + 配置（窄）。
- **aidev 认证特殊**：`ChatCompletionResource` 用 `AIDEV_AGENT_APP_CODE` 凭据 + OpenAI 直通格式（`IS_STANDARD_FORMAT=False`）+ 流式响应。

## 3. 已知问题与常见坑

| 现象 | 触发条件 | 正确做法 |
|------|----------|----------|
| `api.monitor` 调用报 module 不存在 | 误以为 module_name 是 monitor | 实际为 `mointor_v3`（拼写 mointor）；用 `api.mointor_v3.xxx` 或走 `resource.monitor` |
| grafana 401 | org_id 缺失 | `with_org_id=True` 的接口需请求参数带 `org_id`（注入 `X-Grafana-Org-Id`） |
| grafana 用户错误 | 未传用户 | 基类注入 `X-WEBAUTH-USER`（从请求用户取） |
| aidev 流式接口卡住 | 知识库问答为流式 | `CreateKnowledgebaseQueryResource` 返回 `StreamingHttpResponse`，非流式消费方需用 `ChatCompletionResource` |
| aidev 鉴权失败 | 未用 AIDEV 专用凭证 | `ChatCompletionResource.get_headers` 切换 `AIDEV_AGENT_APP_CODE` 凭据 |
| bmw 任务未创建 | 环境未部署 monitor-worker | `base_url = settings.BMW_API_URL`，确认部署 |
