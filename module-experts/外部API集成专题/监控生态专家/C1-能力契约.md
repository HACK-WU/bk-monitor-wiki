# C1-能力契约：监控生态专家

> 黑盒契约。调用方式：`api.{module}.{resource}`。代码示例为使用方代码。

## 1. 监控自身网关（api.monitor）

- **基类** `MonitorAPIGWResource(KernelAPIResource)`：`base_url` 为 bk-monitor 自身网关；`TIMEOUT=300`；**module_name=`mointor_v3`**（注意拼写）。
- **全量 13 类**（均走 `/app/...` apigw 路径）：
  - 采集/拨测：`CollectConfigListResource`、`UptimeCheckTaskListResource`、`UptimeCheckNodeListResource`
  - 报表：`GetStatisticsByJsonResource`、`GetSettingAndNotifyGroupResource`、`TestReportMailResource`、`SendReportResource`
  - 自定义指标：`CreateCustomTimeSeriesResource`、`CustomTimeSeriesDetailResource`
  - 处理任务：`BatchCreateActionBackendResource`、`GetActionParamsBackendResource`、`GetDemoActionContextBackendResource`
  - 告警经验：`GetExperienceResource`
- **使用示例**：`api.mointor_v3.uptime_check_task_list({"bk_biz_id": 2})`（消费方：`alarm_backends/core/cache/models/uptimecheck.py`）

## 2. Grafana（api.grafana）

- **基类** `GrafanaApiResource(Resource)`：**非 APIResource**，`perform_request` 直连 `settings.GRAFANA_URL`；注入 `X-WEBAUTH-USER` / `X-Grafana-Org-Id`；返回统一信封 `{result, code, message, data}`。
- **全量 22 类**：组织（`GetOrganizationByName/ByID/GetAllOrganization`）、仪表盘（`CreateOrUpdateDashboard`/`ByUID`/`GetDashboardByUID`/`DeleteDashboardByUID`/`ImportDashboard`）、数据源（`CreateDataSource`/`GetAllDataSource`）、文件夹（`Create/List/Delete/UpdateFolder`/`GetFolderByUID`）、搜索（`SearchFolderOrDashboard`）、收藏（`Star/UnstarDashboard`）、组织偏好（`Update/Patch/GetOrganizationPreference`）、用户（`CreateUser`）。
- **使用示例**：`api.grafana.search_folder_or_dashboard({"org_id": 1, "query": "xxx"})`（消费方：`monitor_web/grafana/resources/manage.py`）

### exporter.py（DashboardExporter）
- **用途**：Grafana 仪表盘导出为可移植模板。
- **方法**：`templateize_datasource`（数据源引用 → `$DS_xxx` 模板变量 + `__inputs`/`__requires`/`datasource_mapping`）、`replace_table_id_with_data_label`（结果表 ID → data_label）、`make_exportable`（清理 id/uid，输出可导入模板）。
- **消费方**：`monitor_web/as_code/resources.py`、`monitor_web/export_import/import_config.py`。

## 3. APM（api.apm_api）

- **基类** `ApmAPIGWResource(KernelAPIResource)`：`TIMEOUT=300`；多数子类 `backend_cache_type = CacheType.APM`。
- **代表性 Resource**：`CreateApplicationResource`/`ListApplicationResource`/`DeleteApplication`（应用生命周期）、`QuerySpanResource`/`QueryTraceListResource`/`QueryTraceDetailResource`（调用链）、`QueryTopoNodeResource`/`QueryTopoRelationResource`（拓扑）、`ApplyDatasourceResource`（数据源）、`QueryEbpfProfileResource`（eBPF profiling）、`CreateOrUpdateBkdataFlow`（计算平台 Flow）。
- **使用示例**：`api.apm_api.start_application({"bk_biz_id": 2, "app_name": "xxx"})`（消费方：`packages/apm_web/meta/resources.py`）

## 4. RUM（api.rum_api）

- **基类** `RumAPIGWResource(KernelAPIResource)`：`TIMEOUT=300`。
- **全量 12 类**：生命周期（`CreateApplicationResource`/`DeleteApplicationResource`/`ListApplicationResource`/`DetailApplicationResource`/`StartApplicationResource`/`StopApplicationResource`）、数据源（`ApplyDatasourceResource`）、Token（`QueryBkDataTokenInfoResource`）、配置（`GetApplicationConfigResource`/`ReleaseAppConfigResource`/`DeleteAppConfigResource`）。
- **使用示例**：`api.rum_api.query_bk_data_token_info({"bk_biz_id": 2, "app_name": "xxx"})`（消费方：`packages/rum_web/meta/resources.py`）

## 5. AI 开发平台（api.aidev）

- **基类** `AidevAPIGWResource(APIResource)`：`base_url = AIDEV_API_BASE_URL`；`get_headers` 注入 `BK_PLUGIN_APP_INFO` 凭证。
- **全量 3 类**：
  - `ChatCompletionResource`：LLM 对话（OpenAI 兼容，非流式）；`IS_STANDARD_FORMAT=False`；`get_headers` 切换 `AIDEV_AGENT_APP_CODE` 凭据。
  - `OnlyKnowledgebaseQueryResource`：仅知识库检索。
  - `CreateKnowledgebaseQueryResource`：知识库查询并回答（流式，`handle_stream_response` 返回 `StreamingHttpResponse`）。
- **使用示例**：`api.aidev.chat_completion({"model": "...", "messages": [...]})`（消费方：`alarm_backends/service/fta_action/tasks/issue_tasks.py` issue 标题生成）

## 6. 监控 Worker（api.bmw）

- **基类** `MonitorWorkerAPIGWResource(APIResource)`：`base_url = settings.BMW_API_URL`；module_name=`bkmonitor-worker`。
- **全量 4 类**：`CreateTaskResource`（创建）、`ReloadDaemonTaskResource`（重载常驻任务）、`ListTaskResource`（列表）、`RemoveTaskResource`（删除）。
- **使用示例**：`api.bmw.create_task({...})`（消费方：`apm/core/discover/precalculation/daemon.py`）
