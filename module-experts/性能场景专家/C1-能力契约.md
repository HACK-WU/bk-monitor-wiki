## HostPerformanceResource
契约来源：`HostPerformanceResource`（`resources.py`）

### perform_request
- **用途**：获取业务下全量主机列表（基础信息 + 性能指标 + Agent 状态 + 进程 + 告警），走 `HOST` 缓存
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 否 | 业务ID |
- **返回**：`dict` — `{"hosts": list[dict], "update_time": str}`
- **异常**：无（各 fetch 方法对缺失 host 做 continue 跳过）
- **约束**：继承 `CacheResource`，结果按 `CacheType.HOST` 缓存
- **使用示例**：
  ```python
  result = resource.performance.host_performance(bk_biz_id=2)
  # => {"hosts": [{"bk_host_id": 11, "cpu_usage": 12.3, "status": 1, "component": [...], ...}], "update_time": "2026-07-27 10:00:00+0800"}
  ```

### get_process_status (staticmethod)
- **用途**：拉取进程信息填充 `host_dict[bk_host_id]["component"]`
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
  | data | dict[int, dict] | 是 | 聚合容器（原地修改） |
- **返回**：无（原地修改 `data`）
- **约束**：输出含 `ports`/`protocol` 字段

### get_alarm_count (staticmethod)
- **用途**：拉取告警计数填充 `host_dict[bk_host_id]["alarm_count"]`
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
  | data | dict[int, dict] | 是 | 聚合容器（原地修改） |
- **返回**：无（原地修改 `data`）
- **约束**：**无 try/except 降级**，异常会中断整个聚合
- **使用示例**：
  ```python
  HostPerformanceResource.get_alarm_count(bk_biz_id=2, hosts=host_list, data=host_dict)
  ```

## HostTopoNodeDetailResource
契约来源：`HostTopoNodeDetailResource`（`resources.py`）

### perform_request
- **用途**：获取拓扑节点详情（主机数 + 告警数 + 策略数 + 负责人）
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | bk_obj_id | str | 是 | 节点类型（如 `module`/`set`/`biz`） |
  | bk_inst_id | int | 是 | 节点实例ID |
- **返回**：`dict` — 含 `bk_obj_id/bk_inst_id/bk_obj_name/bk_inst_name/operator/bk_bak_operator/child_count/host_count/alarm_count/alarm_strategy`
- **异常**：无
- **约束**：`child_count` 在 `bk_obj_id=="module"` 时取 `len(hosts)`，否则取 `len(node.child)`；`operator`/`bk_bak_operator` 仅 `module` 类型有值；**注意**：当 `bk_obj_id != "module"` 且节点不存在（`node` 为 None）时，`len(node.child)` 会抛 `AttributeError`
- **使用示例**：
  ```python
  detail = resource.performance.host_topo_node_detail(bk_biz_id=2, bk_obj_id="module", bk_inst_id=100)
  # => {"bk_obj_id": "module", "bk_inst_id": 100, "host_count": 5, "alarm_count": 3, "operator": ["admin"], "alarm_strategy": {"enabled": 2, "disabled": 1}, ...}
  ```

### get_alarm_count (staticmethod)
- **用途**：统计拓扑节点下所有主机的告警总数
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
- **返回**：`int` — 告警总数（所有级别求和）
- **约束**：`hosts` 为空时返回 0

## SearchHostInfoResource 分页模式（2026-09 新增）
契约来源：`SearchHostInfoResource`（`monitor_web/performance/resources.py:313`）

### perform_request（带 page 时）
- **用途**：主机列表「按页加载」——CMDB 侧过滤 + 分页，只实例化本页主机；全量请求仍由前端另行发起
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID（经 `validate_bk_biz_id` 解析关联空间） |
  | page | int | 否 | 页码，≥1；**必须与 page_size 成对** |
  | page_size | int | 否 | 每页条数，1~500；**必须与 page 成对** |
  | bk_host_id | int | 否 | 单主机范围（与拓扑范围二选一） |
  | bk_obj_id / bk_inst_id | str/int | 否 | 拓扑节点范围（必须成对） |
- **返回**：带 `page` 时 `dict` — `{"items": list[dict], "total": int, "page": int, "page_size": int}`；**不带 `page` 时仍是 `list[dict]`（兼容旧前端）**
- **异常**：`InvalidParamsError` — `page`/`page_size` 只传一个；`bk_obj_id` 与 `bk_inst_id` 不成对；`bk_obj_id="biz"` 且 `bk_inst_id != bk_biz_id`（防跨业务取数）
- **约束**：
  - 分页路径调用 `api.cmdb.get_host_page`，不再调用 `get_host_by_topo_node`
  - 拓扑走 `raw=True` 原始树 + `TopoTree.module_links_from_raw(raw, 本页模块ID)`，**只为本页涉及的模块构造路径**
  - `get_module_info(..., module_cache)` 第三参数为模块展示缓存，同一模块只构造一次（**调用方需自行传入并复用**）
  - 主机查询与原始拓扑查询仍在线程池 `ThreadPool(2)` 内并发
- **使用示例**：
  ```python
  page = resource.performance.search_host_info(bk_biz_id=2, page=3, page_size=50)
  # => {"items": [{...}], "total": 38357, "page": 3, "page_size": 50}

  all_hosts = resource.performance.search_host_info(bk_biz_id=2)  # 兼容：仍返回数组
  ```

## SearchHostMetricStatsResource（页级卡片统计，2026-09 新增）
契约来源：`SearchHostMetricStatsResource`（`monitor_web/performance/resources.py:684`）+ `host_metric_stats.py`

### perform_request
- **用途**：查询单张主机性能卡片（超阈值主机数），供页级阶段展示，**不接受任意查询表达式**
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | category | str | 是 | `cpu` / `mem` / `disk`（ChoiceField 白名单） |
  | bk_host_id | int | 否 | 单主机范围 |
  | bk_obj_id / bk_inst_id | str/int | 否 | 拓扑节点范围；`biz` 根节点必须等于 `bk_biz_id` |
  | start_time / end_time | int | 否 | 秒级时间戳，**必须成对**且 `start <= end` |
- **返回**：`dict` — `{"category": str, "value": int|None, "complete": bool, "reason": str?}`
  - `value=None` + `complete=False` 表示**未知**（不是 0），`reason` ∈ `partial` / `invalid_result` / `ambiguous_identity`
- **异常**：`InvalidParamsError` — 时间不成对 / 时间倒挂 / 拓扑参数不成对 / `biz` 根跨业务
- **约束**：
  - 走 `api.cmdb.get_host_identities` 取身份白名单（复用业务主机预热缓存），再走 `query_host_metric_stats`
  - 统计主体是**单次 instant UQ 查询**（多数据源表达式必走 UQ），非 per-host 查询
- **使用示例**：
  ```python
  stats = resource.performance.search_host_metric_stats(
      bk_biz_id=2, category="cpu", bk_obj_id="module", bk_inst_id=100,
      start_time=1722000000, end_time=1722000180,
  )
  # => {"category": "cpu", "value": 12, "complete": True}
  # => {"category": "cpu", "value": None, "complete": False, "reason": "ambiguous_identity"}
  ```

## host_metric_stats 模块（统计表达式所在）
契约来源：`monitor_web/performance/host_metric_stats.py`

### HOST_STATS_METRICS
- **用途**：卡片分类 → （结果表, 字段）映射
- **取值**：`cpu → ("system.cpu_summary", "usage")`、`mem → ("system.mem", "pct_used")`、`disk → ("system.disk", "in_use")`

### build_host_stats_query(bk_biz_id, category, hosts)
- **用途**：构造统计用 `UnifyQuery`（两个数据源 a=按 `bk_host_id`、b=按 `bk_target_ip`/`bk_target_cloud_id`）
- **约束**：白名单只随身份数增长，**表达式不为每台主机展开分支**；云区域 `0` 额外兼容空字符串；`group_by = bk_host_id / bk_target_ip / bk_target_cloud_id`
- **返回**：`UnifyQuery`

### query_host_metric_stats(bk_biz_id, category, hosts, start_time=None, end_time=None)
- **用途**：执行 180s 窗口 instant 查询并解释四个量（`value` / `id_count` / `ip_count` / `duplicates`）
- **约束**：
  - `hosts` 为空 → 直接返回 `{"value": 0, "complete": True}`，**不发查询**
  - 阈值判定用 `>= 79.995`（使 `round(v, 2) >= 80` 成立的最小 float64，规避 PromQL round 中点规则差异）
  - `is_partial`、非有限值、字段缺失 → `invalid_result`；身份歧义 → `ambiguous_identity`（判据见 C0 已知坑）
  - 异常**不上抛保护**：查询异常按标准路径抛出，不重试、不回退原生查询

## api.cmdb 新增能力（页级加载依赖，产权属外部 API 集成专题）
契约来源：`bkmonitor/api/cmdb/default.py`、`bkmonitor/api/cmdb/define.py`

### GetHostPage（default.py:327）
- **用途**：在 CMDB 端完成过滤 + 分页，只实例化本页主机
- **参数**：`bk_biz_id`、`fields`、`page`(≥1)、`page_size`(1~500)、`bk_host_id?`、`topo_nodes?`
- **返回**：`{"items": [Host], "total": int}`（`total` 为 CMDB `count`，即过滤后的总数）
- **约束**：
  - 排序沿用 CMDB 默认 `bk_host_id` 顺序（与原 `batch_request` 分页顺序一致）
  - 地址过滤要求 `bk_host_innerip`/`bk_host_innerip_v6` 至少含一个非逗号字符（`contains "[^,]"`，与 `split_inner_host` 对齐，排除 null/空串/纯逗号）
  - `topo_nodes` 经 `_trans_topo_node_to_module_ids` 转 `module_property_filter`；模块集合为空直接返回空页
  - `topo_nodes == {"biz": [bk_biz_id]}` 视为业务根，不加模块过滤

### GetHostIdentities（default.py:381）
- **用途**：输出统计所需身份（`bk_host_id` / `bk_host_innerip` / `bk_host_innerip_v6` / `bk_cloud_id`）+ `has_duplicate_ip`
- **约束**：复用 `get_host_dict_by_biz(bk_biz_id, Host.Fields)` 业务主机预热缓存，**调用参数必须与 `cmdb_api_list` 预热一致**，否则另建缓存键导致全量回源；`has_duplicate_ip` 按全业务 IP+云区域计数（跨节点重复仍标记）

### GetTopoTreeResource（default.py:541）
- **新增参数**：`raw`（bool，默认 False）——`raw=True` 返回原始 dict，跳过 `TopoTree` 构造

### GetProcess（default.py:765）
- **新增参数**：`bk_host_ids`（ListField，可选）——在**构造 Process 对象之前**跳过不在集合内的原始服务实例；传空列表直接返回 `[]`

### TopoTree.module_links_from_raw（define.py:375）
- **用途**：只为目标模块叶子自底向上构造路径，不修改原始拓扑
- **参数**：`tree_data`（原始 dict）、`module_ids`（可迭代，int/str 混用）
