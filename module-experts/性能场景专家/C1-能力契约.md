## HostPerformanceResource
契约来源：`HostPerformanceResource`（`resources.py`）

### perform_request
- **用途**：获取业务下全量主机列表（基础信息 + 性能指标 + Agent 状态 + 进程 + 告警），走 `HOST` 缓存
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 否 | 业务ID |
- **返回**：`dict` — `{"hosts": list[dict], "update_time": str}`
- **异常**：无（各 fetch 方法对缺失 host 做 continue 跳过）
- **约束**：继承 `CacheResource`，结果按 `CacheType.HOST` 缓存
- **使用示例**：
  ```python
  result = resource.performance.host_performance(bk_biz_id=2)
  # => {"hosts": [{"bk_host_id": 11, "cpu_usage": 12.3, "status": 1, "component": [...], ...}], "update_time": "2026-07-27 10:00:00+0800"}
  ```

### get_process_status (staticmethod)
- **用途**：拉取进程信息填充 `host_dict[bk_host_id]["component"]`
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
  | data | dict[int, dict] | 是 | 聚合容器（原地修改） |
- **返回**：无（原地修改 `data`）
- **约束**：输出含 `ports`/`protocol` 字段

### get_alarm_count (staticmethod)
- **用途**：拉取告警计数填充 `host_dict[bk_host_id]["alarm_count"]`
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
  | data | dict[int, dict] | 是 | 聚合容器（原地修改） |
- **返回**：无（原地修改 `data`）
- **约束**：**无 try/except 降级**，异常会中断整个聚合
- **使用示例**：
  ```python
  HostPerformanceResource.get_alarm_count(bk_biz_id=2, hosts=host_list, data=host_dict)
  ```

## HostPerformanceDetailResource
契约来源：`HostPerformanceDetailResource`（`resources.py`）

### perform_request
- **用途**：获取单台主机详情（基础信息 + 拓扑 + Agent 状态 + 业务名）
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_host_id | int | 是 | 主机ID |
  | bk_biz_id | int | 是 | 业务ID |
- **返回**：`dict` — 含 `bk_host_id/bk_host_innerip/bk_host_outerip/bk_cloud_id/bk_cloud_name/bk_host_name/bk_os_name/bk_os_type/region/bk_biz_id/bk_biz_name/module/status/bk_state`
- **异常**：`CustomException` — 主机不存在时 `f"host({bk_host_id}) not found"`
- **约束**：无缓存，实时查询
- **使用示例**：
  ```python
  detail = resource.performance.host_performance_detail(bk_biz_id=2, bk_host_id=11)
  # => {"bk_host_id": 11, "bk_host_innerip": "10.0.0.1", "status": 1, "bk_biz_name": "蓝鲸", "module": [...], ...}
  ```

## HostTopoNodeDetailResource
契约来源：`HostTopoNodeDetailResource`（`resources.py`）

### perform_request
- **用途**：获取拓扑节点详情（主机数 + 告警数 + 策略数 + 负责人）
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | bk_obj_id | str | 是 | 节点类型（如 `module`/`set`/`biz`） |
  | bk_inst_id | int | 是 | 节点实例ID |
- **返回**：`dict` — 含 `bk_obj_id/bk_inst_id/bk_obj_name/bk_inst_name/operator/bk_bak_operator/child_count/host_count/alarm_count/alarm_strategy`
- **异常**：无
- **约束**：`child_count` 在 `bk_obj_id=="module"` 时取 `len(hosts)`，否则取 `len(node.child)`；`operator`/`bk_bak_operator` 仅 `module` 类型有值；**注意**：当 `bk_obj_id != "module"` 且节点不存在（`node` 为 None）时，`len(node.child)` 会抛 `AttributeError`
- **使用示例**：
  ```python
  detail = resource.performance.host_topo_node_detail(bk_biz_id=2, bk_obj_id="module", bk_inst_id=100)
  # => {"bk_obj_id": "module", "bk_inst_id": 100, "host_count": 5, "alarm_count": 3, "operator": ["admin"], "alarm_strategy": {"enabled": 2, "disabled": 1}, ...}
  ```

### get_alarm_count (staticmethod)
- **用途**：统计拓扑节点下所有主机的告警总数
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
- **返回**：`int` — 告警总数（所有级别求和）
- **约束**：`hosts` 为空时返回 0

## TopoNodeProcessStatusResource
契约来源：`TopoNodeProcessStatusResource`（`resources.py`）

### perform_request
- **用途**：获取拓扑节点下的进程名列表
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | bk_obj_id | str | 是 | 节点类型 |
  | bk_inst_id | int | 是 | 节点实例ID |
- **返回**：`list[dict]` — 每项含 `status`(固定 `AGENT_STATUS.UNKNOWN`)/`ports`(`[]`)/`display_name`(进程名)/`protocol`(`""`)
- **异常**：无
- **约束**：进程按 `bk_process_name` 去重；status 硬编码置灰，不查实时状态
- **使用示例**：
  ```python
  processes = resource.performance.topo_node_process_status(bk_biz_id=2, bk_obj_id="module", bk_inst_id=100)
  # => [{"status": 0, "ports": [], "display_name": "nginx", "protocol": ""}, {"status": 0, "ports": [], "display_name": "mysql", "protocol": ""}]
  ```

## SearchHostInfoResource
契约来源：`SearchHostInfoResource`（`resources.py`）

### perform_request
- **用途**：获取业务下全量主机基础信息 + 模块拓扑链
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
- **返回**：`list[dict]` — 每项含 `display_name/bk_host_id/bk_biz_id/bk_cloud_id/bk_cloud_name/bk_host_innerip/bk_host_outerip/bk_os_type/bk_os_name/region/bk_host_name/ignore_monitoring/is_shielding/module`
- **异常**：无
- **约束**：无缓存（ViewSet 有 gzip 压缩）；**无 IAM 权限**（`SearchHostInfoViewSet` 未继承 `PermissionMixin`）
- **使用示例**：
  ```python
  hosts = resource.performance.search_host_info(bk_biz_id=2)
  # => [{"bk_host_id": 11, "display_name": "host-11", "module": [{"id": "module|100", "topo_link": ["biz|2", "set|1", "module|100"], ...}], ...}]
  ```

### get_module_info (staticmethod)
- **用途**：构造模块拓扑链
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_module_ids | list[int] | 是 | 模块ID列表 |
  | topo_links | dict[str, list[TopoNode]] | 是 | 拓扑链字典（key: `module|{id}`） |
- **返回**：`list[dict]` — 每项含 `id`/`bk_inst_id`/`bk_inst_name`/`topo_link`/`topo_link_display`/`bk_obj_name_map`
- **约束**：`topo_link` 和 `topo_link_display` 均 `reversed`（根节点在前）
- **使用示例**：
  ```python
  modules = SearchHostInfoResource.get_module_info([100], topo_links)
  # => [{"id": "module|100", "topo_link": ["biz|2", "set|1", "module|100"], "topo_link_display": ["蓝鲸", "集群1", "模块100"]}]
  ```

## SearchHostMetricResource
契约来源：`SearchHostMetricResource`（`resources.py`）

### perform_request
- **用途**：获取指定主机的 Agent 状态 + 性能指标 + 进程 + 告警（实时，无缓存，支持时间范围）
- **参数**：
  | 参数名 | 类型 | 必填 | 说明 |
  |--------|------|------|------|
  | bk_host_ids | list[int] | 是 | 主机ID列表 |
  | bk_biz_id | int | 是 | 业务ID（经 `validate_bk_biz_id` 校验） |
  | start_time | int | 否 | 开始时间（秒级时间戳，不传默认最近三分钟） |
  | end_time | int | 否 | 结束时间（秒级时间戳） |
- **返回**：`dict[int, dict]` — key 为 `bk_host_id`，value 含 `status/cpu_load/cpu_usage/disk_in_use/io_util/mem_usage/psc_mem_usage/component/alarm_count`
- **异常**：无（`get_alarm_count` 有 `try/except` 降级）
- **约束**：无缓存；`component` 不含 `ports`/`protocol`（与 `HostPerformanceResource` 版不同）；`bk_biz_id` 经 `validate_bk_biz_id` 空间/租户校验
- **使用示例**：
  ```python
  metrics = resource.performance.search_host_metric(bk_biz_id=2, bk_host_ids=[11, 12])
  # => {11: {"status": 1, "cpu_usage": 12.3, "component": [...], "alarm_count": [...]}, 12: {...}}

  # 指定时间范围
  metrics = resource.performance.search_host_metric(
      bk_biz_id=2, bk_host_ids=[11], start_time=1722000000, end_time=1722000180
  )
  ```

### get_agent_status (staticmethod)
- **用途**：拉取 Agent 状态填充 `data[bk_host_id]["status"]`
- **参数**：

  |--------|------|------|------|
  | bk_biz_id | int | 是 | 业务ID |
  | hosts | list[Host] | 是 | 主机列表 |
  | data | dict[int, dict] | 是 | 聚合容器 |
  | start_time | int | 否 | 开始时间 |
  | end_time | int | 否 | 结束时间 |
- **返回**：无（原地修改 `data`）
- **使用示例**：


- **使用示例**：
  ```python
  SearchHostMetricResource.get_performance_data(bk_biz_id=2, hosts=host_list, data=host_dict)
  ```

### get_alarm_count (staticmethod)
- **用途**：拉取告警计数填充 `data[bk_host_id]["alarm_count"]`

- **约束**：**有 try/except 降级**，异常时 `logger.exception` 并保持 `alarm_count` 为默认空列表
- **使用示例**：
