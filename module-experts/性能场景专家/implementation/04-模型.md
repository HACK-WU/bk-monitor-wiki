## 简介
本模块**无持久化数据模型**。`models.py` 仅含版权声明和注释「迁移至 monitor_api 中的 model」，无 Django ORM 模型定义。所有数据均为运行时聚合的内存结构，不落库。
章节来源：[models.py](file://bkmonitor/packages/monitor_web/performance/models.py#L11-L13)

## 实体清单
本模块无 DB 实体。运行时核心数据结构为 `host_dict`（`dict[int, dict]`），由 `perform_request` 在内存中构造，各 fetch 静态方法原地填充。

## 结论
模块无 DB 层，所有数据结构为运行时内存聚合。`host_dict` 是核心聚合容器，默认值兜底设计保证缺失数据不影响响应完整性。`component` 在两个 Resource 间字段略有差异（`HostPerformanceResource` 版含 `ports`/`protocol`，`SearchHostMetricResource` 版不含），跨类使用时需注意。
