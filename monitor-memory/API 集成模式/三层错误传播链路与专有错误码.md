web→api 三层错误传播全链路：前端→web 端 Resource→API 网关(KernelAPIResource/APIResource)→api role Resource。
- 符号: `packages/fta_web/issue/resources.py` RenameIssueResource.perform_request
- 位置: `api/issue/default.py`（RenameResource，action=/app/issue/rename/）
- 位置: `kernel_api/views/v4/issue.py`（RenameResource.perform_request 执行）
- 错误传播：api role 抛 Error 子类→custom_exception_handler(`core/drf_resource/exceptions.py`)→body.code=专有码；web 端 `core/drf_resource/contrib/api.py` APIResource.perform_request HTTPError 分支用 err.response.json() 透传结构化响应体→BKAPIError(`core/errors/api.py`) data 含原始 code；web 端捕获 BKAPIError 按 e.data.code 识别并重抛专有错误。
- HTTP 状态码在 web 网关链路被 BKAPIError 包装（默认 500），前端应认 body.code 而非 HTTP 状态码；CustomException message 带"自定义异常："前缀，需纯净 message 时用自定义 Error 子类（message_tpl="{message}"）。
- 新增专有错误码四步法：① core/errors/<module>.py 建错误类（段 33xxxx，如 issue 用 3327xxx）② api role 抛专有错误 ③ web 网关透传 ④ web 端 Resource 捕获转码。
