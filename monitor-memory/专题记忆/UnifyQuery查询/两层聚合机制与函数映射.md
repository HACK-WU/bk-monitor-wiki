UnifyQuery 的 metrics[].method 会被 to_unify_query_config 分解为两个独立的聚合层：第一层时间轴聚合（time_aggregation）对单条 series 在窗口内做 xxx_over_time，第二层跨 series 聚合（function[0].method）在 group 内按维度分组做 mean/sum 等。

- 符号: `AggMethods`、`CpAggMethods`、`to_unify_query_config`
- 位置: `bkmonitor/bkmonitor/data_source/data_source/__init__.py`、`bkmonitor/bkmonitor/data_source/unify_query/functions.py`

聚合函数映射速查:
- AVG/avg → time_aggregation: avg_over_time + window={interval}s；function[0].method: mean（标准两层：先时间平滑再分组平均）
- SUM/sum → sum_over_time + sum
- COUNT/count → count_over_time + sum（先时间计数再分组求和=总点数和）
- MAX/max → max_over_time + max
- MIN/min → min_over_time + min
- avg_without_time → 不写 time_aggregation（跳过时间层），function[0].method: avg（只做分组avg，不跨时间聚合）
- sum_without_time → 不写 time_aggregation，function[0].method: sum
- cp50/cp95/cp99 → histogram_quantile + vargs_list + position，function[0].method: mean

_without_time 变体用途:
- 当不希望跨时间聚合（不做 avg_over_time 平滑）时使用
- 场景：原始采集点稀疏（1分钟一个点），再做窗口聚合反而丢失细节
- 注意：即使跳过时间聚合，分组聚合仍然执行（avg/sum 等）
- AggMethods 仅含 sum_without_time/avg_without_time/count_without_time/min_without_time/max_without_time 五种

关键理解:
- time_aggregation.window = interval（秒），如 180s；若无 interval 则回退 1h
- function[0].dimensions = group_by 列表，定义分组边界，不同 group 互相隔离
- avg → function[0].method="mean" 而非 "avg"（PromQL 惯用映射）；count → "sum" 同理
- 多 metrics 展开为 query_list 多条，各自 reference_name=a0~aN，经 metric_merge 合成 PromQL
