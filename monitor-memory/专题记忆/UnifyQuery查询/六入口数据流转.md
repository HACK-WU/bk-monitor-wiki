UnifyQuery 对外暴露 6 个公开查询入口，全部经过 use_unify_query() 判定再分流为统一查询后端或数据源原生查询两条总分支。

- 符号: `UnifyQuery.query_data`、`query_data_with_stat`、`query_reference`、`query_log`、`query_dimensions`、`_query_data_using_datasource`、`use_unify_query`
- 位置: `bkmonitor/bkmonitor/data_source/unify_query/query.py`、`bkmonitor/bkmonitor/data_source/data_source/__init__.py`

两条总分支 use_unify_query 判定:
- 返回 False 的情形: data_sources[0].id 不在 UnifyQueryDataSources+GrayUnifyQueryDataSources（恒走下推）；灰度数据源 switch_unify_query 返回 False；接入数据平台+cmdb-level查询+表在 BKDATA_CMDB_LEVEL_TABLES 白名单
- (BK_MONITOR_COLLECTOR, TIME_SERIES) 与 (CUSTOM, TIME_SERIES) 永远走统一查询后端分支

六入口链路:
1. query_data → _query_data_internal(with_series_stat=False) → _query_unify_query → POST /query/ts，返回 list[dict]
2. query_data_with_stat → _query_data_internal(with_series_stat=True) → 同上但返回 {series, series_stat}，series_stat 以 (dimensions_hash, metric_field) 为 key
3. query_reference → _query_reference_using_unify_query → POST /query/ts/reference，limit/from 是每条子查询级别，不设 down_sample_range
4. query_log → _query_log_using_unify_query → POST /query/ts/raw，逐条剥离聚合（function/field_name/time_aggregation 清空），total 恒为 0，不支持 instant
5. query_dimensions → 单数据源走 /query/ts/info/tag_values（InfluxdbDimensionFetcher）；多数据源退化为 query_data 全量拉取再内存去重
6. _query_data_using_datasource → use_unify_query()==False 时进入，逐数据源调 data_source.query_data → DataQueryHandler 路由到存储后端

六入口对照:
- HTTP: query_data→/query/ts；with_stat→/query/ts；reference→/query/ts/reference；log→/query/ts/raw；dimensions→/query/ts/info/tag_values；using_datasource→DataQueryHandler
- instant→step=1m: query_data✅ with_stat✅ reference✅ log❌ dimensions— using_datasource—
- down_sample_range: query_data✅ with_stat✅ reference❌ log❌ dimensions—
- 返回: list / {series,stat} / list / (list,total) / list / (data,stat)
