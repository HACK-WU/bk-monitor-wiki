UnifyQuery.query_data 的参数拼接链路：data_source_class 入参如何经 to_unify_query_config → get_unify_query_params → _query_unify_query 最终拼成统一查询后端 HTTP 请求参数。

- 符号: `TimeSeriesDataSource.to_unify_query_config`、`UnifyQuery.get_unify_query_params`、`UnifyQuery._query_unify_query`
- 位置: `bkmonitor/bkmonitor/data_source/data_source/__init__.py`、`bkmonitor/bkmonitor/data_source/unify_query/query.py`

to_unify_query_config 规则:
- 指标平铺: metrics 列表展开成 query_list 数组多条独立条目，每条携带相同 table_id/group_by/time_field/conditions，各自独立 field_name/reference_name/keep_columns
- 聚合映射: 命中 *_without_time 变体→不写 time_aggregation，function[0].method 直接取映射值；普通 method→time_aggregation={function: "<method>_over_time", window: "<interval>s"}，function[0].method 经 {avg:mean, count:sum} 映射
- 分位数 cp50/cp95/cp99: time_aggregation.function=histogram_quantile + 额外 vargs_list/position
- reference_name = (alias or field).lower()；table_id = data_label or table.lower()；driver = "influxdb"

get_unify_query_params 规则:
- step: interval 有值取 interval，否则默认 60，形如 "180s"
- expression: 非空直接用，为空则 or 拼接各 reference_name
- metric_merge = add_expression_functions(expression, functions)
- order_by: 未传默认 ["-_time"]
- space_uid = bk_biz_id_to_space_uid(bk_biz_id)；bk_tenant_id = bk_biz_id_to_bk_tenant_id(bk_biz_id)
- start_time/end_time: time_alignment=True 且 not_time_align=False 时经 time_interval_align 对齐到步长边界

_query_unify_query 规则:
- instant=True: params["instant"]=True 且 step 被覆盖为 "1m"（固定1分钟，忽略原 interval）
- 补 down_sample_range=""、timezone=get_current_timezone_name()
- 调用 api.unify_query.query_data(**params) → QueryDataResource

后处理 process_unify_query_data:
- 从 series 的 group_keys/group_values 提取维度，columns 中 _time→_time_、_result/_value→_result_
- 时间列秒级转毫秒，返回 list[dict]
- BK_MONITOR_COLLECTOR/TIME_SERIES 不在 process_data_by_datasource 特例列表，直接返回
