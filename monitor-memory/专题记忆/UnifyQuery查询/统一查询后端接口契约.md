UnifyQuery 在统一查询后端分支最终调用 api.unify_query.* 资源（Python 侧 Resource 类），四个资源类定义了请求字段与返回结构。

- 符号: `QueryDataResource`、`QueryRawResource`、`QueryReferenceResource`、`GetDimensionDataResource`
- 位置: `bkmonitor/api/unify_query/default.py`

QueryDataResource (POST /query/ts):
- query_data / query_data_with_stat 统一走此资源
- RequestSerializer 字段: query_list、metric_merge、start_time、end_time、step、space_uid、down_sample_range、timezone、instant、not_time_align
- 返回结构含 series（每条带 group_keys/group_values/columns/types/values/stat）、is_partial、result_table_id

QueryRawResource (POST /query/ts/raw):
- query_log 走此资源
- RequestSerializer 字段: query_list、metric_merge、start_time、end_time、step、limit、_from、space_uid、timezone、instant、order_by
- perform_request 中 params["from"] = params.pop("_from", 0)：因 from 是 Python 关键字，内部用 _from 承载
- 与 QueryDataResource 相比: 无 down_sample_range/not_time_align，多 limit/_from/order_by

QueryReferenceResource (POST /query/ts/reference):
- query_reference 走此资源
- RequestSerializer 字段: query_list、metric_merge、start_time、end_time、step、space_uid、timezone、instant、order_by、look_back_delta（默认 "1m"）
- 与 QueryDataResource 相比: 无 down_sample_range/not_time_align，多 order_by/look_back_delta

GetDimensionDataResource (POST /query/ts/info/tag_values):
- query_dimensions（单数据源）走此资源
- info_type = "tag_values"，请求体含 table_id、metric_name、keys（维度字段列表）、conditions、limit、start_time/end_time（秒级）、space_uid
- 由 InfluxdbDimensionFetcher.query_dimensions 复用 to_unify_query_config()[0] 组装

返回结构通用说明:
- 时序类（/query/ts、/query/ts/reference）: 统一经 process_unify_query_data 把 series 转 list[dict]，维度从 group_keys/group_values 提取，_time→_time_、_result/_value→_result_
- 维度类（/query/ts/info/tag_values）: 直接返回维度值 list
- 日志类（/query/ts/raw）: 经 process_unify_query_log 把元数据移入 _meta，返回 (records, total) 且 total 恒为 0
