kernel_api v4 视图装配层：views/v4/ 是薄装配层，业务逻辑在内部 Resource / 挂载 app 的 Resource 中。通过 resource_routes 声明 endpoint，URL 为 /api/v4/{endpoint}/。v4 是当前主版本，40+ 文件按业务子域组织。

## 装配模式
- ViewSet 通过 `resource_routes = [ResourceRoute("POST", XxxResource, endpoint="xxx")]` 声明 endpoint
- endpoint 对应 URL：`/api/v4/xxx/`（AlertViewSet 部分 endpoint 带 `/` 前缀如 `alert/search`）
- 新增 endpoint 必须在 `views/v4/__init__.py` 加 `from .{module} import *`
- 与 `fta_web`/`monitor_web` 已有 ViewSet 大量复用（继承或 ResourceRoute 引用）

## 核心子域与 ViewSet
- 告警事件中心：`AlertViewSet` / `AlertInfoViewSet` / `SearchAlertViewSet` / `CloseAlertResource` @ `alert.py`
- 告警策略：`AlarmStrategyV2ViewSet` / `AlarmStrategyV3ViewSet`（含 `SearchStrategyWithoutBizResource` / `QosCheckResource`）@ `strategy.py` / `strategy_v2.py` / `strategy_v3.py`
- Issue 功能：`IssueViewSet` + 12 个独立 Resource（Assign/Resolve/Archive/Reopen/Restore/UpdatePriority/Rename/FollowUp/Merge/Split/RegenerateTitle）@ `issue.py`
- 事件：`EventViewSet` / `EventV2ViewSet` / `EventPluginViewSet` @ `event.py` / `event_v2.py` / `event_plugin.py`
- 内核 RPC：`KernelRPCViewSet`（KernelRPCResource）@ `kernel_rpc.py`
- bkm-cli：`BkmCliViewSet`（BkmCliOpCallResource）@ `bkm_cli.py`
- 运营指标：`OperationViewSet` @ `operation.py`
- APM：`ApmMcpViewSet` + 6 个继承 ViewSet（Application/Trace/Service/Metric/Event/Profile）@ `apm.py`
- 容器监控：`BCSViewSet` @ `bcs.py`
- 采集：`CollectViewSet` / `CustomEventViewSet` / `CustomMetricViewSet` @ `collect.py` / `custom_report.py`
- AI 制品仓库：`AIRepoViewSet` @ `ai_repo.py`

## 踩坑点
- 接口报 404：endpoint 未注册 / `__init__.py` 未导出模块 → 确认 `views/v4/__init__.py` 含 `from .{module} import *` 且 ViewSet 的 `resource_routes` 声明了 endpoint
- 错误显示为 500（非业务码）：web 端经网关调用，kernel_api 恒 200 + body.code → 前端/web 端认 `body.code`
- Issue 重名 409：kernel_api 抛 code 3327001，web 端识别转 409
