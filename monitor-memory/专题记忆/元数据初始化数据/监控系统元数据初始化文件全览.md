## 初始化数据目录

路径：`bk-monitor-base/src/bk_monitor_base/metadata/data/`

### 1. init_resulttable.json
- 作用：定义所有内置结果表（ResultTable）及其字段（ResultTableField）
- 关键结构：`table_id`（如 `system.load`）、`field_list`（含 `field_name`、`tag`=metric/dimension/timestamp）
- 对应模型：`metadata.models.result_table.ResultTable`、`ResultTableField`

### 2. init_datasource.json
- 作用：定义数据源（DataSource），即数据采集通道
- 关键字段：`data_name`（如 `base_alarm`、`snapshot`）、`etl_config`（ETL规则）、`bk_data_id`（数据ID）、`source_label`（数据源标签）、`type_label`（数据类型）
- 对应模型：`metadata.models.data_source.DataSource`

### 3. init_storage.json
- 作用：定义存储配置，指定哪些表使用哪种存储
- 结构：按存储类型分组（如 `kafka_storage`），列出使用该存储的表名列表
- 示例：`kafka_storage` 包含 `system.cpu_summary`、`system.load` 等

### 4. init_label.json
- 作用：定义标签分类体系
- 标签类型：`result_table_label`（结果表标签，如 os、component）、`source_label`（数据源标签，如 bk_monitor、bk_data）、`type_label`（数据类型标签，如 time_series、event）
- 对应模型：`metadata.models.common.Label`

### 5. init_cluster_info.json
- 作用：定义存储集群配置（Kafka、InfluxDB、ES）
- 关键字段：`cluster_type`、`domain_name`、`cluster_name`、`port`
- 对应模型：`metadata.models.storage.ClusterInfo`

### 6. init_ts_or_event_group.json
- 作用：定义时序分组（time_series_group）和事件分组
- 关键字段：`bk_data_id`、`table_id`、`label`、`time_series_group_name`
- 对应模型：`metadata.models.time_series_group.TimeSeriesGroup`

### 7. description_unit.json
- 作用：定义指标的描述信息和单位转换
- 关键字段：`item`（指标名）、`conversion_unit`（转换单位）、`description`（描述）、`result_table_id`
- 用于前端展示和单位换算

### 8. k8s_metrics/
- 作用：Kubernetes 相关指标定义
- 包含 K8S 组件的指标采集配置

### 9. k8s_events.json
- 作用：Kubernetes 事件定义

### 10. bkci_data.json
- 作用：蓝盾 CI 数据定义

### 11. metadata_resulttablefield.txt
- 作用：结果表字段的补充描述（文本格式）

## 数据流向

初始化 JSON → Django migration 导入数据库 → `ResultTable`、`DataSource`、`Label` 等模型表 → 业务代码通过模型查询或硬编码引用
