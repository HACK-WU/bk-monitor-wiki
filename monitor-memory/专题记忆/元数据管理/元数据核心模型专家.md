元数据核心模型专家管理监控系统的核心元数据定义：DataSource（数据源）、ResultTable（结果表）、EntityRelation（实体关系）及公共基础模型。含 2 个子专家（数据源管理/结果表管理）。

- 符号: `DataSource`、`ResultTable`、`ResultTableField`、`ResultTableOption`、`CMDBLevelRecord`、`Label`、`OptionBase`、`EntityMeta`、`ResourceDefinition`、`RelationDefinition`
- 位置: `bk-monitor-base/src/bk_monitor_base/metadata/models/data_source.py`、`result_table.py`、`common.py`、`entity_relation.py`

覆盖文件:
- data_source.py(62KB): DataSource 模型、CRUD、连接管理、Consul/GSE 配置同步、register_to_bkbase 计算平台集成
- result_table.py(139KB): ResultTable/ResultTableField/ResultTableOption/CMDBLevelRecord，生命周期管理（创建/修改/升级/删除）
- common.py(9KB): Label 标签模型、OptionBase 基类、BaseModel/BaseModelWithTime 抽象基类
- entity_relation.py(8KB): EntityMeta 抽象基类、ResourceDefinition、RelationDefinition、CustomRelationStatus

子专家:
- 数据源管理子专家: DataSource 全链路 + 公共模型（data_source.py + common.py）
- 结果表管理子专家: ResultTable + Field + Option + CMDBLevelRecord（result_table.py）

与其他专家关系:
- 上游依赖: 存储与数据链路（ClusterInfo/ESStorage/InfluxDBStorage 供 DataSource 集群配置）+ 空间与自定义上报（Space/SpaceDataSource 供空间归属）
- 下游消费: alarm_backends（告警计算）/apm（APM拓扑，EntityRelation 被消费）/api/metadata/default.py（外部API）/kernel_api（内核API）

关键约束:
- constants.py(139KB) 不归属本专家（全局常量，T0 结构化索引）
- entity_relation.py 跨 metadata+APM+bkm_ipchooser 三模块，本专家仅覆盖 metadata 侧模型定义
- 修改 DataSource/ResultTable 字段需评估告警计算影响
