元数据种子数据与数据字典专家管理 bk-monitor 所有内置种子数据（JSON/YAML）的定义、加载机制，以及作为 UnifyQuery 查询链路的"数据字典"层——提供 table/field/unit/description 的映射来源。无子专家。

- 符号: `init_resulttable`、`init_datasource`、`description_unit`、`init_label`、`get_built_in_k8s_metrics`、`get_built_in_k8s_events`
- 位置: `bk-monitor-base/src/bk_monitor_base/metadata/data/`、`migrations/`、`utils/k8s_metric.py`

种子数据文件清单（12类）:
- init_datasource.json(11KB): 内置数据源（bk_data_id/source_label/type_label/etl_config）
- init_resulttable.json(209KB): 内置结果表及字段（table_id/field_list 含 field_name/tag/unit/description）
- init_data.json(177KB): 旧版综合种子数据（result_table_list+datasource_list+cluster_list）
- description_unit.json(98KB): 指标描述与单位（conversion_unit/description/item_display）
- init_label.json(4KB): 标签分类体系（source_label/result_table_label/type_label 三级）
- init_storage.json/init_cluster_info.json: 存储路由/集群初始化
- k8s_metrics/(25 YAML): K8s 各组件内置指标（apiserver/kubelet/etcd/container）
- k8s_events.json/bkci_data.json: K8s 事件/BKCI 指标

加载机制:
- Django Migration 加载: migrations/0002_initial_data.py（bk-monitor-base）+ 0002_create_initial_metadata.py（bkmonitor）+ 0008_import_field_descriptions.py
- 运行时加载: utils/k8s_metric.py（get_built_in_k8s_metrics/get_built_in_k8s_events）
- 数据流: JSON→Model→DB→UnifyQuery 全链路

下游消费者:
- monitor_web/cc/resources/cmdb.py: load_data_source("bk_monitor","time_series")→table/field，种子数据是 UnifyQuery 查询的"数据字典"层
- metadata/resources/resources.py: get_built_in_k8s_metrics()/get_built_in_k8s_events()
- monitor_web/strategies/metric_list_cache.py: K8s 指标列表缓存

与其他专家关系:
- 上游依赖: 元数据核心模型（DataSource/ResultTable/ResultTableField/Label 模型定义）+ 存储与数据链路（ClusterInfo/InfluxDBStorage/ESStorage/KafkaStorage）
- 种子数据加载时创建/更新这些模型的实例
