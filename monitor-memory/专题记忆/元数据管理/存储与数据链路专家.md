存储与数据链路专家管理监控数据的存储引擎配置（InfluxDB/ES/Kafka/VM/Doris）、数据链路编排（清洗/汇聚/流转）、ES 快照、集群管理。含 2 个子专家（存储引擎/数据链路）。

- 符号: `ClusterInfo`、`InfluxDBStorage`、`ESStorage`、`KafkaStorage`、`RedisStorage`、`DorisStorage`、`DataLink`、`EsSnapshot`、`InfluxDBClusterInfo`
- 位置: `bk-monitor-base/src/bk_monitor_base/metadata/models/storage.py`、`data_link/`、`es_snapshot.py`、`influxdb_cluster.py`、`vm/`

覆盖文件:
- storage.py(240KB): ClusterInfo、InfluxDBStorage、ESStorage、KafkaStorage、RedisStorage、DorisStorage、ArgusStorage、BkDataStorage、StorageClusterRecord、SpaceRelatedStorageInfo
- data_link/(6文件): data_link.py(56KB) DataLink 主模型、data_link_configs.py(42KB) 配置基类、relation.py(18KB) BKBase V4 组件关联、service.py(8KB) apply_data_id_v2 等
- es_snapshot.py(55KB): EsSnapshot/EsSnapshotRepository/EsSnapshotIndice/EsSnapshotRestore
- influxdb_cluster.py(34KB): InfluxDBTagInfo/InfluxDBClusterInfo/InfluxDBHostInfo/InfluxDBProxyStorage
- vm/(6文件): BkDataClean/BkDataStorage/AccessVMRecord/SpaceVMInfo/BkDataAccessor

子专家:
- 存储引擎子专家: storage + influxdb_cluster + vm + es_snapshot（storage.py 240KB 最大）
- 数据链路子专家: data_link 全包（仅 metadata 模型定义层，APM 操作服务不在本专题）

与其他专家关系:
- 上游依赖: 元数据核心模型（Storage 依赖 ResultTable table_id 外键、DataSource bk_data_id）+ 空间与自定义上报（Space 隔离影响存储路由）
- 下游消费: 任务调度与运维（task/ 调 Storage 做索引轮转/清理/Consul刷新）+ API与工具库（resources/ 经 service/ 调 Storage CRUD）
- 跨模块: APM 引用 metadata 存储模型做拓扑构建，DataLink 操作服务在 APM（不在本专题）
