空间与自定义上报专家管理监控系统的业务空间隔离（Space）、自定义上报（CustomReport：时序/事件/日志）和记录规则（RecordRule）三大能力域。含 2 个子专家（空间管理/自定义上报）。

- 符号: `Space`、`SpaceDataSource`、`SpaceTableIDRedis`、`CustomReport`、`TimeSeriesCustomReport`、`EventCustomReport`、`LogCustomReport`、`RecordRule`
- 位置: `bk-monitor-base/src/bk_monitor_base/metadata/models/space/`、`custom_report/`、`record_rule/`

覆盖文件:
- space/(6文件): space_table_id_redis.py(74KB) 空间模型与 Redis 路由推送、space.py、utils.py(45KB)
- custom_report/(5文件): time_series.py(106KB) 时序上报全链路、event.py、base.py、订阅配置
- record_rule/(4文件): 记录规则模型（从 PromQL 到计算平台数据流）

子专家:
- 空间管理子专家: space/ 全包，重点 space_table_id_redis.py(74KB) 的 Redis 路由推送机制
- 自定义上报子专家: custom_report/ + record_rule/，重点 time_series.py(106KB) 时序上报全链路

空间隔离四种空间类型:
- BKCC（业务）/BCS（容器）/BKCI（研发）/BKSAAS（SaaS）四种空间类型路由数据
- Space 隔离作用于 DataSource/ResultTable/CustomReport/DataLink
- SpaceTableIDRedis 刷新 ES 路由

与其他专家关系:
- 专家5（API与工具库）: service/space_redis.py 接口契约归专家5，实现细节由空间管理子专家覆盖
- 专家1（元数据核心模型）: Space 隔离作用于 DataSource/ResultTable，CustomReport 依赖 ResultTable 创建
- 专家2（存储与数据链路）: CustomReport 创建时关联存储引擎（InfluxDB/ES/VM）
