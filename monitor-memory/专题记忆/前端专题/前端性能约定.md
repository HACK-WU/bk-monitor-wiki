【专题记忆｜前端性能与执行效率约定】
- 响应式粒度：trace 新增 ref 一律 shallowRef 起步；需要深响应用 import { ref as deepRef } 显式声明；图表 options / series、IntersectionObserver 等原生对象用 shallowRef；触发浅响应更新用原生 triggerRef，不要复制 triggerShallowRef（内部是 JSON 深拷贝，O(n) 且丢 Date / Map / undefined）
- 大列表：万级以上数据搬进 Web Worker，主线程只持有当前页 50 条；微前端下必须用 ?raw + Blob 创建 Worker（webpack Worker chunk 会因 babel core-js 与 publicPath 拼成 /js/js/，7002 与 9002 跨源被拦，postMessage 传 Vue Proxy 会 DataCloneError）；webpack 已配 resourceQuery: /raw/；虚拟滚动是可选不是默认（仅 host 指标表格与 failure 告警详情硬开，trace-explore 用每页 30 条 + 触底加载）
- 表格 popover 用事件委托：表格根节点挂一个捕获阶段监听器，closest 反查触发元素；微前端下先同步取 e.target 再进防抖；滚动期间 pointerEvents='none'，停止 600ms 后恢复；行数据存 Map，DOM 只留 rowKey，卸载时 clear 并置 null
- 刷新机制：代际递增 + 假参数 key（塞进 computed 再 delete）让手动刷新 / 自动刷新 / 时区切换走同一链路；凡影响请求结果但不入参的状态（典型 timezone）必须拼进 key，漏了会「切时区页面没反应」；自动刷新用 customRef 自管，set 里先 clearInterval，间隔 Math.max(value, 60000)，onScopeDispose 置 -1
- 请求竞态：能取消用 AbortController + signal；Vue2 图表用 axios.CancelToken.source()；不能取消的并发分批用自增 requestSeq + isLatestRequest 丢弃过期回调；needCancel 只按 method_url 去重，同一接口并发分批禁止开启；多目标取数用 Promise.allSettled；分批常量与后端上限跨端对齐并写注释
- 图表：三级懒加载（IntersectionObserver 不请求 / ChartLazy 不挂载 / LazyDashboardPanel 两套集合）；视口外把 echarts 实例 group 置空并 hideTip；联动实例数 >= 300 跳过 echarts.connect；降采样按像素宽度算（size = (end-start)/width）；两阶段取数先首屏后 lazyRender，回来校验 requestId；resize 防抖 300ms，用 @blueking/fork-resize-detector
- 深拷贝：structuredClone 的判据是入参会不会是 Vue3 Proxy（Pinia deepRef / reactive / props），是则改用 JSON.parse(JSON.stringify()) 或先 toRaw；postMessage 前 toRaw + JSON 两步都不能省，嵌套 Proxy 仍会 DataCloneError；写 storage 前先试跑 JSON.stringify
- 内存清理：定时器 clearInterval / clearTimeout；IntersectionObserver unobserve + disconnect + 置 null；MutationObserver disconnect；echarts dispose + disconnect；Worker terminate + 清 pending；事件 removeEventListener + Vue2 bus.$off；popover hide + destroy + 置 null；weweb 先 unmountCallback 再 unmount；业务 Map clear 并置 null；依赖 props 重建 DOM 的 watch 里也要清；可重建资源用 effectScope 包起来
- 构建：路由必须懒加载并标 webpackChunkName；embed 库用 ifdef 条件编译且 ifdef-loader enforce: 'pre'；微前端子应用无预加载，mounted 时才 loadApp
