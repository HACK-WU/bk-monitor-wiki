【专题记忆｜前端应用拓扑与微前端运行时】
- 拓扑：monitor-pc（Vue2 主壳）通过 @blueking/bk-weweb 加载 apm / fta-solutions / trace；trace 又可被 APM 通过 Vite 旁路库（monitor-alarm-center / monitor-trace-explore）嵌入；monitor-mobile 独立无微前端；公共包 monitor-api / monitor-common / monitor-ui / monitor-static
- 依赖：apm / fta-solutions 依赖 monitor-pc workspace 包（复用 UI 注册、i18n、公共组件、异常页）；monitor-mobile 只依赖 monitor-common / monitor-static
- 源码到产物：默认 pc → src/monitor-pc → ./monitor → ../static/monitor；-t trace → ./trace → ../static/trace；-apm → ./apm；-f fta-solutions → ./fta；-m monitor-mobile → ./weixin；-external → src/monitor-pc（APP=external）→ ./external
- external 真相：src/external 不存在；路由用 #if APP !== 'external' 条件编译只剩 dashboard，侧栏 filter 只留 dashboard，壳层排除 BizSelect / AiWhale / NoticeGuide，publicPath 用 static_url external/
- 运行时全局变量：__POWERED_BY_BK_WEWEB__（是否子应用）、__BK_WEWEB_DATA__（parentRoute / readonly / navList / host / token / setUnmountCallback / $baseStore / AI 回调）、__BK_WEWEB_APP_KEY__（fta 判断子应用）、window.rawWindow / rawDocument（沙箱真实 window）、window.source_app（monitor / apm / fta / trace，被 APM 嵌入时会改写）；__POWERED_BY_QIANKUN__ 本项目未使用
- parentRoute 用法：const prefix = window.__BK_WEWEB_DATA__?.parentRoute || '/'; path = `${prefix}${innerPath}`.replace(/\/\//g, '/')；各应用在 router 初始化时统一对 routes 拼前缀
- 入口分支：子应用模式跳过 enhancedContext 预加载直接挂载，Vue3 还要 setUnmountCallback(() => app.unmount())；独立运行先 Api.model.enhancedContext() 写 window 再挂载
- 主壳加载：声明式 <bk-weweb>（FTA、告警屏蔽）或命令式 loadApp + Shadow DOM（告警中心加载 trace，setShadowDom: true、container: shadowRoot、data: { host, parentRoute: '/trace/' }）
- 嵌入式 Vite 库：build:alarm-center → monitor-alarm-center；build:trace-explore → monitor-trace-explore；build:vue3-components → monitor-vue3-components；build:vue2-components → monitor-vue2-components；用 IS_APM_MONITOR 条件编译、apm-bk- 前缀样式隔离、CSS 注入 JS、公共包 external；新增对外组件要在 components.ts 注册
- workspace：pnpm-workspace 排除 bk-iframe / bk-weweb / mermaid（已改用 npm 包），新增子包放 src/* 自动纳入
