【专题记忆｜前端高危文件与同类缺陷扫描清单】
- 路由与导航高危：src/*/router/router-config.ts（侧栏菜单 / 面包屑）、src/monitor-pc/router/scenes/*.ts（路由注册 / 懒加载 chunk）、meta.navId（侧栏高亮 / 切业务跳转 / applyGuidePage）、applyGuidePage 的 excludes（引导页是否拉取）；getShowGuidePageByRoute / applyGuidePage 有 26 个文件消费，改公共行为等于同时改 26 处
- 新页面复刻旧行为：在页面层或工具函数做局部映射（navId === 'host' 时特殊处理），不要改公共 navId；excludes 是双向的：正确做法是把页面加进 excludes + 路由挂独立 beforeEnter + introduce.ts 做 navId 映射；看到某页在 excludes 里不代表引导页坏了，先查 introduce.ts 与路由定义
- 隐藏入口三种实现：藏导航保留直链 → router-config.ts 菜单项 hidden: true（app.tsx 有 filter(!hidden)，navigation.vue 有 v-if=!hidden）；藏导航 + 不进产物 → 去掉静态 import / 懒加载引用（直链会失效，先确认）；彻底下线 → 删代码（用户明确说删除才做）；注释代码加 TODO(story=xxx)
- 入口枚举：隐藏一个页面要同时检查主壳侧栏 router-config.ts、子应用自身导航 trace/router-config.ts、首页卡片 / 快捷入口 home/**、表格与详情跳转分支（rg "case '<id>'"）、直链与他人已分享 URL
- 权限两层：启动期 setGlobalBizId（Vue 挂载前，会改写 URL）与路由守卫 beforeEach；改一层必须核对另一层；space_list 没有某 bizId 只代表无该业务权限，白名单路由（isCanAllIn）无权限时仍应放行，不得跳 #/no-business；白名单含 #/、#/event-center、#/share/...、告警中心特殊入口、__BK_WEWEB_DATA__.token 场景；纠正 bizId 时不要把 hash 重置成 #/，会冲掉 share 路由
- 同类缺陷三种高频模式：条件变更不触发刷新（timezone 等非响应式全局量没进 watch/computed，修法收进依赖或显式 refreshImmediate）；structuredClone 遇 Vue3 Proxy 报 DataCloneError（改 JSON 深拷贝或 toRaw）；新旧版行为不一致（逐段对照默认值 / 展示 / 交互 / 请求参数四层）
- 微前端新页面 checklist：monitor-pc/pages/<name>/<name>.tsx 容器组件；容器 class 名与自定义元素 tag 的 kebab-case 不能撞名；monitor-pc 路由注册 + 权限；router-config.ts 菜单 + i18n；trace/pages/<name> 页面；trace/router/modules 子路由；trace/router-config 导航；weweb 参数 appId / Shadow DOM / parentRoute: '/trace/' / hash 对齐；不需要新增 webpack entry
- 撞名事故：Vue2 resolveAsset 会把 <rum-explore/> 解析成 PascalCase 的 RumExplore，若容器组件同名会渲染自身无限递归；新页面优先复用现成元素（trace-explore），新建前确认 tag 的 PascalCase 不等于容器类名
- 大需求节奏：types → Service 层（默认先 mock，严格对齐 types）→ UI 组件 → 接线与状态管理；planning 先产出一页可确认方案（目录结构、复用边界、mock 策略），不在图标语义 / 字段含义上无限循环
