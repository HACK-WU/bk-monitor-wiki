【专题记忆｜前端组件库接入规则与查询入口】
- 选库规则：Vue2 用 bk-magic-vue；Vue3 用 bkui-vue；Vue3 表格优先 @blueking/tdesign-ui 的 PrimaryTable；日期区间用 @blueking/date-picker；查询选择器用 @blueking/search-select-v3；对话组件用 @blueking/chat-x
- bkui-vue（Vue3）：按需 import { Button, Input, Select, Dialog, Message } from 'bkui-vue'，不要全局 Vue.use；样式随组件按需加载；根组件用 ConfigProvider 注入 locale；指令 bkTooltips / clickoutside 在 directive/index.ts 注册；仅 src/trace 使用
- bk-magic-vue（Vue2）：monitor-pc 在 common/import-magicbox-ui.ts 里 Vue.use(bkMagicVue, { zIndex: 3000 }) 全局注册；apm / fta-solutions import 'monitor-pc/common/import-magicbox-ui' 复用；消息 this.$bkMessage，弹窗 this.$bkInfo；monitor-mobile 不用它，改用 Vant 2
- @blueking/tdesign-ui：导出 PrimaryTable（= Table 别名）、EnhancedTable、TableColumn、BaseTable、Button；蓝鲸增量只在 PrimaryTable / EnhancedTable 生效，BaseTable 不含增强；列设置用 bkUiSettings + @bk-ui-settings-change（不是 columnController）；TableColumn 与 columns 数组二选一（columns 优先）；列 filter.type = single | multiple 启用蓝鲸筛选浮层；Pagination 源码存在但当前未导出
- @blueking/date-picker：值是二元区间 DateValue = [start, end]；四种取值模式（绝对 / 最近 ['now-Nu','now'] / 未来 ['now','now+Nu'] / 自然 ['now-1d/d','now-1d/d']），单位 s m h d w M y（M 月、m 分钟）；update:modelValue 带 (value, info, rawVal) 三参，v-model 只取第一个；needTimezone 默认开启，复用导出的 dayjs 实例；vue2 入口事件多 change / timezoneChange / formatChange 别名，v-model 语义不同，插槽与 provide 不透传
- @blueking/search-select-v3：value 是数组，每项 { id, name, values: [{ id, name }] }；data 是键列表，可配 multiple / async + get-menu-list / children / placeholder / showLogicalPanel / isCustomMenu；value-behavior = all（默认纯文本可成 tag）/ need-key（必须命中 key）；get-menu-list(item, keyword) 与 validate-values(item, values) 返回 Promise，校验返回字符串即失败文案；vue2 三条约束：事件用 @change 不是 input、插槽全部失效、必须 import 'vue2/style.css'
- chat-x：.ts 顶部必须带 MIT License 头，.vue 不带；SFC 顺序 template → script setup → style；import 分组 vue → 三方 → 内部相对 → import type；所有用户可见文案走 t('中文') 并在 src/lang/lang.ts 补 key；class 一律 ai- 前缀，字号 var(--ai-font-size, 12px) 必带兜底，禁止 :deep；composable 用箭头函数，只放数据逻辑，跨层共享用 Symbol + provide/inject 三件套；响应式优先 shallowRef / shallowReactive；类型扩展用 declare global；新增导出同步 barrel；每个 composable / 工具 / 组件配 colocated *.spec.ts
- @blueking/bkui-lint：配置预设包，不导出组件；ESLint 9 flat config，文件必须叫 eslint.config.mjs，默认按 Vue3，Vue2 项目用 createVueEslintConfig(2)；codecc/license 默认 error（不需要可关闭）；vue/block-lang 强制 <script lang="ts">，consistent-type-imports 强制 import type；commit-msg 文件名是 verify-commit.mjs（README 的 verifiy-commit.mjs 是拼写错误）；Biome 故意排除 .vue/.scss/.css，导入排序只由 ESLint perfectionist 负责
