【前端组件｜EnhancedTable】
- 本质：封装 tdesign EnhancedTable，支持树形与可编辑表格
- 蓝鲸增强：与 PrimaryTable 共用同一套增量（bkUiSettings / TableColumn / 自定义筛选 / needCustomScroll）
- 适用：需要树形展开或行编辑的表格；普通列表优先 PrimaryTable
- 注意：树形数据与可编辑列的配置以 tdesign 原生 API 为准（references/table-tdesign-api.md）
