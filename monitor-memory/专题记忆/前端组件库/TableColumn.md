【前端组件｜TableColumn】
- 本质：蓝鲸自研声明式列组件，替代 columns 数组
- 用法：在 PrimaryTable / EnhancedTable 内直接写 <TableColumn col-key=... title=... />
- 约束：与 columns 数组二选一；同时存在时 columns 优先
