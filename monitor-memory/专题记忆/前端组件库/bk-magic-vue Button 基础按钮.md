【前端组件｜Button 基础按钮】
- 所属组件库：bk-magic-vue；文档源：.codebuddy/skills/bk-magicbox-vue-components/references/button.md
- 使用：Vue2 全局注册，直接写 <bk-button>（monitor-pc 的 import-magicbox-ui 统一注册；apm/fta 复用 pc 注册）
- 适用：monitor-pc / apm / fta-solutions（Vue2）
- 属性：theme: 按钮类型（默认 `default`）；hover-theme: mouseover 按钮类型，当设置了此属性时，`theme` 和 `text` 失效；size: 尺寸（默认 `normal`）；title: title 文案；icon: 左侧图标，设置为 loading 的时候，会显示转圈的 loading 效果。；icon-right: 右侧图标，设置为 loading 的时候，会显示转圈的 loading 效果。；disabled: 是否禁用（默认 `false`）；loading: 是否加载中（默认 `false`）
- 事件：click: 点击事件
- 检索触发词：Button 基础按钮, bk-magic-vue, 组件, button
