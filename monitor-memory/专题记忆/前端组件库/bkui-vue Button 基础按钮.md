【前端组件｜Button 基础按钮】
- 所属组件库：bkui-vue；文档源：.codebuddy/skills/bkui-vue-components/references/Base/button.md
- 导入：import { Button } from 'bkui-vue'（Vue3 按需引入，禁止全局 Vue.use）
- 适用：src/trace（Vue3）
- 属性：theme: 按钮主题；hover-theme: mouseHover 按钮样式, 当设置了此属性时，theme 和 text 失效；disabled: 是否不可用（默认 false）；text: 是否为文字按钮（默认 false）；outline: 是否为反色按钮（默认 false）；size: 按钮尺寸大小
- 事件：click: 点击时触发事件
- 插槽：default: 默认插槽
- 检索触发词：Button 基础按钮, bkui-vue, 组件, button
