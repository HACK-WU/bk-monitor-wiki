【前端组件｜Notify 通知提示】
- 所属组件库：bkui-vue；文档源：.codebuddy/skills/bkui-vue-components/references/Feedback/notify.md
- 导入：import { Notify } from 'bkui-vue'（Vue3 按需引入，禁止全局 Vue.use）
- 适用：src/trace（Vue3）
- 属性：id: 弹框的 id，值相同时表示同一弹框；theme: 组件主题色（默认 primary）；title: 组件的标题；message: 组件显示的文字内容，支持字符串、函数、VNode；position: 组件出现的方向；delay: 组件延时关闭时间，值为 0 时需要手动关闭（默认 5000）；dismissable: 是否显示右侧关闭 icon（默认 true）；offsetX: 组件出现时距离视口的水平偏移量（默认 10）
