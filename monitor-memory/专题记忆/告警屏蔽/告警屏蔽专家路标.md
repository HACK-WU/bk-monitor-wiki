【专题记忆｜告警屏蔽】
- 资产路径：.module-experts/告警屏蔽专家/（用 expert-lookup 加载详细资产）
- 一句话职责：BK-Monitor 告警屏蔽模块，横跨 Web 管理面（CRUD+展示）与告警引擎面（匹配+通知），支持 5 种屏蔽类型
- 核心能力（≤5）：AddShieldResource（新增屏蔽）/ ShieldObj.is_match（引擎匹配）/ ShieldCacheManager.refresh（缓存同步）/ check_and_send_shield_notice（通知定时任务）/ QuickShield（移动端快捷屏蔽）
- 高频坑（≤3）：event类型存储时转为alert（查询需兼容两种）；dimension_config中_开头键不参与匹配（仅展示元数据）；quick_shield跳过通知/重复检查/ES状态同步（与add_shield行为不一致）
- 关键代码位置（≤5）：AddShieldResource→bkmonitor/packages/monitor_web/shield/resources/backend_resources.py；ShieldObj→bkmonitor/alarm_backends/service/converge/shield/shield_obj.py；ShieldCacheManager→bkmonitor/alarm_backends/core/cache/shield.py；ShieldStatusChecker→bkmonitor/alarm_backends/service/alert/manager/checker/shield.py；QuickShield→bkmonitor/packages/weixin/event/resources.py
- 数据落地：Shield模型（MySQL alarm_shield表）/ AlertDocument（ES is_shielded字段）/ Redis缓存（shield.biz_{bk_biz_id}）
- 检索触发词：告警屏蔽 shield 屏蔽配置 scope strategy alert dimension 屏蔽匹配 维度条件 屏蔽通知 快捷屏蔽
