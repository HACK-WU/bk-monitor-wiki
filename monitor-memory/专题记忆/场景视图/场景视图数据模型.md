场景视图的持久化由 3 个 Django ORM 模型承载：SceneModel（场景）、SceneViewModel（场景视图）、SceneViewOrderModel（视图排序）。配置字段大量使用 JSONField 存放动态结构。

- 符号: `SceneModel`、`SceneViewModel`、`SceneViewOrderModel`、`SceneViewSerializer`、`SceneViewType`
- 位置: `bkmonitor/packages/monitor_web/models/scene_view.py`、`bkmonitor/packages/monitor_web/scene_view/serializers.py`

实体清单:
- SceneModel: bk_biz_id/id(场景ID)/name/data_range(JSON)/view_order(JSON)，唯一键 (bk_biz_id, id)
- SceneViewModel: bk_biz_id/scene_id/id(视图ID)/name/type/mode/variables/order/panels/list/options(JSON)，唯一键 (bk_biz_id, scene_id, type, id)
- SceneViewOrderModel: bk_biz_id/scene_id/type/config(JSON 视图ID有序列表)，唯一键 (bk_biz_id, scene_id, type)

关键字段:
- type: overview(概览)/detail(详情)，允许空串（apm/kubernetes/alert 场景被 validate_scene_type 置空）
- mode: SceneViewType 枚举 auto(平铺)/custom(自定义)，默认 auto
- variables/panels/list/order/options: 均为 JSONField，无 DB 层结构校验，合法性依赖序列化层和内置 JSON 骨架

mode 枚举值不一致高频坑:
- 模型层 SceneViewModel.mode 值为 auto
- 序列化层 SceneViewSerializer.mode 值为 tile
- UpdateSceneViewResource 使用 auto/custom
- 跨层处理时注意映射：DB auto ↔ API tile

排序更新不变量:
- SceneViewModel.update_order 用 @atomic + select_for_update 锁 SceneViewOrderModel 行
- 对 config 列表做移除/插入，避免并发下顺序错乱

序列化契约:
- SceneViewSerializer: 视图配置对外契约，字段与 SceneViewModel 基本对应
- variables 嵌套 RowSerializer（含 PanelSerializer）
- type 限 overview/detail，mode 限 tile/custom
- 面板输出结构由 Panel.to_dict 定义 {id,title,sub_title,targets,options,grid_pos}
