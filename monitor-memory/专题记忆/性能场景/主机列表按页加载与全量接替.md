【专题记忆｜主机列表按页加载与全量接替（PR #12574，2026-09-21 合入 master）】
- 资产路径：.module-experts/性能场景专家/（C0 已知坑、C1 新增契约、C2 新增流程、C5 决策 12~18）
- 一句话职责：把新版主机列表的首屏从「等全量主机+全量指标」中解耦，页级先出屏、全量与统计后台接替
- 三条链：页链（search_host_info 带 page/page_size 走 CMDB 端分页 + 本页 IDs 取 search_host_metric）；全量链（不带 page 的全量信息 + 全量指标，交给前端 Blob Worker 三级缓存计算）；卡片链（search_host_metric_stats 三张卡各自独立请求）
- 接替语义：全量算完后表格与统计卡片在同一轮 Vue 更新中一起替换，页级与单卡响应全部失效；全量失败仍可按页浏览
- 降级语义：全量未就绪期间前端禁用全局排序、过滤、置顶、跨页全选与全局搜索（依赖全量集合），已保存条件暂存、就绪后自动生效
- 高频坑：带 page 与不带 page 返回结构不同；统计 complete=false 时显示未知而不是 0（判据：duplicates 大于 0，或 id_count 与 ip_count 同时非 0，或 ip_count 非 0 且该主机 has_duplicate_ip）；分享列表接口只取一页做存在性校验，新增列表类分享接口必须登记 HOST_LIST_ACTIONS
- 关键代码位置：SearchHostInfoResource.perform_request → monitor_web/performance/resources.py:369；SearchHostMetricStatsResource → resources.py:684；build_host_stats_query、query_host_metric_stats → performance/host_metric_stats.py:17、67；GetHostPage、GetHostIdentities → api/cmdb/default.py:327、381；TopoTree.module_links_from_raw → api/cmdb/define.py:375；HostApiAuthChecker.params_check → bkmonitor/share/handler.py:291；useHostListData → webpack/src/trace/pages/host/composables/use-host-list-data.ts:56；Worker 三级缓存 → pages/host/workers/host-list.worker.raw.js
- 口径锚点：统计与列表共用 180 秒 instant 窗口与阈值 79.995（等价于 Python round(value,2) 大于等于 80）
- 检索触发词：主机列表慢 首屏优化 按页加载 页级加载 翻页卡顿 全量接替 统计卡片未知 主机列表排序不可用 search_host_metric_stats
