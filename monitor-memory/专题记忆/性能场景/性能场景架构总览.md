performance 模块是蓝鲸监控主机性能/拓扑/进程场景的后端聚合层，以 Django DRF Resource 形式对外暴露 6 个接口，内部通过 ThreadPool 线程池并行聚合 CMDB、Agent 状态、TSDB 性能指标、告警计数等多源数据。自身无持久化，models.py 已迁空。

- 符号: `HostPerformanceResource`、`SearchHostMetricResource`、`HostPerformanceDetailResource`、`HostTopoNodeDetailResource`、`TopoNodeProcessStatusResource`、`SearchHostInfoResource`、`PermissionMixin`
- 位置: `bkmonitor/packages/monitor_web/performance/resources.py`、`bkmonitor/packages/monitor_web/performance/views.py`

6 个 Resource 类:
1. HostPerformanceResource: 主机列表聚合（基础信息+性能指标+Agent状态+进程+告警），继承 CacheResource 走 HOST 缓存
2. HostPerformanceDetailResource: 单主机详情（基础信息+拓扑归属+Agent状态+业务名），无缓存
3. HostTopoNodeDetailResource: 拓扑节点详情（主机数+告警数+策略数+负责人）
4. TopoNodeProcessStatusResource: 拓扑节点下进程名列表（status 硬编码 UNKNOWN）
5. SearchHostInfoResource: 主机基础信息+模块拓扑链（无 IAM 权限）
6. SearchHostMetricResource: 指定主机实时指标（无缓存，支持时间范围）

权限模型:
- PermissionMixin 统一 VIEW_HOST 权限，5/6 个 ViewSet 继承
- SearchHostInfoViewSet 未继承 PermissionMixin，无 VIEW_HOST 权限约束

依赖关系:
- resource.cc.*: get_process_info/get_agent_status/get_host_performance_data/get_host_alarm_count/get_topo_strategy_count
- api.cmdb.*: get_host_by_topo_node/get_topo_tree/get_host_by_id/get_business/get_service_instance_by_topo_node/get_module
- 框架: core.drf_resource（Resource/CacheResource）、ThreadPool、CacheType、validate_bk_biz_id
