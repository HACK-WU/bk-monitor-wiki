HostTopoNodeDetailResource 聚合拓扑节点信息+下属主机数+告警数+策略数+负责人。TopoNodeProcessStatusResource 获取拓扑节点下进程名列表（status 硬编码置灰 UNKNOWN）。SearchHostInfoResource 获取主机基础信息+模块拓扑链。

- 符号: `HostTopoNodeDetailResource`、`TopoNodeProcessStatusResource`、`SearchHostInfoResource`、`get_module_info`、`PermissionMixin`
- 位置: `bkmonitor/packages/monitor_web/performance/resources.py`

HostTopoNodeDetailResource.perform_request:
- 入参: bk_biz_id/bk_obj_id/bk_inst_id
- 流程: api.cmdb.get_topo_tree().get_all_nodes_with_relation() 查节点 → api.cmdb.get_host_by_topo_node 查下属主机 → resource.cc.get_topo_strategy_count 查策略 → get_alarm_count 静态方法统计告警
- 返回: bk_obj_id/bk_inst_id/bk_obj_name/bk_inst_name/operator/bk_bak_operator/child_count/host_count/alarm_count/alarm_strategy
- child_count 逻辑: bk_obj_id==module 时取 len(hosts)，否则取 len(node.child)
- 风险: node 为 None 时 len(node.child) 会抛 AttributeError
- operator/bk_bak_operator 仅 module 类型有值

TopoNodeProcessStatusResource.perform_request:
- 入参: bk_biz_id/bk_obj_id/bk_inst_id
- 返回: list[dict]，每项含 status(固定 AGENT_STATUS.UNKNOWN)/ports([])/display_name(进程名)/protocol("")
- 进程按 bk_process_name 去重
- status 硬编码置灰，不查实时状态（设计如此非 bug）

SearchHostInfoResource.perform_request:
- 入参: bk_biz_id
- 返回: list[dict]，每项含 display_name/bk_host_id/bk_biz_id/bk_cloud_id/bk_cloud_name/bk_host_innerip/bk_host_outerip/bk_os_type/bk_os_name/region/bk_host_name/ignore_monitoring/is_shielding/module
- module 由 get_module_info 静态方法构造
- 无 IAM 权限（SearchHostInfoViewSet 未继承 PermissionMixin）
- ViewSet 有 gzip 压缩

SearchHostInfoResource.get_module_info (staticmethod, 跨类复用):
- 入参: bk_module_ids/topo_links
- 返回: list[dict]，每项含 id/bk_inst_id/bk_inst_name/topo_link/topo_link_display/bk_obj_name_map
- topo_link 和 topo_link_display 均 reversed（根节点在前）
- 被 HostPerformanceResource 跨类直接调用
