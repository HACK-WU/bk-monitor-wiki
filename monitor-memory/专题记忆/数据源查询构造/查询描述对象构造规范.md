查询描述对象由 data_source_class 实例化构造，传入 bk_biz_id/interval/metrics/table/group_by 参数。metrics 结构和 group_by 规范决定后续 to_unify_query_config 的 query_list 拼装。

- 符号: `DataSource`、`to_unify_query_config`、`TimeSeriesDataSource`
- 位置: `bkmonitor/bkmonitor/data_source/data_source/__init__.py`

data_source_class 实例化参数:
- bk_biz_id (int, 必填): 业务ID，用于租户空间解析
- interval (int, 可选): 聚合窗口秒数，如 180=3分钟；不传默认 1h
- metrics (list[dict], 必填): 指标列表，每项 {field, method, alias}
- table (str, 必填): 结果表ID，如 system.proc、system.cpu_summary
- group_by (list[str], 可选): 维度字段列表，分组聚合依据

metrics 字段详解:
- field (str): 真实指标名，来自 ResultTableField 中 tag=metric 的字段（如 cpu_usage_pct、load5）
- method (str): 聚合方法 AVG/SUM/COUNT/MAX/MIN 或 *_without_time 变体
- alias (str): 在 expression 中的引用名（如 A），用于关联计算

多指标示例:
metrics = [{field: cpu_usage_pct, method: AVG, alias: A0}, {field: mem_res, method: AVG, alias: A1}, {field: uptime, method: AVG, alias: A2}]
约束: 多 metrics 会被平铺为 query_list 多条目（各自独立 reference_name=a0~aN），适合需要关联计算（如 a0/a1）的场景，不是批量独立查询

group_by 规范:
- 来自 ResultTableField 中 tag=dimension 的字段
- 定义分组边界：不同 group 互相隔离，聚合在组内进行
- 常用维度字段: bk_host_id、bk_target_ip、bk_target_cloud_id、display_name、pid、username

to_unify_query_config 拼装规则:
- field_name = metric.field
- reference_name = (alias or field).lower()
- 方法映射: AVG → avg_over_time + mean；SUM → sum_over_time + sum 等
- table_id = data_label（如有）或 table 参数原始值
- driver = influxdb；time_field 默认 time
- keep_columns = [_time, reference_name, *group_by]
