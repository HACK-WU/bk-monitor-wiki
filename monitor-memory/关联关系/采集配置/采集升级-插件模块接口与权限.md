[强关联] 采集配置升级流程 与 插件管理模块（双向协作）
强度：必改——改插件升级信息接口（plugin_upgrade_info）或插件管理权限常量（MANAGE_AUTH/manage_plugin_v2），采集升级弹窗与权限复用点必须连带改；改采集升级流程，插件模块不用管；反之改插件管理被复用的组件（select-host/import-file/tag-switch），采集目标选择与参数表单必须连带改
原因：采集升级弹窗经插件模块的 pluginUpgradeInfo 拉取新版本参数后回填再走 collecting_config/upgrade 提交；采集 authority-map 的 PLUGIN_MANAGE_AUTH 直接 import 插件管理 MANAGE_AUTH；采集目标选择/参数表单复用插件组件；采集新增页 push plugin-add 制作插件后回跳采集新增，形成完整回路
