【决策记录｜Issue 与告警链路 查询条件无法构造时显式 match_none，不静默丢弃条件】
- 分类：接口契约
- 动机：避坑（条件被静默丢弃会返回业务范围内全量数据，用户以为过滤生效）
- 决策：全文检索场景下，词过短或过长且非枚举显示名时，显式返回 Q("match_none") 表示无命中
- 背景约束：ES 查询串在极端词长下无法构造有效 DSL；若返回无过滤则等价于全量
- 被否决方案：条件构造失败时忽略该条件继续查询，否决理由为代码注释「避免静默丢掉条件后返回业务范围内全量数据」
- 已知代价：用户遇到查什么都为空时会困惑（实际是条件被判定为无效），需前端配合提示
- 重新评估触发条件：调整最小与最大词长阈值；或改为向用户返回明确的条件无效错误
- 关联代码：全文检索构造分支 @ packages/fta_web/alert/handlers/base.py
- 证据来源：代码注释（词过短或过长且非枚举显示名：显式无命中，避免静默丢掉条件后返回业务范围内全量数据）
