【决策记录｜UnifyQuery 多数据源 query_dimensions 退化为全量拉取加 Python 侧去重】
- 分类：兼容处理
- 动机：可维护性（统一查询的维度查询接口只支持单数据源，多源场景需自行兜底）
- 决策：data_sources 多于一个时，query_dimensions 只取 dimension_field 的首个字段（列表入参降级），调用 query_data 拉取全量数据后在 Python 侧用 set 去重返回；单数据源且 supports_unify_query_dimensions 为真时才走 _query_dimensions_using_unify_query
- 背景约束：维度值查询需要后端聚合去重能力，多数据源联合查询下无法下推
- 被否决方案：无（未找到相关记录）
- 已知代价：全量拉取受 limit 截断影响，维度值可能不全；大数据量场景性能差
- 重新评估触发条件：统一查询后端支持多数据源维度查询；或出现维度下拉值不全的反馈
- 关联代码：UnifyQuery.query_dimensions @ unify_query/query.py
- 证据来源：代码实现（data_sources 长度大于 1 分支内 query_data 加 set 去重）；C0 已知问题条目
