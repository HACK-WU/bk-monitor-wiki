【决策记录｜页面权限与数据字段分层】
- 分类：架构设计
- 动机：无
- 决策：[推测] 本模块页面声明的 action 权限（MANAGE_ACTION_CONFIG / ALARM_GROUP_MANAGE_AUTH）其消费方是子树中的跨模块组件（套餐详情编辑按钮、告警组管理入口）；本模块自身页面/按钮的可编辑性由服务端数据字段 edit_allowed 驱动
- 背景约束：「内置规则组不可改」是服务端业务规则（与用户权限无关），无法用 action 权限表达
- 被否决方案：无
- 重新评估触发条件：后端将内置组保护改为按权限表达（如新增 action 类型）
- 关联代码：authority-map.ts、两个 page 壳的 authorityMixinCreate @ bkmonitor/webpack/src/monitor-pc/pages/alarm-dispatch/；跨模块消费方 set-meal-detail.tsx 与 strategy-config 的 alarm-group.tsx
- 证据来源：无直接证据，基于「authority-map 注释 + 本模块 @Inject('authority') 零消费（grep 实证）+ 跨模块组件消费 + edit_allowed 列表/配置双处独立判断」的结构推断
