【决策记录｜[推测] 场景视图内置视图国际化用单一 JSON 骨架 + 运行期递归翻译】
- 分类：技术选型（本条为推测，置信度低于其他条目，查询侧请降级使用）
- 动机：降本（10 类场景乘数十个视图，为每种语言维护 JSON 副本成本高）
- 决策：view_configs 下的 JSON 只维护一份，需要翻译的字符串写成 _(文本) 形式，由 _translate_config 递归替换为翻译结果，只翻译被 _(...) 包裹的字符串
- 背景约束：视图配置是嵌套 JSON（panels、targets、options 多层），翻译点分散在任意层级
- 被否决方案：无（未找到相关记录）
- 已知代价：约定隐式，新增 JSON 字段忘加 _(...) 包裹即不翻译
- 重新评估触发条件：新增内置视图字段未国际化的反馈累计 ≥ 2 次；或需要支持运行期切换语言（当前骨架缓存与翻译时机耦合）
