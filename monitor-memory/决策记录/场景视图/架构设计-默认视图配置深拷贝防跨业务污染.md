【决策记录｜场景视图默认视图配置必须深拷贝返回，防止跨业务污染】
- 分类：架构设计
- 动机：避坑（模块级常量 DEFAULT_HOST_ORDER 被原地 append 业务指标 → 上一业务看到的面板泄漏到下一业务请求）
- 决策：get_default_order 对 DEFAULT_HOST_ORDER / DEFAULT_PROCESS_ORDER 先 deepcopy 再加工返回；调用方 get_order_config 不再自行 copy，由被调方保证返回副本
- 背景约束：默认排序是模块级常量，而已上报指标需按 bk_biz_id 查 MetricListCache 动态追加，两者混合加工必须写副本而非原地修改
- 被否决方案：无（未找到相关记录）
- 重新评估触发条件：新增任何按业务动态追加面板或排序的加工点时，须检查是否对模块级常量做 deepcopy（验证：跨业务并发请求对比返回面板 id 集合是否串扰）
- 关联代码：get_default_order @ scene_view/builtin/host.py；get_order_config @ scene_view/builtin/host.py
- 证据来源：commit 58d27694cc（diff 明确把 DEFAULT_HOST_ORDER 改为 deepcopy 后加工，并修复 metrics.filter 未回赋值的失效调用）
