【决策记录】
- 分类：接口契约
- 动机：避坑：把查不准的结果渲染成 0，用户会误判为没有超阈值主机
- 决策：返回 complete=false、value=None 并带 reason（partial、invalid_result、ambiguous_identity）；身份歧义判据三条：duplicates 大于 0、id_count 与 ip_count 同时非 0、ip_count 非 0 且该主机 has_duplicate_ip；空 hosts 视为成功且为 0（complete=true）
- 背景约束：统计同时使用两套身份（CMDB bk_host_id 与 bk_target_ip 加云区域），CMDB 侧存在重复 IP 或身份映射漂移时无法可靠求交集
- 被否决方案：直接返回 0 或返回较小值：否决理由——会把不确定性伪装成确定结论
- 重新评估触发条件：UQ 侧支持身份 JOIN（代码注释：缺少当前 CMDB 映射 JOIN 时混合身份的交集无法可靠判断，保留未知）
