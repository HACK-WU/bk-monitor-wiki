【决策记录｜导入冲突五级分类与更新白名单】
- 分类：接口契约
- 动机：避坑：无差别允许更新插件会直接覆盖类型冲突/远程配置冲突/内容一致的包 → 不可逆覆盖
- 决策：导入冲突按 conflict_ids 分五级（1 版本不大于当前、2 插件类型冲突、3 远程采集配置项冲突、4 已关联 N 个采集配置、5 内容完全一致）；出现 2/3/5 时不展示更新插件入口（canIUpdatePlubin），只能创建插件；更新至现有插件（官方+超管）走 saveAndReleasePlugin
- 背景约束：冲突分级由后端 import_plugin 响应给出；导入结果需缓存（SET_PLUGIN_CONFIG）后由弹窗驱动分支
- 被否决方案：无（未找到记录）
- 重新评估触发条件：后端新增冲突类型或调整分级语义
- 关联代码：canIUpdatePlubin @ bkmonitor/webpack/src/monitor-pc/pages/plugin-manager/plugin-dialog-single.vue；handeFileSingel @ plugin-manager.vue
- 证据来源：代码注释（plugin-dialog-single.vue 明写冲突五级语义）；implementation/05-接口.md 契约示例 5
