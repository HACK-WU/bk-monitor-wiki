- 分类：架构设计
- 动机：避坑：请求期间无统一骨架 → 失败被看成空数据或一直 loading
- 决策：统计/列表/详情各分区各自展示骨架、失败可局部重试；同数据区只采纳最后一次请求（requestId+AbortController）；已有内容时刷新失败保留旧内容；列表 200ms 延迟才显示骨架（防短请求闪烁）
- 背景约束：列表常驻 5s 轮询，必须区分真的没数据与请求失败；统计与列表加载互不阻塞
