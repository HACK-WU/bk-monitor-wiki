【决策记录｜详情基础信息与目标查询隔离】
- 分类：架构设计
- 动机：避坑：基础信息读取先解析目标 → 拓扑解析依赖实时 Agent 状态 → 超时拖垮基础信息并致侧栏关闭
- 决策：基础信息接口跳过目标解析（with_target_info=false）；目标接口关闭拓扑/模板 Agent 查询；前端分别展示加载与错误，目标失败可单独重试、同配置已加载基础快照保留
- 背景约束：目标解析（实时 Agent 状态查询）是慢路径且可能超时；基础信息本不依赖它
- 被否决方案：无（commit 未记录备选）
- 重新评估触发条件：后端目标解析性能提升（实时 Agent 查询稳定快速）后可评估合并回单接口
- 关联代码：frontendCollectConfigDetail / frontendCollectConfigTargetInfo @ bkmonitor/webpack/src/monitor-api/modules/collecting.js；DetailRequest @ collector-detail/detail-request.ts
