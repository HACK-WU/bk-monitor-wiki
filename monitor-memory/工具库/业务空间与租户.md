业务数据、空间与租户工具集，提供嵌套字典取值、业务ID与空间UID互转、租户ID上下文管理及数据链路双业务ID获取等能力。

嵌套字典取值与空间/业务ID互转工具。
- 位置: `src/bk_monitor_base/metadata/utils/basic.py`
- 方法:
  - `getitems(obj, keys, default)`: 递归获取嵌套字典值（支持 `a.b.c` 点号路径）
  - `get_biz_id_by_space_uid(tenant_id, space_uid)`: space_uid → bk_biz_id（BKCC 类型直接解析，其他类型查 SpaceResource）
  - `get_space_uid_and_bk_biz_id_by_bk_data_id(tenant_id, bk_data_id)`: 根据 data_id 查询 space_uid 和 bk_biz_id

业务ID → space_uid 转换工具（带 lru_cache(2000)）。
- 符号: `bk_biz_id_to_space_uid(bk_biz_id)`
- 位置: `src/bk_monitor_base/metadata/utils/space.py`
- 说明: 正数 → `bkcc__{id}`，负数 → 查 Space 表

租户ID上下文与业务ID/空间UID到租户ID的转换工具。
- 位置: `src/bk_monitor_base/metadata/utils/tenant.py`
- 方法:
  - `set_local_tenant_id(tenant_id)` / `get_local_tenant_id()`: 线程本地租户ID上下文
  - `space_uid_to_bk_tenant_id(space_uid)`: space_uid → tenant_id（@lru_cache(10000)）
  - `bk_biz_id_to_bk_tenant_id(bk_biz_id)`: 业务ID → tenant_id（@lru_cache(10000)）
  - `get_tenant_default_biz_id(tenant_id)`: 获取租户默认业务ID（查变量系统）
  - `get_tenant_datalink_biz_id(tenant_id, bk_biz_id)`: 返回数据链路双业务ID（label_biz_id + data_biz_id）

根据业务ID查询预计算结果表列表及字段/Option信息。
- 符号: `get_record_rule_metrics_by_biz_id(bk_biz_id)`
- 位置: `src/bk_monitor_base/metadata/utils/data_link.py`

获取租户ID的正确方式：

不要用 `get_request_tenant_id()`，它在标准 Django 请求中不可靠（`request.user.tenant_id` 不保证存在，`local.bk_tenant_id` 中间件未设置）。

推荐用 `bk_biz_id_to_bk_tenant_id(bk_biz_id)`，从业务ID反查租户ID。`bk_biz_id` 在 Resource 框架中基本都有，比 `request.user.tenant_id` 可靠得多。

详细踩坑记录见 `项目踩坑点/get_request_tenant_id 在标准请求中不安全`。
