哈希与一致性哈希工具集，提供一致性哈希环、MD5 计算、callable 哈希、bkdata 表名生成及 IPv6 业务判断等能力。

一致性哈希环，支持加权虚拟节点与二分查找定位。
- 符号: `HashRing(nodes, num_vnodes=2**16)`
- 位置: `src/bk_monitor_base/metadata/utils/hashring.py`
- 方法:
  - `_hash(key)`: 基于 MD5 的 32 位哈希
  - `get_node(key)`: 二分查找（bisect_left）定位节点
  - 支持加权虚拟节点（自动计算 multiple）

MD5 计算、callable 哈希、bkdata 表名生成及 IPv6 业务判断等通用哈希工具。
- 位置: `src/bk_monitor_base/metadata/utils/tools.py`
- 方法:
  - `count_md5(content, dict_sort=True, list_sort=True)`: 计算 MD5（递归处理 dict/list）
  - `make_callable_hash(content)`: 计算 callable 的 hash（支持类属性聚合）
  - `is_ipv6_biz(bk_biz_id)`: 判断业务是否支持 IPv6
  - `gen_bk_data_rt_id_without_biz_id(table_id)`: 截取 32 字节 bkdata 表名
  - `to_bk_data_rt_id(table_id, suffix=None)`: 生成带业务 ID 的 bkdata 表名

哈希计算辅助工具（具体提供方需查阅源码）。
- 位置: `src/bk_monitor_base/metadata/utils/hash_util.py`
