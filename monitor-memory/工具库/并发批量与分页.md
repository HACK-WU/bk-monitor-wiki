### 并发与批量处理工具

**文件**: `src/bk_monitor_base/metadata/utils/api_request.py`
- `bulk_request(api_func, request_data_iterable, ignore_exceptions=False)`: 多线程批量并发请求
  - 使用 `ThreadPool` + `apply_async`
  - 支持忽略单个异常（但全部报错仍会抛出第一个异常）
  - 返回值按输入顺序返回

**文件**: `src/bk_monitor_base/metadata/utils/db.py`
- `array_group(data, key, group=0)`: 数组按 key 分组（支持去重或聚合）
- `array_chunk(data, size=100)`: 数组分块
- `filter_model_by_in_page(model, field_op, filter_data, page_size=500)`: 分页 IN 查询，避免一次性超大 IN 导致 DB 锁
  - 支持 `values` / `values_list` 输出格式
  - 支持附加过滤条件

**文件**: `src/bk_monitor_base/metadata/utils/serializers.py`
- `TenantIdField(serializers.CharField)`: DRF 字段，自动从请求获取租户ID补全空值
