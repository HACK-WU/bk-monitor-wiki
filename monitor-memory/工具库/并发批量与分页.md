并发与批量处理工具集，提供多线程批量请求、数组分组/分块、分页 IN 查询及 DRF 租户ID字段等能力。

多线程批量并发请求工具。
- 符号: `bulk_request(api_func, request_data_iterable, ignore_exceptions=False)`
- 位置: `src/bk_monitor_base/metadata/utils/api_request.py`
- 说明:
  - 使用 `ThreadPool` + `apply_async`
  - 支持忽略单个异常（但全部报错仍会抛出第一个异常）
  - 返回值按输入顺序返回

数组分组、分块与分页 IN 查询工具。
- 位置: `src/bk_monitor_base/metadata/utils/db.py`
- 方法:
  - `array_group(data, key, group=0)`: 数组按 key 分组（支持去重或聚合）
  - `array_chunk(data, size=100)`: 数组分块
  - `filter_model_by_in_page(model, field_op, filter_data, page_size=500)`: 分页 IN 查询，避免一次性超大 IN 导致 DB 锁
    - 支持 `values` / `values_list` 输出格式
    - 支持附加过滤条件

DRF 租户ID字段，自动从请求获取租户ID补全空值。
- 符号: `TenantIdField(serializers.CharField)`
- 位置: `src/bk_monitor_base/metadata/utils/serializers.py`
