业务时区时间处理工具集，支持时区转换、时间范围解析、格式化、时间戳互转、时间对齐等常用操作。

- 位置: `src/bk_monitor_base/metadata/utils/time_tools.py`
- 方法:
  - `now()` / `now_str(format)`: 当前时间（带业务时区）
  - `localtime(value)` / `utc2localtime(utc_time)`: 时区转换
  - `timestamp2datetime(timestamp)`: 时间戳转 datetime
  - `biz_time_zone_offset()`: 业务时区偏移量（小时精度）
  - `biz2utc_str(local_time)` / `utc2biz_str(utc_time)`: 业务时间与 UTC 互转
  - `gen_default_time_range(days=1, offset=0)`: 生成默认业务日期范围
  - `parse_time_range(time_range)`: 解析前端传来的时间范围 → UTC 时间戳
  - `date_convert(_date, _format)`: 万能时间格式转换（str/datetime/utc/int）
  - `get_timestamp_range_by_biz_date(date)`: 日期字符串 → 时间戳范围
  - `get_datetime_range(period, distance)`: 按 period(minute/hour/day) 生成时间范围
  - `hms_string(sec_elapsed)`: 秒数 → 人类可读格式（1d 12h 3m）
  - `parse_time_compare_abbreviation(time_offset)`: 支持 1d/0.5m/-5w 简写转秒
  - `time_interval_align(timestamp, interval)`: 时间对齐（考虑时区偏移）
