外部组件连接工具集，提供 Consul 客户端封装、ES 客户端创建、InfluxDB 连接、ES Curator 运维及 bk-collector 配置下发等能力。

Consul 客户端封装，自动适配 Django settings 中的 consul 配置。
- 符号: `BKConsul(consul.Consul)` / `is_file_exists(file_path)`
- 位置: `src/bk_monitor_base/metadata/utils/consul.py`
- 说明:
  - 自动处理 TLS 证书（client_cert, client_key, server_cert）
  - 自动切换 http → https 并调整端口
  - 127.0.0.1 自动转换为 localhost（绕过 Python SSL SNI 问题）
  - `is_file_exists(file_path)`: 安全的文件存在判断

Consul 工具函数补充（与 consul.py 配套使用）。
- 位置: `src/bk_monitor_base/metadata/utils/consul_tools.py`

ES 客户端创建与运维工具，支持多版本适配与重试策略。
- 位置: `src/bk_monitor_base/metadata/utils/es_tools.py`
- 方法:
  - `compose_es_hosts(host, port)`: 组装 ES host 字符串（兼容 IPv6）
  - `get_client_by_datasource_info(datasource_info)`: 根据数据源信息创建 ES 客户端
    - 自动适配 ES 5.x/6.x/7.x 版本
    - 支持 SSL 身份验证
    - 支持 host 级别的超时配置
  - `get_client(bk_tenant_id, cluster_id)`: 通过 ClusterInfo Model 获取 ES 客户端
  - `get_cluster_disk_size(es_client)`: 获取集群磁盘分配总量
  - `es_retry_session(es_client, retry_num, backoff_factor)`: 为 ES 客户端注入请求重试策略（指数退避）

InfluxDB 连接与查询工具。
- 位置: `src/bk_monitor_base/metadata/utils/influxdb_tools.py`

Elasticsearch Curator 运维工具（索引生命周期管理）。
- 位置: `src/bk_monitor_base/metadata/utils/es_curator.py`

bk-collector 配置生成与下发工具。
- 位置: `src/bk_monitor_base/metadata/utils/bk_collector_config.py`
