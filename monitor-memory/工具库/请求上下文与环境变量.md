线程本地存储与请求上下文工具集，提供线程/Greenlet 本地存储、请求对象获取、租户ID/用户名获取及环境变量列表读取等能力。必须使用 `bkmonitor/bkmonitor/utils/` 下的工具，禁止使用 `bk-monitor-base` 中的同名工具，否则会导致 `get_request(): current thread hasn't request` 错误。

线程/Greenlet 本地存储与请求上下文管理器。
- 符号: `Local(Localbase)` / `local` / `with_request_local()` / `with_client_user(username)` / `with_client_operator(update_user)`
- 位置: `bkmonitor/bkmonitor/utils/local.py`
- 说明:
  - `local = Local()`: 全局线程本地实例（被 RequestProvider 中间件正确设置）
  - `with_request_local()`: 上下文管理器，临时清除 operator/username/current_request 并恢复
  - `with_client_user(username)`: 上下文管理器，设置 username
  - `with_client_operator(update_user)`: 上下文管理器，设置 operator

从当前请求获取租户ID、用户名、用户对象、request 对象及 space_uid。
- 位置: `bkmonitor/bkmonitor/utils/request.py`
- 方法:
  - `get_request_tenant_id(peaceful=True)`: 从当前请求获取租户ID
  - `get_request_username()`: 从当前请求获取用户名
  - `get_request_user()`: 获取当前请求用户对象
  - `get_request()`: 获取当前 Django request 对象
  - `get_space_uid()`: 从请求中获取 space_uid

按数字编号获取环境变量列表。
- 符号: `get_env_list(env_prefix)`
- 位置: `bkmonitor/bkmonitor/utils/env.py`
- 用法: `get_env_list("IP")` → 读取 `IP0`, `IP1`, ... `IPn`, 返回数组

用户信息相关辅助函数。
- 位置: `bkmonitor/bkmonitor/utils/user.py`

错误导入（禁止使用）：

```python
# 错误：bk_monitor_base 的 Local 从未被中间件设置
from bk_monitor_base.metadata.utils.local import local
from bk_monitor_base.metadata.utils.request import get_request, get_request_username

# 正确：使用 bkmonitor 的工具
from bkmonitor.utils.local import local
from bkmonitor.utils.request import get_request, get_request_username
```
