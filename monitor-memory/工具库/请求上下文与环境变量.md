### 线程本地存储与请求上下文

**文件**: `src/bk_monitor_base/metadata/utils/local.py`
- `Local(Localbase)`: 线程/Greenlet 本地存储（兼容 greenlet）
  - 自动通过 `get_ident` 隔离不同线程数据
  - `local.attr = xxx` 自动按线程隔离
  - `local.clear()`: 清除当前线程数据
- `local = Local()`: 全局线程本地实例
- `with_request_local()`: 上下文管理器，临时清除 operator/username/current_request 并恢复
- `with_client_user(username)`: 上下文管理器，设置 username
- `with_client_operator(update_user)`: 上下文管理器，设置 operator

**文件**: `src/bk_monitor_base/metadata/utils/request.py`
- `get_request_tenant_id(peaceful=True)`: 从当前请求获取租户ID
- `get_request_username()`: 从当前请求获取用户名
- `get_request_user()`: 获取当前请求用户对象
- `get_request()`: 获取当前 Django request 对象
- `get_space_uid()`: 从请求中获取 space_uid

**文件**: `src/bk_monitor_base/metadata/utils/env.py`
- `get_env_list(env_prefix)`: 获取按数字编号的环境变量列表
  - 例：`get_env_list("IP")` → 读取 `IP0`, `IP1`, ... `IPn`, 返回数组

**文件**: `src/bk_monitor_base/metadata/utils/user.py`
- 用户信息相关辅助函数
