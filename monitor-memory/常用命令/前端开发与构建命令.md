运行 bkmonitor/webpack 前端开发、构建与辅助脚本的命令速查（均在 bkmonitor/webpack 下执行）。
- 环境：Node >= 20.17.0（团队实测 v22），pnpm 10.x（preinstall 强制 only-allow pnpm）；nvm use 后 pnpm i（等价 make deps）
- 启动主应用：pnpm dev 或 pnpm pc:dev 或 make dev-pc，占 7001，只启动 monitor-pc
- 启动子应用（另开终端，占 7002，一次只能一个）：pnpm trace:dev 或 make dev-vue3（trace）；pnpm apm:dev 或 make dev-apm；pnpm fta:dev 或 make dev-fta
- 独立入口：pnpm mobile:dev 或 make dev-mobile（移动端）；pnpm external:dev 或 make dev-external（外部应用）
- 构建：pnpm build 或 make build（run-p 并行构建 6 个应用）；make prod（build + clean + move 到 ../static/）；单模块 make build-pc / build-vue3 / build-apm / build-fta / build-mobile / build-external；make build-s 串行构建；产物分析 make vis-pc / vis-vue3 等
- 嵌入式 Vite 库：pnpm build:alarm-center / build:trace-explore / build:vue3-components / build:vue2-components
- dev server 辅助脚本：node .codebuddy/skills/bkmonitor-dev-server/scripts/setup-config.js（生成或检查 local.settings.js，无参输出 CONFIG_VALID 或 CONFIG_INVALID:<原因>）；sync-local-auth.js（刷新 Cookie 与 X-CSRFToken，--dry-run 只检查）；check-env.sh（检查 Node / pnpm）
- 回归用例：bkmonitor/webpack/tests/ 下有 29 个 node:test 用例（*.test.cjs 26 个、*.test.mjs 3 个），用 node --test 直接跑，秒级且无需起 dev server；改动命中时优先跑对应文件
- 端口排查：lsof -i:7001 -i:7002 确认两个进程都在监听
- 注意：dev server、构建、批量 lint / format 修复执行前需用户授权；只读侦察（git status / diff / log、rg、ls）可直接跑
- 检索触发词：pnpm dev, make dev-pc, make dev-vue3, 构建命令, dev server 脚本, 端口排查, 前端常用命令, node --test
