BK-Monitor 技术栈清单：主语言 Python，Web 框架 Django（单体架构），数据分析使用 duckdb 嵌入式 SQL，Embedding/Reranker 模型使用 SiliconFlow。

| 类别 | 技术 |
|------|------|
| 主语言 | Python |
| Web 框架 | Django（单体架构） |
| 数据分析 | duckdb（嵌入式 SQL 查询分析） |
| Embedding 模型 | SiliconFlow Qwen/Qwen3-Embedding-8B（4096维） |
| Reranker 模型 | SiliconFlow Qwen/Qwen3-Reranker-8B |
| Python 环境 | `/root/bk-monitor/bkmonitor/.venv/bin/python` |
