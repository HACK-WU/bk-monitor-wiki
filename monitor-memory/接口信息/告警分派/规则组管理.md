【接口信息｜规则组管理】
- 子功能：规则组管理
- 所属模块：告警分派（前端 monitor-pc）
- 接口列表：
  - GET fta/assign/rule_groups/ → listAssignGroup @ bkmonitor/webpack/src/monitor-api/modules/model.js：规则组列表（全量；响应字段 id/name/priority/edit_allowed/update_time/update_user/settings.public_conditions）；调用点 列表页与配置页 getAlarmDispatchGroupData
  - POST fta/assign/rule_groups/ → createAssignGroup @ 同上：新建规则组（{name, priority}，响应 id 用于跳转配置页）；调用点 alarm-dispatch.tsx handleAddAlarmDispatchGroup
  - PATCH fta/assign/rule_groups/{pk}/ → partialUpdateAssignGroup @ 同上：更新组名或优先级（单字段，列表页行内编辑即时落库）；调用点 alarm-dispatch.tsx handleBatchEditSubmit
  - DELETE fta/assign/rule_groups/{pk}/ → destroyAssignGroup @ 同上：删除规则组（组内规则连带删除，不可恢复）；调用点 debugging-result.tsx handleSave（仅「调试并删除」链，禁止直接调用）
  - 注：retrieveAssignGroup / updateAssignGroup / create·update·partialUpdate·destroy·retrieveAssignRule 共 7 个规则级端点前端零调用（已全前端 grep 实证），规则编辑统一走整组 batchUpdate
