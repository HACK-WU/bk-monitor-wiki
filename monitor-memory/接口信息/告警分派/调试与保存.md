【接口信息｜调试与保存】
- 子功能：调试与保存（效果调试三态与整组提交）
- 所属模块：告警分派（前端 monitor-pc）
- 接口列表：
  - POST fta/assign/rule_operate/match_debug/ → matchDebug @ bkmonitor/webpack/src/monitor-api/modules/assign.js：规则匹配调试（预览命中告警）；入参=提交体+{start_time,end_time} 或 {exclude_groups}+时间窗；响应 [{group_id, group_name, priority, alerts_count, rules[{user_groups,conditions,is_enabled,is_changed,alerts[{id,severity,alert_name,metrics,content}]}]}]；只取时间窗内前 1000 条；调用点 debugging-result.tsx getRuleMatchDebug
  - POST fta/assign/rule_operate/batch_update/ → batchUpdate @ 同上：整组保存生效（配置页「调试并生效」唯一保存路径）；入参=同一份 debugData（{bk_biz_id, assign_group_id, priority, group_name, rules[由 RuleData.getSubmitParams 生成], settings:{public_conditions}}）；调用点 debugging-result.tsx handleSave
- 关键契约：matchDebug 与 batchUpdate 必须使用同一份 debugData（源码注释「此为调试数据，保存时也用此数据」）；itsm 动作无 action_id 时被过滤不提交
