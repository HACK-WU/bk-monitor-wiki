- 子功能：前端展示
- 所属模块：告警屏蔽
- 路由：ShieldViewSet @ packages/monitor_web/shield/views.py（权限 VIEW_DOWNTIME）
- 接口列表：
  - POST frontend_shield_list → FrontendShieldListResource @ packages/monitor_web/shield/resources/frontend_resources.py：前端屏蔽列表（category_name/status_name/shield_cycle 等展示增强，内存模糊搜索，ThreadPoolExecutor 20 线程富化）
  - GET frontend_shield_detail → FrontendShieldDetailResource @ 同上：前端屏蔽详情（把 dimension_config 中的 ID 翻译为服务实例名/拓扑路径/动态分组名）

  - GET frontend_clone_info → FrontendCloneInfoResource @ 同上：克隆信息（取创建新屏蔽所需的完整配置）
