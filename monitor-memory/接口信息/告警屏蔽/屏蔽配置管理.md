【接口信息｜屏蔽配置管理】
- 子功能：屏蔽配置管理（CRUD）
- 所属模块：告警屏蔽
- 路由：ShieldViewSet @ packages/monitor_web/shield/views.py，ResourceRouter 注册 @ shield/urls.py（挂载于 monitor_web/urls.py）；权限按 action 分级——查询类 VIEW_DOWNTIME，管理类 MANAGE_DOWNTIME
- 接口列表：
  - POST shield_list → ShieldListResource @ packages/monitor_web/shield/resources/backend_resources.py：通用屏蔽列表查询（多条件过滤 + 分页）
  - GET shield_detail → ShieldDetailResource @ 同上：按 ID 查询单条屏蔽详情（返回原始字段）
  - POST add_shield → AddShieldResource @ 同上：新增屏蔽，支持 5 种 category + end_policy（notify_once/close）
  - POST bulk_add_alert_shield → BulkAddAlertShieldResource @ 同上：批量为多个告警创建屏蔽（带 bk_topo_node 时自动降级为 scope）
  - POST edit_shield → EditShieldResource @ 同上：编辑屏蔽（仅时间/周期/通知/描述/等级/标签，不可改维度；end_policy 不可修改）
  - POST disable_shield → DisableShieldResource @ 同上：解除屏蔽（置 is_enabled=False + failure_time=now，非即时生效）
