【接口信息｜快捷屏蔽】
- 子功能：快捷屏蔽
- 所属模块：告警屏蔽（独立 ViewSet，不在 ShieldViewSet 中）
- 接口列表：
  - POST quick_shield → QuickShield @ packages/weixin/event/resources.py：移动端快速屏蔽事件（type=scope/strategy/event，注册在 EventViewSet，NoCsrfSessionAuthentication 绕 CSRF，返回 JSON {id}）
  - GET alert/quick_shield → QuickAlertShield @ packages/fta_web/alert/resources.py：通知链接快捷屏蔽告警（注册在 QuickAlertHandleViewSet，QuickActionTokenResource 验 token，默认屏蔽 3 小时，PlainTextRenderer 返回重定向 HTML 或纯文本统计）
  - GET alert/quick_ack → QuickAlertAck @ 同上：通知链接快捷确认告警
- 关键契约：三者最终都调用 resource.shield.add_shield（AddShieldResource）；快捷入口不传 end_policy，走默认 notify_once（传 close 会被序列化器拒绝）；quick_shield 跳过 AlertDocument.is_shielded 更新、重复检查与通知处理
