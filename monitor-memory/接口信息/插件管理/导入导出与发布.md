【接口信息｜导入导出与发布】
- 子功能：导入导出与发布
- 所属模块：插件管理（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/collector_plugin/import_plugin/ → importPluginCollectorPlugin @ bkmonitor/webpack/src/monitor-api/modules/model.js：导入 .gz/.tgz（file_data 自动转 FormData），返回 conflict_ids 1~5 分级；调用点 plugin-manager.vue handeFileSingel/handleFileMultiple
  - GET rest/v2/collector_plugin/{pk}/export_plugin/ → exportPluginCollectorPlugin @ 同上：导出（返回 download_url → downFile）
  - POST rest/v2/collector_plugin/{pk}/release/ → releaseCollectorPlugin @ 同上：发布（两阶段提交第二阶段，参数 {config_version, info_version, token}）；调用点 step-set-done.vue / metric-dimension-dialog.tsx / indicator-dimension/utils.ts
  - POST rest/v2/save_and_release_plugin/ → saveAndReleasePlugin @ bkmonitor/webpack/src/monitor-api/modules/plugin.js：保存并直接发布（导入官方/安全插件、更新至现有插件）
