【接口信息｜指标与维度】
- 子功能：指标与维度
- 所属模块：插件管理（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/metric_plugin/save/ → saveMetric @ bkmonitor/webpack/src/monitor-api/modules/plugin.js：保存 metric_json（两阶段第一阶段，返回 {token?, config_version, info_version}；含 token 必须补 release）；三条编辑器路径共用
  - GET rest/v2/strategies/get_unit_list/ → getUnitList @ bkmonitor/webpack/src/monitor-api/modules/strategies.js：指标单位列表；调用点 v1/v2 指标编辑器
  - GET rest/v2/get_reserved_word/ → getReservedWord @ plugin.js：保留关键字（命名校验，RT_RESERVED_WORD_EXACT）；store 缓存 reservedWords
  - GET rest/v2/commons/get_label/ → getLabel @ commons.js：插件标签树（include_admin_only:false）
  - POST rest/v2/data_dog_plugin/ → dataDogPluginUpload @ plugin.js：DataDog check 包上传；调用点 upload.vue
