【接口信息｜插件列表与详情】
- 子功能：插件列表与详情
- 所属模块：插件管理（前端 monitor-pc）
- 接口列表：
  - GET rest/v2/collector_plugin/ → listCollectorPlugin @ bkmonitor/webpack/src/monitor-api/modules/model.js：插件列表（分页/搜索/标签/排序），返回 {count, list}；调用点 plugin-manager.vue
  - GET rest/v2/collector_plugin/{pk}/ → retrieveCollectorPlugin @ 同上：插件详情（pk=plugin_id）；调用点 plugin-info.vue / step-set-plugin.vue / 指标编辑器
  - GET rest/v2/collector_plugin/check_id/ → checkIdCollectorPlugin @ 同上：插件 ID 可用性校验；调用点 step-set-plugin.vue
  - GET rest/v2/collector_plugin/tag_options/ → tagOptionsCollectorPlugin @ 同上：标签选项；调用点 plugin-manager.vue
  - GET rest/v2/collector_plugin/operator_system/ → operatorSystemCollectorPlugin @ 同上：操作系统列表；调用点 store getOsList
