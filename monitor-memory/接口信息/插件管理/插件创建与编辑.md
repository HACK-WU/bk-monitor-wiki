【接口信息｜插件创建与编辑】
- 子功能：插件创建与编辑
- 所属模块：插件管理（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/collector_plugin/ → createCollectorPlugin @ bkmonitor/webpack/src/monitor-api/modules/model.js：新建插件；调用点 step-set-plugin.vue
  - POST rest/v2/collector_plugin/{pk}/edit/ → editCollectorPlugin @ 同上：编辑插件（步骤1 保存 / 列表行内改标签）
  - POST rest/v2/collector_plugin/delete/ → deleteCollectorPlugin @ 同上：批量删除（plugin_ids 数组）；调用点 plugin-manager.vue
  - POST rest/v2/collector_plugin/upload_file/ → uploadFileCollectorPlugin @ 同上：上传采集器文件（Exporter）；调用点 upload.vue
  - 未使用预留：destroyCollectorPlugin / partialUpdateCollectorPlugin / updateCollectorPlugin / replacePluginCollectorPlugin / pluginImportWithoutFrontendCollectorPlugin（仅定义无调用点）
