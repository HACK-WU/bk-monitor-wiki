【接口信息｜注册与调试】
- 子功能：注册与调试
- 所属模块：插件管理（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/register_plugin/ → pluginRegister @ bkmonitor/webpack/src/monitor-api/modules/plugin.js：注册插件（异步任务，config 传 isAsync:true）；调用点 step-set-plugin.vue
  - GET rest/v2/commons/query_async_task_result/ → queryAsyncTaskResult @ bkmonitor/webpack/src/monitor-api/modules/commons.js：异步任务轮询（1.5s，is_completed/state/data.token）
  - POST rest/v2/collector_plugin/{pk}/start_debug/ → startDebugCollectorPlugin @ model.js：启动调试（返回 task_id）；调用点 step-set-test.vue
  - GET rest/v2/collector_plugin/{pk}/fetch_debug_log/ → fetchDebugLogCollectorPlugin @ 同上：调试日志（2s 轮询，timeOut>180 自动 stopDebug）
  - POST rest/v2/collector_plugin/{pk}/stop_debug/ → stopDebugCollectorPlugin @ 同上：停止调试
  - POST rest/v2/commons/host_agent_status/ → hostAgentStatus @ commons.js：调试目标主机 Agent 状态
