【接口信息｜列表与统计】
- 子功能：列表与统计
- 所属模块：采集配置（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/collecting_config/config_list/ → collectConfigList @ bkmonitor/webpack/src/monitor-api/modules/collecting.js：采集配置列表（搜索/分页/refresh_status 强制刷新状态）；返回 {config_list, total, type_list}；调用点 collector-config.vue
  - GET rest/v2/collecting_config/fetch_collect_config_stat/ → fetchCollectConfigStat @ 同上：顶部统计（类型×状态计数，type_list 形态）；调用点 collector-config.vue；失败走页面级 statsError 不弹窗
  - POST rest/v2/collecting_config/rename/ → renameCollectConfig @ 同上：重命名配置；调用点 collector-config-detail.vue / collector-configuration.tsx
