【接口信息｜新建与下发】
- 子功能：新建与下发
- 所属模块：采集配置（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/collecting_config/save/ → saveCollectConfig @ bkmonitor/webpack/src/monitor-api/modules/collecting.js：保存配置（保存即触发下发；operation=ADD_DEL 为增删目标增量模式）；调用点 config-select.vue / config-delivery.vue / bk-host.vue
  - POST rest/v2/collecting_config/check_plugin_version/ → checkPluginVersion @ 同上：进程采集保存前插件版本校验，result=false 时弹窗列出低版本主机（可强制继续）；调用点 config-select.vue / bk-host.vue
  - POST rest/v2/collecting_config/is_task_ready/ → isTaskReady @ 同上：部署任务是否就绪（下发表格前置门闩，调用方 2s 递归重试永不 reject）；5 处调用 config-delivery / config-deploy / target-table / collector-status-details / stop-start-host
  - POST rest/v2/collecting_config/rollback/ → rollbackDeploymentConfig @ 同上：回滚本次下发；调用点 target-table.vue / config-delivery.vue / stop-start-host.vue
  - GET rest/v2/collecting_config/get_collect_variables/ → getCollectVariables @ 同上：变量提示数据；调用点 config-set.vue / variable-table.vue
