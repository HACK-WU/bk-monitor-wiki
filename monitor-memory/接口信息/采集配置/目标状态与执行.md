  - GET rest/v2/collecting_config/status/ → collectTargetStatus @ bkmonitor/webpack/src/monitor-api/modules/collecting.js：目标级状态与下发内容（10s 进度轮询主接口）；调用点 target-table / config-delivery / stop-start-host / collector-dialog-delete
