【接口信息｜配置管理】
- 子功能：配置管理
- 所属模块：采集配置（前端 monitor-pc）
- 接口列表：
  - POST rest/v2/collecting_config/toggle/ → toggleCollectConfigStatus @ bkmonitor/webpack/src/monitor-api/modules/collecting.js：启用/停用（action=enable|disable，disable 异步需轮询观察进度）；调用点 stop-start-host.vue / collector-dialog-delete.vue
  - POST rest/v2/collecting_config/upgrade/ → upgradeCollectPlugin @ 同上：插件版本升级（与启停共用流程壳）；调用点 stop-start-host.vue
  - POST rest/v2/collecting_config/delete/ → deleteCollectConfig @ 同上：删除配置；调用点 collector-dialog-delete.vue（真实路径）
  - POST rest/v2/collecting_config/list_related_strategy/ → listRelatedStrategy @ 同上：关联策略查询（精准/模糊两档），删除弹层提示并可勾选级联删除；调用点 collector-dialog-delete.vue
