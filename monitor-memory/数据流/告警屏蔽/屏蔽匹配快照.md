【数据流｜屏蔽匹配快照（Redis）】
- 实体类型：缓存（Redis string）
- 结构：key = ALERT_SHIELD_SNAPSHOT.get_key(strategy_id=..., alert_id=...)，value = 该告警命中的屏蔽配置 ID 列表（JSON 字符串），TTL = ALERT_SHIELD_SNAPSHOT.ttl
- 生产方：AlertShieldConfigShielder.set_shield_objs_cache @ converge/shield/shielder/saas_config.py（首次匹配完成后写入）
- 主要消费方：AlertShieldConfigShielder.get_shield_objs_from_cache（命中则直接返回，不再遍历屏蔽配置）
- 业务用途：避免每轮告警检测重复遍历全部屏蔽配置；无策略的第三方告警（strategy_id 为空）不缓存
- 详细流向：见 .module-experts/告警屏蔽专家/implementation/03-数据流转.md
