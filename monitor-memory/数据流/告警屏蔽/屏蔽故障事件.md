【数据流｜屏蔽故障事件（Redis Hash）】
- 实体类型：缓存（Redis Hash）
- 结构：key = CACHE_KEY_PREFIX.shield.failure.{module}，field = target，value = expected_end_timestamp（预期故障结束时间戳）
- 生产方：ShieldCacheManager.publish_failure @ alarm_backends/core/cache/shield.py（由 alarm_backends/service/alert/qos/influence.publish_failure 调用，入口为 kernel_api FailureResource @ kernel_api/resource/qos.py）
- 主要消费方：IncidentShielder（经 get_failure_scope_config → get_all_failures 取故障中 target）@ alert/qos/influence.py；clear_failure（get_last_failure_end 判断后发布 0 时长清除）
- 业务用途：故障（如采集/存储异常）期间对相关 target 的告警做屏蔽，避免故障期噪声告警
- 详细流向：见 .module-experts/告警屏蔽专家/implementation/03-数据流转.md
