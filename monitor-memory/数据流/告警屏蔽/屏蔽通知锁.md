【数据流｜屏蔽通知锁（Redis）】
- 实体类型：缓存（Redis string，锁）
- 结构：key = NOTICE_SHIELD_KEY_LOCK.get_key(shield_id=...)，value = "__lock__"，TTL = NOTICE_SHIELD_KEY_LOCK.ttl
- 生产方：ShieldObj.check_and_send_notice @ converge/shield/shield_obj.py（开始通知前 SET，结束通知发出后 DELETE）
- 主要消费方：ShieldObj.can_send_start_notice（有锁则只续期不再发）、can_send_end_notice（无锁直接返回 False，即只有发过开始通知的屏蔽才可能发结束通知）
- 业务用途：屏蔽开始/结束通知的幂等控制（各只发一次）；注意幂等仅在 ShieldObj 层，调度层分片/多实例并发未加锁（tasks.py 留有 TODO）
