【数据流｜屏蔽配置缓存（Redis）】
- 实体类型：缓存（Redis string）
- 结构：key = CACHE_KEY_PREFIX.shield.biz_{bk_biz_id}；value = 该业务生效屏蔽配置的 JSON 列表（extended_json 序列化，每条为 Shield 全字段 dict，含 end_policy），TTL = CACHE_TIMEOUT
- 生产方：ShieldCacheManager.refresh @ alarm_backends/core/cache/shield.py（过滤 begin_time <= now+10min 且 end_time >= now 且 is_enabled=True；按业务 pipeline 写入；无屏蔽的业务删 key）
- 主要消费方：AlertShieldConfigShielder（引擎屏蔽判定，经 get_shields_by_biz_id）@ converge/shield/shielder/saas_config.py；CloseShieldMatcher（筛 end_policy=close 候选）@ converge/shield/close.py
- 业务用途：引擎侧避免每条告警查 MySQL；预取 10 分钟让即将生效的屏蔽提前进缓存（读取方必须自行校验时间）
- 详细流向：见 .module-experts/告警屏蔽专家/implementation/03-数据流转.md
