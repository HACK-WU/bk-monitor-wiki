【数据流｜指标维度定义】
- 实体类型：数据结构（metric_json，前端侧无持久化）
- 结构：分组数组 [{table_name, table_desc, rule_list, fields}]；fields 含 monitor_type/type/unit/is_diff_metric 等（提交前剔除 FRONT_END_FIELD_KEYS 前端态字段，diff 转 double+is_diff_metric）
- 生产方：saveMetric → releaseCollectorPlugin（两阶段提交）@ 三条编辑器路径：metric-dimension-dialog.tsx / indicator-dimension 工具族 / 采集向导内嵌弹窗
- 主要消费方：后端 metric_plugin；采集配置模块（指标选择与字段形态）；场景视图（collect_<id> 面板字段来源）；监控数据链路（指标入库形态）
- 业务用途：定义插件产出的指标/维度结构，决定采集数据的元数据形态
- 详细流向：见 .module-experts/前端专题/插件管理专家/C4-数据流向与消费.md
