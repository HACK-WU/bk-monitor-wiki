【数据流｜插件定义】
- 实体类型：数据结构（前端提交体，前端侧无持久化）
- 结构：{plugin_id, plugin_display_name, plugin_type, label, bk_biz_id, config_version, info_version, collector_json, config_json, description_md, is_support_remote, is_split_measurement, enable_field_blacklist}（升级/导入场景追加 import_plugin_config）
- 生产方：createCollectorPlugin / editCollectorPlugin（步骤1）、deleteCollectorPlugin、importPluginCollectorPlugin + saveAndReleasePlugin @ bkmonitor/webpack/src/monitor-pc/pages/plugin-manager/（终点 monitor-api/modules/model.js）
- 主要消费方：后端 collector_plugin（MySQL）；采集配置模块（插件选择器 / 对象类型映射 / check_plugin_version）；采集下发链路（经节点管理下发插件包）
- 业务用途：定义采什么指标、用什么采集器、参数是什么的插件元数据
- 详细流向：见 .module-experts/前端专题/插件管理专家/C4-数据流向与消费.md
