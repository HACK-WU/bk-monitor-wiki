【数据流｜采集配置提交体】
- 实体类型：数据结构（前端提交体，前端侧无持久化）
- 结构：{name, bk_biz_id, collect_type, plugin_id, params:{collector,plugin}, target_object_type, target_node_type, target_nodes, remote_collecting_host, label, id?, operation?}
- 生产方：saveCollectConfig / toggleCollectConfigStatus / upgradeCollectPlugin / renameCollectConfig / deleteCollectConfig @ bkmonitor/webpack/src/monitor-pc/pages/collector-config/（接口定义 monitor-api/modules/collecting.js）
- 主要消费方：后端 collecting 模块（MySQL）；下游为采集下发链路（bkmonitorbeat）、采集列表/详情回读、告警策略（关联策略可级联删除）、场景视图（collect_<id> 数据源）、导出配置页（export-configuration）
- 业务用途：定义采什么、在哪采、怎么采的采集任务，是监控数据产生的源头配置
- 详细流向：见 .module-experts/前端专题/采集专家/C4-数据流向与消费.md
