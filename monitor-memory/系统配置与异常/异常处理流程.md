异常处理流程：描述错误码继承链（Error → APIError → ESBAPIError/BKAPIError）、DRF 异常层（CustomException/exception_handler）、APIResource 错误上报与蓝鲸平台错误码体系。

## 错误码继承链

- 符号: `Error` → `APIError` → `ESBAPIError` / `BKAPIError`
- 位置: `core/errors/errors.py`、`core/errors/api.py`

- `Error` (base): `code` `name` `_lazy` 国际化
- `APIError`: 系统级错误，带 `system_name`/`url`/`result`
- `BKAPIError` (code 3301001): 蓝鲸规范接口错误

## DRF 异常层

- 符号: `CustomException` (code 3300002)、`exception_handler()`
- 位置: `core/drf_resource/exceptions.py`

- `CustomException` (code 3300002): 业务校验失败专用，继承 `Error`
- `exception_handler()`: DRF 统一序列化异常为 JSON，包含 `code`/`name`/`message`/`data`
- `Error.extra` **平铺到响应顶层**（非嵌套在 data 中），前端可直接读取额外字段

## APIResource 错误

远端调用失败时自动上报 `API_FAILURE` Prometheus 指标。

## 错误码体系

`3` 开头 code 统一表示蓝鲸平台相关错误（3301xxx=外部API，3300xxx=业务逻辑）

## 关键文件

- 位置: `core/errors/errors.py` — 基类链
- 位置: `core/errors/api.py` — BKAPIError
- 位置: `core/drf_resource/exceptions.py` — DRF 异常处理
