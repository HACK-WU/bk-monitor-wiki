## 项目目录架构

模块化 AI 增强监控平台，以 bk-monitor 为核心：

| 目录 | 职责 |
|------|------|
| `ai-docs/` | Agent 文档与 Skills |
| `ai_agent/` | 核心 Agent 逻辑 |
| `bk-monitor-base/` | 共享基础库 |
| `bk-monitor-wiki/` | 内部技术文档与知识库 |
| `bkmonitor/` | Django 单体主工程（api/、apm/、alarm_backends/ 等） |

采用分层架构，将 AI Agent 与传统监控组件融合。
