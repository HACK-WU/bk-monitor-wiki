## BK-Monitor 项目简介

BlueKing Monitor（BK-MONITOR）是蓝鲸 PaaS 官方集成的监控平台，提供可扩展的数据采集、大规模处理、简洁的 UI 和可扩展性。面向多样化的监控场景，旨在提升在线服务的及时性、准确性和智能化水平。

- master 分支不稳定，稳定版本通过 GitHub Releases 发布
- 项目采用模块化 AI 增强架构，在传统 Django 单体中集成 AI Agent 能力
