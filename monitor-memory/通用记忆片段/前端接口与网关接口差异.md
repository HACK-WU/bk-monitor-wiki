### 前端接口 vs 网关接口的差异
| | 前端接口（浏览访问） | 网关接口（API 调用） |
|---|---|---|
| **URL 前缀** | `/ftaweb/issue/...` | `/api/ftaweb/issue/...` |
| **ViewSet** | `fta_web/issue/views.py` 中的 `BaseViewSet` 子类（`IssueViewSet`） | `kernel_api/views/v4/` 中的 `ResourceViewSet` |
| **URL注册** | 由 `urls.py` 直接用 DRF Router 注册 | 由 `ResourceRouter.register_module()` 自动扫描注册 |
| **用途** | 前端用户/浏览器直接访问 | 给网关平台/后端引流过来，或 OpenAI/其他系统调用 |
| **认证** | 走 Session + 用户登录认证 | 走 JWT / Token / API Token 认证 |
| **路由组织** | 各模块自己管理 | 统一 `kernel_api/urls.py` 管理 V2/V3/V4 版本 |

- **前端路由示例**: `/ftaweb/issue/` → `IssueViewSet`（`fta_web/issue/views.py`）
- **网关路由示例**: `/api/ftaweb/issue/search/` → `SearchIssueResource`（`kernel_api/views/v4/issue.py` 通过 `ResourceRoute` 注册）
