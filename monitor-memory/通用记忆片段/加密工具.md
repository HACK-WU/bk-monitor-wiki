### 加密工具（AESCipher）
- **入口**: `bkmonitor/utils/cipher.py`
- **Key 生成**: `key = SHA256(settings.SECRET_KEY)`（固定 32 字节）
- **模式**: AES-CBC（PKCS7 填充）
- **IV 处理**:
  - 不传 IV → 随机生成 16 字节 → `IV + ciphertext` 拼接密文
  - 解密时 → 从密文前 16 字节提取 IV
  - 传固定 IV → 相同明文产生相同密文（不推荐，TAPD token 场景避免）
- **TAPD token 加密场景**: **不传固定 IV**，防止相同 token 密文泄露相等性
- **Usage**:
  ```python
  cipher = AESCipher()  # key=SHA256(settings.SECRET_KEY)
  encrypted = cipher.encrypt("sensitive_data")  # IV 自动拼到密文前
  decrypted = cipher.decrypt(encrypted)  # 自动从前16字节读回 IV
  ```
- **注意**: CBC 模式下，相同明文+相同IV = 相同密文；高安全场景考虑改为随机 IV + 提取前缀模式
