【错误库｜采集配置改名跨业务静默假成功】
- 报错原文片段：无报错——POST rest/v2/collecting_config/rename/ 返回 "success"，但目标配置未变更（跨业务时必然发生，属于静默假成功）
- 现象：跨业务配置改名（详情页名称旁的编辑图标）前端提示成功，刷新后名称未变；业务 2 用户对业务 75 配置 id=1538 改名即命中
- 根因：RenameCollectConfigResource 用 CollectConfigMeta.objects.filter(id=..., bk_biz_id=...).update(name=...)——filter 匹配 0 行时不抛异常、直接返回 success（monitor_web/collecting/resources/backend.py:602-604），前端无从感知失败
- 解法：改为 get(id, bk_biz_id) + DoesNotExist 时抛 CollectConfigNotExist（与其他写接口口径一致）；前端跨业务行隐藏/禁用改名字段
- 验证方式：跨业务调用 rename 观察返回与实际数据（修复后应报 3311003 而非 success）；补单测断言 filter 无命中时抛错
- 关联方案：无
