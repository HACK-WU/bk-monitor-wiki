## 步骤 1：TapdRequiredPermission 权限类

- [ ] `1.1` 创建 `TapdRequiredPermission(BasePermission)` § S06 §4a
  - 从 `request` 获取 `bk_biz_id`（通过 `get_bk_biz_id(request, view)` 或 request context） § S06 §4a
  - 从请求上下文获取 `bk_tenant_id`（`get_bk_tenant_id(request)`） § S06 §4a

- [ ] `1.2` `has_permission()` 实现 § S06 §4a
  ```
  redis_key = f"tapd_uat:{bk_tenant_id}:{request.user.username}"
  token_data = redis_client.get(redis_key)
  
  if not token_data:
      # Token 不存在或已过期
      auth_url = generate_auth_url(bk_biz_id)  # B02 已实现
      raise PermissionDenied(detail={"auth_url": auth_url})
  
  return True
  ```
