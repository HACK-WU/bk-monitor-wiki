# TAPD 授权与建单 — UI 设计稿（文字版）

> 本文档将设计稿图片转为结构化文字描述，覆盖 TAPD 授权流程的全部前端交互页面。
> 页面按用户操作顺序排列，共 4 个关键页面。

---

## 页面总览

| 页面编号 | 页面名称 | 触发场景 | 对应需求 |
|:---:|------|------|------|
| P-01 | 创建单据入口 | 用户点击「创建单据」按钮 | 建单入口 |
| P-02 | 用户态 OAuth 授权页 | 首次使用，未完成用户态授权 | B-05 |
| P-03 | 关联 TAPD 项目列表页 | 用户态授权完成，展示可选项目 | B-02 / S-03 |
| P-04 | 应用态项目授权页 | 用户点击「去关联」，跳转 TAPD 安装授权 | B-06 |

---

## P-01：创建单据入口

### 页面描述

用户在告警处理/事件详情页面点击「创建单据」按钮，弹出下拉菜单，展示可选的单据类型。

### 交互结构

```
┌─────────────────────────────┐
│  📋 创建单据          ▼     │  ← 主按钮（带下拉箭头）
├─────────────────────────────┤
│  📋 TAPD 单据               │  ← 下拉选项 1
│  🐛 GitHub Issue            │  ← 下拉选项 2
├─────────────────────────────┤
│  基础信息                    │  ← 页面下方区域标题
│  ...                        │
└─────────────────────────────┘
```

### 元素说明

| 元素 | 类型 | 说明 |
|------|------|------|
| 创建单据 | 下拉按钮 | 点击展开单据类型列表 |
| TAPD 单据 | 下拉选项 | 点击后进入 TAPD 建单流程（先检查授权状态） |
| GitHub Issue | 下拉选项 | 点击后进入 GitHub Issue 建单流程 |

### 前端逻辑

点击「TAPD 单据」后，前端需调用授权状态检查接口，根据返回状态跳转到对应页面：

```
点击「TAPD 单据」
  → 检查用户态授权状态
    → 未授权 → 显示 P-02（用户态 OAuth 授权页）
    → 已授权 → 检查已关联项目
      → 无已关联项目 → 显示 P-03（关联 TAPD 项目列表页）
      → 有已关联项目 → 直接进入建单表单（本次不做）
```

## P-02：用户态 OAuth 授权页（第三方应用授权）

### 页面描述

用户首次使用 TAPD 建单功能时，弹窗展示「第三方应用授权」页面，引导用户完成 TAPD 用户态 OAuth 授权，以便拉取用户有权限的 TAPD 项目列表。

### 交互结构

```
┌──────────────────────────────────────────────┐
│  📋 TAPD 单据                          ✕    │  ← 弹窗标题栏
├──────────────────────────────────────────────┤
│                                              │
│         [TAPD]  ⇄  [蓝鲸监控]               │  ← 品牌 Logo 展示区
│                                              │
│          第三方应用授权                        │  ← 页面标题
│                                              │
│   [蓝鲸监控] 需要先拉取您在 TAPD 有权限的      │  ← 授权说明（标签+文案）
│   项目列表                                    │
│                                              │
│   如果您授权这个应用，应用将获得以下访问权限：    │  ← 权限说明标题
│                                              │
│   • 读取您有权限的项目列表    • 读取项目角色信息  │  ← 权限列表（2列4项）
│   • 用于发起项目关联授权      • 不直接创建或修改单据│
│                                              │
│  ┌──────────────────┐ ┌──────────────────┐   │
│  │ 同意授权并拉取项目 │ │    取消授权       │   │  ← 操作按钮
│  └──────────────────┘ └──────────────────┘   │
│       主按钮（黑色）        次按钮（白色描边）   │
└──────────────────────────────────────────────┘
```

### 元素说明

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | 标题栏 | 左侧图标 + "TAPD 单据" + 右侧关闭按钮 ✕ |
| 品牌展示区 | 图标组合 | TAPD Logo ⇄ 蓝鲸监控 Logo，双向箭头表示数据互通 |
| 页面标题 | 居中标题 | "第三方应用授权" |
| 授权说明 | 标签+文案 | "蓝鲸监控"标签 + "需要先拉取您在 TAPD 有权限的项目列表" |
| 权限列表 | 2列4项列表 | 明确告知用户授权后应用能做什么/不能做什么 |
| 同意授权并拉取项目 | 主按钮（黑色） | 点击后跳转 TAPD 用户态 OAuth 页面 |
| 取消授权 | 次按钮（白色描边） | 点击后关闭弹窗，不执行授权 |

### 权限清单

| 权限项 | 说明 |
|------|------|
| 读取您有权限的项目列表 | 调用 TAPD API 获取用户可见项目 |
| 读取项目角色信息 | 获取用户在各项目中的角色 |
| 用于发起项目关联授权 | 作为应用态授权的前置步骤 |
| 不直接创建或修改单据 | 明确告知此步骤不涉及建单操作 |

### 前端逻辑

```
点击「同意授权并拉取项目」
  → 调用后端接口 B-05 获取用户态授权 URL
  → window.open() 跳转到 TAPD OAuth 页面
  → 用户在 TAPD 完成授权
  → TAPD 回调后端 B-01
  → 后端换 token 并存 Redis
  → 前端收到授权成功响应
  → 切换到 P-03（关联 TAPD 项目列表页）
```

### 元素说明

| 元素 | 类型 | 说明 |
|------|------|------|
| 弹窗标题 | 标题栏 | 同 P-02，左侧图标 + "TAPD 单据" + 关闭按钮 |
| 引导区块 | 高亮卡片 | 蓝色/浅色背景，说明"关联 TAPD 项目"目的和操作引导 |
| 项目卡片 | 列表项 | 每行一个项目，包含：项目名称、状态说明、操作按钮 |
| 项目名称 | 加粗文本 | TAPD 项目名称，如"IEG-登录服务" |
| 状态说明 | 灰色小字 | "用户态授权已拉取 · 需完成蓝鲸监控关联项目授权" |
| 去关联 | 操作按钮 | 蓝色描边按钮，点击后跳转 P-04（应用态授权页） |
| 取消 | 次按钮 | 关闭弹窗 |
| 重置演示状态 | 次按钮 | 仅用于演示/测试环境，重置授权状态 |

### 项目状态说明

每个项目卡片显示的状态文案根据后端返回的 `is_bound` 字段决定：

| is_bound 状态 | 显示文案 | 操作按钮 | 说明 |
|:---:|------|:---:|------|
| `unbound` | 用户态授权已拉取 · 需完成蓝鲸监控关联项目授权 | [去关联] | 未关联，可发起关联 |
| `importable` | TAPD 侧已安装应用，可一键导入 | [一键导入] | TAPD 已装应用，本地无 binding |
| `bound` | 已关联 | [查看]（或无按钮） | 双向一致，已完成关联 |
| `stale` | TAPD 侧已解绑，需重新关联 | [重新关联] | 本地有 binding 但 TAPD 侧已解绑 |

> 注：设计稿截图中仅展示了 `unbound` 状态，其余状态为评审文档补充的完整四态。

### 前端逻辑

```
页面加载
  → 调用后端接口 B-02 获取用户 TAPD 项目列表
  → 同时调用 B-04 获取已关联项目列表
  → 合并数据，计算每个项目的 is_bound 状态
  → 渲染项目卡片列表

点击「去关联」
  → 调用后端接口 B-06 获取应用态授权 URL（携带 cb 回调地址 + signed_state）
  → window.open() 跳转到 TAPD 应用安装授权页面（P-04）
  → 用户在 TAPD 完成授权
  → TAPD 回调后端 B-03（cb 参数）
  → 后端写入关联表 + 302 重定向回前端
  → 前端刷新项目列表，关联状态更新
```

## P-04：应用态项目授权页（TAPD 安装授权）

### 页面描述

用户点击「去关联」后，跳转到 TAPD 平台的应用安装授权页面。此页面由 TAPD 渲染，非蓝鲸监控前端控制，此处仅记录其展示内容供前端理解完整流程。

### 交互结构

```
┌──────────────────────────────────────────────────┐
│                                                  │
│         [TAPD]  ⇄  [蓝鲸监控]                    │  ← 品牌 Logo 展示区
│                                                  │
│          第三方应用授权                            │  ← TAPD 平台标题
│                                                  │
│   [蓝鲸监控] 正在请求项目（IEG-登录服务）的         │  ← 授权说明
│   数据授权                                        │
│                                                  │
│   如果您授权这个应用，应用将获得项目的以下访问权限：  │  ← 权限说明
│                                                  │
│   • 读取并写入应用态数据    • 读取缺陷数据          │  ← 权限列表（2列6项）
│   • 写入缺陷数据           • 读取需求数据          │
│   • 写入需求数据           • 读取并写入用户信息数据  │
│                                                  │
│  ┌──────────────────┐ ┌──────────────────┐       │
│  │    同意授权       │ │    取消安装       │       │  ← TAPD 平台按钮
│  └──────────────────┘ └──────────────────┘       │
└──────────────────────────────────────────────────┘
```

### 元素说明（TAPD 平台控制）

| 元素 | 说明 |
|------|------|
| 品牌展示区 | TAPD Logo ⇄ 蓝鲸监控 Logo |
| 页面标题 | "第三方应用授权" |
| 授权说明 | "蓝鲸监控 正在请求项目（{项目名称}）的数据授权" |
| 权限列表 | TAPD 项目级应用权限，共 6 项 |
| 同意授权 | 主按钮，点击后 TAPD 完成安装授权 |
| 取消安装 | 次按钮，取消授权 |

### TAPD 项目级权限清单

| 权限项 | 说明 |
|------|------|
| 读取并写入应用态数据 | 读写 TAPD 应用自定义数据 |
| 读取缺陷数据 | 读取 TAPD 缺陷/Bug 数据 |
| 写入缺陷数据 | 在 TAPD 中创建/修改缺陷 |
| 读取需求数据 | 读取 TAPD 需求数据 |
| 写入需求数据 | 在 TAPD 中创建/修改需求 |
| 读取并写入用户信息数据 | 读写 TAPD 用户信息 |

### 回调流程（后端处理，非前端）

```
用户点击「同意授权」
  → TAPD 完成应用安装授权
  → TAPD 浏览器回调 → 蓝鲸监控后端 B-03（cb=xxx）
  → 后端验证 signed_state 签名
  → 从 TAPD 回调参数提取 workspace_id / workspace_name
  → 通过 app 级 Basic Auth 调用 get_workspace_info 获取项目信息
  → 写入 TapdWorkspaceBinding 表（幂等 upsert）
  → 302 重定向回前端页面（前端刷新后显示已关联状态）
```

## 前后端接口对应关系

| 页面 | 前端操作 | 后端接口 | 说明 |
|------|------|------|------|
| P-01 → P-02 | 进入 TAPD 建单 | 授权状态检查接口 | 判断当前用户/空间的授权状态 |
| P-02 按钮点击 | 同意授权 | B-05 生成用户态授权 URL | 返回 TAPD OAuth 跳转地址 |
| P-02 回调 | OAuth 回调 | B-01 用户态 OAuth 回调 | 换 token 存 Redis |
| P-03 加载 | 获取项目列表 | B-02 获取用户 TAPD 项目列表 | 返回项目列表 + is_bound 状态 |
| P-03 加载 | 获取已关联项目 | B-04 获取已关联项目列表 | 返回当前空间已关联的项目 |
| P-03 按钮点击 | 去关联 | B-06 生成应用态授权 URL | 返回 TAPD 安装授权跳转地址 |
| P-04 回调 | TAPD 回调 | B-03 应用态授权回调 | 写入关联表 + 302 重定向 |

## 设计要点备忘

1. **所有弹窗统一标题栏样式**：左侧 "📋 TAPD 单据" 图标 + 标题，右侧 ✕ 关闭按钮
2. **品牌展示区**：P-02 和 P-04 均有 TAPD ⇄ 蓝鲸监控 Logo 组合，表示双向数据互通
3. **权限透明**：每个授权页面都明确列出授权范围，包括"不做什么"（如 P-02 的"不直接创建或修改单据"）
4. **操作按钮规范**：
   - 主按钮（黑色填充）：确认/同意类操作
   - 次按钮（白色/描边）：取消类操作
5. **P-04 为 TAPD 平台页面**：蓝鲸监控仅控制跳转 URL 和回调处理，页面渲染由 TAPD 控制
6. **重置演示状态按钮**：仅用于演示/测试环境，生产环境不显示
