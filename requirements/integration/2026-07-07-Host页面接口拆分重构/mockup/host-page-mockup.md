## 设计说明

### 1. 页面结构
- **主机监控 / 左侧栏选中【节点】/ 右侧Tab选中【主机列表】**

### 2. 顶部标题栏
1. 直接左侧拆分为：主机监控、进程监控 2个Tab（减少空间消耗）
2. 分享使用、APM 的交互，有定位功能
3. 节点筛选：节点: EDTEST ↔ 主机: 10.0.1.100

### 3. 增加 Tab：主机列表、指标汇聚
1. 原来选中【节点】，看的汇聚的指标视图，放在【指标汇聚】Tab
2. 原来【主机监控器】的【列表】挪到【选中节点】的【主机列表】Tab
3. 默认选中【业务节点】

## 1. 整体布局

页面采用**左侧导航 + 右侧主内容区**的布局。

### 1.1 顶部导航栏
- **左侧**: 蓝鲸监控平台 Logo + 常用菜单
- **中间**: 一级导航（首页、仪表盘、数据探索、告警事件、观测场景、配置、集成）
- **右侧**: 全局搜索（Ctrl+K）、通知、用户（admin）

### 1.2 左侧边栏
- **当前选中**: 主机监控
- **子菜单**: 进程监控、节点（EDTEST）
- **下方区域**: 主机拓扑树

### 1.3 右侧主内容区
- **顶部**: 面包屑导航 + 筛选条件（节点: EDTEST）
- **主体**: 主机列表 + 指标汇聚选项卡

## 2. 主机拓扑树（左侧面板）

### 2.1 搜索框
- **占位符**: 搜索IP / 主机名 / 主机拓扑
- **功能**: 实时过滤主机列表
- **交互说明**:
  - 搜索命中【父节点】时，默认折叠【子内容】，但是可以展开的
  - 目前展开了，导致：我搜索节点后，是看不到里面的IP的

### 2.2 拓扑结构
```
业务（BK-Monitor）
├── 集群（idle_Pool）
│   ├── 10.0.2.100 VM-2-100-tencentos
│   ├── 10.0.2.101 VM-2-101-tencentos
│   ├── 10.0.2.102 VM-3-102-tencentos
│   └── 10.0.2.103 VM-3-103-tencentos
├── 节点（监控平台）
│   ├── k8s-master
│   └── k8s-node
```

### 2.3 交互
- 点击拓扑节点，右侧主机列表过滤显示对应主机
- 支持多选、展开/折叠

### 2.4 拓扑详细设计说明

#### 2.4.1 默认状态
- 默认勾选【隐藏无主机节点】

#### 2.4.2 Icon按钮
- 全部收起按钮
- 刷新按钮

#### 2.4.3 拓扑交互状态
| 状态 | 说明 |
|------|------|
| a. 节点 normal | 鼠标未悬停，显示节点名称和主机数量（如"EDTEST 24"） |
| b. 节点 hover | 鼠标悬停，显示完整信息 |
| c. 节点 click 选中 & 展开 | 点击节点，展开子节点 |
| d. 收起的节点 | 折叠状态，显示小三角图标 |
| e. 节点 normal（主机） | 主机节点正常状态，显示IP和主机名（如"10.0.2.100 VM-2-100-tencentos"） |
| f. 节点 hover（主机） | 主机节点悬停，显示详细信息：IP和主机名 |
| g. 节点 click 选中（主机） | 点击主机节点，右侧列表过滤显示该主机 |

#### 2.4.4 数字显示
- 节点后的数字表示主机数量

## 4. 关键交互流程

### 4.1 主机详情查看
1. 用户在主机列表点击主机名/IP
2. 跳转到主机详情页，包含：
   - 基础信息（IP、主机名、操作系统等）
   - 指标图表（CPU、内存、磁盘、网络）
   - 进程列表
   - 告警事件

### 4.2 进程详情查看
1. 在主机详情页，点击进程标签
2. 跳转到进程详情页，包含：
   - 进程基础信息（PID、端口、启动命令等）
   - 进程指标图表（CPU、内存使用率）
   - 进程日志

5. 选择多个指标进行对比分析

## 5. 前端接口需求（与后端拆分对应）

### 5.1 主机列表页面需要的接口
| 接口用途 | 当前接口 | 后端拆分后接口 |
|----------|----------|----------------|
| 获取主机拓扑树 | `get_topo_tree` | 保持不变 |
| 获取主机列表 | `host_performance`（大聚合） | `search_host_info` + `search_host_metric` |
| 获取主机进程列表 | `get_host_process_list`（字段不足） | `get_host_process_list`（补全字段） |
| 获取主机面板配置 | `get_scene_view`（包含host+process） | `get_host_views_panels` + `get_host_metric_group_panel_order` |
| 获取进程面板配置 | `get_scene_view`（包含host+process） | `get_process_views_panels` + `get_process_metric_group_panel_order` |

### 5.2 数据流示意
```
前端页面
  ↓
调用接口获取数据
  ↓
渲染主机列表 + 统计卡片 + 拓扑树
  ↓
用户点击主机 → 调用主机详情接口
  ↓
用户点击进程 → 调用进程详情接口
```

## 6. 设计要点总结

1. **左侧拓扑树可折叠**: 支持展开/折叠操作
2. **分页加载**: 支持分页加载主机列表和进程列表
3. **状态可视化**: 通过状态指示灯展示主机状态
4. **批量操作**: 支持多选主机进行批量操作（如指标对比、批量告警）
5. **搜索与筛选**: 支持多维度搜索和筛选，快速定位目标主机
6. **指标汇聚**: 提供系统指标的可视化展示，支持多种汇聚方法和对比分析
