# Memory MCP 服务反馈规则

## 状态说明

当前 Memory MCP 服务（memory-lancedb-mcp）仍处于**测试验证阶段**，尚未完全稳定。

## 反馈要求

### 必须反馈的情况

1. **功能异常**
   - 语义搜索结果不准确或不相关
   - 向量化存储失败或超时
   - scope 权限问题
   - 命令执行报错

2. **效率问题**
   - 搜索响应时间过长（>5秒）
   - 批量导入耗时异常
   - 重复查询结果不一致

3. **使用体验**
   - 关键词匹配不理想
   - 分组结构不符合预期
   - 摘要质量需要改进

### 反馈方式

使用过程中发现问题时，应：

1. **及时汇报**：发现问题后立即说明，不要等到任务结束
2. **提供依据**：说明具体的操作、期望结果、实际结果
3. **记录上下文**：保留相关的命令输出、错误信息

### 反馈示例

```
问题：mem search "告警引擎" 返回结果不相关
操作：执行 mem search "告警引擎" --scope monitor
期望：返回告警引擎核心模块相关文档
实际：返回了不相关的测试数据
```

## 优化建议

如果发现可以优化的地方，请随时提出：

- 搜索算法改进
- 关键词提取策略
- 分组结构调整
- 配置参数优化

## 目标

通过持续反馈，帮助 Memory MCP 服务尽快达到生产可用状态。
