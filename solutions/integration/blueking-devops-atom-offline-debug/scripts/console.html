蓝盾插件离线联调控制台 本地模拟器

按 task.json 定义动态渲染表单 → 生成 input.json → 真跑插件 → 回显日志；并把 selector 选项接口与监控接口 mock 掉。
这不是蓝盾前端。它按官方文档复刻表单渲染与数据契约，用于在没有插件工作台权限时自证「配置是否合法 / mock 接口是否符合 CORS 规范 / 插件与平台的数据契约是否对齐」。 它无法证明蓝盾真实前端的 origin、附加请求头（如 x-devops-project-id）、渲染细节与 URL 白名单校验——这些必须在拿到权限后回平台实测。
